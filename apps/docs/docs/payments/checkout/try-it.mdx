## What just happened

The customer's approval became a transaction. The first recorded output is its
anatomy:

- **`Paid order-1001: 1 USDC (1000000 base units)`.** USDC has 6 decimals, so
  1 USDC is 1,000,000 base units. Code always works in base units.
- **`Reference`.** A fresh address created for this order and attached to the
  transfer. The shop uses it to tell which order a payment is for.
- **`Signature`.** The transaction's ID. The checkout hands it to the shop's
  server, which looks the payment up by it.
- **`Fee: 5000 lamports`.** The network fee, 0.000005 SOL. In this example the
  customer's wallet pays it. [Go live](/docs/payments/checkout/go-live) shows
  how your app can pay it instead.

The second output is the shop's check. The same transaction passes when the
shop expects 1 USDC and fails with `amount mismatch` when it expects 2 USDC.
The shop trusts the network's record, not the customer's word.
