Pay-per-call lets a client pay for one HTTP request at a time. The server
answers an unpaid request with `402 Payment Required` and a price. The client
signs a stablecoin payment, retries the request with it, and gets the data. There
is no signup, API key or invoice, so the same flow works for people's apps and
for AI agents that pay for the tools they call.

Each payment is a Solana

## Protocols

Two protocols settle these payments on Solana. Both use the `402` status code,
with different headers and payment models.
