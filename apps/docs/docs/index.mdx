## What are you building?

<Columns cols={3}>
<Card title="Accept dollar payments that settle in seconds" icon="credit-card" href="/docs/payments/checkout">
Take USDC (digital dollars) from anyone with a wallet. Payments confirm in under a second for a fraction of a cent, with no percentage fee and no chargebacks.

See it work in about 5 minutes. **Build a checkout →**
</Card>
<Card title="Charge a few cents per API call" icon="webhook" href="/docs/payments/paywall-api">
Price each request at a cent or less. Apps and AI agents pay inline over HTTP, with no signup, API key or invoice.

See it work in about 5 minutes. **Paywall an endpoint →**
</Card>
<Card title="Issue a tokenized asset with compliance controls" icon="layers" href="/docs/assets/issue-asset">
A fund share, a loyalty point or a real-world asset, with an approval list and a pause switch that the network enforces on every transfer.

See it work in about 10 minutes. **Issue an asset →**
</Card>
</Columns>
