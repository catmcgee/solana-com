Annulla l'iscrizione alle notifiche di modifica dell'account

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "accountUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  id della sottoscrizione dell'account da cancellare
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  messaggio di successo dell'annullamento dell'iscrizione
</ResponseField>
