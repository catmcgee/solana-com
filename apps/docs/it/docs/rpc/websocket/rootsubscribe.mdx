sidebarTitle: rootSubscribe

Iscriviti per ricevere notifiche ogni volta che viene impostata una nuova root
dal validator.

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Nessuno**

### Result

<ResponseField name="result" type="integer">
  id di sottoscrizione (necessario per annullare l'iscrizione)
</ResponseField>

#### Formato della notifica:

Il risultato è il numero dell'ultimo slot root.

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
