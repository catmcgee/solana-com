Annulla l'iscrizione alle notifiche degli slot

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="integer" required>
  id di sottoscrizione da cancellare
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  messaggio di successo per l'annullamento dell'iscrizione
</ResponseField>
