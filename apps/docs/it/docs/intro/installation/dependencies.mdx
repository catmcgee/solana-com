Una guida per configurare il tuo ambiente di sviluppo Solana locale. Scopri come
installare Rust, la CLI di Solana e Anchor Framework su Windows (WSL), Linux e
Mac. Usa questa guida se preferisci installare ogni dipendenza individualmente,
o se l'[installazione rapida](/docs/intro/installation/) fallisce per qualsiasi
motivo.

### Prerequisiti

<AccordionGroup>
<Accordion title="Windows">

Per sviluppare programmi Solana su Windows **devi** usare
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). Dopo aver installato WSL, tutte le altre dipendenze verranno installate
tramite il terminale Linux.

Per installare WSL, esegui il seguente comando in Windows PowerShell:

```bash Terminal
wsl --install
```

Il processo di installazione ti chiederà di creare un account utente
predefinito.

<Frame caption="Installazione WSL">
  ![Installazione WSL](/docs-assets/assets/docs/intro/installation/wsl-install.png)
</Frame>

Per impostazione predefinita, WSL installa Ubuntu. Puoi aprire un terminale
Linux cercando "Ubuntu" nella barra di ricerca.

<Frame caption="WSL Ubuntu">
  ![WSL Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-search.png)
</Frame>

Se il tuo terminale Ubuntu appare come nell'immagine qui sotto, potresti
riscontrare un problema in cui `ctrl + v` (scorciatoia da tastiera per
incollare) non funziona nel terminale.

<Frame caption="Terminale Ubuntu">
  ![Terminale Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)
</Frame>

Se riscontri questo problema, apri Windows Terminal cercando "Terminal" nella
barra di ricerca.

<Frame caption="Windows Terminal">
  ![Windows Terminal](/docs-assets/assets/docs/intro/installation/wsl-windows-terminal.png)
</Frame>

Successivamente, chiudi Windows Terminal e riapri un terminale Linux cercando
Ubuntu di nuovo. Il terminale dovrebbe ora apparire come nell'immagine qui
sotto, dove `ctrl + v` (scorciatoia da tastiera per incollare) funziona.

<Frame caption="Terminale Ubuntu">
  ![Terminale Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)
</Frame>

Se usi VS Code,
l'[estensione WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial) ti
consente di usare WSL e VS Code insieme.

<Frame caption="Configurazione WSL in VS Code">
  ![Configurazione WSL in VS Code](/docs-assets/assets/docs/intro/installation/wsl-vscode.png)
</Frame>

Vedrai quanto segue nella barra di stato di VS Code:

<Frame caption="WSL: Ubuntu">
  ![WSL: Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-vscode-ubuntu.png)
</Frame>

Una volta configurato WSL, sei pronto per:

- Completare l'[installazione rapida](/docs/intro/installation) utilizzando il
  terminale Ubuntu (Linux)
- Installare [Rust](#install-rust), la [Solana CLI](#install-solana-cli) e la
  [Anchor CLI](#install-anchor-cli) individualmente, come descritto di seguito

</Accordion>
<Accordion title="Linux">

<Tabs>
<Tab title=".deb">
Se utilizzi Debian o alternative derivate da Debian come Ubuntu o Mint, segui i passaggi seguenti:

1. Aggiorna gli elenchi dei pacchetti per assicurarti che tutti i pacchetti
   siano aggiornati:

```bash Terminal
sudo apt-get update
```

2. Installa le seguenti dipendenze:

```bash Terminal
sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Note>
Se riscontri il seguente errore durante l'installazione di `protobuf-compiler`, assicurati
di eseguire prima `sudo apt-get update`

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Note>

  </Tab>

    <Tab title=".rpm">
    Per i derivati RHEL come Fedora o Red Hat Linux, segui i seguenti passaggi.

Aggiorna gli elenchi dei pacchetti per ottenere le versioni più recenti dei
pacchetti eseguendo il comando.

    ```bash Terminal
    sudo dnf upgrade --refresh
    ```

    Successivamente, installa le seguenti dipendenze:

    ```bash Terminal
    sudo dnf group install c-development development-tools \
    && sudo dnf install pkg-config openssl-devel
    ```

  </Tab>
</Tabs>

</Accordion>
</AccordionGroup>

<Steps titleSize="h3">
<Step title="Installa Rust">

Gli sviluppatori creano programmi Solana utilizzando il linguaggio di
programmazione [Rust](https://www.rust-lang.org/).

1. Installa Rust utilizzando [rustup](https://www.rust-lang.org/tools/install)
   inserendo il seguente comando nel tuo terminale:

```bash Terminal
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

Dopo un'installazione riuscita vedrai il seguente messaggio:

<AccordionGroup>
<Accordion title="Messaggio di installazione Rust riuscita">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</AccordionGroup>

2. Ricarica la variabile d'ambiente PATH per includere la directory bin di
   [Cargo](https://github.com/rust-lang/cargo):

```bash Terminal
. "$HOME/.cargo/env"
```

3. Verifica che l'installazione sia andata a buon fine.

```bash Terminal
rustc --version
```

Vedrai un output simile al seguente:

```
rustc 1.86.0 (05f9846f8 2025-03-31)
```

</Step>
<Step title="Installa Solana CLI">

La Solana CLI fornisce tutti gli strumenti necessari per costruire e distribuire
programmi Solana.

1. Installa la suite di strumenti Solana CLI utilizzando il comando di
   installazione ufficiale:

```bash Terminal
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Note>
  Puoi sostituire `stable` con il tag di release corrispondente alla versione
  software della release desiderata (ad es. `v2.0.3`), oppure utilizzare uno dei
  tre nomi di canale simbolici: `stable`, `beta`, o `edge`.
</Note>

2. Aggiungi una variabile d'ambiente PATH

Una prima installazione della Solana CLI potrebbe richiederti di aggiungere una
variabile d'ambiente `PATH`. Per farlo, chiudi e riapri il tuo terminale oppure
esegui il seguente comando nella tua shell:

```
export PATH="/Users/test/.local/share/solana/install/active_release/bin:$PATH"
```

3. Aggiorna la tua variabile d'ambiente PATH

<Tabs>
<Tab title="Windows & Linux">

Se stai utilizzando **Linux** o **WSL**, devi aggiungere il binario della Solana
CLI al tuo PATH in modo che il comando sia disponibile nel tuo terminale. Per
farlo, segui i passaggi seguenti:

**a.** Verifica quale shell stai utilizzando:

```bash Terminal
echo $SHELL
```

- Se l'output contiene `/bash`, usa `.bashrc`.
- Se l'output contiene `/zsh`, usa `.zshrc`.

**b.** Esegui il comando appropriato, in base alla tua shell.

Per Bash (`bashrc`):

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

Per Zsh (`zshrc`):

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

</Tab>
<Tab title="Mac">

Se usi un Mac con `zsh`, l'esecuzione del comando `export PATH` predefinito
registrato dall'installazione non persiste una volta chiuso il terminale.
Invece, aggiungi il PATH al file di configurazione della tua shell eseguendo il
seguente comando:

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.zshrc
```

<Note>
  I passaggi precedenti non si applicano agli utenti `bash`, poiché le modifiche
  alla variabile PATH persisteranno per impostazione predefinita.
</Note>

</Tab>
</Tabs>

4. Riavvia il terminale o esegui il seguente comando per aggiornare la sessione
   del terminale:

```bash Terminal
source ~/.bashrc # If using Bash
source ~/.zshrc # If using Zsh
```

5. Verifica che l'installazione sia riuscita controllando la versione della CLI
   di Solana:

```bash Terminal
solana --version
```

Vedrai un output simile al seguente:

```
solana-cli 2.2.12 (src:0315eb6a; feat:1522022101, client:Agave)
```

<Note>

Puoi visualizzare tutte le versioni disponibili sul
[repository Github di Agave](https://github.com/anza-xyz/agave/releases). Agave
è il client validator di [Anza](https://www.anza.xyz/), precedentemente noto
come client validator di Solana Labs.

</Note>

5. Aggiorna la CLI di Solana all'ultima versione, se necessario _(Opzionale)_

```bash Terminal
agave-install update
```

</Step>
<Step title="Installa la CLI di Anchor">

[Anchor](https://www.anchor-lang.com/) è un framework per lo sviluppo di
programmi Solana. Il framework Anchor sfrutta le macro Rust per semplificare il
processo di scrittura dei programmi Solana.

#### Prerequisiti

Il file di test predefinito del progetto Anchor (TypeScript) creato con il
comando `anchor init` richiede Node.js e Yarn. (Il template di test Rust
è disponibile utilizzando `anchor init --test-template rust`)

<AccordionGroup>
<Accordion title="Installazione di Node">

1. Installa Node utilizzando
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm) eseguendo il
   seguente comando:

```bash Terminal
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/master/install.sh | bash
```

2. Riavvia il terminale e conferma che il comando `nvm` venga eseguito
   correttamente:

```bash Terminal
command -v nvm
```

3. Usa `nvm` per installare Node:

```bash Terminal
nvm install node
```

4. Verifica che l'installazione sia riuscita controllando la versione di Node:

```bash Terminal
node --version
```

Vedrai un output simile al seguente:

```
v23.7.0
```

</Accordion>
<Accordion title="Installazione di Yarn">

1. Installa Yarn:

```bash Terminal
npm install --global yarn
```

2. Verifica che l'installazione sia riuscita controllando la versione di Yarn:

```bash Terminal
yarn --version
```

Vedrai il seguente output:

```
1.22.1
```

</Accordion>
</AccordionGroup>

#### Installazione

Puoi installare la CLI e gli strumenti di Anchor in due modi:

- Anchor Version Manager (AVM) — metodo di installazione consigliato
- Senza AVM — installa direttamente da GitHub

<Tabs>
<Tab title="AVM">

Anchor Version Manager (AVM) ti consente di installare e gestire diverse
versioni di Anchor sul tuo sistema e di aggiornare facilmente le versioni di
Anchor in futuro. Per installare Anchor utilizzando AVM, segui i passaggi
seguenti:

1. Installa AVM con il seguente comando:

```bash Terminal
curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  Conferma che AVM sia stato installato correttamente:

```bash Terminal
avm --version
```

3. Installa la CLI di Anchor utilizzando AVM:

Per installare l'ultima versione:

```bash Terminal
avm install latest
avm use latest
```

Per installare una versione specifica, specifica il numero di versione:

```bash Terminal
avm install 0.30.1
avm use 0.30.1
```

<Warning>

Durante l'installazione di Anchor CLI su Linux o WSL, potresti incontrare questo errore:

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

Se visualizzi questo messaggio di errore, segui i passaggi seguenti:

1. Installa le dipendenze elencate nella sezione
   [Linux](/docs/intro/installation/dependencies) in cima a questa
   pagina.
2. Riprova a installare Anchor CLI.

</Warning>

4. Verifica che l'installazione sia riuscita, controllando la versione della CLI
   di Anchor:

```bash Terminal
anchor --version
```

Vedrai un output simile al seguente:

```
anchor-cli 0.31.1
```

<Info>

Non dimenticare di eseguire il comando `avm use` per dichiarare la
versione della CLI di Anchor da eseguire sul tuo sistema.

- Se hai installato la versione `latest`, esegui `avm use latest`.
- Se hai installato la versione `0.30.1`, esegui `avm use 0.30.1`.

</Info>

</Tab>

<Tab title="Without AVM">

1. Installa una versione specifica di Anchor CLI con il seguente comando:

```bash Terminal
cargo install --git https://github.com/solana-foundation/anchor --tag v0.30.1 anchor-cli
```

2. Verifica che l'installazione sia riuscita, controllando la versione di Anchor
   CLI:

```bash Terminal
anchor --version
```

Vedrai un output simile al seguente:

```
anchor-cli 0.31.1
```

</Tab>
</Tabs>

surfpool --version
