Metodi per manipolare il tempo e accedere alle variabili di sistema. Ogni getter di sysvar ha un setter corrispondente; le struct sono semplici mirror Go del sorgente Solana.

## Manipolazione del Clock

### WarpToSlot

```go
func (s *LiteSVM) WarpToSlot(slot uint64) error
```

Avanza il clock interno a uno slot specifico.

```go
before, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("current slot: %d", before.Slot)

if err := svm.WarpToSlot(10_000_000); err != nil {
    t.Fatal(err)
}

after, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("new slot:     %d", after.Slot)
```

### Clock

```go
// sysvar is github.com/gagliardetto/solana-go/sysvar
type Clock struct {
    Slot                uint64
    EpochStartTimestamp int64
    Epoch               uint64
    LeaderScheduleEpoch uint64
    UnixTimestamp       int64
}

func (s *LiteSVM) Clock() (*sysvar.Clock, error)
```

Legge la sysvar Clock.

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("slot=%d epoch=%d unix=%d", c.Slot, c.Epoch, c.UnixTimestamp)
```

### SetClock

```go
func (s *LiteSVM) SetClock(c *sysvar.Clock) error
```

Sovrascrive la sysvar Clock. Leggila, modifica i campi e riscrivila quando hai bisogno di controllare `Epoch` o `UnixTimestamp` (che `WarpToSlot` non aggiorna).

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
c.Slot = 1_000
c.Epoch = 10
c.UnixTimestamp = 1_735_689_600
if err := svm.SetClock(c); err != nil {
    t.Fatal(err)
}
```

<Info>
  `WarpToSlot` aggiorna solo `Slot`. Usa `SetClock` quando il tuo programma legge
  `Epoch` o `UnixTimestamp` dalla sysvar Clock.
</Info>

## Epoch Rewards

```go
type EpochRewards struct {
    DistributionStartingBlockHeight uint64
    NumPartitions                   uint64
    ParentBlockhash                 solana.Hash
    TotalPoints                     bin.Uint128 // u128 total_points
    TotalRewards                    uint64
    DistributedRewards              uint64
    Active                          bool
}

func (s *LiteSVM) EpochRewards() (*sysvar.EpochRewards, error)
func (s *LiteSVM) SetEpochRewards(e *sysvar.EpochRewards) error
```

`total_points` è un `u128` lato Solana; `litesvm-go` espone entrambe le metà
esplicitamente in modo che i chiamanti Go non abbiano bisogno di una libreria u128. Per i valori che rientrano in 64 bit, `TotalPointsHi` è `0` e `TotalPointsLo` è il valore.

### SlotHistory

`SlotHistory` è un bitvec di ~128 KB; `litesvm-go` lo espone come handle anziché come slice.

```go
sh := sysvar.NewSlotHistory()

sh.Add(42)

switch sh.Check(42) {
case sysvar.SlotHistoryFound:
    // ...
case sysvar.SlotHistoryNotFound:
    // ...
case sysvar.SlotHistoryTooOld:
    // ...
case sysvar.SlotHistoryFuture:
    // ...
}

if err := svm.SetSlotHistory(sh); err != nil {
    t.Fatal(err)
}
```

| Metodo                                           | Descrizione                                |
| ------------------------------------------------ | ------------------------------------------ |
| `litesvm.NewSlotHistory() (*SlotHistory, error)` | Handle vuoto                               |
| `sh.Add(slot uint64)`                            | Registra uno slot                              |
| `sh.Check(slot uint64) SlotHistoryCheck`         | `Future` / `TooOld` / `Found` / `NotFound` |
| `sh.Oldest() uint64`                             | Slot più vecchio tracciato                        |
| `sh.Newest() uint64`                             | Slot più recente tracciato                        |
| `sh.NextSlot() uint64`                           | Prossimo slot da registrare                        |
| `sh.SetNextSlot(slot uint64) error`              | Sovrascrive il marcatore del prossimo slot              |
| `sh.Close()`                                     | Rilascia l'handle                         |
| `svm.SlotHistory() (*SlotHistory, error)`        | Legge in un nuovo handle                   |
| `svm.SetSlotHistory(*SlotHistory) error`         | Installa sulla SVM                         |

## Test della Logica Dipendente dal Tempo

Usa `WarpToSlot` per l'avanzamento semplice basato su slot, `SetClock` per il controllo completo:

```go
func TestTimeLockedVault(t *testing.T) {
    svm, err := litesvm.New()
    if err != nil {
        t.Fatal(err)
    }
    defer svm.Close()

    const unlockSlot = uint64(10_000)

    // Setup: create the time-locked account ...

    // Test 1: Try to withdraw before unlock (should fail)
    before, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("current slot: %d", before.Slot)
    // ... attempt withdrawal, expect failure ...

    // Warp time forward past unlock slot
    if err := svm.WarpToSlot(unlockSlot + 1); err != nil {
        t.Fatal(err)
    }

    // Test 2: Try to withdraw after unlock (should succeed)
    after, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("new slot: %d", after.Slot)
    // ... attempt withdrawal, expect success ...
}
```
