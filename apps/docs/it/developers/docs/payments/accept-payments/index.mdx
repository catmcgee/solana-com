Accetta pagamenti su Solana utilizzando componenti drop-in, il protocollo Solana
Pay o integrazione RPC diretta.

## Convenzione per l'indirizzo di ricezione

Su Solana, **condividi il tuo indirizzo wallet, non il tuo token account**. È
tipico che il mittente derivi l'appropriato
[associated token account (ATA)](/developers/docs/payments/how-payments-work#token-accounts)
per qualsiasi token stia inviando (vedi
[Inviare pagamenti](/developers/docs/payments/send-payments) per maggiori dettagli).

**Esempio:** Condividi `7EcDhS...` (il tuo wallet), non `9xKpQ...` (il tuo token
account USDC).

<Note>
  Per punti vendita ed e-commerce, vedi [Solana
  Pay](/developers/docs/tools/solana-pay) per codici QR e URL di
  pagamento, o [Payment Button](/developers/docs/tools/commerce-kit/quickstart/payment-button)
  per componenti React drop-in.
</Note>

## Opzioni di integrazione

| Approccio                                                       | Ideale per                                | Complessità |
| --------------------------------------------------------------- | ----------------------------------------- | ----------- |
| [Payment Button](/developers/docs/tools/commerce-kit/quickstart/payment-button) | App React, integrazione rapida            | Bassa       |
| [Solana Pay](/developers/docs/tools/solana-pay)         | Codici QR, link di pagamento, POS         | Media       |
| [Direct RPC](/developers/docs/payments/interacting-with-solana)            | Flussi personalizzati, controllo completo | Più alta    |

## Verifica

Dopo aver ricevuto un pagamento, verifica che sia arrivato utilizzando gli
[strumenti di verifica](/developers/docs/payments/accept-payments/verification-tools). Per
applicazioni ad alto volume, vedi
[Indexing](/developers/docs/payments/accept-payments/indexing) per il monitoraggio delle
transazioni a livello di produzione.
