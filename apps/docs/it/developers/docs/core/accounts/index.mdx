Un account è l'unità dati fondamentale di Solana per memorizzare lo stato. La
rete memorizza tutto lo stato in un archivio chiave-valore dove ogni chiave è un
indirizzo di 32 byte e ogni valore è un account.

## Fatti chiave

- **Struttura**: Ogni account ha gli stessi
  [cinque campi](/developers/docs/core/accounts/account-structure): lamport, data, owner,
  executable, rent_epoch.
- **Indirizzo**: Ogni account è identificato da un indirizzo univoco di 32 byte
  (una chiave pubblica Ed25519 o un [PDA](/developers/docs/core/pda)).
- **Proprietà**: Solo il programma proprietario dell'account può modificare i
  suoi dati o addebitare lamport. Qualsiasi programma può accreditare lamport a
  qualsiasi account scrivibile.
- **Archiviazione dell'account**: ogni account deve mantenere un saldo minimo in lamport rimborsabile,
  proporzionale alla dimensione dei dati, per rimanere onchain.

## Limiti

| Limite                             | Valore                                                       | Fonte                                                                                                                        |
| --------------------------------- | ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Dimensione massima dati account             | 10 MiB (10.485.760 byte)                                   | [`MAX_ACCOUNT_DATA_LEN`](https://github.com/anza-xyz/agave/blob/v3.1.8/transaction-context/src/lib.rs#L34)                    |
| Crescita massima dati per istruzione   | 10 KiB (10.240 byte)                                       | [`MAX_PERMITTED_DATA_INCREASE`](https://github.com/anza-xyz/solana-sdk/blob/clock%40v2.2.3/account-info/src/lib.rs#L17)       |
| Crescita massima dati per transazione   | 20 MiB (20.971.520 byte)                                   | [`MAX_ACCOUNT_DATA_GROWTH_PER_TRANSACTION`](https://github.com/anza-xyz/agave/blob/v3.1.8/transaction-context/src/lib.rs#L38) |
| Overhead di archiviazione base account     | 64 byte per account                                        | [`TRANSACTION_ACCOUNT_BASE_SIZE`](https://github.com/anza-xyz/agave/blob/v3.1.8/svm/src/account_loader.rs#L45)                |
| Dimensione indirizzo                      | 32 byte (chiave pubblica Ed25519)                               | --                                                                                                                            |
| Saldo minimo di archiviazione (formula) | (account_size + 128) \* 3.480 lamport/byte-anno \* 2 anni | [`minimum_balance()`](https://github.com/anza-xyz/solana-sdk/blob/clock%40v2.2.3/rent/src/lib.rs#L93)                         |
