Sottoscrivi per ricevere notifiche ogni volta che uno slot viene elaborato dal
validator

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Nessuno**

### Result

<ResponseField name="result" type="integer">
  Id di sottoscrizione (necessario per annullare la sottoscrizione)
</ResponseField>

#### Formato della notifica:

La notifica sarà un oggetto con i seguenti campi:

- `parent: <u64>` - Lo slot padre
- `root: <u64>` - Lo slot root corrente
- `slot: <u64>` - Il nuovo valore dello slot impostato

Esempio:

```json
{
  "jsonrpc": "2.0",
  "method": "slotNotification",
  "params": {
    "result": {
      "parent": 75,
      "root": 44,
      "slot": 76
    },
    "subscription": 0
  }
}
```
