Annulla l'iscrizione alla notifica di conferma della firma

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "signatureUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  id di sottoscrizione da cancellare
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  messaggio di successo dell'annullamento dell'iscrizione
</ResponseField>
