Annulla l'iscrizione alla registrazione delle transazioni

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "logsUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="integer" required>
  id di sottoscrizione da cancellare
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  messaggio di successo dell'annullamento dell'iscrizione
</ResponseField>
