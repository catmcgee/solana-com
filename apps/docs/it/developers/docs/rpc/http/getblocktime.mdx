Restituisce il tempo di produzione stimato di un blocco.

<Info>
  Ogni validator riporta il proprio tempo UTC al ledger a intervalli regolari,
  aggiungendo periodicamente un timestamp a un Voto per un blocco specifico. Il
  tempo di un blocco richiesto viene calcolato dalla media ponderata in base
  allo stake dei timestamp dei Voti in un insieme di blocchi recenti registrati
  sul ledger.
</Info>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getBlockTime",
      "params": [
        5
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let slotNumber = BigInt(377268280);
  let blockTime = await rpc.getBlockTime(slotNumber).send();

  console.log("Block time:", blockTime);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let slotNumber = 377268280;
  let blockTime = await connection.getBlockTime(slotNumber);

  console.log("Block time:", blockTime);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let slot_number = 377268280;

      let block_time = client.get_block_time(slot_number).await?;

      println!("Blocks time: {:?}", block_time);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="slot number" type="u64" required>
  Numero del blocco, identificato dallo Slot
</ParamField>

## Result

<ResponseField name="result" type="i64" post={["available"]}>
  Tempo di produzione stimato, come timestamp Unix (secondi dall'epoca Unix)
</ResponseField>

<ResponseField name="result" type="object" post={["unavailable"]}>
  Oggetto errore
</ResponseField>
