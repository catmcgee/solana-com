---
title: Metodo RPC getRecentBlockhash
sidebarTitle: getRecentBlockhash
mode: wide
---

Restituisce un hash di blocco recente dal registro e un piano tariffario che può
essere utilizzato per calcolare il costo di invio di una transazione
utilizzandolo.

<Warning>
  **Metodo Deprecato**

  Questo metodo dovrebbe essere rimosso nella versione `solana-core` v2.0. Si
  prega di utilizzare [getLatestBlockhash](/developers/docs/rpc/http/getlatestblockhash)
  invece.
</Warning>
