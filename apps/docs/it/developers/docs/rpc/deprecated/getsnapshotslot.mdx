<Warning>
  **Metodo Deprecato**

  Questo metodo sarà rimosso nella versione `solana-core` v2.0. Si prega di
  utilizzare [getHighestSnapshotSlot](/developers/docs/rpc/http/gethighestsnapshotslot)
  invece.
</Warning>
