sidebarTitle: getFeeCalculatorForBlockhash

---

Restituisce il calcolatore di commissioni associato al blockhash della query, o
`null` se il blockhash è scaduto

<Warning>
  **Metodo Deprecato**

  Questo metodo dovrebbe essere rimosso in `solana-core` v2.0. Si prega di
  utilizzare [isBlockhashValid](/developers/docs/rpc/http/isblockhashvalid) o
  [getFeeForMessage](/developers/docs/rpc/http/getfeeformessage) invece.
</Warning>
