title: Scrivere sulla rete
description:
  Learn how to write data to the Solana network by sending transactions and
  instructions. Follow step-by-step examples to transfer SOL and create a token
  mint using Solana Kit.
---

Nella sezione precedente, hai imparato come
[leggere i dati dalla rete Solana](/developers/docs/intro/quick-start/reading-from-network)
tramite il recupero degli account. Per scrivere dati sulla rete Solana è
necessaria una [transazione](/developers/docs/core/transactions). Una transazione contiene
una o più [istruzioni](/developers/docs/core/instructions), e ogni istruzione invoca un
programma.

I programmi definiscono la logica di business per ogni istruzione. Quando invii
una transazione, il runtime di Solana esegue le istruzioni della transazione in
ordine. Le transazioni sono atomiche: o tutte le istruzioni della transazione
hanno successo, oppure l'intera transazione fallisce.

Gli esempi in questa sezione mostrano come:

1. Trasferire SOL tra account
2. Creare un nuovo token mint

## Trasferire SOL

L'esempio seguente trasferisce SOL da un account a un altro. Solo il programma designato come proprietario di un account può modificare i dati dell'account o sottrarre lamport dal suo saldo. Gli account wallet sono di proprietà del
[System Program](/developers/docs/core/programs/builtin-programs#the-system-program), quindi trasferire SOL tra account wallet richiede un'istruzione che invochi l'istruzione
[transfer](https://github.com/anza-xyz/agave/blob/v2.1.11/programs/system/src/system_processor.rs#L183-L213)
del System Program. L'account sorgente deve anche firmare la transazione.

```ts title="Transfer SOL"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getTransferSolInstruction } from "@solana-program/system";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const receiver = await generateKeyPairSigner();

const transferInstruction = getTransferSolInstruction({
  source: client.payer,
  destination: receiver.address,
  amount: lamports(10_000_000n)
});

const result = await client.sendTransaction([transferInstruction]);

console.log("Transaction Signature:", result.context.signature);

const { value: senderBalance } = await client.rpc
  .getBalance(client.payer.address)
  .send();
const { value: receiverBalance } = await client.rpc
  .getBalance(receiver.address)
  .send();

console.log("Sender Balance:", senderBalance);
console.log("Receiver Balance:", receiverBalance);
```

<Note>
  **`createClient`**

  Crea un client Kit per il validator locale. `generatedPayer()` aggiunge un
  firmatario pagante, `solanaRpc()` aggiunge le funzionalità RPC e di invio delle
  transazioni, `rpcAirdrop()` aggiunge `client.airdrop`, e `airdropPayer()`
  finanzia il pagante con SOL di test.

  **`receiver`**

  Genera un firmatario per l'account che riceve SOL. Il destinatario non deve
  firmare questo trasferimento. Se l'indirizzo del destinatario non ha già un
  account, ricevere SOL crea un account di sistema a quell'indirizzo.

  **`transferInstruction`**

  Costruisci l'istruzione System Program che trasferisce lamport dal pagatore
  client al destinatario.

  **`sendTransaction`**

  Invia l'istruzione come transazione. Il client Kit recupera un blockhash
  recente, imposta il pagatore delle commissioni, firma con i firmatari richiesti,
  invia la transazione e attende la conferma.

  **`balances`**

  Recupera i saldi del mittente e del destinatario dopo che la transazione è
  confermata.
</Note>

## Crea un token

L'esempio seguente crea un nuovo mint token utilizzando il
[Token Extensions Program](/developers/docs/tokens/extensions). Un mint account è l'account
che definisce le impostazioni globali di un token, come decimali, fornitura,
autorità di mint e autorità di blocco.

La creazione di un mint account richiede due istruzioni:

1. Invocare il System Program per creare un nuovo account di proprietà del Token
   Extensions Program.
2. Invocare il Token Extensions Program per inizializzare quell'account come
   mint.

```ts title="Create mint account"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getCreateAccountInstruction } from "@solana-program/system";
import {
  fetchMint,
  getInitializeMintInstruction,
  getMintSize,
  TOKEN_2022_PROGRAM_ADDRESS
} from "@solana-program/token-2022";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const mint = await generateKeyPairSigner();

const space = BigInt(getMintSize());

const rent = await client.rpc.getMinimumBalanceForRentExemption(space).send();

const createAccountInstruction = getCreateAccountInstruction({
  payer: client.payer,
  newAccount: mint,
  space,
  lamports: rent,
  programAddress: TOKEN_2022_PROGRAM_ADDRESS
});

const initializeMintInstruction = getInitializeMintInstruction({
  mint: mint.address,
  decimals: 2,
  mintAuthority: client.payer.address,
  freezeAuthority: client.payer.address,
  tokenProgram: TOKEN_2022_PROGRAM_ADDRESS
});

const result = await client.sendTransaction([
  createAccountInstruction,
  initializeMintInstruction
]);

console.log("Mint Address:", mint.address);
console.log("Transaction Signature:", result.context.signature);

const mintAccount = await fetchMint(client.rpc, mint.address);
console.log("Mint Account:", mintAccount);
```

<Note>
  **`createClient`**

  Crea e finanzia un client Kit per il validator locale. Il pagante finanziato
  copre il rent dell'account e le commissioni di transazione.

  **`mint`**

  Genera un firmatario da utilizzare come indirizzo del nuovo mint account. Il
  firmatario autorizza la creazione di quell'account.

  **`space`**

  Calcola il numero di byte necessari per un mint account senza estensioni.

  **`rent`**

  Calcola i lamport necessari per rendere il mint account esente da rent.

  **`createAccountInstruction`**

  Costruisce l'istruzione del System Program che crea il mint account e lo assegna
  al Token Extensions Program.

  **`initializeMintInstruction`**

  Costruisce l'istruzione del Token Extensions Program che scrive i dati iniziali
  del mint nel nuovo account.

  **`sendTransaction`**

  Invia entrambe le istruzioni come un'unica transazione. L'ordine delle
  istruzioni è importante: l'account deve essere creato prima di poter essere
  inizializzato.

  **`mintAccount`**

  Recupera il mint account dopo la conferma. Il metodo helper legge l'account e
  deserializza il campo dati del mint account nel tipo Mint.
</Note>

    const mintAccount = await fetchMint(client.rpc, mint.address);
    console.log("Mint Account:", mintAccount);
