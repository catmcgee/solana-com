## Obiettivo della lezione

Configura una pipeline di eventi più efficiente in modo che il dispositivo o l'app reagisca all'attività su Solana senza necessità di polling manuale continuo.

## Checkpoint

- Identifica quali eventi webhook sono rilevanti per il tuo flusso.
- Osserva come il servizio ricevente dovrebbe validare ed elaborare gli eventi.
- Decidi cosa deve accadere quando la consegna del webhook fallisce o subisce ritardi.
