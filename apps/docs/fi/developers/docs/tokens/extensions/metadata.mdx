## Mitä Metadata Pointer- ja Token Metadata -laajennukset ovat?

Token Extensions Program -ohjelman `MetadataPointer` mint-laajennus
tallentaa kaksi kenttää mintille:

- Valtuutus, joka voi päivittää osoittimen
- Tilin osoite, joka tallentaa tokenin metadatan

Osoitin voi viitata mihin tahansa tiliin, jonka omistaa ohjelma, joka toteuttaa
[token-metadata-rajapinnan](https://github.com/solana-program/token-metadata/tree/main/interface).

Token Extensions Program toteuttaa myös saman rajapinnan suoraan
`TokenMetadata` mint-laajennuksen kautta. `TokenMetadata`-laajennuksella
mint tallentaa tokenin `name`-, `symbol`-, `uri`-,
`update_authority`-kentät ja mukautetun metadatan suoraan mint-tilille.

<Info>
  **Off-chain-metadatan URI**

  `uri`-kenttä osoittaa off-chain JSON-metadataan. Katso
  [Off-chain-metadatan muoto](/developers/docs/tokens/metaplex#off-chain-metadata-format).
</Info>

Nämä kaksi laajennusta ratkaisevat eri ongelmia:

- `MetadataPointer` määrittää tilin, joka tallentaa metadatan.
- `TokenMetadata` tallentaa metadatan suoraan mint-tilille.

<Info>
  **Muuttuvan pituuden laajennus**

  `TokenMetadata` on muuttuvan pituuden TLV-laajennus.
  _rsINLINE_CODE_PLACEHOLDER_662394a59107c294_-,
  _rsINLINE_CODE_PLACEHOLDER_57ad0e221016adef_- ja
  _rsINLINE_CODE_PLACEHOLDER_491037e2b9d5e1ed_-toiminnot voivat muuttaa
  mint-tilin datan kokoa, mutta ne eivät siirrä lisää lamportteja. Mint-tilillä
  täytyy olla riittävästi lamportteja pysyäkseen vuokravapaa tallennettavalle
  metadatalle. Jos metadata kasvaa myöhemmin, lisää lamportteja täytyy siirtää
  mint-tilille ennen kokomuutosta suorittavaa käskyä.
</Info>

## Token-metadatan tallentaminen mint-tilille

Tallentaaksesi metadatan mint-tilille:

1. Laske mint-tilin koko ja tarvittava vuokra mintille, laajennuksille ja
   metadatalle.
2. Luo mint-tili käyttäen `CreateAccount`, alusta `MetadataPointer` ja
   alusta mint käyttäen `InitializeMint`.
3. Alusta `TokenMetadata` mint-tilille ja käytä sitten `UpdateField`
   -toimintoa metadatan lisäämiseen tai päivittämiseen.
4. Käytä `RemoveKey`, `UpdateAuthority` ja `Emit` -toimintoja
   mukautetun metadatan poistamiseen, päivitysvaltuuden muuttamiseen tai
   tyhjentämiseen taikka nykyisen metadatan palauttamiseen transaktion
   paluudatassa.

      authority: client.payer.address,

        updateAuthority: client.payer,

  **Käskyjen järjestys**

  `MetadataPointerInstruction::Initialize` on suoritettava ennen

### Typescript

Alla oleva `Kit`-esimerkki käyttää suoraan generoituja ohjeita. Vanhat esimerkit, jotka käyttävät `@solana/web3.js`-, `@solana/spl-token`- ja `@solana/spl-token-metadata`-kirjastoja, on sisällytetty viitteeksi. Vanhoissa esimerkeissä `maxSupportedTransactionVersion` on rajattu arvoon `0`, koska web3.js v1 ei pysty deserialisoimaan [v1-transaktioita](/developers/docs/core/transactions/versioned-transactions#v1-message-format).
