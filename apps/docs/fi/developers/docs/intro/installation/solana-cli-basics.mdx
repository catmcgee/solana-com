Tämä osio tarjoaa yleisiä komentoja ja esimerkkejä, jotka auttavat sinua
pääsemään alkuun Solana CLI:n käytössä.

## Solana-konfiguraatio

Solana-konfiguraatiosi määrittää seuraavat muuttujat:

- **Asetustiedosto**: Polku asetustiedostoosi
- **RPC URL & Websocket URL**: Solana-klusteri, johon CLI tekee pyynnöt
- **Keypair-polku**: Polku oletusarvoiseen Solana-lompakkoon (keypair), jota
  käytetään transaktiomaksujen maksamiseen ja ohjelmien käyttöönottoon.
  Oletuksena tämä tiedosto on tallennettu sijaintiin `~/.config/solana/id.json`.

Nähdäksesi nykyiset konfiguraatioasetuksesi, syötä seuraava komento
päätteessäsi.

```bash Terminal
solana config get
```

Onnistunut komento palauttaa seuraavankaltaisen tulosteen:

```txt title="Example output"
Config File: /Users/test/.config/solana/cli/config.yml
RPC URL: https://api.mainnet.solana.com
WebSocket URL: wss://api.mainnet.solana.com/ (computed)
Keypair Path: /Users/test/.config/solana/id.json
Commitment: confirmed
```

Voit vaihtaa Solana CLI -klusteria seuraavilla komennoilla:

<Tabs>

<Tab title="Full commands">

```bash Terminal
solana config set --url mainnet-beta
solana config set --url devnet
solana config set --url localhost
solana config set --url testnet
```

</Tab>
<Tab title="Short commands">

```bash Terminal
solana config set -um    # For mainnet
solana config set -ud    # For devnet
solana config set -ul    # For localhost
solana config set -ut    # For testnet
```

</Tab>
</Tabs>

## Luo lompakko

Ennen kuin voit lähettää transaktioita Solana CLI:n avulla, tarvitset Solana-
lompakon, jossa on SOL-varoja.

Luodaksesi keypair-avaimen oletuspolkuun, suorita seuraava komento:

```bash Terminal
solana-keygen new
```

Onnistunut komento palauttaa seuraavankaltaisen tulosteen:

```txt title="Example output"
Generating a new keypair

For added security, enter a BIP39 passphrase

NOTE! This passphrase improves security of the recovery seed phrase NOT the
keypair file itself, which is stored as insecure plain text

BIP39 Passphrase (empty for none):

Wrote new keypair to /Users/test/.config/solana/id.json
===========================================================================
pubkey: 8dBTPrjnkXyuQK3KDt9wrZBfizEZijmmUQXVHpFbVwGT
===========================================================================
Save this seed phrase and your BIP39 passphrase to recover your new keypair:
cream bleak tortoise ocean nasty game gift forget fancy salon mimic amazing
===========================================================================
```

<Info>
  Tämä komento ei korvaa olemassa olevaa tiliä oletussijainnissa, ellet käytä
  `--force` -lippua.
</Info>

Nähdäksesi lompakkosi osoitteen (julkinen avain), suorita:

```bash Terminal
solana address
```

## SOL-pudotus

Pyydä SOL-pudotusta lompakkoosi maksaaksesi transaktioita ja ohjelmien
käyttöönottoja.

1. Aseta klusterisi Devnetiin:

```bash Terminal
solana config set -ud
```

2. Pyydä airdrop Devnet SOL:ia:

```bash Terminal
solana airdrop 2
```

<Note>

Devnet-airdropit rajoittavat pyynnöt 5 SOL:iin per pyyntö. Jos kohtaat
rajoituksia tai virheitä, kokeile käyttää
[Web-faucettia](https://faucet.solana.com) sen sijaan.

</Note>

Tarkistaaksesi lompakkosi SOL-saldon, suorita seuraava komento:

```bash Terminal
solana balance
```
