  Learn how to write data to the Solana network by sending transactions and
  instructions. Follow step-by-step examples to transfer SOL and create a token
  mint using Solana Kit.

Edellisessä osiossa opit, miten
[luetaan dataa Solana-verkosta](/developers/docs/intro/quick-start/reading-from-network)
hakemalla tilejä. Datan kirjoittaminen Solana-verkkoon edellyttää
[transaktiota](/developers/docs/core/transactions). Transaktio sisältää yhden tai useamman
[ohjeen](/developers/docs/core/instructions), ja jokainen ohje kutsuu ohjelmaa.

Ohjelmat määrittelevät liiketoimintalogiikan kullekin ohjeelle. Kun lähetät
transaktion, Solana-ajonaikainen ympäristö suorittaa transaktion ohjeet
järjestyksessä. Transaktiot ovat atomisia. Joko kaikki transaktion ohjeet
onnistuvat, tai koko transaktio epäonnistuu.

Tämän osion esimerkit näyttävät, miten:

1. Siirretään SOL tilien välillä
2. Luodaan uusi token mint

## SOL:n siirtäminen

Alla oleva esimerkki siirtää SOL:ia yhdeltä tililtä toiselle. Vain ohjelman, joka on merkitty tilin omistajaksi, on mahdollista muokata tilin tietoja tai vähentää lamports-yksiköitä sen saldosta. Lompakkotilit ovat [System Program](/developers/docs/core/programs/builtin-programs#the-system-program)in omistamia, joten SOL:in siirtäminen lompakkotilien välillä edellyttää ohjetta, joka kutsuu System Program'in
[transfer](https://github.com/anza-xyz/agave/blob/v2.1.11/programs/system/src/system_processor.rs#L183-L213)
ohjetta. Lähdetilin on myös allekirjoitettava tapahtuma.

```ts title="Transfer SOL"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getTransferSolInstruction } from "@solana-program/system";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const receiver = await generateKeyPairSigner();

const transferInstruction = getTransferSolInstruction({
  source: client.payer,
  destination: receiver.address,
  amount: lamports(10_000_000n)
});

const result = await client.sendTransaction([transferInstruction]);

console.log("Transaction Signature:", result.context.signature);

const { value: senderBalance } = await client.rpc
  .getBalance(client.payer.address)
  .send();
const { value: receiverBalance } = await client.rpc
  .getBalance(receiver.address)
  .send();

console.log("Sender Balance:", senderBalance);
console.log("Receiver Balance:", receiverBalance);
```

<Note>
  **`createClient`**

  Luo Kit-asiakas paikallista validatoria varten. `generatedPayer()` lisää
  maksajan allekirjoittajan, `solanaRpc()` lisää RPC- ja transaktion
  lähetysominaisuudet, `rpcAirdrop()` lisää `client.airdrop`:n, ja
  `airdropPayer()` rahoittaa maksajan testi-SOL:lla.

  **`receiver`**

  Luo allekirjoittaja SOL:n vastaanottavalle tilille. Vastaanottajan ei tarvitse
  allekirjoittaa tätä siirtoa. Jos vastaanottajan osoitteella ei vielä ole tiliä,
  SOL:n vastaanottaminen luo järjestelmätilin kyseiseen osoitteeseen.

  **`transferInstruction`**

  Rakenna System Program -käsky, joka siirtää lamporteja asiakkaan maksajalta
  vastaanottajalle.

  **`sendTransaction`**

  Lähetä käsky tapahtumana. Kit-asiakas hakee viimeisimmän lohkohashin, asettaa
  maksajan, allekirjoittaa tarvittavilla allekirjoittajilla, lähettää tapahtuman
  ja odottaa vahvistusta.

  **`balances`**

  Hae lähettäjän ja vastaanottajan saldot tapahtuman vahvistamisen jälkeen.
</Note>

## Luo token

Alla oleva esimerkki luo uuden token mintin käyttämällä
[Token Extensions Program](/developers/docs/tokens/extensions). mint account on tili, joka
määrittää tokenin globaalit asetukset, kuten desimaalit, tarjonnan, mint
authorityn ja freeze authorityn.

Mint-tilin luominen vaatii kaksi ohjetta:

1. Kutsu System Program luomaan uusi tili, jonka omistaa Token Extensions
   Program.
2. Kutsu Token Extensions Program alustamaan kyseinen tili mintiksi.

```ts title="Create mint account"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getCreateAccountInstruction } from "@solana-program/system";
import {
  fetchMint,
  getInitializeMintInstruction,
  getMintSize,
  TOKEN_2022_PROGRAM_ADDRESS
} from "@solana-program/token-2022";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const mint = await generateKeyPairSigner();

const space = BigInt(getMintSize());

const rent = await client.rpc.getMinimumBalanceForRentExemption(space).send();

const createAccountInstruction = getCreateAccountInstruction({
  payer: client.payer,
  newAccount: mint,
  space,
  lamports: rent,
  programAddress: TOKEN_2022_PROGRAM_ADDRESS
});

const initializeMintInstruction = getInitializeMintInstruction({
  mint: mint.address,
  decimals: 2,
  mintAuthority: client.payer.address,
  freezeAuthority: client.payer.address,
  tokenProgram: TOKEN_2022_PROGRAM_ADDRESS
});

const result = await client.sendTransaction([
  createAccountInstruction,
  initializeMintInstruction
]);

console.log("Mint Address:", mint.address);
console.log("Transaction Signature:", result.context.signature);

const mintAccount = await fetchMint(client.rpc, mint.address);
console.log("Mint Account:", mintAccount);
```

<Note>
  **`createClient`**

  Luo ja rahoita Kit-asiakas paikalliselle validatorille. Rahoitettu maksaja
  maksaa tilin rentin ja transaktiomaksut.

  **`mint`**

  Generoi allekirjoittaja käytettäväksi uuden mint accountin osoitteena.
  Allekirjoittaja valtuuttaa kyseisen tilin luomisen.

  **`space`**

  Laske mint accountin vaatimien tavujen määrä ilman laajennuksia.

  **`rent`**

  Laske lamportit, joita tarvitaan mint accountin tekemiseen rent-vapautetuksi.

  **`createAccountInstruction`**

  Rakenna System Program -ohje, joka luo mint accountin ja määrittää tilin Token
  Extensions Programille.

  **`initializeMintInstruction`**

  Rakenna Token Extensions Program -ohje, joka kirjoittaa alkuperäisen mint-datan
  uuteen tiliin.

  **`sendTransaction`**

  Lähetä molemmat ohjeet yhtenä tapahtumana. Ohjeiden järjestyksellä on
  merkitystä: tili on luotava ennen kuin se voidaan alustaa.

  **`mintAccount`**

  Hae mint account vahvistuksen jälkeen. Apufunktio lukee tilin ja purkaa mint
  account -kentän tiedot Mint-tyypiksi.
</Note>
