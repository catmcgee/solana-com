Palauttaa tietoa nykyisestä tarjonnasta.

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getSupply",
      "params": [
        {
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let supply = await rpc.getSupply().send();

  console.log(supply);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let supply = await connection.getSupply();

  console.log(supply);
  ```
</RequestExample>

## Parameters

<ParamField body="0" type="object">
  Konfiguraatio-objekti, joka sisältää seuraavat kentät:

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      Commitment kuvaa, kuinka viimeistelty lohko on tietyllä ajanhetkellä. Katso
      [Tilan sitoutumisen määrittäminen](/developers/docs/rpc#configuring-state-commitment).
    </ParamField>

    <ParamField body="excludeNonCirculatingAccountsList" type="bool">
      Jätä ei-kiertävien tilien luettelo pois vastauksesta
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="object">
  Tulos on JSON-objekti, joka sisältää:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="circulating" type="u64">
      Liikkeellä oleva tarjonta lamport-yksiköissä
    </ResponseField>

    <ResponseField name="nonCirculating" type="u64">
      Ei-kiertävä tarjonta lamporteissa
    </ResponseField>

    <ResponseField name="nonCirculatingAccounts" type="array">
      Taulukko ei-kiertävien tilien osoitteista merkkijonoina. Jos
      `excludeNonCirculatingAccountsList` on käytössä, palautettu taulukko on tyhjä.
    </ResponseField>

    <ResponseField name="total" type="u64">
      Kokonaistarjonta lamporteissa
    </ResponseField>
  </Expandable>
</ResponseField>
