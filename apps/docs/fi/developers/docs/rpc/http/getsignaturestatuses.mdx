Palauttaa listan allekirjoitusten tilat. Jokaisen allekirjoituksen on oltava
[txid](/developers/docs/references/terminology#transaction-id), eli transaktion ensimmäinen
allekirjoitus.

<Info>
  Ellei `searchTransactionHistory` -määritysparametria ole sisällytetty, tämä
  metodi etsii vain allekirjoitusten viimeaikaista tilavälimuistia, joka
  säilyttää tilat kaikille aktiivisille sloteille sekä `MAX_RECENT_BLOCKHASHES`
  juurrutetuille sloteille.
</Info>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getSignatureStatuses",
      "params": [
        [
          "4cdd1oX7cfVALfr26tP52BZ6cSzrgnNGtYD7BFhm6FFeZV5sPTnRvg6NRn8yC6DbEikXcrNChBM5vVJnTgKhGhVu"
        ],
        {
          "searchTransactionHistory": true
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc, type Signature } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let signatures = [
    "4cdd1oX7cfVALfr26tP52BZ6cSzrgnNGtYD7BFhm6FFeZV5sPTnRvg6NRn8yC6DbEikXcrNChBM5vVJnTgKhGhVu" as unknown as Signature
  ];

  let config = {
    searchTransactionHistory: true
  };

  let signatureStatus = await rpc.getSignatureStatuses(signatures, config).send();

  console.log(signatureStatus);
  ```

  ```ts web3.js
  import {
    Connection,
    clusterApiUrl,
    type SignatureStatusConfig
  } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let signatures = [
    "4cdd1oX7cfVALfr26tP52BZ6cSzrgnNGtYD7BFhm6FFeZV5sPTnRvg6NRn8yC6DbEikXcrNChBM5vVJnTgKhGhVu"
  ];

  let config: SignatureStatusConfig = {
    searchTransactionHistory: true
  };

  let signatureStatus = await connection.getSignatureStatuses(signatures, config);
  console.log(signatureStatus);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::{commitment_config::CommitmentConfig, signature::Signature};
  use std::str::FromStr;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let signatures_str = [
          "4cdd1oX7cfVALfr26tP52BZ6cSzrgnNGtYD7BFhm6FFeZV5sPTnRvg6NRn8yC6DbEikXcrNChBM5vVJnTgKhGhVu",
      ];
      let signatures = signatures_str.map(|sig| Signature::from_str(sig).unwrap());

      let signature_status = client
          .get_signature_statuses_with_history(&signatures)
          .await?;

      println!("{:#?}", signature_status);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="0" type="array" required>
  Taulukko vahvistettavia transaktioallekirjoituksia base-58-koodattuina
  merkkijonoina (enintään 256 kappaletta)
</ParamField>

<ParamField body="1" type="object">
  Määritysobjekti, joka sisältää seuraavat kentät:

  <Expandable title="properties" defaultOpen>
    <ParamField body="searchTransactionHistory" type="bool">
      jos `true` - Solana-solmu etsii allekirjoituksia, joita ei löydy viimeaikaisesta
      tilavälimuistista, sen kirjanpitovälimuistista
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="array">
  Taulukko `RpcResponse<object>` -objekteja, jotka koostuvat joko `null` -arvosta
  tai objektista, joka sisältää seuraavat kentät:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="slot" type="u64">
      Slot, jossa transaktio käsiteltiin
    </ResponseField>

    <ResponseField name="confirmations" type="usize | null">
      Lohkojen määrä allekirjoituksen vahvistuksen jälkeen, `null` jos juurrutettu,
      sekä klusterin superenemmistön viimeistelty
    </ResponseField>

    <ResponseField name="err" type="object | null">
      Virhe jos transaktio epäonnistui, `null` jos transaktio onnistui. Katso
      [TransactionError-määritelmät](https://github.com/anza-xyz/solana-sdk/blob/50dfbd088c51b7229c67d432d8c8801dafaa7904/transaction-error/src/lib.rs#L15)
    </ResponseField>

    <ResponseField name="status" type="object">
      **VANHENTUNUT** Transaktion tila

      - `"Ok": <null>` - Transaktio onnistui
      - `"Err": <ERR>` - Transaktio epäonnistui TransactionError-virheellä
    </ResponseField>

    <ResponseField name="confirmationStatus" type="string | null">
      Transaktion klusterin vahvistustila; Joko `processed`, `confirmed`, tai
      `finalized`. Katso [Sitoutuminen](/developers/docs/rpc/#configuring-state-commitment)
      saadaksesi lisätietoa optimistisesta vahvistuksesta.
    </ResponseField>
  </Expandable>
</ResponseField>
