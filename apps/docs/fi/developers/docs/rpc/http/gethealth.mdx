sidebarTitle: getHealth

Palauttaa solmun nykyisen tilan. Terve solmu on sellainen, joka on enintään
`HEALTH_CHECK_SLOT_DISTANCE` slotia jäljessä klusterin viimeisimmästä
vahvistetusta slotista.

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getHealth"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let health = await rpc.getHealth().send();

  console.log(health);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let health = client.get_health().await?;

      println!("{:#?}", health);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Terve
  {
    "jsonrpc": "2.0",
    "result": "ok",
    "id": 1
  }
  ```

  ```json Epäterve
  {
    "jsonrpc": "2.0",
    "error": {
      "code": -32005,
      "message": "Node is unhealthy",
      "data": { "numSlotsBehind": 42 }
    },
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

None

## Result

<ResponseField name="result" type="string" post={["Terve"]}>
  Jos solmu on terve: "ok"
</ResponseField>

<ResponseField name="result" type="object" post={["Epäterve"]}>
  Jos solmu on epäterve, palautetaan JSON RPC -virheviesti. Virheviestin
  yksityiskohdat ovat **EPÄVAKAITA** ja saattavat muuttua tulevaisuudessa
</ResponseField>
