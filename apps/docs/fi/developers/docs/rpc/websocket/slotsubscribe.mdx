Tilaa ilmoitukset aina kun validator käsittelee slotin

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Ei mitään**

### Result

<ResponseField name="result" type="integer">
  Tilauksen tunnus (tarvitaan tilauksen peruuttamiseen)
</ResponseField>

#### Ilmoitusmuoto:

Ilmoitus on objekti, jossa on seuraavat kentät:

- `parent: <u64>` - Vanhempi slot
- `root: <u64>` - Nykyinen juuri-slot
- `slot: <u64>` - Uusi asetettu slot-arvo

Esimerkki:

```json
{
  "jsonrpc": "2.0",
  "method": "slotNotification",
  "params": {
    "result": {
      "parent": 75,
      "root": 44,
      "slot": 76
    },
    "subscription": 0
  }
}
```
