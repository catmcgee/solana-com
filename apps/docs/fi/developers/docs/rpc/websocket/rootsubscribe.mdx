Tilaa ilmoitukset aina, kun validator asettaa uuden juuren.

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Ei mitään**

### Result

<ResponseField name="result" type="integer">
  tilauksen tunnus (tarvitaan tilauksen peruuttamiseen)
</ResponseField>

#### Ilmoitusmuoto:

Tulos on viimeisin root slot -numero.

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
