sidebarTitle: getFeeCalculatorForBlockhash

---

Palauttaa kyselyyn liittyvän lohkotiivisteen maksulaskurin, tai `null` jos
lohkotiiviste on vanhentunut

<Warning>
  **Vanhentunut metodi**

  Tämä metodi poistetaan todennäköisesti `solana-core` v2.0 -versiossa. Käytä
  sen sijaan [isBlockhashValid](/developers/docs/rpc/http/isblockhashvalid) tai
  [getFeeForMessage](/developers/docs/rpc/http/getfeeformessage) -metodia.
</Warning>
