## ripemd160

`ripemd160` laskee arvon Ripemd160-tiivisteen.

### Syötteet

| Nimi    | Tyyppi                  | Kuvaus                          |
| ------- | ----------------------- | ------------------------------- |
| `value` | buffer \| array[buffer] | Tiivistettävä hex-koodattu arvo |

### Tuloste

| Nimi    | Tyyppi | Kuvaus            |
| ------- | ------ | ----------------- |
| `value` | string | Tiivistetty tulos |

```hcl
output "hashed_data" {
    value = ripemd160(encode_hex("hello, world"))
}
// > hashed_data: 0xa3201f82fca034e46d10cd7b27e174976e241da2
```

## keccak256

`std::keccak256` laskee arvon keccak256-tiivisteen.

### Syötteet

| Nimi    | Tyyppi | Kuvaus                       |
| ------- | ------ | ---------------------------- |
| `value` | string | Tiivistettävä merkkijonoarvo |

### Tuloste

| Nimi    | Tyyppi | Kuvaus            |
| ------- | ------ | ----------------- |
| `value` | string | Tiivistetty tulos |

```hcl
output "hashed_data" {
    value = keccak256("hello, world")
}
// > hashed_data: 0x29bf7021020ea89dbd91ef52022b5a654b55ed418c9e7aba71ef3b43a51669f2
```
