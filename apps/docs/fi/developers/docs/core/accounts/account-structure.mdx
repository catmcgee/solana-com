<Info>
  **Yhteenveto**

  Tileillä on 5 kenttää: lamports, data, owner, executable ja rent_epoch.
  Jokainen tili tunnistetaan ainutlaatuisella 32-tavuisella osoitteella. Tilien
  on säilytettävä vähimmäis-lamport-saldo, joka on suhteessa niiden datakokoon,
  pysyäkseen ketjussa.
</Info>

## Tiliosoite

Jokainen tiliosoite on 32-tavuinen arvo, joka näytetään base58-koodattuna
merkkijonona. Osoite voi olla kahta tyyppiä:

1. **Julkinen avain**: vastaa [Ed25519](https://ed25519.cr.yp.to/) keypairia
   (sisältää yksityisen avaimen)
2. **Program Derived Address (PDA)**: johdettu deterministisesti ohjelma-ID:stä
   ja siemenistä (ei yksityistä avainta)

### Julkinen avain

`Keypair` koostuu julkisesta avaimesta (käytetään tiliosoitteena) ja
yksityisestä avaimesta (käytetään transaktioiden allekirjoittamiseen). Seuraava
esimerkki generoi keypair-parin Solana SDK:n avulla.

<CodeGroup>

```ts Kit
import { generateKeyPairSigner } from "@solana/kit";

// Kit does not enable extractable private keys
const keypairSigner = await generateKeyPairSigner();
console.log(keypairSigner);
```

```ts Legacy
import { Keypair } from "@solana/web3.js";

const keypair = Keypair.generate();
console.log(`Public Key: ${keypair.publicKey}`);
console.log(`Secret Key: ${keypair.secretKey}`);
```

```rs Rust
use solana_sdk::signer::{keypair::Keypair, Signer};

#[tokio::main]
async fn main() {
    let keypair = Keypair::new();
    println!("Public Key: {}", keypair.pubkey());
    println!("Secret Key: {:?}", keypair.to_bytes());
}
```

</CodeGroup>

### Program Derived Address

[Program Derived Address](/developers/docs/core/pda) (PDA) johdetaan deterministisesti
ohjelma-ID:stä ja yhdestä tai useammasta valinnaisesta siemenestä. PDA:lla ei
ole vastaavaa yksityistä avainta. Seuraava esimerkki johtaa PDA:n Solana SDK:n
avulla.

<CodeGroup>

```ts Kit
import { Address, getProgramDerivedAddress } from "@solana/kit";

const programAddress = "11111111111111111111111111111111" as Address;

const seeds = ["helloWorld"];
const [pda, bump] = await getProgramDerivedAddress({
  programAddress,
  seeds
});

console.log(`PDA: ${pda}`);
console.log(`Bump: ${bump}`);
```

```ts Legacy
import { PublicKey } from "@solana/web3.js";

const programAddress = new PublicKey("11111111111111111111111111111111");

const seeds = [Buffer.from("helloWorld")];
const [pda, bump] = await PublicKey.findProgramAddressSync(
  seeds,
  programAddress
);

console.log(`PDA: ${pda}`);
console.log(`Bump: ${bump}`);
```

```rs Rust
use solana_sdk::pubkey; // macro
use solana_sdk::pubkey::Pubkey;

#[tokio::main]
async fn main() {
    let program_address = pubkey!("11111111111111111111111111111111");
    let seeds = [b"helloWorld".as_ref()];
    let (pda, bump) = Pubkey::find_program_address(&seeds, &program_address);
    println!("PDA: {}", pda);
    println!("Bump: {}", bump);
}
```

</CodeGroup>

## Tilin kentät

Jokaisella
[`Account`](https://github.com/anza-xyz/solana-sdk/blob/clock%40v2.2.3/account/src/lib.rs#L32-L56)
-tilillä on enimmäiskoko
[`MAX_ACCOUNT_DATA_LEN`](https://github.com/anza-xyz/agave/blob/v3.1.8/transaction-context/src/lib.rs#L34)
(10 MiB, vastaa `MAX_PERMITTED_DATA_LENGTH`) ja se sisältää viisi kenttää:

| Kenttä       | Tyyppi    | Kuvaus                                                                                 |
| ------------ | --------- | -------------------------------------------------------------------------------------- |
| `lamports`   | `u64`     | Saldo lamporteissa. Omistaja voi veloittaa; mikä tahansa ohjelma voi hyvittää.         |
| `data`       | `Vec<u8>` | Tilin tila tai ohjelman tavukoodi. Enintään 10 MiB. Vain omistaja voi kirjoittaa.      |
| `owner`      | `Pubkey`  | Ohjelma, jolla on kirjoitusoikeus. Uudelleenmääritettävissä vain kun data on nollattu. |
| `executable` | `bool`    | True = ohjelmatili.                                                                    |
| `rent_epoch` | `Epoch`   | Vanhentunut. Asetettu arvoon `u64::MAX` rent-vapautetuille tileille.                   |

```rust Account
pub struct Account {
    /// lamports in the account
    pub lamports: u64,
    /// data held in this account
    #[cfg_attr(feature = "serde", serde(with = "serde_bytes"))]
    pub data: Vec<u8>,
    /// the program that owns this account. If executable, the program that loads this account.
    pub owner: Pubkey,
    /// if true, this account's data contains a program (and is now read-only)
    pub executable: bool,
    /// deprecated
    pub rent_epoch: Epoch,
}
```

<Steps>
  <Step title="Lamportit">
    `lamports`-kenttä sisältää tilin saldon
    [lamporteissa](/developers/docs/references/terminology#lamport) (1 SOL = 1 000 000 000
    lamportia).

    Jokaisen tilin on ylläpidettävä vähimmäis-lamport-saldoa, jotta sen tiedot pysyvät
    tallennettuina ketjussa. Tämä palautettava tallennussaldo on suhteessa tilin tietojen
    kokoon.

    <Info>
      Ajoympäristö ja RPC-metodinimet kutsuvat tätä "rent-exempt minimumiksi", mutta
      jatkuva vuokranperintä on poistettu käytöstä. Käsittele saldo palautettavana tilin
      tallennustalletuksena: koko saldo voidaan palauttaa, kun tili suljetaan.
    </Info>

    Katso
    [`minimum_balance()`](https://github.com/anza-xyz/solana-sdk/blob/clock%40v2.2.3/rent/src/lib.rs#L93)
    ja rent-
    [vakiot](https://github.com/anza-xyz/solana-sdk/blob/clock%40v2.2.3/rent/src/lib.rs#L47-L80).

    ```rust title="Account Examples" focus={3,13}
    // Example Token Mint Account
    Account {
        lamports: 1461600,
        data.len: 82,
        owner: TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb,
        executable: false,
        rent_epoch: 0,
        data: 010000001e213c90625a7e643d9555bb01b6c3fe6416d7afd523ce8c7ddd9b923ceafb9d00000000000000000901010000001e213c90625a7e643d9555bb01b6,
    }

    // Example Token Program Account
    Account {
        lamports: 4513200894,
        data.len: 134080,
        owner: BPFLoader2111111111111111111111111111111111,
        executable: true,
        rent_epoch: 18446744073709551615,
        data: 7f454c460201010000000000000000000300f70001000000d8f90000000000004000000000000000800902000000000000000000400038000400400009000800,
    }
    ```
  </Step>

  <Step title="Data">
    `data`-kenttä tallentaa mielivaltaisen tavutaulukon. Sen sisältö riippuu tilin
    tyypistä:

    - **Ohjelmatilit**: Sisältää suoritettavan tavukoodin tai
      [ohjelman datatilin](/developers/docs/core/accounts/account-types#program-data-accounts)
      osoitteen, joka tallentaa tavukoodin.
    - **Datatilit**: Sisältää ohjelman määrittelemän tiladatan. Omistava ohjelma
      määrittelee serialisointimuodon.

    Tilin datan lukeminen vaatii kaksi vaihetta:

    1. Hae tili sen [osoitteella](#tiliosoite).
    2. Deserialisoi `data`-kenttä raakatavuista ohjelman määrittelemään
       datarakenteeseen.

    ```rust title="Account Examples" focus={4,8,14,18}
    // Example Token Mint Account
    Account {
        lamports: 1461600,
        data.len: 82,
        owner: TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb,
        executable: false,

    }

    // Example Token Program Account
    Account {
        lamports: 4513200894,
        data.len: 134080,
        owner: BPFLoader2111111111111111111111111111111111,
        executable: true,
        rent_epoch: 18446744073709551615,
        data: 7f454c460201010000000000000000000300f70001000000d8f90000000000004000000000000000800902000000000000000000400038000400400009000800,
    }
    ```
  </Step>

  <Step title="Omistaja">
    `owner`-kenttä sisältää ohjelman tunnisteen (julkisen avaimen) ohjelmasta, joka
    omistaa tämän tilin.

    Omistaja-ohjelma on ainoa ohjelma, joka voi:

    - Muokata tilin `data`-kenttää
    - Vähentää lamportteja tilin `lamports`-kentästä

    Mikä tahansa ohjelma voi lisätä lamportteja toiselle tilille, mutta vain
    omistaja voi vähentää lamportteja siitä.

    Ohjelmatileillä omistaja on tilin
    [latausohjelma](/developers/docs/core/programs/builtin-programs#loader-programs).

    ```rust title="Account Examples" focus={5,15}

    ```
  </Step>

  <Step title="Suoritettava">
    `executable`-kenttä on totuusarvo, joka määrittää, onko tili

  <Step title="Rent epoch">
    **`rent_epoch`-kenttä on vanhentunut.**

    `rent_epoch` on asetettu arvoon `u64::MAX` kaikille uusille tileille, jotka täyttävät vähimmäis-
    tallennussaldon vaatimuksen.
