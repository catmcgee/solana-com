## Oppitunnin tavoite

Määritä selkeämpi tapahtumakäsittelyputki, jotta laite tai sovellus reagoi Solana-toimintaan ilman jatkuvaa manuaalista kyselyä.

## Tarkistuspisteet

- Selvitä, mitkä webhook-tapahtumat ovat oleellisia työnkulkusi kannalta.
- Huomioi, miten vastaanottavan palvelun tulisi validoida ja käsitellä ne.
- Päätä, mitä pitäisi tapahtua, kun webhook-toimitus epäonnistuu tai viivästyy.
