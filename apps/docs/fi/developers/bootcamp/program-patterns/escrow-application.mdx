## Projektin tavoite

Mallinna escrow-vuorovaikutus selkeillä omistajuus- ja vapautussäännöillä.

## Tarkistuspisteet

- Listaa kaikki escrow-tilasiirtymät ennen koodin kirjoittamista.
- Varmista valtuutusmalli luonti-, hyväksymis-, peruutus- ja selvitystoiminnoille.
- Vahvista PDA-johdannaiset ja allekirjoittajan odotukset jokaiselle vaiheelle.
