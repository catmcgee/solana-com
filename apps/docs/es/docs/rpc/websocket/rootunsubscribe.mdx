Cancelar suscripción a notificaciones root

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  id de suscripción a cancelar
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  mensaje de éxito de cancelación de suscripción
</ResponseField>
