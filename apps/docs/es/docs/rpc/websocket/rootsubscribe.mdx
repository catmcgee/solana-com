---
title: Método RPC rootSubscribe
sidebarTitle: rootSubscribe
---

Suscríbete para recibir notificaciones cada vez que se establezca una nueva raíz
por el validator.

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Ninguno**

### Result

<ResponseField name="result" type="integer">
  id de suscripción (necesario para cancelar la suscripción)
</ResponseField>

#### Formato de notificación:

El resultado es el número del último slot raíz.

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
