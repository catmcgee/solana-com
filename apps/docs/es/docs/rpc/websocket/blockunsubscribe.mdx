Cancelar suscripción a notificaciones de bloques

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "blockUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="integer" required>
  id de suscripción a cancelar
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  mensaje de éxito de cancelación de suscripción
</ResponseField>
