---
title: Método RPC programUnsubscribe
sidebarTitle: programUnsubscribe
---

Cancelar la suscripción a las notificaciones de cambios en cuentas propiedad del
programa

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "programUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  id de la suscripción de cuenta a cancelar
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  mensaje de éxito de cancelación de suscripción
</ResponseField>
