## Qué cubre esta lección

- Cómo está estructurado el bootcamp de cuatro módulos
- Para qué sirve cada página complementaria
- Cómo navegar entre videos, notas, código y puntos de control

## Antes de continuar

- Guarda como favorito el repositorio del bootcamp y la barra lateral de lecciones.
- Decide cómo llevarás el seguimiento de notas, cambios de código y preguntas.
- Planifica completar las lecciones en orden para que los módulos posteriores se construyan sobre los anteriores.
