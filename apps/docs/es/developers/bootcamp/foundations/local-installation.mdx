## Qué vas a construir

Una configuración de desarrollo local con todas las herramientas necesarias para ejecutar ejemplos e
implementar en devnet.

## Lista de verificación de configuración

- Instala Rust y la CLI de Solana.
- Instala Node.js y tu gestor de paquetes.
- Confirma las versiones de la CLI y la configuración de la billetera.
- Ejecuta un comando básico para validar tu entorno.

## Criterios de finalización

Puedes ejecutar comandos de herramientas localmente sin errores de entorno.
