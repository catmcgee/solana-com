## Objetivo de la lección

Prepara un entorno local confiable para pasar de ver videos a
construir en Solana.

## Puntos de control

- Instala las herramientas de línea de comandos principales y las herramientas de desarrollo complementarias.
- Confirma que tu máquina puede ejecutar el flujo de trabajo local esperado.
- Identifica cualquier problema de configuración que debas resolver antes de continuar.
