## Objetivo del proyecto

Aprende cómo las reglas de intercambio, la liquidez y las suposiciones de precios afectan el comportamiento del protocolo.

## Puntos de control

- Identifica los invariantes del pool que siempre deben cumplirse.
- Rastrea la ruta del intercambio desde la entrada del usuario hasta los saldos actualizados.
- Verifica cómo las comisiones y el deslizamiento se reflejan tanto en el código como en la interfaz de usuario.
