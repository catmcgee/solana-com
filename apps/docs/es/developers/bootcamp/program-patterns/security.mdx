## Objetivo de revisión

Convierte los patrones del bootcamp que ya has utilizado en una lista de verificación de seguridad repetible.

## Puntos de control

- Revisa las restricciones de cuenta y las suposiciones del firmante.
- Busca verificaciones de autoridad faltantes y transiciones de estado inesperadas.
- Captura al menos un invariante que quieras que las pruebas apliquen en adelante.
