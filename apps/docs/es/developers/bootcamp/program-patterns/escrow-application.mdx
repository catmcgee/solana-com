## Objetivo del proyecto

Modelar una interacción de custodia con reglas claras de propiedad y liberación.

## Puntos de control

- Enumera todas las transiciones de estado del contrato de custodia antes de escribir el código.
- Verifica el modelo de autoridad para las acciones de creación, aceptación, cancelación y liquidación.
- Confirma las derivaciones de PDA y las expectativas del firmante para cada paso.
