Conectar el dispositivo a la red rápidamente para que pueda administrarse de forma remota y prepararse para las lecciones relacionadas con Solana que siguen.

## Puntos de control

- Configurar la Pi sin depender de un monitor ni un teclado.
- Validar que el dispositivo se una a tu red correctamente.
- Registrar los detalles de conexión que necesitarás más adelante.
