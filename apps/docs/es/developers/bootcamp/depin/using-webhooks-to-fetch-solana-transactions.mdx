## Objetivo de la lección

Configura un pipeline de eventos más limpio para que el dispositivo o la aplicación reaccione a la actividad de Solana
sin necesidad de consultas manuales constantes.

## Puntos de control

- Comprende qué eventos de webhook son relevantes para tu flujo.
- Observa cómo el servicio receptor debe validar y procesarlos.
- Define qué debe ocurrir cuando la entrega del webhook falla o se retrasa.
