## Kora v2.2.0-beta.6

_23-03-2026_ |
[Versión en GitHub](https://github.com/solana-foundation/kora/releases/tag/v2.2.0-beta.6)
| `cargo install kora-cli@2.2.0-beta.6`

Prelanzamiento con soporte para paquetes Jito, nuevos métodos RPC y funciones de
seguridad mejoradas.

- Se agregó soporte para paquetes Jito con los métodos `signBundle`,
  `signAndSendBundle` y `estimateBundleFee`
- Se agregó el método RPC `getVersion`
- Se agregó protección del pagador de comisiones de Lighthouse
- Se agregó protección contra bots reCAPTCHA v3 para puntos de firma
- Se agregaron límites de uso por billetera con soporte Redis
- Se agregaron imágenes oficiales de Docker en GHCR
- Se agregaron reglas granulares de límites de uso
- SDK: `KoraClient` ahora acepta un objeto de opciones; nuevo `koraPlugin` para
  `@solana/kit`

Consulta la [Documentación Beta](/developers/docs/tools/kora/beta) para más detalles.

## SDK de TypeScript de Kora v0.2.0

_09-03-2026_ |
[Versión en GitHub](https://github.com/solana-foundation/kora/releases/tag/ts-sdk-v0.2.0)
| `pnpm add @solana/kora@0.2.0`

Arquitectura de complementos del cliente Kit para transacciones sin gas
componibles.

- Se agregó `createKitKoraClient()` con composición de complementos de Kit
  (complementos de planificador, ejecutor y pagador)
- Permite la composición con complementos de programas de Kit como
  `tokenProgram()`
- Se agregó soporte para Token-2022 mediante la opción de configuración
  `tokenProgramId`
- Se agregó soporte de instrucción de presupuesto de cómputo con estimación de
  CU basada en simulación
- Se agregó el campo faltante `signature` a la respuesta
  `signAndSendTransaction`
- Devuelve `NoopSigner` de `getPaymentInstruction` para la deduplicación de
  firmantes de Kit v6
- Se actualizó la dependencia par de `@solana/kit` a `^6.1.0`

Consulta la [Guía del cliente Kit](/developers/docs/tools/kora/guides/kit-client).

## Kora v2.0.0

_19-11-2025_ |
[Versión de GitHub](https://github.com/solana-foundation/kora/releases/tag/v2.0.0)
| `cargo install kora-cli@2.0.0`

Versión principal con nueva arquitectura.

- Introducida una nueva arquitectura para el nodo Kora
- Publicado SDK de TypeScript `@solana/kora` v0.1.0
- Migrado a Solana SDK v3.0.x y actualizadas todas las dependencias
- Reemplazado el Kora Signer personalizado con el crate solana-signers
- Eliminados los métodos `sign_transaction_if_paid` y `get_all_signers`
- Cambiados los tipos de respuesta: eliminadas las firmas de
  `signAndSendTransaction` y `signTransaction`
- Mejoras en experiencia del desarrollador, seguridad y rendimiento
