## ripemd160

`ripemd160` calcula el hash Ripemd160 de un valor.

### Entradas

| Nombre  | Tipo                    | Descripción                          |
| ------- | ----------------------- | ------------------------------------ |
| `value` | buffer \| array[buffer] | El valor codificado en hex a hashear |

### Salida

| Nombre  | Tipo   | Descripción           |
| ------- | ------ | --------------------- |
| `value` | string | El resultado hasheado |

```hcl
output "hashed_data" {
    value = ripemd160(encode_hex("hello, world"))
}
// > hashed_data: 0xa3201f82fca034e46d10cd7b27e174976e241da2
```

## keccak256

`std::keccak256` calcula el hash keccak256 de un valor.

### Entradas

| Nombre  | Tipo   | Descripción                  |
| ------- | ------ | ---------------------------- |
| `value` | string | El valor de cadena a hashear |

### Salida

| Nombre  | Tipo   | Descripción           |
| ------- | ------ | --------------------- |
| `value` | string | El resultado hasheado |

```hcl
output "hashed_data" {
    value = keccak256("hello, world")
}
// > hashed_data: 0x29bf7021020ea89dbd91ef52022b5a654b55ed418c9e7aba71ef3b43a51669f2
```
