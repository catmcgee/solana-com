Esta sección proporciona algunos comandos y ejemplos comunes para ayudarte a
comenzar a usar el [Anchor CLI](https://www.anchor-lang.com/docs).

<Steps titleSize="h3">
<Step title="Inicializar el proyecto">

Crea un nuevo proyecto de Anchor ejecutando el comando que se muestra a
continuación. Creará un nuevo directorio con el nombre del proyecto y lo usará
para inicializar un nuevo proyecto de Anchor.

```bash Terminal
anchor init <project-name>
```

Por ejemplo, el comando a continuación creará un proyecto llamado `my-project`.
El directorio `my-project` contendrá un programa básico en Rust y una plantilla
de prueba en TypeScript.

```bash Terminal
anchor init my-project
```

Luego navega al directorio del proyecto:

```bash Terminal
cd <project-name>
```

Consulta la
[estructura de archivos del proyecto](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure)
de Anchor.

</Step>
<Step title="Compilar el programa">

Para compilar tu proyecto, ejecuta el siguiente comando:

```bash Terminal
anchor build
```

Puedes encontrar el programa compilado en el directorio `/target/deploy`.

<Warning>

Al ejecutar `anchor build`, si encuentras los siguientes errores:

<AccordionGroup>
<Accordion title="error: not a directory">

```
error: not a directory: '.../solana-release/bin/sdk/sbf/dependencies/platform-tools/rust/lib'
```

Prueba estas soluciones:

1. Forzar la instalación usando el siguiente comando:

```bash Terminal
cargo build-sbf --force-tools-install
```

2. Si la solución anterior no funciona, limpia la caché de Solana:

```bash Terminal
rm -rf ~/.cache/solana/*
```

</Accordion>

<Accordion title="lock file version 4 requires `-Znext-lockfile-bump">
Puedes solucionar esto cambiando el campo version del archivo `Cargo.lock` de 4 a 3:

```diff Cargo.lock
-version = 4
+version = 3
```

Consulta [este issue](https://github.com/solana-foundation/anchor/issues/3392)
para más información.

</Accordion>

</AccordionGroup>

Después de aplicar la solución anterior, intenta ejecutar `anchor build`
de nuevo.

</Warning>

</Step>
<Step title="Despliega el programa">

Para desplegar tu proyecto, ejecuta el siguiente comando:

```bash Terminal
anchor deploy
```

Este comando despliega tu programa en el `cluster` especificado en el archivo
[`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml).

</Step>
<Step title="Prueba el programa">

Para probar tu proyecto, ejecuta el siguiente comando:

```bash Terminal
anchor test
```

Este comando compila, despliega y ejecuta las pruebas de tu proyecto.

<Note>
  Al usar el clúster `localnet`, Anchor inicia automáticamente un validador
  local, despliega el programa, ejecuta las pruebas y luego detiene el
  validador.
</Note>

<Warning>

Cualquiera de los siguientes errores puede indicar que no tienes Node.js o Yarn
instalados:

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Warning>

</Step>
</Steps>
