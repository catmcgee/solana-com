title: Método RPC logsUnsubscribe
sidebarTitle: logsUnsubscribe

Cancelar suscripción a los registros de transacciones

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "logsUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="integer" required>
  id de suscripción a cancelar
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  mensaje de éxito de cancelación de suscripción
</ResponseField>
