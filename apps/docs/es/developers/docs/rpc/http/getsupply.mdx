title: Método RPC getSupply
sidebarTitle: getSupply
---

Devuelve información sobre el suministro actual.

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getSupply",
      "params": [
        {
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let supply = await rpc.getSupply().send();

  console.log(supply);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let supply = await connection.getSupply();

  console.log(supply);
  ```
</RequestExample>

## Parameters

<ParamField body="0" type="object">
  Objeto de configuración que contiene los siguientes campos:

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      El commitment describe qué tan finalizado está un bloque en ese momento. Ver
      [Configuración del compromiso de estado](/developers/docs/rpc#configuring-state-commitment).
    </ParamField>

    <ParamField body="excludeNonCirculatingAccountsList" type="bool">
      Excluir la lista de cuentas no circulantes de la respuesta
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="object">
  El resultado será un objeto JSON que contiene:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="circulating" type="u64">
      Suministro circulante en lamport
    </ResponseField>

    <ResponseField name="nonCirculating" type="u64">
      Suministro no circulante en lamports
    </ResponseField>

    <ResponseField name="nonCirculatingAccounts" type="array">
      Un array de direcciones de cuentas no circulantes, como cadenas de texto. Si
      `excludeNonCirculatingAccountsList` está habilitado, el array devuelto estará
      vacío.
    </ResponseField>

    <ResponseField name="total" type="u64">
      Suministro total en lamports
    </ResponseField>
  </Expandable>
</ResponseField>
