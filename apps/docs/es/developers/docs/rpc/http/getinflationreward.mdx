---
title: Método RPC getInflationReward
sidebarTitle: getInflationReward
---

Devuelve la recompensa de inflación / staking para una lista de direcciones
durante un epoch

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getInflationReward",
      "params": [
        [
          "6dmNQ5jwLeLk5REvio1JcMshcbvkYMwy26sJ8pbkvStu",
          "BGsqMegLpV6n6Ve146sSX2dTjUMj3M92HnU8BbNRMhF2"
        ],
        {
          "epoch": 800,
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { address, createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let addresses = [
    address("6dmNQ5jwLeLk5REvio1JcMshcbvkYMwy26sJ8pbkvStu"),
    address("BGsqMegLpV6n6Ve146sSX2dTjUMj3M92HnU8BbNRMhF2")
  ];

  let epoch = BigInt(2);

  let inflationReward = await rpc.getInflationReward(addresses, { epoch }).send();

  console.log(inflationReward);
  ```

  ```ts web3.js
  import { Connection, PublicKey, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let addresses = [
    new PublicKey("6dmNQ5jwLeLk5REvio1JcMshcbvkYMwy26sJ8pbkvStu"),
    new PublicKey("BGsqMegLpV6n6Ve146sSX2dTjUMj3M92HnU8BbNRMhF2")
  ];

  let epoch = 2;

  let inflationReward = await connection.getInflationReward(addresses, epoch);

  console.log(inflationReward);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::{commitment_config::CommitmentConfig, pubkey};

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let addresses = [
          pubkey!("6dmNQ5jwLeLk5REvio1JcMshcbvkYMwy26sJ8pbkvStu"),
          pubkey!("BGsqMegLpV6n6Ve146sSX2dTjUMj3M92HnU8BbNRMhF2"),
      ];

      let epoch = 2;

      let inflation_reward = client.get_inflation_reward(&addresses, Some(epoch)).await?;

      println!("{:#?}", inflation_reward);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="0" type="array">
  Un array de direcciones para consultar, como cadenas codificadas en base-58
</ParamField>

<ParamField body="1" type="object">
  Objeto de configuración que contiene los siguientes campos:

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      El commitment describe qué tan finalizado está un bloque en ese momento. Ver
      [Configuración del State Commitment](/developers/docs/rpc#configuring-state-commitment).
    </ParamField>

    <ParamField body="epoch" type="u64">
      Un epoch para el cual ocurre la recompensa. Si se omite, se utilizará el epoch
      anterior
    </ParamField>

    <ParamField body="minContextSlot" type="number">
      El slot mínimo en el que se puede evaluar la solicitud
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="array">
  El campo de resultado será un array JSON de objetos que contiene:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="epoch" type="u64">
      Epoch para el cual ocurrió la recompensa
    </ResponseField>

    <ResponseField name="effectiveSlot" type="u64">
      El slot en el que las recompensas son efectivas
    </ResponseField>

    <ResponseField name="amount" type="u64">
      Cantidad de recompensa en lamports
    </ResponseField>

    <ResponseField name="postBalance" type="u64">
      Saldo posterior de la cuenta en lamports
    </ResponseField>

    <ResponseField name="commission" type="u8 | undefined">
      Comisión de la cuenta de voto cuando se acreditó la recompensa
    </ResponseField>
  </Expandable>
</ResponseField>
