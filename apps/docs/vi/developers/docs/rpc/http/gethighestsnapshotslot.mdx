---
title: Phương thức RPC getHighestSnapshotSlot
sidebarTitle: getHighestSnapshotSlot
---

Trả về thông tin slot cao nhất mà node có snapshot.

Phương thức này sẽ tìm slot snapshot đầy đủ cao nhất, và slot snapshot tăng dần
cao nhất _dựa trên_ slot snapshot đầy đủ, nếu có.

<Warning>
  **Giới hạn phiên bản**

  Phương thức này chỉ có sẵn trong `solana-core` v1.9 hoặc mới hơn. Vui lòng sử
  dụng [getSnapshotSlot](/developers/docs/rpc/deprecated/getsnapshotslot) cho `solana-core`
  v1.8 và thấp hơn.
</Warning>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getHighestSnapshotSlot"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let hightestSnapshotSlot = await rpc.getHighestSnapshotSlot().send();

  console.log(hightestSnapshotSlot);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let highest_snapshot_slot = client.get_highest_snapshot_slot().await?;

      println!("{:#?}", highest_snapshot_slot);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Snapshot
  {
    "jsonrpc": "2.0",
    "result": {
      "full": 100,
      "incremental": 110
    },
    "id": 1
  }
  ```

  ```json title="Không có Snapshot"
  {
    "jsonrpc": "2.0",
    "error": {
      "code": -32008,
      "message": "No snapshot"
    },
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

None

## Result

<ResponseField name="result" type="object" post={["Snapshot"]}>
  Khi node có snapshot, phương thức này trả về một đối tượng JSON với các trường
  sau:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="full" type="u64">
      Slot snapshot đầy đủ cao nhất
    </ResponseField>

    <ResponseField name="incremental" type="u64 | null">
      Slot snapshot tăng dần cao nhất _dựa trên_ `full`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="result" type="object" post={["Không có Snapshot"]}>
  Nếu node không có snapshot, một phản hồi lỗi JSON RPC sẽ được trả về.
</ResponseField>
