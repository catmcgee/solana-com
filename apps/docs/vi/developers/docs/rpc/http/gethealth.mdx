Trả về tình trạng sức khỏe hiện tại của node. Một node khỏe mạnh là node nằm
trong phạm vi `HEALTH_CHECK_SLOT_DISTANCE` slot so với slot đã được xác nhận mới
nhất của cluster.

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getHealth"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let health = await rpc.getHealth().send();

  console.log(health);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let health = client.get_health().await?;

      println!("{:#?}", health);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json title="Khỏe mạnh"
  {
    "jsonrpc": "2.0",
    "result": "ok",
    "id": 1
  }
  ```

  ```json title="Không khỏe mạnh"
  {
    "jsonrpc": "2.0",
    "error": {
      "code": -32005,
      "message": "Node is unhealthy",
      "data": { "numSlotsBehind": 42 }
    },
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

None

## Result

<ResponseField name="result" type="string" post={["Khỏe mạnh"]}>
  Nếu node khỏe mạnh: "ok"
</ResponseField>

<ResponseField name="result" type="object" post={["Không khỏe mạnh"]}>
  Nếu node không khỏe mạnh, một phản hồi lỗi JSON RPC sẽ được trả về. Chi tiết của
  phản hồi lỗi là **KHÔNG ỔN ĐỊNH** và có thể thay đổi trong tương lai
</ResponseField>
