Đăng ký để nhận thông báo bất cứ khi nào một slot được xử lý bởi validator

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Không có**

### Result

<ResponseField name="result" type="integer">
  Id đăng ký (cần thiết để hủy đăng ký)
</ResponseField>

#### Định dạng thông báo:

Thông báo sẽ là một đối tượng với các trường sau:

- `parent: <u64>` - Slot cha
- `root: <u64>` - Slot gốc hiện tại
- `slot: <u64>` - Giá trị slot mới được thiết lập

Ví dụ:

```json
{
  "jsonrpc": "2.0",
  "method": "slotNotification",
  "params": {
    "result": {
      "parent": 75,
      "root": 44,
      "slot": 76
    },
    "subscription": 0
  }
}
```
