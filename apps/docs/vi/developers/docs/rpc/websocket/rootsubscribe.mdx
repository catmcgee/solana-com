---
title: Phương thức RPC rootSubscribe
sidebarTitle: rootSubscribe
---

Đăng ký để nhận thông báo bất cứ khi nào một root mới được thiết lập bởi
validator.

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Không có**

### Result

<ResponseField name="result" type="integer">
  id đăng ký (cần thiết để hủy đăng ký)
</ResponseField>

#### Định dạng thông báo:

Kết quả là số slot root mới nhất.

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
