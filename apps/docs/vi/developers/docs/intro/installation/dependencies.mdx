Hướng dẫn thiết lập môi trường phát triển Solana cục bộ. Tìm hiểu cách cài đặt
Rust, Solana CLI và Anchor Framework trên Windows (WSL), Linux và Mac. Sử dụng
hướng dẫn này nếu bạn muốn cài đặt từng phụ thuộc riêng lẻ, hoặc nếu
[cài đặt nhanh](/developers/docs/intro/installation/) gặp sự cố vì bất kỳ lý do gì.

### Điều kiện tiên quyết

<AccordionGroup>
<Accordion title="Windows">

Để phát triển các chương trình Solana trên Windows, bạn **phải** sử dụng
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). Sau khi cài đặt WSL, tất cả các phụ thuộc khác sẽ được cài đặt thông qua
terminal Linux.

Để cài đặt WSL, chạy lệnh sau trong Windows PowerShell:

```bash Terminal
wsl --install
```

Quá trình cài đặt sẽ yêu cầu bạn tạo tài khoản người dùng mặc định.

<Frame caption="Cài đặt WSL">
  ![Cài đặt WSL](/docs-assets/assets/docs/intro/installation/wsl-install.png)
</Frame>

Theo mặc định, WSL cài đặt Ubuntu. Bạn có thể mở terminal Linux bằng cách tìm
kiếm "Ubuntu" trong thanh tìm kiếm.

<Frame caption="WSL Ubuntu">
  ![WSL Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-search.png)
</Frame>

Nếu terminal Ubuntu của bạn trông giống như hình ảnh bên dưới, bạn có thể gặp sự
cố khi `ctrl + v` (phím tắt dán) không hoạt động trong terminal.

<Frame caption="Terminal Ubuntu">
  ![Terminal Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)
</Frame>

Nếu bạn gặp sự cố này, hãy mở Windows Terminal bằng cách tìm kiếm "Terminal"
trong thanh tìm kiếm.

<Frame caption="Windows Terminal">
  ![Windows Terminal](/docs-assets/assets/docs/intro/installation/wsl-windows-terminal.png)
</Frame>

Tiếp theo, đóng Windows Terminal và mở lại terminal Linux bằng cách tìm kiếm
Ubuntu một lần nữa. Terminal bây giờ sẽ trông giống như hình ảnh bên dưới, trong
đó `ctrl + v` (phím tắt dán) hoạt động.

<Frame caption="Terminal Ubuntu">
  ![Terminal Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)
</Frame>

Nếu bạn sử dụng VS Code,
[tiện ích mở rộng WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial)
cho phép bạn sử dụng WSL và VS Code cùng nhau.

<Frame caption="Thiết lập WSL trong VS Code">
  ![Thiết lập WSL trong VS Code](/docs-assets/assets/docs/intro/installation/wsl-vscode.png)
</Frame>

Bạn sẽ thấy nội dung sau trong thanh trạng thái của VS Code:

<Frame caption="WSL: Ubuntu">
  ![WSL: Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-vscode-ubuntu.png)
</Frame>

Sau khi đã thiết lập WSL, bạn đã sẵn sàng để:

- Hoàn thành [cài đặt nhanh](/developers/docs/quickstart) bằng terminal Ubuntu
  (Linux)
- Cài đặt [Rust](#install-rust), [Solana CLI](#install-solana-cli), và
  [Anchor CLI](#install-anchor-cli) riêng lẻ, như mô tả bên dưới

</Accordion>
<Accordion title="Linux">

<Tabs>
<Tab title=".deb">
Nếu bạn đang sử dụng Debian hoặc các bản phái sinh từ Debian như Ubuntu hoặc Mint, hãy làm theo các bước dưới đây:

1. Cập nhật danh sách gói để đảm bảo tất cả các gói đều được cập nhật:

```bash Terminal
sudo apt-get update
```

2. Cài đặt các phụ thuộc sau:

```bash Terminal
sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Note>
Nếu bạn gặp lỗi sau khi cài đặt `protobuf-compiler`, hãy
đảm bảo bạn chạy `sudo apt-get update` trước

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Note>

  </Tab>

    <Tab title=".rpm">
    Đối với các bản phái sinh RHEL như Fedora hoặc Red Hat Linux, hãy làm theo các bước sau.

Cập nhật danh sách gói để lấy các phiên bản mới hơn của các gói bằng cách chạy
lệnh.

    ```bash Terminal
    sudo dnf upgrade --refresh
    ```

    Tiếp theo, cài đặt các phụ thuộc sau:

    ```bash Terminal
    sudo dnf group install c-development development-tools \
    && sudo dnf install pkg-config openssl-devel
    ```

  </Tab>
</Tabs>

<Step title="Cài đặt Rust">

Các nhà phát triển xây dựng chương trình Solana bằng ngôn ngữ lập trình
[Rust](https://www.rust-lang.org/).

1. Cài đặt Rust bằng [rustup](https://www.rust-lang.org/tools/install) bằng cách
   nhập lệnh sau vào terminal của bạn:

```bash Terminal
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

Sau khi cài đặt thành công, bạn sẽ thấy thông báo sau:

<AccordionGroup>
<Accordion title="Thông báo cài đặt Rust thành công">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</AccordionGroup>

2. Tải lại biến môi trường PATH của bạn để bao gồm thư mục bin của
   [Cargo](https://github.com/rust-lang/cargo):

```bash Terminal
. "$HOME/.cargo/env"
```

3. Xác minh rằng quá trình cài đặt đã thành công.

```bash Terminal
rustc --version
```

Bạn sẽ thấy kết quả như sau:

```
rustc 1.86.0 (05f9846f8 2025-03-31)
```

</Step>
<Step title="Cài đặt Solana CLI">

Solana CLI cung cấp tất cả các công cụ cần thiết để xây dựng và triển khai các
chương trình Solana.

1. Cài đặt bộ công cụ Solana CLI bằng cách sử dụng lệnh cài đặt chính thức:

```bash Terminal
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Note>
  Bạn có thể thay thế `stable` bằng thẻ phát hành tương ứng với phiên bản phần
  mềm của bản phát hành mong muốn (ví dụ: `v2.0.3`), hoặc sử dụng một trong ba
  tên kênh tượng trưng: `stable`, `beta`, hoặc `edge`.
</Note>

2. Thêm biến môi trường PATH

Lần cài đặt đầu tiên của Solana CLI có thể nhắc bạn thêm biến môi trường `PATH`.
Để thực hiện điều này, đóng và mở lại terminal của bạn hoặc chạy lệnh sau trong
shell của bạn:

```
export PATH="/Users/test/.local/share/solana/install/active_release/bin:$PATH"
```

3. Cập nhật biến môi trường PATH của bạn

<Tabs>
<Tab title="Windows & Linux">

Nếu bạn đang sử dụng **Linux** hoặc **WSL**, bạn phải thêm tệp nhị phân Solana
CLI vào PATH của mình để lệnh có sẵn trong terminal của bạn. Để thực hiện điều
này, hãy làm theo các bước dưới đây:

**a.** Kiểm tra shell nào bạn đang sử dụng:

```bash Terminal
echo $SHELL
```

- Nếu kết quả chứa `/bash`, hãy sử dụng `.bashrc`.
- Nếu kết quả chứa `/zsh`, hãy sử dụng `.zshrc`.

**b.** Chạy lệnh phù hợp, dựa trên shell của bạn.

Đối với Bash (`bashrc`):

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

Đối với Zsh (`zshrc`):

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

</Tab>
<Tab title="Mac">

Nếu bạn sử dụng Mac với `zsh`, việc chạy lệnh `export PATH` mặc định được ghi từ
quá trình cài đặt sẽ không tồn tại sau khi bạn đóng terminal. Thay vào đó, hãy
thêm PATH vào tệp cấu hình shell của bạn bằng cách chạy lệnh sau:

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.zshrc
```

<Note>
  Các bước trên không áp dụng cho người dùng `bash`, vì các thay đổi đối với
  biến PATH sẽ tồn tại theo mặc định.
</Note>

</Tab>
</Tabs>

4. Khởi động lại terminal của bạn hoặc chạy lệnh sau để làm mới phiên terminal:

```bash Terminal
source ~/.bashrc # If using Bash
source ~/.zshrc # If using Zsh
```

5. Xác minh rằng quá trình cài đặt đã thành công bằng cách kiểm tra phiên bản
   Solana CLI:

```bash Terminal
solana --version
```

Bạn sẽ thấy kết quả như sau:

```
solana-cli 2.2.12 (src:0315eb6a; feat:1522022101, client:Agave)
```

<Note>

Bạn có thể xem tất cả các phiên bản có sẵn trên
[Agave Github repo](https://github.com/anza-xyz/agave/releases). Agave là
validator client từ [Anza](https://www.anza.xyz/), trước đây được biết đến là
Solana Labs validator client.

</Note>

5. Cập nhật Solana CLI lên phiên bản mới nhất, nếu cần _(Tùy chọn)_

```bash Terminal
agave-install update
```

</Step>
<Step title="Cài đặt Anchor CLI">

[Anchor](https://www.anchor-lang.com/) là một framework để phát triển các chương
trình Solana. Framework Anchor tận dụng các macro của Rust để đơn giản hóa quá
trình viết các chương trình Solana.

#### Điều kiện tiên quyết

Tệp kiểm thử dự án Anchor mặc định (TypeScript) được tạo bằng lệnh
`anchor init` yêu cầu Node.js và Yarn. (Mẫu kiểm thử Rust có sẵn khi sử
dụng `anchor init --test-template rust`)

<AccordionGroup>
<Accordion title="Cài đặt Node">

1. Cài đặt Node bằng cách sử dụng
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm) bằng cách chạy
   lệnh sau:

```bash Terminal
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/master/install.sh | bash
```

2. Khởi động lại terminal của bạn và xác nhận rằng lệnh `nvm` chạy thành công:

```bash Terminal
command -v nvm
```

3. Sử dụng `nvm` để cài đặt Node:

```bash Terminal
nvm install node
```

4. Xác minh rằng quá trình cài đặt đã thành công bằng cách kiểm tra phiên bản
   Node:

```bash Terminal
node --version
```

Bạn sẽ thấy kết quả như sau:

```
v23.7.0
```

</Accordion>
<Accordion title="Cài đặt Yarn">

1. Cài đặt Yarn:

```bash Terminal
npm install --global yarn
```

2. Xác minh rằng quá trình cài đặt đã thành công bằng cách kiểm tra phiên bản
   Yarn:

```bash Terminal
yarn --version
```

Bạn sẽ thấy kết quả sau:

```
1.22.1
```

</Accordion>
</AccordionGroup>

#### Cài đặt

Bạn có thể cài đặt Anchor CLI và các công cụ theo hai cách:

- Anchor Version Manager (AVM) — Phương pháp cài đặt được khuyến nghị
- Không dùng AVM — Cài đặt trực tiếp từ GitHub

<Tabs>
<Tab title="AVM">

Anchor Version Manager (AVM) cho phép bạn cài đặt và quản lý các phiên bản
Anchor khác nhau trên hệ thống của bạn và dễ dàng cập nhật phiên bản Anchor
trong tương lai. Để cài đặt Anchor bằng AVM, hãy làm theo các bước dưới đây:

1. Cài đặt AVM bằng lệnh sau:

```bash Terminal
curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  Xác nhận rằng AVM đã được cài đặt thành công:

```bash Terminal
avm --version
```

3. Cài đặt Anchor CLI bằng AVM:

Để cài đặt phiên bản mới nhất:

```bash Terminal
avm install latest
avm use latest
```

Để cài đặt một phiên bản cụ thể, hãy chỉ định số phiên bản:

```bash Terminal
avm install 0.30.1
avm use 0.30.1
```

<Warning>

Khi cài đặt Anchor CLI trên Linux hoặc WSL, bạn có thể gặp lỗi sau:

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

Nếu bạn thấy thông báo lỗi này, hãy làm theo các bước sau:

1. Cài đặt các gói phụ thuộc được liệt kê trong phần
   [Linux](/developers/docs/intro/installation/dependencies) ở đầu trang
   này.
2. Thử cài đặt lại Anchor CLI.

</Warning>

4. Xác minh rằng việc cài đặt đã thành công bằng cách kiểm tra phiên bản Anchor
   CLI:

```bash Terminal
anchor --version
```

Bạn sẽ thấy kết quả như sau:

```
anchor-cli 0.31.1
```

<Info>

Đừng quên chạy lệnh `avm use` để khai báo phiên bản Anchor CLI sẽ chạy
trên hệ thống của bạn.

- Nếu bạn đã cài đặt phiên bản `latest`, hãy chạy `avm use latest`.
- Nếu bạn đã cài đặt phiên bản `0.30.1`, hãy chạy `avm use 0.30.1`.

</Info>

</Tab>

<Tab title="Without AVM">

1. Cài đặt một phiên bản cụ thể của Anchor CLI bằng lệnh sau:

```bash Terminal
cargo install --git https://github.com/solana-foundation/anchor --tag v0.30.1 anchor-cli
```

2. Xác minh rằng việc cài đặt đã thành công bằng cách kiểm tra phiên bản Anchor
   CLI:

```bash Terminal
anchor --version
```

Bạn sẽ thấy kết quả như sau:

```
anchor-cli 0.31.1
```

</Tab>
</Tabs>

<Step title="Cài đặt Surfpool CLI">

[Surfpool](https://surfpool.run/) là một công cụ dành cho phát triển cục bộ và
là sự thay thế cải tiến cho `solana-test-validator`. Tìm hiểu thêm về các tính
năng của Surfpool trong [tài liệu Surfpool](https://docs.surfpool.run/).

1. Cài đặt Surfpool bằng lệnh sau:

```bash Terminal
curl -sL https://run.surfpool.run/ | bash
```

2. Xác minh rằng việc cài đặt đã thành công bằng cách kiểm tra phiên bản
   Surfpool CLI:

```bash Terminal
surfpool --version
```

Bạn sẽ thấy kết quả như sau:

```
surfpool 0.12.0
```

</Step>
