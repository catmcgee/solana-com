Phần Cơ Bản Về SPL Token bao gồm các lệnh cơ bản để tương tác với SPL Token, tập
trung vào chức năng được chia sẻ bởi cả Token Program gốc và Token Extensions
Program (Token 2022).

<Info>
  Tham khảo [tài liệu Metaplex](https://developers.metaplex.com/token-metadata)
  để biết thêm thông tin về cách thêm metadata vào SPL Token.
</Info>
