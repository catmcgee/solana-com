Hủy đăng ký thông báo bỏ phiếu

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "voteUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="integer" required>
  id đăng ký cần hủy
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  thông báo hủy đăng ký thành công
</ResponseField>
