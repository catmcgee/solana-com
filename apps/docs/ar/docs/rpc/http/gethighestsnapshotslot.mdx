---
title: طريقة getHighestSnapshotSlot RPC
sidebarTitle: getHighestSnapshotSlot
---

تُرجع معلومات أعلى slot يمتلك العقدة لقطات له.

ستجد هذه الطريقة أعلى slot للقطة كاملة، وأعلى slot للقطة تزايدية _بناءً على_
slot اللقطة الكاملة، إذا كان موجودًا.

<Warning>
  **قيود الإصدار**

  هذه الطريقة متاحة فقط في `solana-core` الإصدار 1.9 أو أحدث. يرجى استخدام
  [getSnapshotSlot](/docs/rpc/deprecated/getsnapshotslot) للإصدار `solana-core`
  1.8 وما قبله.
</Warning>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getHighestSnapshotSlot"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let hightestSnapshotSlot = await rpc.getHighestSnapshotSlot().send();

  console.log(hightestSnapshotSlot);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let highest_snapshot_slot = client.get_highest_snapshot_slot().await?;

      println!("{:#?}", highest_snapshot_slot);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json لقطة
  {
    "jsonrpc": "2.0",
    "result": {
      "full": 100,
      "incremental": 110
    },
    "id": 1
  }
  ```

  ```json title="لا توجد لقطة"
  {
    "jsonrpc": "2.0",
    "error": {
      "code": -32008,
      "message": "No snapshot"
    },
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

None

## Result

<ResponseField name="result" type="object" post={["لقطة"]}>
  عندما يكون لدى العقدة لقطة، تُرجع كائن JSON يحتوي على الحقول التالية:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="full" type="u64">
      أعلى slot للقطة كاملة
    </ResponseField>

    <ResponseField name="incremental" type="u64 | null">
      أعلى slot للقطة تزايدية _بناءً على_ `full`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="result" type="object" post={["لا توجد لقطة"]}>
  إذا لم يكن لدى العقدة لقطة، يتم إرجاع استجابة خطأ JSON RPC.
</ResponseField>
