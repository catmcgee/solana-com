title: طريقة RPC لـ getRecentPerformanceSamples
sidebarTitle: getRecentPerformanceSamples
---

تُرجع قائمة بعينات الأداء الأخيرة، بترتيب عكسي للـ slot. يتم أخذ عينات الأداء كل
60 ثانية وتتضمن عدد المعاملات والـ slots التي تحدث في نافذة زمنية معينة.

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getRecentPerformanceSamples",
      "params": [
        2
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let limit = 2;

  let performanceSamples = await rpc.getRecentPerformanceSamples(limit).send();

  console.log(performanceSamples);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let limit = 2;

  let performanceSamples = await connection.getRecentPerformanceSamples(limit);

  console.log(performanceSamples);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let limit = 2;
      let performance_samples = client.get_recent_performance_samples(limit.into()).await?;

      println!("{:#?}", performance_samples);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="عدد العينات" type="usize">
  عدد العينات المراد إرجاعها (الحد الأقصى 720)
</ParamField>

## Result

<ResponseField name="result" type="array">
  مصفوفة من كائنات عينات الأداء تحتوي على:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="slot" type="u64">
      الـ slot الذي تم أخذ العينة فيه
    </ResponseField>

    <ResponseField name="numTransactions" type="u64">
      عدد المعاملات التي تمت معالجتها خلال فترة أخذ العينات
    </ResponseField>

    <ResponseField name="numSlots" type="u64">
      عدد الـ slots المكتملة خلال فترة أخذ العينات
    </ResponseField>

    <ResponseField name="samplePeriodSecs" type="u16">
      عدد الثواني في نافذة العينة
    </ResponseField>

    <ResponseField name="numNonVoteTransactions" type="u64">
      عدد المعاملات غير التصويتية التي تمت معالجتها خلال فترة العينة

      <Info>
        `numNonVoteTransactions` متوفر بدءًا من الإصدار v1.15. للحصول على عدد معاملات
        التصويت، قم بحساب: `numTransactions - numNonVoteTransactions`
      </Info>
    </ResponseField>
  </Expandable>
</ResponseField>
