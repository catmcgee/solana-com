دوال للتعامل مع الوقت والوصول إلى متغيرات النظام. لكل دالة قراءة sysvar دالة كتابة مقابلة؛ والبنيات هي مرايا Go مباشرة لمصدر سولانا.

## التعامل مع الساعة

### WarpToSlot

```go
func (s *LiteSVM) WarpToSlot(slot uint64) error
```

تقديم الساعة الداخلية إلى slot محدد.

```go
before, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("current slot: %d", before.Slot)

if err := svm.WarpToSlot(10_000_000); err != nil {
    t.Fatal(err)
}

after, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("new slot:     %d", after.Slot)
```

### Clock

```go
// sysvar is github.com/gagliardetto/solana-go/sysvar
type Clock struct {
    Slot                uint64
    EpochStartTimestamp int64
    Epoch               uint64
    LeaderScheduleEpoch uint64
    UnixTimestamp       int64
}

func (s *LiteSVM) Clock() (*sysvar.Clock, error)
```

قراءة الـ sysvar الخاص بـ Clock.

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("slot=%d epoch=%d unix=%d", c.Slot, c.Epoch, c.UnixTimestamp)
```

### SetClock

```go
func (s *LiteSVM) SetClock(c *sysvar.Clock) error
```

الكتابة فوق الـ sysvar الخاص بـ Clock. اقرأه، عدّل الحقول، ثم اكتبه مجدداً عندما تحتاج إلى التحكم في `Epoch` أو `UnixTimestamp` (اللذين لا يقوم `WarpToSlot` بتحديثهما).

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
c.Slot = 1_000
c.Epoch = 10
c.UnixTimestamp = 1_735_689_600
if err := svm.SetClock(c); err != nil {
    t.Fatal(err)
}
```

<Info>
  يقوم `WarpToSlot` بتحديث `Slot` فقط. استخدم `SetClock` عندما يقرأ برنامجك
  `Epoch` أو `UnixTimestamp` من الـ sysvar الخاص بـ Clock.
</Info>

```go
type EpochRewards struct {
    DistributionStartingBlockHeight uint64
    NumPartitions                   uint64

    TotalPoints                     bin.Uint128 // u128 total_points
```

`total_points` هو نوع `u128` على جانب سولانا؛ يعرض `litesvm-go` النصفين
بشكل صريح حتى لا يحتاج مستخدمو Go إلى مكتبة u128. بالنسبة للقيم التي تتناسب مع 64

### SlotHistory

`SlotHistory` عبارة عن bitvec بحجم ~128 كيلوبايت؛ يعرضها `litesvm-go` كمقبض بدلاً
من شريحة.

```go
sh := sysvar.NewSlotHistory()

sh.Add(42)

switch sh.Check(42) {
case sysvar.SlotHistoryFound:
    // ...
case sysvar.SlotHistoryNotFound:
    // ...
case sysvar.SlotHistoryTooOld:
    // ...
case sysvar.SlotHistoryFuture:
    // ...
}

if err := svm.SetSlotHistory(sh); err != nil {
    t.Fatal(err)
}
```

| الدالة                                           | الوصف                                |
| ------------------------------------------------ | ------------------------------------------ |
| `litesvm.NewSlotHistory() (*SlotHistory, error)` | مقبض فارغ                               |
| `sh.Add(slot uint64)`                            | تسجيل slot                              |
| `sh.Check(slot uint64) SlotHistoryCheck`         | `Future` / `TooOld` / `Found` / `NotFound` |
| `sh.Oldest() uint64`                             | أقدم slot مُتتبَّع                        |
| `sh.Newest() uint64`                             | أحدث slot مُتتبَّع                        |
| `sh.NextSlot() uint64`                           | الـ slot التالي للتسجيل                        |
| `sh.SetNextSlot(slot uint64) error`              | تجاوز علامة الـ slot التالي              |
| `sh.Close()`                                     | تحرير المقبض                         |
| `svm.SlotHistory() (*SlotHistory, error)`        | القراءة في مقبض جديد                   |
| `svm.SetSlotHistory(*SlotHistory) error`         | التثبيت على SVM                         |

## اختبار المنطق المعتمد على الوقت

استخدم `WarpToSlot` للتقدم البسيط القائم على الـ slot، و`SetClock` للتحكم الكامل:

```go
func TestTimeLockedVault(t *testing.T) {
    svm, err := litesvm.New()
    if err != nil {
        t.Fatal(err)
    }
    defer svm.Close()

    const unlockSlot = uint64(10_000)

    // Setup: create the time-locked account ...

    // Test 1: Try to withdraw before unlock (should fail)
    before, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("current slot: %d", before.Slot)
    // ... attempt withdrawal, expect failure ...

    // Warp time forward past unlock slot
    if err := svm.WarpToSlot(unlockSlot + 1); err != nil {
        t.Fatal(err)
    }

    // Test 2: Try to withdraw after unlock (should succeed)
    after, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("new slot: %d", after.Slot)
    // ... attempt withdrawal, expect success ...
}
```
