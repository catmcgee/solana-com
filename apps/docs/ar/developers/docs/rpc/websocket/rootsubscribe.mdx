title: طريقة RPC لـ rootSubscribe
sidebarTitle: rootSubscribe
---

اشترك لتلقي إشعار في أي وقت يتم فيه تعيين جذر جديد بواسطة الـ validator.

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**لا شيء**

### Result

<ResponseField name="result" type="integer">
  معرف الاشتراك (مطلوب لإلغاء الاشتراك)
</ResponseField>

#### تنسيق الإشعار:

النتيجة هي رقم الـ slot الجذر الأحدث.

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
