إلغاء الاشتراك من إشعارات التصويت

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "voteUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="integer" required>
  معرف الاشتراك المراد إلغاؤه
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  رسالة نجاح إلغاء الاشتراك
</ResponseField>
