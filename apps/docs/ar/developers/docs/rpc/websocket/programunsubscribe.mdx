---
title: طريقة RPC لإلغاء الاشتراك في البرنامج
sidebarTitle: programUnsubscribe
---

إلغاء الاشتراك من إشعارات تغيير الحساب المملوك للبرنامج

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "programUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  معرّف اشتراك الحساب المراد إلغاؤه
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  رسالة نجاح إلغاء الاشتراك
</ResponseField>
