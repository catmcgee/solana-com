في القسم السابق، تعلّمت كيفية
[قراءة البيانات من شبكة سولانا](/developers/docs/intro/quick-start/reading-from-network)
عبر جلب الحسابات. تتطلب كتابة البيانات إلى شبكة سولانا
[معاملة](/developers/docs/core/transactions). تحتوي المعاملة على تعليمة واحدة أو أكثر من
[التعليمات](/developers/docs/core/instructions)، وكل تعليمة تستدعي برنامجاً.

تحدد البرامج منطق الأعمال لكل تعليمة. عند إرسال معاملة، يُنفّذ وقت تشغيل سولانا
تعليمات المعاملة بالترتيب. المعاملات ذرية. إما أن تنجح كل تعليمة في المعاملة، أو
تفشل المعاملة بأكملها.

توضّح الأمثلة في هذا القسم كيفية:

1. نقل SOL بين الحسابات
2. إنشاء سك رمز مميز جديد

## نقل SOL

المثال أدناه ينقل SOL من حساب إلى آخر. فقط البرنامج المحدد كمالك للحساب يمكنه تعديل بيانات الحساب أو خصم lamports من رصيده. حسابات المحافظ مملوكة من قِبل
[System Program](/developers/docs/core/programs/builtin-programs#the-system-program)، لذا فإن نقل SOL بين حسابات المحافظ يتطلب تعليمة تستدعي تعليمة
[transfer](https://github.com/anza-xyz/agave/blob/v2.1.11/programs/system/src/system_processor.rs#L183-L213)
الخاصة بـ System Program. يجب أيضاً أن يوقّع الحساب المصدر على المعاملة.

```ts title="Transfer SOL"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getTransferSolInstruction } from "@solana-program/system";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const receiver = await generateKeyPairSigner();

const transferInstruction = getTransferSolInstruction({
  source: client.payer,
  destination: receiver.address,
  amount: lamports(10_000_000n)
});

const result = await client.sendTransaction([transferInstruction]);

console.log("Transaction Signature:", result.context.signature);

const { value: senderBalance } = await client.rpc
  .getBalance(client.payer.address)
  .send();
const { value: receiverBalance } = await client.rpc
  .getBalance(receiver.address)
  .send();

console.log("Sender Balance:", senderBalance);
console.log("Receiver Balance:", receiverBalance);
```

<Note>
  **`createClient`**

  أنشئ عميل Kit للـ validator المحلي. يضيف `generatedPayer()` موقّع الدافع، ويضيف
  `solanaRpc()` قدرات RPC وإرسال المعاملات، ويضيف `rpcAirdrop()` الـ
  `client.airdrop`، ويموّل `airdropPayer()` الدافع برصيد اختباري من SOL.

  **`receiver`**

  أنشئ موقّعاً للحساب المستقبِل لـ SOL. لا يحتاج المستقبِل إلى توقيع هذه العملية.
  إذا لم يكن للعنوان المستقبِل حساب بالفعل، فإن استقبال SOL سيُنشئ حساباً نظامياً
  على ذلك العنوان.

  **`transferInstruction`**

  أنشئ تعليمة System Program التي تنقل lamports من الدافع العميل إلى المستلم.

  **`sendTransaction`**

  أرسل التعليمة كمعاملة. يجلب عميل Kit تجزئة كتلة حديثة، ويحدد دافع الرسوم، ويوقّع
  باستخدام الموقّعين المطلوبين، ويرسل المعاملة، وينتظر التأكيد.

  **`balances`**

  استرجع أرصدة المُرسِل والمستلم بعد تأكيد المعاملة.
</Note>

## إنشاء رمز مميز

يوضح المثال أدناه كيفية إنشاء mint account جديد باستخدام
[Token Extensions Program](/developers/docs/tokens/extensions). mint account هو الحساب الذي
يحدد الإعدادات العامة للرمز المميز، مثل الكسور العشرية، والإمداد، وصلاحية
الإصدار، وصلاحية التجميد.

يتطلب إنشاء mint account تعليمتين:

1. استدعاء System Program لإنشاء حساب جديد مملوك لـ Token Extensions Program.
2. استدعاء Token Extensions Program لتهيئة ذلك الحساب كـ mint.

```ts title="Create mint account"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getCreateAccountInstruction } from "@solana-program/system";
import {
  fetchMint,
  getInitializeMintInstruction,
  getMintSize,
  TOKEN_2022_PROGRAM_ADDRESS
} from "@solana-program/token-2022";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const mint = await generateKeyPairSigner();

const space = BigInt(getMintSize());

const rent = await client.rpc.getMinimumBalanceForRentExemption(space).send();

const createAccountInstruction = getCreateAccountInstruction({
  payer: client.payer,
  newAccount: mint,
  space,
  lamports: rent,
  programAddress: TOKEN_2022_PROGRAM_ADDRESS
});

const initializeMintInstruction = getInitializeMintInstruction({
  mint: mint.address,
  decimals: 2,
  mintAuthority: client.payer.address,
  freezeAuthority: client.payer.address,
  tokenProgram: TOKEN_2022_PROGRAM_ADDRESS
});

const result = await client.sendTransaction([
  createAccountInstruction,
  initializeMintInstruction
]);

console.log("Mint Address:", mint.address);
console.log("Transaction Signature:", result.context.signature);

const mintAccount = await fetchMint(client.rpc, mint.address);
console.log("Mint Account:", mintAccount);
```

<Note>
  **`createClient`**

  أنشئ عميل Kit وموّله للـ validator المحلي. يتولى الدافع الممول سداد rent الحساب
  ورسوم المعاملات.

  **`mint`**

  أنشئ موقّعاً لاستخدامه كعنوان لـ mint account الجديد. يُخوّل الموقّع إنشاء ذلك
  الحساب.

  **`space`**

  احسب عدد البايتات المطلوبة لـ mint account بدون أي امتدادات.

  **`rent`**

  احسب الـ lamports المطلوبة لجعل mint account معفياً من الـ rent.

  **`createAccountInstruction`**

  أنشئ تعليمة System Program التي تُنشئ mint account وتُسند الحساب إلى Token
  Extensions Program.

  **`initializeMintInstruction`**

  أنشئ تعليمة Token Extensions Program التي تكتب بيانات الإصدار الأولية في الحساب
  الجديد.

  **`sendTransaction`**

  أرسل كلا التعليمتين كمعاملة واحدة. يهم ترتيب التعليمات: يجب إنشاء الحساب قبل أن
  يمكن تهيئته.

  **`mintAccount`**

  استرجع mint account بعد التأكيد. تقرأ الدالة المساعدة الحساب وتُفكك تسلسل حقل
  البيانات الخاص بـ mint account إلى نوع Mint.
</Note>
