<Info>

`WithdrawExcessLamports` و `UnwrapLamports` متاحان عبر
[`@solana-program/token`](https://www.npmjs.com/package/@solana-program/token)
العميل. استدعاء Token Program عبر CPI ينطبق على البرامج الموجودة على السلسلة.

</Info>

## استرجاع Lamport

`WithdrawExcessLamports` يسترجع SOL الزائدة عن الحد الأدنى المعفى من الإيجار
من token account والمنافذ وحسابات متعددي التوقيعات. `UnwrapLamports` يحوّل
SOL المُغلَّفة في native token account إلى lamports.
