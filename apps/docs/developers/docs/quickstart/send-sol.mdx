Every change on Solana is a transaction: a list of instructions, signed by the
accounts they spend from. In this step you send 0.01 SOL from your wallet to a
new address.

## Send the transaction

Save this as `send-sol.ts` next to `config.ts` and run `npx tsx send-sol.ts`.

<Send />

What the code does:

- `getTransferSolInstruction(...)` builds one instruction for the System
  Program, the program that owns every wallet and moves SOL between them.
- `send(wallet, [transfer])`, from `config.ts`, does the rest:
  1. fetches a recent blockhash, which makes the transaction expire after about
     a minute if it doesn't land;
  2. sets your wallet as the fee payer and signs with it;
  3. sends the transaction and waits until the network confirms it.

The fee was 5,000 lamports (0.000005 SOL). To see the transaction, open the
`Explorer:` link the script prints. It opens the transaction in Solana Explorer
on devnet.
