On Solana you don't deploy a contract to create a token. You create a mint
account that the shared Token Program manages, then a token account for each
holder. In this step you do both and mint 1,000 tokens to yourself.

## Create and mint the token

Save this as `create-token.ts` next to `config.ts` and run
`npx tsx create-token.ts`.

<Token />

What the code does, in one transaction:

1. **Create the mint account.** `getCreateAccountInstruction` makes a new
   account owned by the Token Program, funded with the deposit (rent) that
   keeps it open. `getInitializeMintInstruction` makes it a mint with 2
   decimals, and your wallet as the mint authority, the only key that can
   create more.
2. **Create your token account.** `findAssociatedTokenPda` works out the
   standard token account address for your wallet and this mint, and
   `getCreateAssociatedTokenIdempotentInstruction` creates it.
3. **Mint 1,000 tokens.** `getMintToInstruction` adds 100,000 base units, which
   is 1,000 tokens with 2 decimals. The script reads the balance back and prints
   `Balance: 1000 tokens`.

If any instruction fails, none of them take effect.

To see your token, open the `Explorer:` link the script prints. It opens the
mint in Solana Explorer on devnet, with its supply, decimals, and mint
authority.
