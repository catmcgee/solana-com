A wallet is a key pair: a public address that anyone can pay, and a private key
that signs for it. In this step you create one, read its balance from devnet,
and get free test SOL (to pay fees) and test dollars (USDC, to send in the next
step).

## Set up a project

You need [Node.js](https://nodejs.org) 20.18 or later. Create a folder and
install Solana Kit and the clients for the programs this quickstart calls (the
System Program, the Token Program, and Token-2022):

```bash Terminal
mkdir solana-quickstart && cd solana-quickstart
npm init -y && npm pkg set type=module
npm install @solana/kit @solana-program/system @solana-program/token @solana-program/token-2022
```

Save this as `config.ts`. It connects to devnet, keeps your wallet in
`wallet.json`, and has a `send` helper you'll use in the next step.

## Read the balance

Save this as `balance.ts` and run it with `npx tsx balance.ts`. The first run
creates `wallet.json`, finds a balance of 0, and asks devnet for 1 SOL. Later
runs reuse the same wallet.

<Balance />

What the code does:

- `rpc.getBalance(address)` asks a devnet RPC node for the balance. Balances
  are in lamports; 1 SOL is 1,000,000,000 lamports.
- `airdrop(...)` asks devnet to send free test SOL to your address and waits
  until the transfer is confirmed. It prints the transaction signature.
- `rpc.getTokenAccountBalance(...)` reads your USDC. Dollars on Solana are
  tokens: your wallet holds USDC in a token account for the USDC mint. Until you
  get some, there's no token account yet, so the script prints `USDC: 0`.

## Get test dollars

Devnet USDC is free from Circle. Open the [Circle faucet](https://faucet.circle.com),
choose **USDC** and **Solana Devnet**, paste your wallet address (the script
printed it), and send. Then run `npx tsx balance.ts` again:

```text
USDC: 10
```

<Tip>
**Airdrop refused?** Devnet limits airdrops per address and per day. When it
refuses, the script prints this instead of a balance:

```text
Airdrop refused (devnet faucets are rate-limited). Get devnet SOL for <your address> at https://faucet.solana.com, then run this again.
```

Paste your wallet address into the [Solana faucet](https://faucet.solana.com)
to get test SOL, then run `npx tsx balance.ts` again.
</Tip>
