On Solana you don't deploy a contract to create an asset. You create a mint
account that a shared token program manages, then a token account for each
holder. In this step you create an asset called Example Fund (EXF), with its
name, symbol, and details stored onchain, and mint 1,000 units to yourself.

## Create and mint the asset

Save this as `create-asset.ts` next to `client.ts` and run
`npx tsx create-asset.ts`.

<Asset />

Your run prints a link to your own asset on devnet. Open it to see the mint in
Solana Explorer, with its name, symbol, supply, and mint authority.

What the code does:

1. **Create the asset.** `client.token2022.instructions.createMint(...)`
   creates a mint account owned by Token-2022, funded with the deposit (rent)
   that keeps it open, with 2 decimals and your wallet as the mint authority,
   the only key that can create more. Two extensions store the asset's
   metadata in the mint itself: `MetadataPointer` says where the metadata
   lives, and `TokenMetadata` holds the name, symbol, a link to more details,
   and any extra fields you add (here, `asset class: fund share`).
2. **Mint 1,000 units to yourself.** `mintToATA(...)` opens your token account
   for the asset, which holds your balance, and adds 100,000 base units, which
   is 1,000 units with 2 decimals.
3. **Send it.** `client.sendTransaction([...])` puts both in one transaction.
   If any instruction fails, none of them take effect.

The script then reads the mint back from the network and prints
`Name: Example Fund (EXF)` and `Supply: 1000 EXF`.
