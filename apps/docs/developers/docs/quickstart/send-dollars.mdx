Every change on Solana is a transaction: a list of instructions, signed by the
accounts they spend from. In this step you send 1 USDC from your wallet to a
new address. It settles in under a second, and the fee is a fraction of a cent,
paid in SOL.

## Send the transaction

Save this as `send-dollars.ts` next to `client.ts` and run
`npx tsx send-dollars.ts`, or run the commands in the **CLI** tab.

<Send />

Your run prints a link to your own transaction on devnet. Open it to see the
transaction in Solana Explorer.

What the code does:

- `tokenBalance(...)`, from `client.ts`, checks that you have at least 1 USDC
  before sending.
- `client.token.instructions.transferToATA(...)` builds two instructions:
  1. Open the recipient's USDC token account if it doesn't exist (and do
     nothing if it does). Your wallet pays its small deposit.
  2. Move 1 USDC: 1,000,000 base units, because USDC has 6 decimals. It's a
     `TransferChecked` instruction, so the program also checks the mint and
     decimals, and a wrong amount fails instead of sending 1,000 times too
     much.
- `.sendTransaction()` puts both in one transaction, sets your wallet as the
  fee payer, signs, sends it, and waits until the network confirms it. It
  returns the transaction's signature.

Both instructions run in one transaction, so the account is never opened
without the payment arriving.

<Tip>
**No devnet USDC yet?** The script prints where to get it instead of sending.
Get test USDC from the [Circle faucet](https://faucet.circle.com) (pick
**Solana Devnet**), as in [step 1](/developers/docs/quickstart/check-balance#get-test-dollars),
then run `npx tsx send-dollars.ts` again.
</Tip>
