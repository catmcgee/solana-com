Every change on Solana is a transaction: a list of instructions, signed by the
accounts they spend from. In this step you send 1 USDC from your wallet to a
new address. It settles in under a second, and the fee is a fraction of a cent,
paid in SOL.

## Send the transaction

Save this as `send-dollars.ts` next to `config.ts` and run
`npx tsx send-dollars.ts`.

<Send />

What the code does:

- `findAssociatedTokenPda(...)` works out the standard USDC token account for
  your wallet and for the recipient. A new address has no token account yet.
- `getCreateAssociatedTokenIdempotentInstruction(...)` opens the recipient's
  token account if it doesn't exist (and does nothing if it does). Your wallet
  pays its small deposit.
- `getTransferCheckedInstruction(...)` moves 1 USDC: 1,000,000 base units,
  because USDC has 6 decimals. "Checked" means the program also checks the
  mint and decimals, so a wrong amount fails instead of sending 1,000 times too
  much.
- `send(wallet, [openAccount, transfer])`, from `config.ts`, does the rest:
  1. fetches a recent blockhash, which makes the transaction expire after about
     a minute if it doesn't land;
  2. sets your wallet as the fee payer and signs with it;
  3. sends the transaction and waits until the network confirms it.

Both instructions run in one transaction, so the account is never opened
without the payment arriving. To see the transaction, open the `Explorer:` link
the script prints. It opens the transaction in Solana Explorer on devnet.

<Tip>
**No devnet USDC yet?** The script prints where to get it instead of sending.
Get test USDC from the [Circle faucet](https://faucet.circle.com) (pick
**Solana Devnet**), as in [step 1](/developers/docs/quickstart/check-balance#get-test-dollars),
then run `npx tsx send-dollars.ts` again.
</Tip>
