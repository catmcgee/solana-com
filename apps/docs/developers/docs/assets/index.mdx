## Tokenization

Solana gives tokenized assets confirmation in under a second, a network fee of a
fraction of a cent, and a token standard with built-in compliance controls:
transfer restrictions, pausing, confidential transfers, and permanent delegates.
On other chains these need custom smart contracts. These pages cover regulated
and real-world assets: who may hold them, how holders are verified, how they
settle, and how funds are priced.

### Issuance tools

| Tool                                                       | What it does                                                                                                         |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| [Mosaic](https://github.com/solana-foundation/mosaic)      | The Solana Foundation's open-source issuance toolkit: an SDK and templates for gated Token-2022 mints; pre-1.0       |
| [Token ACL](/developers/docs/tokenization/token-acl)       | Shared programs for delegated freeze authority and permissionless thaw against a gate, with a reference allow/block list gate |
| [Attestations](/developers/docs/tools/attestations)        | Onchain credentials bound to an address; the schema determines what is published                                     |
| [Solana Developer Platform](https://platform.solana.com)   | An API and dashboard for token issuance and payments on Solana                                                       |

### How it fits together

Tokenized assets on Solana are built on the [Token-2022 program](/developers/docs/tokens)
and its [extensions](/developers/docs/tokens/extensions), the same primitives documented
in the core docs. The tokenization guides are workflow-oriented: each page
walks through a task end to end and links down to the underlying extension
reference when you need the full API surface.
