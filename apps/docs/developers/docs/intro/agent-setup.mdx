These steps are written for a coding agent to follow. Run each command in the
user's project folder (the current working directory). Every command runs
without prompts. When you finish, tell the user what you installed and whether
they need to restart you.

People setting this up by hand can follow
[Build with AI agents](https://solana.com/developers/docs/intro/coding-with-agents)
instead.

## 1. Add the Solana MCP server

The server is `https://mcp.solana.com/mcp` (streamable HTTP, no API key). Run
the command for the agent you are:

- **Claude Code:**
  `claude mcp add --transport http solana-mcp https://mcp.solana.com/mcp`
- **Codex:** `codex mcp add solana-mcp --url https://mcp.solana.com/mcp`
- **Any other agent:** `npx add-mcp https://mcp.solana.com/mcp -a <agent> -y`,
  where `<agent>` is your name in `npx add-mcp list-agents`, for example
  `cursor`, `vscode`, `gemini-cli`, or `opencode`. If add-mcp reports that your
  agent only supports a global install (for example `windsurf`), add `-g`.

If you can't run shell commands, ask the user to add the server in your MCP
settings with the URL above.

## 2. Install the Solana skill

```bash
npx skills add https://github.com/solana-foundation/solana-dev-skill -a <agent> -y
```

Use the same `<agent>` name, for example `claude-code`, `codex`, or `cursor`.
The skill is copied into the project, for example
`.claude/skills/solana-dev/SKILL.md` for Claude Code.

## 3. Check that both work

- **MCP server:** run `claude mcp list` or `codex mcp list` and check that
  `solana-mcp` is listed. Other agents list it in their MCP settings. A new
  server is usually loaded only after a restart; once it is, call its
  `list_sections` tool, which returns the Solana documentation sources.
- **Skill:** run `npx skills list` and check that `solana-dev` is listed.

If either check fails, show the user the command output and stop.

## 4. Suggest a first task

Offer to follow the Solana Quickstart with the user:
[https://solana.com/developers/docs/quickstart.md](https://solana.com/developers/docs/quickstart.md).
In about 5 minutes it creates a wallet, checks its balance, sends SOL, and
creates a token on devnet, Solana's free public test network. It needs
Node.js 20.18 or later.
