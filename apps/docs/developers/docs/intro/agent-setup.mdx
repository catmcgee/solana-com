Do these steps in order. Run commands in the user's project folder. Ask before changing anything outside it.

1. **Add the Solana MCP server.** Run `npx add-mcp https://mcp.solana.com/mcp -n solana-mcp -g -y`. It finds the agents installed on this machine and adds the server to each, without prompting. If that fails, add it to yourself directly:
   - Claude Code: `claude mcp add --transport http solana-mcp https://mcp.solana.com/mcp`
   - Codex: `codex mcp add solana-mcp --url https://mcp.solana.com/mcp`
   - Cursor: add `{"mcpServers": {"solana-mcp": {"url": "https://mcp.solana.com/mcp"}}}` to `.cursor/mcp.json`.
   - VS Code: add `{"servers": {"solana-mcp": {"type": "http", "url": "https://mcp.solana.com/mcp"}}}` to `.vscode/mcp.json`.
   - Windsurf: add `{"mcpServers": {"solana-mcp": {"serverUrl": "https://mcp.solana.com/mcp"}}}` to `~/.codeium/windsurf/mcp_config.json`.
2. **Install the Solana skill.** Run `npx skills add https://github.com/solana-foundation/solana-dev-skill`.
3. **Check it works.** Use the Solana MCP to search the docs for "transaction fees" and summarise the answer in one sentence. If the MCP tool isn't available, tell the user to restart the agent and stop here.
4. **Tell the user what you did** in two lines, then offer to start the Quickstart (`/developers/docs/quickstart`): check a devnet balance, send SOL, and create a token. Ask before running anything that spends SOL. The Quickstart only uses devnet.
