This quickstart talks to devnet, Solana's public test network, from TypeScript
with [`@solana/kit`](/developers/docs/clients/official/javascript). Devnet SOL is
free and has no value, so nothing here costs money. It has three steps and takes
about 5 minutes.

1. **Check a balance.** Create a wallet, read its balance, and get free test SOL.
2. **Send SOL.** Build, sign, and send a transaction that pays another address.
3. **Create a token.** Create your own token and mint 1,000 of it to yourself.

## Two ways to follow it

**In your browser.** Every step shows its code with a **Run** button that
steps through what the code prints on a local test network. Nothing to install.

**On your machine.** You need [Node.js](https://nodejs.org) 20.18 or later and a
terminal. Each step is one file you run with `npx tsx`. You don't need the
Solana CLI, Rust, or Anchor.
