Follow this to get an intuition for how Solana works. You don't need to know
anything about Solana yet. In five short steps on devnet, Solana's public test
network, you create a wallet and send test dollars (USDC). Then you create an
asset, like a share or a currency, send it to someone, and freeze their account
to apply a simple control. Devnet SOL and USDC are free, so nothing here costs
money.

## Or follow along locally

<Tabs>
  <Tab title="Start with an agent">
    ```bash Terminal
    npx add-mcp https://mcp.solana.com/mcp -n solana-mcp -g -y
    ```

    Ask your agent to follow this Quickstart with you.
  </Tab>
  <Tab title="Follow along manually">
    Install the local tools with one command. The installer sets up Rust, the
    Solana CLI, Anchor CLI, Surfpool CLI, Node.js, and Yarn. Pick your
    operating system:

    <div className="sol-os-tabs">
      <Tabs>
        <Tab title="macOS">
          Run the installer in Terminal:

          ```bash Terminal
          curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
          ```
        </Tab>
        <Tab title="Linux">
          Run the installer in your terminal. It detects supported package
          managers and installs their system dependencies automatically.

          ```bash Terminal
          curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
          ```
        </Tab>
        <Tab title="Windows">
          The tools run in Linux on Windows (WSL).

          1. In Windows PowerShell, install WSL, then restart Windows if
             prompted:

             ```powershell PowerShell
             wsl --install
             ```

          2. Open the **Ubuntu** terminal and run the installer there:

             ```bash Terminal
             curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
             ```

          See [Install dependencies](/developers/docs/intro/installation/dependencies)
          for the complete WSL setup.
        </Tab>
      </Tabs>
    </div>

    You can [review the installer
    source](https://github.com/solana-developers/solana-install/blob/main/install.sh)
    before running it. Then restart your terminal so the new commands are on
    your `PATH`, and check every tool:

    ```bash Terminal
    rustc --version
    solana --version
    anchor --version
    surfpool --version
    node --version
    yarn --version
    ```

## What you'll do

The code is TypeScript with [`@solana/kit`](/developers/docs/clients/official/javascript)
and its plugins. Each step is one short file you run with `npx tsx`, and shows
what it prints. Each step also has a **CLI** tab that does the same with the
Solana CLI and `spl-token`.
