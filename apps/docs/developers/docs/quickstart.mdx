<Stepper />

Follow this to get an intuition for how Solana works. You don't need to know
anything about Solana yet. In three short steps you create a wallet, send a
transaction, and create a token on devnet, Solana's public test network.
Devnet SOL is free, so nothing here costs money.

<Playground />

## Or follow along locally

<Tabs>
  <Tab title="Start with an agent">
    ```bash Terminal
    npx add-mcp https://mcp.solana.com/mcp -n solana-mcp -g -y
    ```

    Ask your agent to follow this Quickstart with you.
  </Tab>
  <Tab title="Follow along manually">
    ```bash Terminal
    curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
    ```

    [Then continue to step 1 →](/developers/docs/quickstart/check-balance)
  </Tab>
</Tabs>

## What you'll do

The code is TypeScript with [`@solana/kit`](/developers/docs/clients/official/javascript).
Each step is one file you run with `npx tsx`, and shows what it prints.
