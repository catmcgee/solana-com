## Receiving Address Convention

On Solana, **share your wallet address, not your token account**. It is typical
for the sender to derive the appropriate
[Associated Token Account (ATA)](/developers/docs/payments/how-payments-work#token-accounts)
for whatever token they're sending (see
[Sending Payments](/developers/docs/payments/send-payments) for more details).

**Example:** Share `7EcDhS...` (your wallet), not `9xKpQ...` (your USDC token
account).

<Note>
  For point-of-sale and e-commerce, see [Solana Pay](/developers/docs/tools/solana-pay)
  for QR codes and payment URLs (Commerce Kit has
  [Solana Pay helpers](/developers/docs/tools/commerce-kit/quickstart/solana-pay)), or
  [PaymentButton](/developers/docs/tools/commerce-kit/quickstart/payment-button) for
  drop-in React components. To charge for HTTP API access, follow
  [Paywall an endpoint](/developers/docs/payments/paywall-api) or use the
  [Pay.sh](/developers/docs/payments/pay-sh) gateway.
</Note>

## Integration Options

| Approach                                                            | Best For                      | Complexity |
| ------------------------------------------------------------------- | ----------------------------- | ---------- |
| [PaymentButton](/developers/docs/tools/commerce-kit/quickstart/payment-button) | React apps, quick integration | Low        |
| [Pay.sh](/developers/docs/payments/pay-sh)                                     | Paid APIs and subscriptions   | Low        |
| [Solana Pay](/developers/docs/tools/solana-pay)                                | QR codes, payment links, POS  | Medium     |
| [Direct RPC](/developers/docs/payments/interacting-with-solana)                | Custom flows, full control    | Higher     |

## Verification

After receiving a payment, verify it on your server before you fulfil the
order: [Confirm payments from your backend](/developers/docs/payments/checkout/backend)
shows the checks, and
[Verification Tools](/developers/docs/payments/accept-payments/verification-tools) covers
balance checks, subscriptions, and transaction history. For
high-volume applications, see
[Indexing](/developers/docs/payments/accept-payments/indexing) for production-grade
transaction monitoring.
