Solana has a single global state, ~400ms block times, and sub-cent fees, and
every program (DEXs, lending markets, oracles, and perps) can be composed within
a single atomic transaction. This section
is the workflow layer for building financial applications; it links down to
[How Solana works](/developers/docs/core/transactions) and the
[cookbook](/developers/cookbook) for the underlying mechanics.
