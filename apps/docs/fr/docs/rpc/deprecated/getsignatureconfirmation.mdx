---
title: Méthode RPC getSignatureConfirmation
sidebarTitle: getSignatureConfirmation
mode: wide
---

Récupère le statut actuel d'une signature de transaction (traitée, confirmée,
finalisée).

<Warning>
  **Méthode dépréciée**

  Cette méthode devrait être supprimée dans `solana-core` v2.0. Veuillez
  utiliser [getSignatureStatuses](/docs/rpc/http/getsignaturestatuses) à la
  place.
</Warning>
