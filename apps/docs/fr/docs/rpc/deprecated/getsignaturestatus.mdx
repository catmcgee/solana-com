---
title: Méthode RPC getSignatureStatus
sidebarTitle: getSignatureStatus
mode: wide
---

Récupère l'état actuel d'une signature de transaction (traitée, confirmée,
finalisée).

<Warning>
  **Méthode dépréciée**

  Cette méthode devrait être supprimée dans `solana-core` v2.0. Veuillez
  utiliser [getSignatureStatuses](/docs/rpc/http/getsignaturestatuses) à la
  place.
</Warning>
