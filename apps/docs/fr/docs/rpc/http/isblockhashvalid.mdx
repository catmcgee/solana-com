title: Méthode RPC isBlockhashValid
sidebarTitle: isBlockhashValid
---

Indique si un blockhash est toujours valide ou non

<Warning>
  **Restriction de version**

  Cette méthode n'est disponible que dans `solana-core` v1.9 ou plus récent.
  Veuillez utiliser
  [getFeeCalculatorForBlockhash](/docs/rpc/deprecated/getfeecalculatorforblockhash)
  pour `solana-core` v1.8 et versions antérieures.
</Warning>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 45,
      "method": "isBlockhashValid",
      "params": [
        "J7rBdM6AecPDEZp8aPq5iPSNKVkU5Q76F3oAV4eW5wsW",
        {
          "commitment": "processed"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc, type Blockhash } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let blockhash = "J7rBdM6AecPDEZp8aPq5iPSNKVkU5Q76F3oAV4eW5wsW";

  let isValid = await rpc.isBlockhashValid(blockhash as Blockhash).send();

  console.log(isValid);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let blockhash = "J7rBdM6AecPDEZp8aPq5iPSNKVkU5Q76F3oAV4eW5wsW";

  let isValid = await connection.isBlockhashValid(blockhash);

  console.log(isValid);
  ```

  ```rs Rust
  use std::str::FromStr;

  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::{commitment_config::CommitmentConfig, hash::Hash};

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let blockhash = Hash::from_str("J7rBdM6AecPDEZp8aPq5iPSNKVkU5Q76F3oAV4eW5wsW")?;

      let is_valid = client
          .is_blockhash_valid(&blockhash, CommitmentConfig::finalized())
          .await?;

      println!("{:#?}", is_valid);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="blockhash" type="string" required>
  Le blockhash du bloc à évaluer, sous forme de chaîne encodée en base-58
</ParamField>

<ParamField body="config" type="object">
  Objet de configuration contenant les champs suivants :

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      Le commitment décrit le niveau de finalisation d'un bloc à un moment donné. Voir
      [Configuration de l'engagement d'état](/docs/rpc#configuring-state-commitment).
    </ParamField>

    <ParamField body="minContextSlot" type="number">
      Le slot minimum auquel la requête peut être évaluée
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="bool">
  Si le blockhash est toujours valide
</ResponseField>
