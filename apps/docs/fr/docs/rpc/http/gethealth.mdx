---
title: Méthode RPC getHealth
sidebarTitle: getHealth
---

Renvoie l'état de santé actuel du nœud. Un nœud en bon état est un nœud qui se
trouve à moins de `HEALTH_CHECK_SLOT_DISTANCE` slots du dernier slot confirmé
par le cluster.

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getHealth"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let health = await rpc.getHealth().send();

  console.log(health);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let health = client.get_health().await?;

      println!("{:#?}", health);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json title="En bon état"
  {
    "jsonrpc": "2.0",
    "result": "ok",
    "id": 1
  }
  ```

  ```json title="En mauvais état"
  {
    "jsonrpc": "2.0",
    "error": {
      "code": -32005,
      "message": "Node is unhealthy",
      "data": { "numSlotsBehind": 42 }
    },
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

None

## Result

<ResponseField name="result" type="string" post={["En bon état"]}>
  Si le nœud est en bon état : "ok"
</ResponseField>

<ResponseField name="result" type="object" post={["En mauvais état"]}>
  Si le nœud est en mauvais état, une réponse d'erreur JSON RPC est renvoyée. Les
  détails de la réponse d'erreur sont **INSTABLES** et peuvent changer à l'avenir
</ResponseField>
