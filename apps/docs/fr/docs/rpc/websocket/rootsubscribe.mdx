title: Méthode RPC rootSubscribe
sidebarTitle: rootSubscribe
---

Abonnez-vous pour recevoir une notification chaque fois qu'une nouvelle racine
est définie par le validator.

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Aucun**

### Result

<ResponseField name="result" type="integer">
  identifiant d'abonnement (nécessaire pour se désabonner)
</ResponseField>

#### Format de notification :

Le résultat est le numéro du dernier slot racine.

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
