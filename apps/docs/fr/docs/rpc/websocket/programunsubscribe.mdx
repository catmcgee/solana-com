---
title: Méthode RPC programUnsubscribe
sidebarTitle: programUnsubscribe
---

Se désabonner des notifications de changement de compte appartenant à un
programme

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "programUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  identifiant de l'abonnement au compte à annuler
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  message de succès du désabonnement
</ResponseField>
