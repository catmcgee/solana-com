Chaque [transaction](/docs/core/transactions) Solana nécessite des frais payés
en SOL. Les frais comportent deux composantes : des **frais de base** et des
**frais de priorisation** optionnels. Les frais de base rémunèrent les
validateurs pour le travail cryptographique de vérification des signatures. Les
frais de priorisation augmentent la probabilité que le leader actuel planifie
votre transaction avant les transactions concurrentes.

## Points clés

- **Frais de base** : par signature, répartis 50 % brûlés / 50 % au validateur.
- **Frais de priorisation** :
  `ceil(compute_unit_price * compute_unit_limit / 1,000,000)` lamports. 100 % reversés au
  validator. Dans le prochain
  [format v1](/docs/core/transactions/versioned-transactions#v1-message-format)
  le frais est un total absolu en lamports défini dans la configuration du message.
