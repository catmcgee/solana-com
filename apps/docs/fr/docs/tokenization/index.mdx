Solana est conçu pour émettre et gérer des actifs tokenisés à grande échelle :
finalité en moins d'une seconde, frais inférieurs à 0,001 $, et un standard de token avec des
contrôles de conformité natifs - restrictions de transfert, suspension, transferts
confidentiels et délégués permanents - qui sur d'autres blockchains nécessitent des smart
contracts personnalisés.

## Comment tout s'articule

Les actifs tokenisés sur Solana sont construits sur le [programme Token-2022](/docs/tokens)
et ses [extensions](/docs/tokens/extensions) - les mêmes primitives documentées
dans la documentation principale. Cette section est orientée flux de travail : chaque page décrit une
tâche de bout en bout et renvoie vers la référence de l'extension sous-jacente lorsque vous
avez besoin de la surface API complète.
