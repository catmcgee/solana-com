## and_bool

`and_bool` retourne le ET binaire des arguments gauche et droit.

### Entrées

| Nom   | Type | Description          |
| ----- | ---- | -------------------- |
| `lhs` | bool | Une valeur booléenne |
| `rhs` | bool | Une valeur booléenne |

### Sortie

| Nom     | Type | Description                                          |
| ------- | ---- | ---------------------------------------------------- |
| `value` | bool | Le résultat d'un ET binaire entre les deux arguments |

```hcl
output "my_bool" {
  value = false && true
}
// > my_bool: false
```

## div

`div` retourne la division entière de l'argument gauche par l'argument droit, en
arrondissant tout reste vers le bas à l'entier le plus proche.

### Entrées

| Nom   | Type    | Description  |
| ----- | ------- | ------------ |
| `lhs` | integer | Le dividende |
| `rhs` | integer | Le diviseur  |

### Sortie

| Nom     | Type    | Description                                             |
| ------- | ------- | ------------------------------------------------------- |
| `value` | integer | Le résultat de la division du dividende par le diviseur |

```hcl
output "my_int" {
  value = 11 / -3
}
// > my_int: -3
```

## eq

`eq` retourne `true` si les arguments de gauche et de droite sont égaux et
`false` s'ils ne le sont pas.

### Entrées

| Nom   | Type | Description  |
| ----- | ---- | ------------ |
| `lhs` | any  | Toute valeur |
| `rhs` | any  | Toute valeur |

### Sortie

| Nom     | Type | Description                                                     |
| ------- | ---- | --------------------------------------------------------------- |
| `value` | bool | Le résultat d'une vérification d'égalité entre les deux entrées |

```hcl
output "is_eq" {
  value = "arg" == "arg"
}
// > is_eq: true
```

## neq

`neq` retourne `true` si les arguments de gauche et de droite ne sont pas égaux
et `false` dans le cas contraire.

### Entrées

| Nom   | Type | Description                |
| ----- | ---- | -------------------------- |
| `lhs` | any  | Une valeur à comparer      |
| `rhs` | any  | Une valeur à comparer avec |

### Sortie

| Nom     | Type | Description                                                          |
| ------- | ---- | -------------------------------------------------------------------- |
| `value` | bool | Le résultat d'une vérification d'égalité niée entre les deux entrées |

```hcl
output "is_neq" {
  value = 2 != 3
}
// > is_neq: true
```
