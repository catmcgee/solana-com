## Objectif du projet

Connecter les mécanismes de transfert privé à un flux d'application orienté utilisateur.

## Points de contrôle

- Répertorier les actions utilisateur et les opérations onchain qui les sous-tendent.
- Noter où les hypothèses de confidentialité sont importantes dans le flux de l'interface utilisateur et du backend.
- Vérifier comment vous expliquerez les états d'échec aux utilisateurs.
