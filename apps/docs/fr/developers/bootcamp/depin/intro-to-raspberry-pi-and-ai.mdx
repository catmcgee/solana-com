## Objectif de la leçon

Familiarisez-vous avec l'environnement Raspberry Pi et comprenez pourquoi il constitue un point de départ utile pour les expériences Solana de type DePIN.

## Points de contrôle

- Identifier les composants matériels essentiels de la configuration.
- Noter la place de l'IA dans le flux de travail global de l'appareil.
- Décider du type de prototype physique que vous souhaitez construire.
