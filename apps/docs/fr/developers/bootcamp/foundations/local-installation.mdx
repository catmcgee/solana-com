## Ce que vous allez construire

Un environnement de développement local avec tous les outils nécessaires pour exécuter des exemples et
déployer sur le devnet.

## Liste de vérification de la configuration

- Installez Rust et la CLI Solana.
- Installez Node.js et votre gestionnaire de paquets.
- Vérifiez les versions de la CLI et la configuration du portefeuille.
- Exécutez une commande de base pour valider votre environnement.

## Critères de validation

Vous pouvez exécuter des commandes d'outillage en local sans erreurs d'environnement.
