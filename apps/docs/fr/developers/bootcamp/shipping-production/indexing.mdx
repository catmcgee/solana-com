## Objectif de la leçon

Concevoir la couche de lecture qui transforme les données brutes onchain en quelque chose que les produits peuvent utiliser rapidement et de manière fiable.

## Points de contrôle

- Identifier les vues qui doivent être servies à partir de données indexées.
- Décider comment la fraîcheur et la cohérence des données doivent être gérées.
- Lister les modes de défaillance qui rendraient l'interface utilisateur d'un produit trompeuse.
