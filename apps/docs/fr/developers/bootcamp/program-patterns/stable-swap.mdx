## Objectif du projet

Découvrez comment les règles d'échange, la liquidité et les hypothèses de tarification influencent le comportement du protocole.

## Points de contrôle

- Identifier les invariants du pool qui doivent toujours être respectés.
- Retracer le chemin d'échange depuis la saisie de l'utilisateur jusqu'aux soldes mis à jour.
- Vérifier comment les frais et le glissement sont exposés dans le code et l'interface utilisateur.
