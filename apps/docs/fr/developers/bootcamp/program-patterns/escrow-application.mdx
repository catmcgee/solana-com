## Objectif du projet

Modéliser une interaction d'entiercement avec des règles claires de propriété et de libération des fonds.

## Points de contrôle

- Lister toutes les transitions d'état de l'entiercement avant d'écrire le code.
- Vérifier le modèle d'autorité pour les actions de création, d'acceptation, d'annulation et de règlement.
- Confirmer les dérivations PDA et les attentes de signataire pour chaque étape.
