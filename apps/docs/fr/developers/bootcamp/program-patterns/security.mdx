## Objectif de la revue

Transformez les modèles de bootcamp que vous avez déjà utilisés en une liste de contrôle de sécurité reproductible.

## Points de contrôle

- Vérifiez les contraintes de compte et les hypothèses relatives aux signataires.
- Recherchez les vérifications d'autorité manquantes et les transitions d'état inattendues.
- Identifiez au moins un invariant que vous souhaitez que les tests appliquent à l'avenir.
