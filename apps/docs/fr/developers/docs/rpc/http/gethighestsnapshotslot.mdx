---
title: Méthode RPC getHighestSnapshotSlot
sidebarTitle: getHighestSnapshotSlot
---

Renvoie les informations sur le slot le plus élevé pour lequel le nœud possède
des snapshots.

Cette méthode trouve le slot de snapshot complet le plus élevé, et le slot de
snapshot incrémental le plus élevé _basé sur_ le slot de snapshot complet, s'il
en existe un.

<Warning>
  **Restriction de version**

  Cette méthode n'est disponible que dans `solana-core` v1.9 ou plus récent.
  Veuillez utiliser [getSnapshotSlot](/developers/docs/rpc/deprecated/getsnapshotslot) pour
  `solana-core` v1.8 et versions antérieures.
</Warning>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getHighestSnapshotSlot"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let hightestSnapshotSlot = await rpc.getHighestSnapshotSlot().send();

  console.log(hightestSnapshotSlot);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let highest_snapshot_slot = client.get_highest_snapshot_slot().await?;

      println!("{:#?}", highest_snapshot_slot);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Snapshot
  {
    "jsonrpc": "2.0",
    "result": {
      "full": 100,
      "incremental": 110
    },
    "id": 1
  }
  ```

  ```json title="Pas de snapshot"
  {
    "jsonrpc": "2.0",
    "error": {
      "code": -32008,
      "message": "No snapshot"
    },
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

None

## Result

<ResponseField name="result" type="object" post={["Snapshot"]}>
  Lorsque le nœud possède un snapshot, cela renvoie un objet JSON avec les champs
  suivants :

  <Expandable title="properties" defaultOpen>
    <ResponseField name="full" type="u64">
      Le slot de snapshot complet le plus élevé
    </ResponseField>

    <ResponseField name="incremental" type="u64 | null">
      Le slot de snapshot incrémental le plus élevé _basé sur_ `full`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="result" type="object" post={["Pas de snapshot"]}>
  Si le nœud n'a pas de snapshot, une réponse d'erreur JSON RPC est renvoyée.
</ResponseField>
