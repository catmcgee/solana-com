sidebarTitle: slotsUpdatesUnsubscribe

Se désabonner des notifications de mise à jour des slots

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotsUpdatesUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  identifiant d'abonnement à annuler
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  message de succès du désabonnement
</ResponseField>
