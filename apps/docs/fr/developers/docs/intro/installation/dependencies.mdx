Un guide pour configurer votre environnement de développement Solana local.
Apprenez à installer Rust, la CLI Solana et Anchor Framework sur Windows (WSL),
Linux et Mac. Utilisez ce guide si vous préférez installer chaque dépendance
individuellement, ou si l'[installation rapide](/developers/docs/intro/installation/)
échoue pour une raison quelconque.

### Prérequis

<AccordionGroup>
<Accordion title="Windows">

Pour développer des programmes Solana sur Windows, vous **devez** utiliser
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). Après avoir installé WSL, toutes les autres dépendances seront installées
via le terminal Linux.

Pour installer WSL, exécutez la commande suivante dans Windows PowerShell :

```bash Terminal
wsl --install
```

Le processus d'installation vous invitera à créer un compte utilisateur par
défaut.

<Frame caption="Installation WSL">
  ![Installation WSL](/docs-assets/assets/docs/intro/installation/wsl-install.png)
</Frame>

Par défaut, WSL installe Ubuntu. Vous pouvez ouvrir un terminal Linux en
recherchant « Ubuntu » dans la barre de recherche.

<Frame caption="WSL Ubuntu">
  ![WSL Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-search.png)
</Frame>

Si votre terminal Ubuntu ressemble à l'image ci-dessous, vous pourriez
rencontrer un problème où `ctrl + v` (raccourci clavier pour coller) ne
fonctionne pas dans le terminal.

<Frame caption="Terminal Ubuntu">
  ![Terminal Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)
</Frame>

Si vous rencontrez ce problème, ouvrez Windows Terminal en recherchant «
Terminal » dans la barre de recherche.

<Frame caption="Windows Terminal">
  ![Windows Terminal](/docs-assets/assets/docs/intro/installation/wsl-windows-terminal.png)
</Frame>

Ensuite, fermez Windows Terminal et rouvrez un terminal Linux en recherchant à
nouveau Ubuntu. Le terminal devrait maintenant ressembler à l'image ci-dessous,
où `ctrl + v` (raccourci clavier pour coller) fonctionne.

<Frame caption="Terminal Ubuntu">
  ![Terminal Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)
</Frame>

Si vous utilisez VS Code,
l'[extension WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial) vous
permet d'utiliser WSL et VS Code ensemble.

<Frame caption="Configuration WSL dans VS Code">
  ![Configuration WSL dans VS Code](/docs-assets/assets/docs/intro/installation/wsl-vscode.png)
</Frame>

Vous verrez ce qui suit dans la barre d'état de VS Code :

<Frame caption="WSL: Ubuntu">
  ![WSL: Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-vscode-ubuntu.png)
</Frame>

Une fois WSL configuré, vous êtes prêt à :

- Effectuer l'[installation rapide](/developers/docs/quickstart) en utilisant le
  terminal Ubuntu (Linux)
- Installer [Rust](#install-rust), la [CLI Solana](#install-solana-cli) et la
  [CLI Anchor](#install-anchor-cli) individuellement, comme décrit ci-dessous

</Accordion>
<Accordion title="Linux">

<Tabs>
<Tab title=".deb">
Si vous êtes sur Debian ou des alternatives dérivées de Debian comme Ubuntu ou Mint, suivez les étapes ci-dessous :

1. Mettez à jour les listes de paquets pour vous assurer que tous les paquets
   sont à jour :

```bash Terminal
sudo apt-get update
```

2. Installez les dépendances suivantes :

```bash Terminal
sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Note>
Si vous rencontrez l'erreur suivante lors de l'installation de `protobuf-compiler`, assurez-vous
d'abord d'exécuter `sudo apt-get update`

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Note>

  </Tab>

    <Tab title=".rpm">
    Pour les dérivés RHEL comme Fedora ou Red Hat Linux, suivez les étapes suivantes.

Mettez à jour les listes de paquets pour obtenir les versions plus récentes des
paquets en exécutant la commande.

    ```bash Terminal
    sudo dnf upgrade --refresh
    ```

    Ensuite, installez les dépendances suivantes :

    ```bash Terminal
    sudo dnf group install c-development development-tools \
    && sudo dnf install pkg-config openssl-devel
    ```

  </Tab>
</Tabs>

<Steps titleSize="h3">
<Step title="Installer Rust">

Les développeurs créent des programmes Solana en utilisant le langage de
programmation [Rust](https://www.rust-lang.org/).

1. Installez Rust en utilisant [rustup](https://www.rust-lang.org/tools/install)
   en saisissant la commande suivante dans votre terminal :

```bash Terminal
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

Après une installation réussie, vous verrez le message suivant :

<AccordionGroup>
<Accordion title="Message d'installation réussie de Rust">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</AccordionGroup>

2. Rechargez votre variable d'environnement PATH pour inclure le répertoire bin
   de [Cargo](https://github.com/rust-lang/cargo) :

```bash Terminal
. "$HOME/.cargo/env"
```

3. Vérifiez que l'installation a réussi.

```bash Terminal
rustc --version
```

Vous verrez une sortie comme celle-ci :

```
rustc 1.86.0 (05f9846f8 2025-03-31)
```

</Step>
<Step title="Installer Solana CLI">

Solana CLI fournit tous les outils nécessaires pour créer et déployer des
programmes Solana.

1. Installez la suite d'outils Solana CLI en utilisant la commande
   d'installation officielle :

```bash Terminal
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Note>
  Vous pouvez remplacer `stable` par la balise de version correspondant à la
  version logicielle de votre version souhaitée (par exemple `v2.0.3`), ou
  utiliser l'un des trois noms de canaux symboliques : `stable`, `beta`, ou
  `edge`.
</Note>

2. Ajoutez une variable d'environnement PATH

Une première installation de Solana CLI peut vous inviter à ajouter une variable
d'environnement `PATH`. Pour ce faire, fermez et rouvrez votre terminal ou
exécutez la commande suivante dans votre shell :

```
export PATH="/Users/test/.local/share/solana/install/active_release/bin:$PATH"
```

3. Mettez à jour votre variable d'environnement PATH

<Tabs>
<Tab title="Windows & Linux">

Si vous utilisez **Linux** ou **WSL**, vous devez ajouter le binaire Solana CLI
à votre PATH afin que la commande soit disponible dans votre terminal. Pour ce
faire, suivez les étapes ci-dessous :

**a.** Vérifiez quel shell vous utilisez :

```bash Terminal
echo $SHELL
```

- Si la sortie contient `/bash`, utilisez `.bashrc`.
- Si la sortie contient `/zsh`, utilisez `.zshrc`.

**b.** Exécutez la commande appropriée en fonction de votre shell.

Pour Bash (`bashrc`) :

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

Pour Zsh (`zshrc`) :

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

</Tab>
<Tab title="Mac">

Si vous utilisez un Mac avec `zsh`, l'exécution de la commande `export PATH` par
défaut enregistrée lors de l'installation ne persiste pas une fois que vous
fermez votre terminal. Au lieu de cela, ajoutez le PATH à votre fichier de
configuration shell en exécutant la commande suivante :

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.zshrc
```

<Note>
  Les étapes ci-dessus ne s'appliquent pas aux utilisateurs de `bash`, car les
  modifications apportées à la variable PATH persisteront par défaut.
</Note>

</Tab>
</Tabs>

4. Redémarrez votre terminal ou exécutez la commande suivante pour actualiser la
   session du terminal :

```bash Terminal
source ~/.bashrc # If using Bash
source ~/.zshrc # If using Zsh
```

5. Vérifiez que l'installation a réussi en vérifiant la version de l'interface
   de ligne de commande Solana :

```bash Terminal
solana --version
```

Vous verrez une sortie comme celle-ci :

```
solana-cli 2.2.12 (src:0315eb6a; feat:1522022101, client:Agave)
```

<Note>

Vous pouvez consulter toutes les versions disponibles sur le
[dépôt Github d'Agave](https://github.com/anza-xyz/agave/releases). Agave est le
client validator d'[Anza](https://www.anza.xyz/), anciennement connu sous le nom
de client validator de Solana Labs.

</Note>

5. Mettez à jour l'interface de ligne de commande Solana vers la dernière
   version, si nécessaire _(Optionnel)_

```bash Terminal
agave-install update
```

</Step>
<Step title="Installer l'interface de ligne de commande Anchor">

[Anchor](https://www.anchor-lang.com/) est un framework de développement de
programmes Solana. Le framework Anchor exploite les macros Rust pour simplifier
le processus d'écriture de programmes Solana.

#### Prérequis

Le fichier de test par défaut du projet Anchor (TypeScript) créé avec la
commande `anchor init` nécessite Node.js et Yarn. (Le modèle de test Rust
est disponible en utilisant `anchor init --test-template rust`)

<AccordionGroup>
<Accordion title="Installation de Node">

1. Installez Node en utilisant
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm) en exécutant la
   commande suivante :

```bash Terminal
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/master/install.sh | bash
```

2. Redémarrez votre terminal et confirmez que la commande `nvm` s'exécute avec
   succès :

```bash Terminal
command -v nvm
```

3. Utilisez `nvm` pour installer Node :

```bash Terminal
nvm install node
```

4. Vérifiez que l'installation a réussi en vérifiant la version de Node :

```bash Terminal
node --version
```

Vous verrez une sortie comme celle-ci :

```
v23.7.0
```

</Accordion>
<Accordion title="Installation de Yarn">

1. Installez Yarn :

```bash Terminal
npm install --global yarn
```

2. Vérifiez que l'installation a réussi en vérifiant la version de Yarn :

```bash Terminal
yarn --version
```

Vous verrez la sortie suivante :

```
1.22.1
```

</Accordion>
</AccordionGroup>

#### Installation

Vous pouvez installer l'interface en ligne de commande (CLI) et les outils
Anchor de deux manières :

- Anchor Version Manager (AVM) — méthode d'installation recommandée
- Sans AVM — installation directe depuis GitHub

<Tabs>
<Tab title="AVM">

Le gestionnaire de versions Anchor (AVM) vous permet d'installer et de gérer
différentes versions d'Anchor sur votre système et de mettre à jour facilement
les versions d'Anchor à l'avenir. Pour installer Anchor à l'aide d'AVM, suivez
les étapes ci-dessous :

1. Installez AVM avec la commande suivante :

```bash Terminal
curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  Confirmez qu'AVM s'est installé avec succès :

```bash Terminal
avm --version
```

3. Installez l'interface de ligne de commande Anchor à l'aide d'AVM :

Pour installer la dernière version :

```bash Terminal
avm install latest
avm use latest
```

Pour installer une version spécifique, spécifiez le numéro de version :

```bash Terminal
avm install 0.30.1
avm use 0.30.1
```

<Warning>

Lors de l'installation de l'Anchor CLI sur Linux ou WSL, vous pouvez rencontrer cette erreur :

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

Si vous voyez ce message d'erreur, suivez ces étapes :

1. Installez les dépendances listées dans la section
   [Linux](/developers/docs/intro/installation/dependencies) en haut de cette
   page.
2. Réessayez d'installer l'Anchor CLI.

</Warning>

4. Vérifiez que l'installation a réussi en contrôlant la version de l'interface
   de ligne de commande Anchor :

```bash Terminal
anchor --version
```

Vous verrez une sortie comme celle-ci :

```
anchor-cli 0.31.1
```

<Info>

N'oubliez pas d'exécuter la commande `avm use` pour déclarer la version
de l'interface de ligne de commande Anchor à exécuter sur votre système.

- Si vous avez installé la version `latest`, exécutez `avm use latest`.
- Si vous avez installé la version `0.30.1`, exécutez `avm use 0.30.1`.

</Info>

</Tab>

<Tab title="Without AVM">

1. Installez une version spécifique du CLI Anchor avec la commande suivante :

```bash Terminal
cargo install --git https://github.com/solana-foundation/anchor --tag v0.30.1 anchor-cli
```

2. Vérifiez que l'installation a réussi en contrôlant la version du CLI Anchor :

```bash Terminal
anchor --version
```

Vous verrez une sortie comme celle-ci :

```
anchor-cli 0.31.1
```

</Tab>
</Tabs>

1. Installez Surfpool avec la commande suivante :

```bash Terminal
curl -sL https://run.surfpool.run/ | bash
```

2. Vérifiez que l'installation a réussi en contrôlant la version du CLI Surfpool
   :

```bash Terminal
surfpool --version
```

Vous verrez une sortie comme celle-ci :

```
surfpool 0.12.0
```
