## ripemd160

`ripemd160` calcule le hachage Ripemd160 d'une valeur.

### Entrées

| Nom     | Type                    | Description                               |
| ------- | ----------------------- | ----------------------------------------- |
| `value` | buffer \| array[buffer] | La valeur encodée en hexadécimal à hacher |

### Sortie

| Nom     | Type   | Description       |
| ------- | ------ | ----------------- |
| `value` | string | Le résultat haché |

```hcl
output "hashed_data" {
    value = ripemd160(encode_hex("hello, world"))
}
// > hashed_data: 0xa3201f82fca034e46d10cd7b27e174976e241da2
```

| ------- | ------ | ----------------- |
| `value` | string | Le résultat haché |

```hcl
output "hashed_data" {

```

## keccak256

`std::keccak256` calcule le hachage keccak256 d'une valeur.

### Entrées

| Nom     | Type   | Description                  |
| ------- | ------ | ---------------------------- |
| `value` | string | La valeur de chaîne à hacher |

### Sortie

| Nom     | Type   | Description       |
| ------- | ------ | ----------------- |
| `value` | string | Le résultat haché |

```hcl
output "hashed_data" {
    value = keccak256("hello, world")
}
// > hashed_data: 0x29bf7021020ea89dbd91ef52022b5a654b55ed418c9e7aba71ef3b43a51669f2
```
