У попередньому розділі ви дізналися, як
[читати дані з мережі Solana](/docs/intro/quick-start/reading-from-network)
шляхом отримання акаунтів. Запис даних у мережу Solana потребує
[транзакції](/docs/core/transactions). Транзакція містить одну або кілька
[інструкцій](/docs/core/instructions), і кожна інструкція викликає програму.

Програми визначають бізнес-логіку для кожної інструкції. Коли ви надсилаєте
транзакцію, середовище виконання Solana виконує інструкції транзакції по
порядку. Транзакції є атомарними. Або кожна інструкція в транзакції виконується
успішно, або вся транзакція завершується невдачею.

Приклади в цьому розділі показують, як:

1. Переказати SOL між акаунтами
2. Створити нове карбування токенів

## Переказ SOL

Наведений нижче приклад переказує SOL з одного рахунку на інший. Лише програма,
призначена власником рахунку, може змінювати дані рахунку або списувати
lamports з його балансу. Гаманці належать
[System Program](/docs/core/programs/builtin-programs#the-system-program), тому
переказ SOL між гаманцями вимагає інструкції, яка викликає
інструкцію
[transfer](https://github.com/anza-xyz/agave/blob/v2.1.11/programs/system/src/system_processor.rs#L183-L213)
System Program. Вихідний рахунок також повинен підписати транзакцію.

```ts title="Transfer SOL"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getTransferSolInstruction } from "@solana-program/system";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const receiver = await generateKeyPairSigner();

const transferInstruction = getTransferSolInstruction({
  source: client.payer,
  destination: receiver.address,
  amount: lamports(10_000_000n)
});

const result = await client.sendTransaction([transferInstruction]);

console.log("Transaction Signature:", result.context.signature);

const { value: senderBalance } = await client.rpc
  .getBalance(client.payer.address)
  .send();
const { value: receiverBalance } = await client.rpc
  .getBalance(receiver.address)
  .send();

console.log("Sender Balance:", senderBalance);
console.log("Receiver Balance:", receiverBalance);
```

<Note>
  **`createClient`**

  Створіть клієнт Kit для локального validator. `generatedPayer()` додає
  підписувача платника, `solanaRpc()` додає можливості RPC та надсилання
  транзакцій, `rpcAirdrop()` додає `client.airdrop`, а `airdropPayer()` поповнює
  рахунок платника тестовим SOL.

  **`receiver`**

  Згенеруйте підписувача для акаунта, який отримує SOL. Одержувачу не потрібно
  підписувати цей переказ. Якщо за адресою одержувача ще немає акаунта, отримання
  SOL створить системний акаунт за цією адресою.

  **`transferInstruction`**

  Створіть інструкцію System Program, яка переказує lamports від платника клієнта
  до отримувача.

  **`sendTransaction`**

  Надішліть інструкцію як транзакцію. Клієнт Kit отримує останній blockhash,
  встановлює платника комісії, підписує з необхідними підписантами, надсилає
  транзакцію та очікує підтвердження.

  **`balances`**

  Отримайте баланси відправника та отримувача після підтвердження транзакції.
</Note>

## Створення токена

Наведений нижче приклад створює новий mint account за допомогою
[Token Extensions Program](/docs/tokens/extensions). mint account — це обліковий
запис, який визначає глобальні параметри токена, такі як кількість десяткових
знаків, обсяг емісії, повноваження на випуск та повноваження на заморожування.

Для створення mint account потрібні дві інструкції:

1. Викликати System Program, щоб створити новий обліковий запис, яким володіє
   Token Extensions Program.
2. Викликати Token Extensions Program, щоб ініціалізувати цей обліковий запис як
   mint.

```ts title="Create mint account"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getCreateAccountInstruction } from "@solana-program/system";
import {
  fetchMint,
  getInitializeMintInstruction,
  getMintSize,
  TOKEN_2022_PROGRAM_ADDRESS
} from "@solana-program/token-2022";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const mint = await generateKeyPairSigner();

const space = BigInt(getMintSize());

const rent = await client.rpc.getMinimumBalanceForRentExemption(space).send();

const createAccountInstruction = getCreateAccountInstruction({
  payer: client.payer,
  newAccount: mint,
  space,
  lamports: rent,
  programAddress: TOKEN_2022_PROGRAM_ADDRESS
});

const initializeMintInstruction = getInitializeMintInstruction({
  mint: mint.address,
  decimals: 2,
  mintAuthority: client.payer.address,
  freezeAuthority: client.payer.address,
  tokenProgram: TOKEN_2022_PROGRAM_ADDRESS
});

const result = await client.sendTransaction([
  createAccountInstruction,
  initializeMintInstruction
]);

console.log("Mint Address:", mint.address);
console.log("Transaction Signature:", result.context.signature);

const mintAccount = await fetchMint(client.rpc, mint.address);
console.log("Mint Account:", mintAccount);
```

<Note>
  **`createClient`**

  Створіть і поповніть клієнт Kit для локального validator. Платник із поповненим
  рахунком оплачує rent облікового запису та комісії за транзакції.

  **`mint`**

  Згенеруйте підписанта для використання як адреси нового mint account. Підписант
  авторизує створення цього облікового запису.

  **`space`**

  Обчисліть кількість байтів, необхідних для mint account без розширень.

  **`rent`**

  Обчисліть кількість lamport, необхідних для звільнення mint account від сплати
  rent.

  **`createAccountInstruction`**

  Сформуйте інструкцію System Program, яка створює mint account і призначає
  обліковий запис Token Extensions Program.

  **`initializeMintInstruction`**

  Сформуйте інструкцію Token Extensions Program, яка записує початкові дані mint у
  новий обліковий запис.

  **`sendTransaction`**

  Надішліть обидві інструкції як одну транзакцію. Порядок інструкцій важливий:
  акаунт потрібно створити до того, як його можна буде ініціалізувати.

  **`mintAccount`**

  Отримайте mint account після підтвердження. Допоміжна функція зчитує акаунт і
  десеріалізує поле даних mint account у тип Mint.
</Note>

    ```ts title="Create mint account" focus={12-23}
    import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
    import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
    import { getCreateAccountInstruction } from "@solana-program/system";
    import {
      fetchMint,
      getInitializeMintInstruction,
      getMintSize,
      TOKEN_2022_PROGRAM_ADDRESS
    } from "@solana-program/token-2022";

    const client = await createClient()
      .use(generatedPayer())
      .use(
        solanaRpc({
          rpcUrl: "http://localhost:8899",
          rpcSubscriptionsUrl: "ws://localhost:8900"
        })
      )
      .use(rpcAirdrop())
      .use(airdropPayer(lamports(1_000_000_000n)));

    const mint = await generateKeyPairSigner();
    ```

    ```ts title="Mint account size and rent"
    const space = BigInt(getMintSize());

    const rent = await client.rpc.getMinimumBalanceForRentExemption(space).send();
    ```

    ```ts title="Create account instruction"
    const createAccountInstruction = getCreateAccountInstruction({
      payer: client.payer,
      newAccount: mint,
      space,
      lamports: rent,
      programAddress: TOKEN_2022_PROGRAM_ADDRESS
    });
    ```

    ```ts title="Initialize mint instruction"
    const initializeMintInstruction = getInitializeMintInstruction({
      mint: mint.address,
      decimals: 2,
      mintAuthority: client.payer.address,
      freezeAuthority: client.payer.address,
      tokenProgram: TOKEN_2022_PROGRAM_ADDRESS
    });
    ```

    ```ts title="Send transaction"
    const result = await client.sendTransaction([
      createAccountInstruction,
      initializeMintInstruction
    ]);
    ```

    ```ts title="Create mint account" focus={45-48} expandable
    console.log("Mint Address:", mint.address);
    console.log("Transaction Signature:", result.context.signature);
    ```
