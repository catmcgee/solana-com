title: RPC-метод getSlotLeader
sidebarTitle: getSlotLeader
---

Повертає поточного лідера slot

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getSlotLeader",
      "params": [
        {
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let slotLeader = await rpc.getSlotLeader().send();

  console.log(slotLeader);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let slotLeader = await connection.getSlotLeader();

  console.log(slotLeader);
  ```
</RequestExample>

<ResponseExample>

## Parameters

<ParamField body="0" type="object">
  Об'єкт конфігурації, що містить такі поля:

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      Параметр commitment описує, наскільки фіналізованим є блок у певний момент часу.
      Дивіться
      [Налаштування підтвердження стану](/docs/rpc#configuring-state-commitment).
    </ParamField>

    <ParamField body="minContextSlot" type="number">
      Мінімальний slot, на якому може бути оцінений запит
    </ParamField>
  </Expandable>
</ParamField>

</ResponseField>
