## Мета перевірки

Перетворіть шаблони буткемпу, які ви вже використовували, на повторюваний контрольний список безпеки.

## Контрольні точки

- Перевірте обмеження облікових записів та припущення щодо підписантів.
- Шукайте відсутні перевірки прав доступу та неочікувані переходи між станами.
- Зафіксуйте принаймні один інваріант, який ви хочете забезпечити тестами в подальшому.
