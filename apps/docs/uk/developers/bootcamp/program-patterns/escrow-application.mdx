## Мета проєкту

Змоделюйте взаємодію через ескроу з чіткими правилами власності та вивільнення коштів.

## Контрольні точки

- Перелічіть усі переходи між станами ескроу перед написанням коду.
- Перевірте модель авторизації для дій створення, прийняття, скасування та врегулювання.
- Підтвердьте деривації PDA та очікування підписувачів для кожного кроку.
