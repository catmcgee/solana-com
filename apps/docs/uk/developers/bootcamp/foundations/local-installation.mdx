## Що ви створите

Локальне середовище розробника з усіма необхідними інструментами для запуску прикладів і
розгортання в devnet.

## Список перевірки налаштувань

- Встановіть Rust і Solana CLI.
- Встановіть Node.js і ваш менеджер пакетів.
- Перевірте версії CLI та конфігурацію гаманця.
- Виконайте базову команду для перевірки вашого середовища.

## Критерії завершення

Ви можете виконувати команди інструментів локально без помилок середовища.
