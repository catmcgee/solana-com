## Мета уроку

Побудуйте міст сповіщень, який робить активність смарт-контракту корисною за межами самого застосунку.

## Контрольні точки

- Визначте, які події мають генерувати повідомлення в Telegram.
- Вирішіть, який контекст потрібен кожному повідомленню, щоб воно було придатне до дії.
- Продумайте обмеження частоти запитів, збої доставки та шум для оператора.
