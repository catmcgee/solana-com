## Мета уроку

Налаштуйте надійне локальне середовище, щоб перейти від перегляду відео до
реального розроблення на Solana.

## Контрольні точки

- Встановіть основний CLI та допоміжні інструменти розробки.
- Переконайтеся, що ваша машина може виконувати очікуваний локальний робочий процес.
- Зафіксуйте всі проблеми з налаштуванням, які потрібно вирішити перед тим, як рухатися далі.
