Сім концепцій утворюють основу розробки на Solana. Почніть з акаунтів
та програм, потім простежте, як інструкції перетворюються на транзакції. PDA, CPI та
комісії доповнюють цю модель виконання.

<Columns cols={2}>
  <Card title="Акаунти" href="/developers/docs/core/accounts">
    Solana зберігає весь стан в акаунтах — сховищі типу «ключ-значення» з 32-байтними
    адресами. Кожен акаунт має п'ять полів: lamports, data, owner, executable
    та rent_epoch.
  </Card>
  <Card title="Програми" href="/developers/docs/core/programs">
    Смартконтракти Solana, скомпільовані у sBPF. Програми не мають стану, і весь
    змінний стан зберігається в окремих акаунтах даних, що передаються через інструкції.
  </Card>
  <Card title="Інструкції" href="/developers/docs/core/instructions">
    Запит на виконання однієї програми, що містить ідентифікатор програми, список акаунтів
    та байти даних. Кілька інструкцій об'єднуються в одну
    транзакцію.
  </Card>
  <Card title="Транзакції" href="/developers/docs/core/transactions">
    Атомарна одиниця виконання на Solana. Містить підписи та повідомлення
    (адреси акаунтів, останній хеш блоку та скомпільовані інструкції). Максимум 1232
    байти або 4096 у форматі v1.
  </Card>
  <Card title="Комісії" href="/developers/docs/core/fees">
    Базова комісія — 5 000 lamports за підпис, плюс необов'язкова пріоритетна комісія
    на основі запитуваних обчислювальних одиниць. Максимум 1,4 млн обчислювальних одиниць на транзакцію.
  </Card>
  <Card title="Program Derived Addresses (PDAs)" href="/developers/docs/core/pda">
    Детерміновані адреси, похідні від ідентифікатора програми та seeds. Тільки програма-власник
    може підписувати від імені PDA через invoke_signed.
  </Card>
  <Card title="Cross-Program Invocations (CPIs)" href="/developers/docs/core/cpi">
    Виклик однієї програми іншою через invoke або invoke_signed. Привілеї підписувача та права на запис
    поширюються на викликану програму. Максимальна глибина стеку інструкцій — 5 (верхній рівень
    плюс CPI).
  </Card>
</Columns>
