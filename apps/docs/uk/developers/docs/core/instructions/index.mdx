Інструкція — це запит на виконання певної функції у програмі Solana. Інструкції
є фундаментальним будівельним блоком для операцій в мережі. Кожна інструкція
вказує лише одну програму для виклику, необхідні облікові записи та масив байтів
даних, які програма інтерпретує (зазвичай дискримінатор для визначення обробника
інструкції, за яким слідують серіалізовані аргументи). Логіка виконання кожної
інструкції зберігається в [програмі](/developers/docs/core/programs), де кожна програма
визначає власний набір інструкцій. Для взаємодії з мережею Solana одна або
кілька інструкцій додаються до [транзакції](/developers/docs/core/transactions) і
надсилаються в мережу для обробки.

## Ключові факти

- **Одна програма**: кожна інструкція спрямована рівно на одну програму через
  `program_id`.
- **Метадані облікового запису**: масив `accounts` надає
  [`AccountMeta`](/developers/docs/core/instructions/instruction-structure#account-metadata)
  для кожного облікового запису, який інструкція читає або записує.
- **Непрозорі дані**: поле `data` є масивом байтів, формат якого визначається
  цільовою програмою.
