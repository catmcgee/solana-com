Методи для маніпуляцій з часом та доступу до системних змінних. Кожен гетер sysvar
має відповідний сетер; структури є простими Go-дзеркалами джерела Solana.

## Маніпуляції з годинником

### WarpToSlot

```go
func (s *LiteSVM) WarpToSlot(slot uint64) error
```

Перемотати внутрішній годинник до певного slot.

```go
before, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("current slot: %d", before.Slot)

if err := svm.WarpToSlot(10_000_000); err != nil {
    t.Fatal(err)
}

after, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("new slot:     %d", after.Slot)
```

### Clock

```go
// sysvar is github.com/gagliardetto/solana-go/sysvar
type Clock struct {
    Slot                uint64
    EpochStartTimestamp int64
    Epoch               uint64
    LeaderScheduleEpoch uint64
    UnixTimestamp       int64
}

func (s *LiteSVM) Clock() (*sysvar.Clock, error)
```

Зчитати sysvar Clock.

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("slot=%d epoch=%d unix=%d", c.Slot, c.Epoch, c.UnixTimestamp)
```

### SetClock

```go
func (s *LiteSVM) SetClock(c *sysvar.Clock) error
```

Перезаписати sysvar Clock. Зчитайте його, змініть поля та запишіть назад, якщо вам потрібен
контроль над `Epoch` або `UnixTimestamp` (які `WarpToSlot` не оновлює).

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
c.Slot = 1_000
c.Epoch = 10
c.UnixTimestamp = 1_735_689_600
if err := svm.SetClock(c); err != nil {
    t.Fatal(err)
}
```

<Info>
  `WarpToSlot` оновлює лише `Slot`. Використовуйте `SetClock`, коли ваша програма зчитує
  `Epoch` або `UnixTimestamp` зі sysvar Clock.
</Info>

## Epoch Rewards

```go
type EpochRewards struct {
    DistributionStartingBlockHeight uint64
    NumPartitions                   uint64
    ParentBlockhash                 solana.Hash
    TotalPoints                     bin.Uint128 // u128 total_points
    TotalRewards                    uint64
    DistributedRewards              uint64
    Active                          bool
}

func (s *LiteSVM) EpochRewards() (*sysvar.EpochRewards, error)
func (s *LiteSVM) SetEpochRewards(e *sysvar.EpochRewards) error
```

`total_points` є `u128` на стороні Solana; `litesvm-go` надає обидві половини
явно, щоб Go-розробникам не потрібна була бібліотека u128. Для значень, що вміщуються в 64
біти, `TotalPointsHi` дорівнює `0`, а `TotalPointsLo` — саме значення.

### SlotHistory

`SlotHistory` — це бітовий вектор ~128 КБ; `litesvm-go` надає його як дескриптор, а не
як зріз.

```go
sh := sysvar.NewSlotHistory()

sh.Add(42)

switch sh.Check(42) {
case sysvar.SlotHistoryFound:
    // ...
case sysvar.SlotHistoryNotFound:
    // ...
case sysvar.SlotHistoryTooOld:
    // ...
case sysvar.SlotHistoryFuture:
    // ...
}

if err := svm.SetSlotHistory(sh); err != nil {
    t.Fatal(err)
}
```

| Метод                                           | Опис                                |
| ------------------------------------------------ | ------------------------------------------ |
| `litesvm.NewSlotHistory() (*SlotHistory, error)` | Порожній дескриптор                               |
| `sh.Add(slot uint64)`                            | Записати slot                              |
| `sh.Check(slot uint64) SlotHistoryCheck`         | `Future` / `TooOld` / `Found` / `NotFound` |
| `sh.Oldest() uint64`                             | Найстаріший відстежуваний slot                        |
| `sh.Newest() uint64`                             | Найновіший відстежуваний slot                        |
| `sh.NextSlot() uint64`                           | Наступний slot для запису                        |
| `sh.SetNextSlot(slot uint64) error`              | Перевизначити маркер наступного slot              |
| `sh.Close()`                                     | Звільнити дескриптор                         |
| `svm.SlotHistory() (*SlotHistory, error)`        | Зчитати у новий дескриптор                   |
| `svm.SetSlotHistory(*SlotHistory) error`         | Встановити на SVM                         |

## Тестування логіки, залежної від часу

Використовуйте `WarpToSlot` для простого просування на основі slot, `SetClock` — для повного контролю:

```go
func TestTimeLockedVault(t *testing.T) {
    svm, err := litesvm.New()
    if err != nil {
        t.Fatal(err)
    }
    defer svm.Close()

    const unlockSlot = uint64(10_000)

    // Setup: create the time-locked account ...

    // Test 1: Try to withdraw before unlock (should fail)
    before, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("current slot: %d", before.Slot)
    // ... attempt withdrawal, expect failure ...

    // Warp time forward past unlock slot
    if err := svm.WarpToSlot(unlockSlot + 1); err != nil {
        t.Fatal(err)
    }

    // Test 2: Try to withdraw after unlock (should succeed)
    after, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("new slot: %d", after.Slot)
    // ... attempt withdrawal, expect success ...
}
```
