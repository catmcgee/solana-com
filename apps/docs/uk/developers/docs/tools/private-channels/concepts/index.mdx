---
title: Концепції
description: Основні концепції протоколу Private Channels
---

Ці сторінки пояснюють, як працює Private Channels зсередини. Розробникам,
які інтегруються з існуючим екземпляром, слід спочатку прочитати **Channel Lifecycle**.
Операторам та всім, хто створює інструменти для операторів, також слід ознайомитися з
довідником **Sparse Merkle Tree**.

- **[Channel Lifecycle](/developers/docs/tools/private-channels/concepts/channels)** —
  учасники, ролі та процес від депозиту до виведення коштів
- **[Sparse Merkle Tree](/developers/docs/tools/private-channels/concepts/smt)** — як
  докази виведення перевіряються в мережі для запобігання подвійним витратам
- **[Authentication & Roles](/developers/docs/tools/private-channels/concepts/auth)** — JWT-автентифікація,
  RBAC та верифікація гаманця
