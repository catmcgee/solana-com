## Семантика годинника

<Warning>
  **Мітки часу в мілісекундах; годинник повертає секунди**

  `surfnet_timeTravel`'s `absoluteTimestamp` is in **мілісекундах**, like
  JavaScript's `Date.now()`, but the `Clock` sysvar that programs read reports
  **секунди**. Passing a value straight from the clock back into the cheatcode
  lands in early 1970 — and since the clock only moves forward, the call is
  rejected rather than ignored. Multiply by 1000 first.
</Warning>

Щодо еквівалентів чіткодів годинника на рівні SDK, дивіться
[Подорож у часі](/developers/docs/tools/surfpool/sdk/time-travel).
