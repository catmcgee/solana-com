## ripemd160

`ripemd160` обчислює хеш Ripemd160 від значення.

### Вхідні дані

| Ім'я    | Тип                     | Опис                                   |
| ------- | ----------------------- | -------------------------------------- |
| `value` | buffer \| array[buffer] | Значення у hex-кодуванні для хешування |

### Вихідні дані

| Ім'я    | Тип    | Опис                |
| ------- | ------ | ------------------- |
| `value` | string | Результат хешування |

```hcl
output "hashed_data" {
    value = ripemd160(encode_hex("hello, world"))
}
// > hashed_data: 0xa3201f82fca034e46d10cd7b27e174976e241da2
```

## sha256

`sha256` обчислює хеш sha256 від значення.

### Вхідні дані

| Ім'я    | Тип                     | Опис                                   |
| ------- | ----------------------- | -------------------------------------- |
| `value` | buffer \| array[buffer] | Значення у hex-кодуванні для хешування |

### Вихідні дані

| Ім'я    | Тип    | Опис                |
| ------- | ------ | ------------------- |
| `value` | string | Результат хешування |

```hcl
output "hashed_data" {
    value = sha256(encode_hex("hello, world"))
}
// > hashed_data: 0x09ca7e4eaa6e8ae9c7d261167129184883644d07dfba7cbfbc4c8a2e08360d5b
```

## keccak256

`std::keccak256` обчислює хеш keccak256 від значення.

### Вхідні дані

| Ім'я    | Тип    | Опис                           |
| ------- | ------ | ------------------------------ |
| `value` | string | Рядкове значення для хешування |

### Вихідні дані

| Ім'я    | Тип    | Опис                |
| ------- | ------ | ------------------- |
| `value` | string | Результат хешування |

```hcl
output "hashed_data" {
    value = keccak256("hello, world")
}
// > hashed_data: 0x29bf7021020ea89dbd91ef52022b5a654b55ed418c9e7aba71ef3b43a51669f2
```
