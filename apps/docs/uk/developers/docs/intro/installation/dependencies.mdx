Посібник з налаштування локального середовища розробки Solana. Дізнайтеся, як
встановити Rust, Solana CLI та Anchor Framework на Windows (WSL), Linux та Mac.
Використовуйте цей посібник, якщо ви віддаєте перевагу встановленню кожної
залежності окремо, або якщо [швидке встановлення](/developers/docs/intro/installation/) з
якоїсь причини не спрацювало.

### Передумови

<AccordionGroup>
<Accordion title="Windows">

Для розробки програм Solana на Windows ви **повинні** використовувати
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). Після встановлення WSL всі інші залежності встановлюватимуться через
термінал Linux.

Щоб встановити WSL, виконайте наступну команду в Windows PowerShell:

```bash Terminal
wsl --install
```

Процес встановлення запропонує вам створити обліковий запис користувача за
замовчуванням.

<Frame caption="Встановлення WSL">
  ![Встановлення WSL](/docs-assets/assets/docs/intro/installation/wsl-install.png)
</Frame>

За замовчуванням WSL встановлює Ubuntu. Ви можете відкрити термінал Linux,
шукаючи "Ubuntu" у рядку пошуку.

<Frame caption="WSL Ubuntu">
  ![WSL Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-search.png)
</Frame>

Якщо ваш термінал Ubuntu виглядає як на зображенні нижче, ви можете зіткнутися з
проблемою, коли `ctrl + v` (комбінація клавіш для вставки) не працює в
терміналі.

<Frame caption="Термінал Ubuntu">
  ![Термінал Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)
</Frame>

Якщо ви зіткнулися з цією проблемою, відкрийте Windows Terminal, шукаючи
"Terminal" у рядку пошуку.

<Frame caption="Windows Terminal">
  ![Windows Terminal](/docs-assets/assets/docs/intro/installation/wsl-windows-terminal.png)
</Frame>

Далі закрийте Windows Terminal і знову відкрийте термінал Linux, знову шукаючи
Ubuntu. Тепер термінал повинен виглядати як на зображенні нижче, де `ctrl + v`
(комбінація клавіш для вставки) працює.

<Frame caption="Термінал Ubuntu">
  ![Термінал Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)
</Frame>

Якщо ви використовуєте VS Code,
[розширення WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial)
дозволяє вам використовувати WSL та VS Code разом.

<Frame caption="Налаштування WSL у VS Code">
  ![Налаштування WSL у VS Code](/docs-assets/assets/docs/intro/installation/wsl-vscode.png)
</Frame>

Ви побачите наступне в рядку стану VS Code:

<Frame caption="WSL: Ubuntu">
  ![WSL: Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-vscode-ubuntu.png)
</Frame>

Після налаштування WSL ви готові або:

- Завершити [швидке встановлення](/developers/docs/quickstart), використовуючи
  термінал Ubuntu (Linux)
- Встановити [Rust](#install-rust), [Solana CLI](#install-solana-cli) та
  [Anchor CLI](#install-anchor-cli) окремо, як описано нижче

</Accordion>
<Accordion title="Linux">

<Tabs>
<Tab title=".deb">
Якщо ви використовуєте Debian або похідні від Debian альтернативи, такі як Ubuntu або Mint, виконайте наступні кроки:

1. Оновіть списки пакетів, щоб переконатися, що всі пакети актуальні:

```bash Terminal
sudo apt-get update
```

2. Встановіть наступні залежності:

```bash Terminal
sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Note>
Якщо ви зіткнулися з наступною помилкою під час встановлення `protobuf-compiler`, переконайтеся,
що ви спочатку виконали `sudo apt-get update`

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Note>

  </Tab>

    <Tab title=".rpm">
    Для похідних від RHEL, таких як Fedora або Red Hat Linux, виконайте наступні кроки.

Оновіть списки пакетів, щоб отримати новіші версії пакетів, виконавши команду.

    ```bash Terminal
    sudo dnf upgrade --refresh
    ```

    Далі встановіть наступні залежності:

    ```bash Terminal
    sudo dnf group install c-development development-tools \
    && sudo dnf install pkg-config openssl-devel
    ```

  </Tab>
</Tabs>

<Step title="Встановлення Rust">

Розробники створюють програми Solana, використовуючи мову програмування
[Rust](https://www.rust-lang.org/).

1. Встановіть Rust за допомогою
   [rustup](https://www.rust-lang.org/tools/install), ввівши наступну команду у
   вашому терміналі:

```bash Terminal
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

Після успішного встановлення ви побачите таке повідомлення:

<AccordionGroup>
<Accordion title="Повідомлення про успішне встановлення Rust">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</AccordionGroup>

2. Перезавантажте змінну середовища PATH, щоб включити директорію bin
   [Cargo](https://github.com/rust-lang/cargo):

```bash Terminal
. "$HOME/.cargo/env"
```

3. Переконайтеся, що встановлення пройшло успішно.

```bash Terminal
rustc --version
```

Ви побачите вивід, схожий на такий:

```
rustc 1.86.0 (05f9846f8 2025-03-31)
```

</Step>
<Step title="Встановлення Solana CLI">

Solana CLI надає всі інструменти, необхідні для створення та розгортання програм
Solana.

1. Встановіть набір інструментів Solana CLI за допомогою офіційної команди
   встановлення:

```bash Terminal
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Note>
  Ви можете замінити `stable` на тег релізу, що відповідає версії програмного
  забезпечення бажаного релізу (наприклад, `v2.0.3`), або використати одну з
  трьох символічних назв каналів: `stable`, `beta` або `edge`.
</Note>

2. Додайте змінну середовища PATH

Під час першого встановлення Solana CLI може з'явитися запит на додавання
змінної середовища `PATH`. Для цього закрийте та знову відкрийте термінал або
виконайте наступну команду у вашій оболонці:

```
export PATH="/Users/test/.local/share/solana/install/active_release/bin:$PATH"
```

3. Оновіть змінну середовища PATH

<Tabs>
<Tab title="Windows & Linux">

Якщо ви використовуєте **Linux** або **WSL**, вам потрібно додати бінарний файл
Solana CLI до вашого PATH, щоб команда була доступна у вашому терміналі. Для
цього виконайте наступні кроки:

**a.** Перевірте, яку оболонку ви використовуєте:

```bash Terminal
echo $SHELL
```

- Якщо вивід містить `/bash`, використовуйте `.bashrc`.
- Якщо вивід містить `/zsh`, використовуйте `.zshrc`.

**б.** Виконайте відповідну команду залежно від вашої оболонки.

Для Bash (`bashrc`):

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

Для Zsh (`zshrc`):

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

</Tab>
<Tab title="Mac">

Якщо ви використовуєте Mac з `zsh`, виконання стандартної команди `export PATH`,
яка виводиться під час встановлення, не зберігається після закриття терміналу.
Натомість додайте PATH до файлу конфігурації вашої оболонки, виконавши наступну
команду:

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.zshrc
```

<Note>
  Наведені вище кроки не стосуються користувачів `bash`, оскільки зміни змінної
  PATH зберігатимуться за замовчуванням.
</Note>

</Tab>
</Tabs>

4. Перезапустіть термінал або виконайте наступну команду, щоб оновити сесію
   терміналу:

```bash Terminal
source ~/.bashrc # If using Bash
source ~/.zshrc # If using Zsh
```

5. Переконайтеся, що встановлення пройшло успішно, перевіривши версію Solana
   CLI:

```bash Terminal
solana --version
```

Ви побачите вивід, схожий на наступний:

```
solana-cli 2.2.12 (src:0315eb6a; feat:1522022101, client:Agave)
```

<Note>

Ви можете переглянути всі доступні версії в
[репозиторії Agave на Github](https://github.com/anza-xyz/agave/releases). Agave
— це клієнт validator від [Anza](https://www.anza.xyz/), раніше відомий як
клієнт validator Solana Labs.

</Note>

5. Оновіть Solana CLI до останньої версії за потреби _(Опціонально)_

```bash Terminal
agave-install update
```

</Step>
<Step title="Встановлення Anchor CLI">

[Anchor](https://www.anchor-lang.com/) — це фреймворк для розробки програм
Solana. Фреймворк Anchor використовує макроси Rust для спрощення процесу
написання програм Solana.

#### Передумови

Стандартний тестовий файл проєкту Anchor (TypeScript), створений командою
`anchor init`, потребує Node.js та Yarn. (Шаблон тестів Rust доступний за
допомогою `anchor init --test-template rust`)

<AccordionGroup>
<Accordion title="Встановлення Node">

1. Встановіть Node за допомогою
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm), виконавши
   наступну команду:

```bash Terminal
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/master/install.sh | bash
```

2. Перезапустіть термінал і переконайтеся, що команда `nvm` виконується успішно:

```bash Terminal
command -v nvm
```

3. Використайте `nvm` для встановлення Node:

```bash Terminal
nvm install node
```

4. Переконайтеся, що встановлення пройшло успішно, перевіривши версію Node:

```bash Terminal
node --version
```

Ви побачите вивід, схожий на наступний:

```
v23.7.0
```

</Accordion>
<Accordion title="Встановлення Yarn">

1. Встановіть Yarn:

```bash Terminal
npm install --global yarn
```

2. Переконайтеся, що встановлення пройшло успішно, перевіривши версію Yarn:

```bash Terminal
yarn --version
```

Ви побачите наступний вивід:

```
1.22.1
```

</Accordion>
</AccordionGroup>

#### Встановлення

Ви можете встановити Anchor CLI та інструменти двома способами:

- Anchor Version Manager (AVM) — рекомендований спосіб встановлення
- Без AVM — встановлення безпосередньо з GitHub

<Tabs>
<Tab title="AVM">

Anchor Version Manager (AVM) дозволяє встановлювати та керувати різними версіями
Anchor у вашій системі та легко оновлювати версії Anchor у майбутньому. Щоб
встановити Anchor за допомогою AVM, виконайте наступні кроки:

1. Встановіть AVM за допомогою наступної команди:

```bash Terminal
curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  Підтвердьте успішне встановлення AVM:

```bash Terminal
avm --version
```

3. Встановіть Anchor CLI за допомогою AVM:

Щоб встановити останню версію:

```bash Terminal
avm install latest
avm use latest
```

Щоб встановити конкретну версію, вкажіть номер версії:

```bash Terminal
avm install 0.30.1
avm use 0.30.1
```

<Warning>

Під час встановлення Anchor CLI на Linux або WSL ви можете зіткнутися з такою помилкою:

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

Якщо ви бачите це повідомлення про помилку, виконайте такі кроки:

1. Встановіть залежності, перелічені в розділі
   [Linux](/developers/docs/intro/installation/dependencies) на початку цієї
   сторінки.
2. Повторіть спробу встановлення Anchor CLI.

</Warning>

4. Перевірте успішність встановлення, перевіривши версію Anchor CLI:

```bash Terminal
anchor --version
```

Ви побачите вивід, схожий на наступний:

```
anchor-cli 0.31.1
```

<Info>

Не забудьте виконати команду `avm use`, щоб оголосити версію Anchor CLI,
яка буде запускатися у вашій системі.

- Якщо ви встановили версію `latest`, виконайте `avm use latest`.
- Якщо ви встановили версію `0.30.1`, виконайте `avm use 0.30.1`.

</Info>

</Tab>

<Tab title="Without AVM">

1. Встановіть конкретну версію Anchor CLI за допомогою наступної команди:

```bash Terminal
cargo install --git https://github.com/solana-foundation/anchor --tag v0.30.1 anchor-cli
```

2. Перевірте, що встановлення пройшло успішно, перевіривши версію Anchor CLI:

```bash Terminal
anchor --version
```

Ви побачите вивід, схожий на наступний:

```
anchor-cli 0.31.1
```

</Tab>

```bash Terminal
surfpool --version
```

```
surfpool 0.12.0
```
