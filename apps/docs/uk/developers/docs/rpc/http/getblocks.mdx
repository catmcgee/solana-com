Повертає список підтверджених блоків між двома слотами

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getBlocks",
      "params": [
        5,
        10,
        {
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let startSlot = BigInt(377268280);
  let endSlot = BigInt(377268285);
  let blocks = await rpc.getBlocks(startSlot, endSlot).send();

  console.log("Blocks produced:", blocks);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let startSlot = 377268280;
  let endSlot = 377268285;
  let blocks = await connection.getBlocks(startSlot, endSlot);

  console.log("Blocks produced:", blocks);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let start_slot = 377268280;
      let end_slot = 377268285;
      let blocks = client.get_blocks(start_slot, Some(end_slot)).await?;

      println!("Blocks produced: {:#?}", blocks);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": [5, 6, 7, 8, 9, 10],
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="start slot" type="u64" required>
  Початковий slot
</ParamField>

<ParamField body="end slot" type="u64">
  Кінцевий slot (має бути не більше ніж на 500 000 блоків вище за `start_slot`)
</ParamField>

<ParamField body="2" type="object">
  Об'єкт конфігурації

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      Параметр commitment описує, наскільки фіналізованим є блок у певний момент часу.
      Дивіться
      [Налаштування підтвердження стану](/developers/docs/rpc#configuring-state-commitment).

      - "processed" не підтримується
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="array">
  Масив цілих чисел u64, що перераховує підтверджені блоки між `start_slot` та або
  `end_slot` - якщо надано, або останнім підтвердженим slot, включно. Максимально
  дозволений діапазон становить 500 000 slot.
</ResponseField>
