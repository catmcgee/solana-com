---
title: RPC-метод getHealth
sidebarTitle: getHealth
---

Повертає поточний стан здоров'я вузла. Здоровий вузол — це той, що знаходиться в
межах `HEALTH_CHECK_SLOT_DISTANCE` слотів від останнього підтвердженого слота
кластера.

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getHealth"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let health = await rpc.getHealth().send();

  console.log(health);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let health = client.get_health().await?;

      println!("{:#?}", health);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Здоровий
  {
    "jsonrpc": "2.0",
    "result": "ok",
    "id": 1
  }
  ```

  ```json Нездоровий
  {
    "jsonrpc": "2.0",
    "error": {
      "code": -32005,
      "message": "Node is unhealthy",
      "data": { "numSlotsBehind": 42 }
    },
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

None

## Result

<ResponseField name="result" type="string" post={["Здоровий"]}>
  Якщо вузол здоровий: "ok"
</ResponseField>

<ResponseField name="result" type="object" post={["Нездоровий"]}>
  Якщо вузол нездоровий, повертається помилка JSON RPC. Деталі повідомлення про
  помилку є **НЕСТАБІЛЬНИМИ** і можуть змінитися в майбутньому
</ResponseField>
