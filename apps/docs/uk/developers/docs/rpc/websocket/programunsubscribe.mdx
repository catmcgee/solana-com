sidebarTitle: programUnsubscribe

Скасування підписки на сповіщення про зміни в облікових записах програми

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "programUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  ідентифікатор підписки на обліковий запис, яку потрібно скасувати
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  повідомлення про успішне скасування підписки
</ResponseField>
