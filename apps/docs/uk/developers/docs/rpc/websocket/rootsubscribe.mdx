---
title: RPC-метод rootSubscribe
sidebarTitle: rootSubscribe
---

Підпишіться, щоб отримувати сповіщення щоразу, коли validator встановлює новий
root.

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Відсутні**

### Result

<ResponseField name="result" type="integer">
  ідентифікатор підписки (потрібен для скасування підписки)
</ResponseField>

#### Формат сповіщення:

Результатом є номер останнього root slot.

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
