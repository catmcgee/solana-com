sidebarTitle: signatureUnsubscribe

Скасувати підписку на сповіщення про підтвердження підпису

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "signatureUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  ідентифікатор підписки для скасування
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  повідомлення про успішне скасування підписки
</ResponseField>
