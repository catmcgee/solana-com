sidebarTitle: slotSubscribe

Підписатися на отримання сповіщень щоразу, коли validator обробляє slot

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Відсутні**

### Result

<ResponseField name="result" type="integer">
  Ідентифікатор підписки (потрібен для скасування підписки)
</ResponseField>

#### Формат сповіщення:

Сповіщення буде об'єктом з такими полями:

- `parent: <u64>` - Батьківський slot
- `root: <u64>` - Поточний кореневий slot
- `slot: <u64>` - Нове встановлене значення slot

Приклад:

```json
{
  "jsonrpc": "2.0",
  "method": "slotNotification",
  "params": {
    "result": {
      "parent": 75,
      "root": 44,
      "slot": 76
    },
    "subscription": 0
  }
}
```
