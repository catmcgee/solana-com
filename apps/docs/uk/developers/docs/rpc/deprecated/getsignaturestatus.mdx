title: RPC-метод getSignatureStatus
sidebarTitle: getSignatureStatus

---

Отримати поточний статус підпису транзакції (оброблено, підтверджено,
фіналізовано).

<Warning>
  **Застарілий метод**

  Цей метод планується видалити в `solana-core` v2.0. Будь ласка, використовуйте
  [getSignatureStatuses](/developers/docs/rpc/http/getsignaturestatuses) замість нього.
</Warning>
