---
title: RPC метод getFeeCalculatorForBlockhash
sidebarTitle: getFeeCalculatorForBlockhash
mode: wide
---

Повертає калькулятор комісій, пов'язаний із запитуваним хешем блоку, або `null`,
якщо хеш блоку прострочений

<Warning>
  **Застарілий метод**

  Цей метод планується видалити в `solana-core` v2.0. Будь ласка, використовуйте
  [isBlockhashValid](/developers/docs/rpc/http/isblockhashvalid) або
  [getFeeForMessage](/developers/docs/rpc/http/getfeeformessage) замість нього.
</Warning>
