Розділ «Основи SPL Token» охоплює базові інструкції для взаємодії з
SPL-токенами, зосереджуючись на функціональності, спільній як для оригінального
Token Program, так і для Token Extensions Program (Token 2022).

<Info>
  Перегляньте [документацію
  Metaplex](https://developers.metaplex.com/token-metadata) для отримання
  додаткової інформації про те, як додати метадані до SPL-токенів.
</Info>
