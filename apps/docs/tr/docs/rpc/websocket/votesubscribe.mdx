Dedikoduda (gossip) yeni bir oy gözlemlendiğinde bildirim almak için abone olun.
Bu oylar ön-konsensüs aşamasındadır, bu nedenle bu oyların deftere gireceğine
dair garanti yoktur.

<Warning>
  **Kararsız Metot**

  Bu abonelik kararsızdır ve yalnızca validator
  `--rpc-pubsub-enable-vote-subscription` bayrağı ile başlatıldıysa
  kullanılabilir. Bu aboneliğin formatı gelecekte değişebilir.
</Warning>

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "voteSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Yok**

### Result

<ResponseField name="result" type="integer">
  abonelik kimliği (abonelikten çıkmak için gereklidir)
</ResponseField>

#### Bildirim Formatı:

Bildirim, aşağıdaki alanları içeren bir nesne olacaktır:

- `hash: <string>` - Oy hash'i
- `slots: <array>` - Oy tarafından kapsanan slot'lar, u64 tamsayılarının bir
  dizisi olarak
- `timestamp: <i64|null>` - Oyun zaman damgası
- `signature: <string>` - Bu oyu içeren işlemin imzası
- `votePubkey: <string>` - Oy hesabının açık anahtarı, base-58 kodlanmış dize
  olarak

```json
{
  "jsonrpc": "2.0",
  "method": "voteNotification",
  "params": {
    "result": {
      "hash": "8Rshv2oMkPu5E4opXTRyuyBeZBqQ4S477VG26wUTFxUM",
      "slots": [1, 2],
      "timestamp": null
    },
    "subscription": 0
  }
}
```
