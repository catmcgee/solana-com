Validator tarafından işlenen herhangi bir slot hakkında bildirim almak için
abone olun

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Yok**

### Result

<ResponseField name="result" type="integer">
  Abonelik kimliği (abonelikten çıkmak için gereklidir)
</ResponseField>

#### Bildirim Formatı:

Bildirim, aşağıdaki alanları içeren bir nesne olacaktır:

- `parent: <u64>` - Üst slot
- `root: <u64>` - Mevcut kök slot
- `slot: <u64>` - Yeni ayarlanan slot değeri

Örnek:

```json
{
  "jsonrpc": "2.0",
  "method": "slotNotification",
  "params": {
    "result": {
      "parent": 75,
      "root": 44,
      "slot": 76
    },
    "subscription": 0
  }
}
```
