title: rootSubscribe RPC Metodu
sidebarTitle: rootSubscribe
---

Validator tarafından yeni bir root belirlendiğinde bildirim almak için abone
olun.

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Yok**

### Result

<ResponseField name="result" type="integer">
  abonelik kimliği (abonelikten çıkmak için gereklidir)
</ResponseField>

#### Bildirim Formatı:

Sonuç, en son root slot numarasıdır.

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
