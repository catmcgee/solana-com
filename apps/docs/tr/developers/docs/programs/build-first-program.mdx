Bu hızlı başlangıç kılavuzu, `anchor init` tarafından oluşturulan
[Anchor framework](https://www.anchor-lang.com/docs) başlangıç projesini
kullanır. Projeyi yerel olarak oluşturacak, testlerini çalıştıracak, programı
derleyecek ve Anchor'ın oluşturduğu program kodunu inceleyeceksiniz.

## Ön Koşullar

Başlamadan önce,
[Solana geliştirme araçlarını yükleyin](/developers/docs/intro/installation). Kurulum;
Rust, Solana CLI ve Anchor CLI'yi içerir.

Bu şablon için Anchor CLI sürüm 1.1.2 veya daha yüksek bir sürüm kullanın. Yüklü
sürümünüzü kontrol edin:

```bash Terminal
anchor --version
```

<Steps titleSize="h3">

<Step title="Projeyi Oluşturun">

Terminalinizde aşağıdaki komutları çalıştırın:

```bash Terminal
anchor init my-program
cd my-program
```

Başlangıç projesi, `programs/my-program` altında bir Solana programı içerir.
Program, bir sayaç hesabını başlatmak ve sayacı artırmak için iki talimat
içerir.

Şablonun bazı bölümleri yaygın Solana program kalıplarını gösterir:
[PDA](/developers/docs/core/pda) hesap adreslerini türetme, SOL aktarmak için Cross Program
Invocation ([CPI](/developers/docs/core/cpi)) yapma ve bir koşul başarısız olduğunda
talimatı durdurmak için özel hata denetimleri kullanma.

          <Tree.File name="test_initialize.rs" />
        </Tree.Folder>
      </Tree.Folder>
    </Tree.Folder>
  </Tree.Folder>
</Tree>

</Step>

<Step title="Programı Derleyin">

Başlangıç programını derlemek için `anchor build` komutunu çalıştırın:

```bash Terminal
anchor build
```

Derlenen program, `target/deploy/my_program.so` konumuna yazılır. Program
dağıtıldığında, bu `.so` dosyasının içeriği zincir üzerinde bir hesapta
depolanır.

</Step>

<Step title="Testi Çalıştır">

Varsayılan testi çalıştırın:

```bash Terminal
anchor test
```

Bu şablonun `Anchor.toml`'i Rust test komutunu kullanır:

```toml Anchor.toml
skip_local_validator = true

[scripts]
test = "cargo test"
```

Test, derlenmiş programı [LiteSVM](https://www.litesvm.com/) içine yükler, bir
ödeyici oluşturur, `initialize` ve `increment` talimatlarını gönderir,
ardından sayaç hesabının durumunu kontrol eder.

`anchor test` komutunun çalıştırılması programı da derler; bu nedenle yerel
testlerde `anchor build` komutunu önceden çalıştırmanız gerekmez.

</Step>

<Step title="Programı Dağıt">

Yerel testler en hızlı geri bildirim döngüsüdür. Bir ağa, örneğin devnet'e
dağıtmaya hazır olduğunuzda önce derleyin, ardından bir kümeye dağıtın.

Bir Solana programının dağıtılması SOL gerektirir; çünkü program bir hesapta
depolanır ve hesap kullandığı alan için ücret ödemek zorundadır. Devnet'te,
[Solana Faucet](https://faucet.solana.com/) adresinden veya Solana CLI ile
ücretsiz devnet SOL talep edebilirsiniz:

```bash Terminal
solana airdrop 2 --url devnet
```

```bash Terminal
anchor build
anchor deploy --provider.cluster devnet
```

</Step>

</Steps>

## Kaynak dosyalar

`src` dizini Solana programını içerir. Anchor'ın
[Program Yapısı](https://www.anchor-lang.com/docs/basics/program-structure)
dokümantasyonu, `declare_id!`, `#[program]`, `#[derive(Accounts)]`
ve `#[account]` dahil olmak üzere burada kullanılan temel makroları açıklar.
Bu bölüm şablon dosyalarını adım adım ele alır.

### lib.rs

`lib.rs`, programın giriş noktasıdır. Kaynak dosyaları birbirine bağlar, program
adresini tanımlar ve kullanıcıların çağırabileceği program talimatlarını
tanımlar.

```rust programs/my-program/src/lib.rs wrap
pub mod constants;
pub mod error;
pub mod instructions;
pub mod state;

use anchor_lang::prelude::*;

pub use constants::*;
pub use instructions::*;
pub use state::*;

declare_id!("82sFkffP9wxwpyfZyeaKHH2chQoJPUGsJZSPi9mrUuXd");

#[program]
pub mod my_program {
    use super::*;

    pub fn initialize(ctx: Context<Initialize>) -> Result<()> {
        crate::instructions::initialize::handle_initialize(ctx)
    }

    pub fn increment(ctx: Context<Increment>) -> Result<()> {
        crate::instructions::increment::handle_increment(ctx)
    }
}
```

<Note>
  **`pub mod constants`**

  `pub mod constants` ifadesi, `constants.rs` öğesini program crate'inin bir
  parçası yapar. Şablon, PDA seed, transfer miktarı ve maksimum sayaç değeri gibi
  paylaşılan program değerlerini burada saklar.

  **`pub mod error`**

  `pub mod error` ifadesi, `error.rs` öğesini program crate'inin bir parçası
  yapar. Bu dosya, bir talimat geçersiz olduğunda programın döndürebileceği özel
  hataları tanımlar.

  **`pub mod instructions`**

  `pub mod instructions` ifadesi, `instructions.rs` öğesini program crate'inin
  bir parçası yapar. Bu dosya, `src/instructions/` içindeki talimata özgü dosyalar
  için bir dizin görevi görür.

  **`pub mod state`**

  `pub mod state` ifadesi, `state.rs` öğesini program crate'inin bir parçası
  yapar. Bu dosya, `Counter` hesabı da dahil olmak üzere bu programa ait
  hesapların veri düzenini tanımlar.

  **`anchor_lang::prelude`**

  `anchor_lang::prelude::*`, bir Solana programı tanımlamak için kullanılan
  Anchor türlerini ve makrolarını içe aktarır; bunlar arasında `Context`,
  `Result`, `Pubkey`, `Account`, `Signer` ve Anchor hesap
  nitelikleri yer alır.

  `pub use` satırları, alt modüllerdeki genel öğeleri crate kökünden
  erişilebilir kılar. Bu sayede talimat giriş noktaları, uzun bir modül yolu
  yerine `Context<Initialize>` gibi kısa tutulur.

  **`declare_id!`**

  `declare_id!`, programın adresini tanımlar. Bu adres; `Anchor.toml`,
  dağıtılmış program account ve programı çağıran tüm kullanıcılar ya da testlerle
  eşleşmelidir.

  **`#[program]`**

  `#[program]`, Anchor'a Solana program giriş noktasını ve talimat dağıtım
  kodunu oluşturmasını söyler. Bu modüldeki genel fonksiyonlar, kullanıcıların
  çağırabileceği talimatlar haline gelir.

  **`pub fn initialize`, `pub fn increment`**

  `initialize` ve `increment`, kullanıcıların çağırabileceği iki talimat
  adıdır. Her biri bir `Context<T>` alır. `Context` içindeki tür, o
  talimat için gereken hesapları tanımlar ve Anchor, talimat çalışmadan önce bu
  hesapları doğrular.

  **`handle_initialize`, `handle_increment`**

  İşleyici fonksiyon, talimat için gereken mantığı içerir.
</Note>

    ```toml Anchor.toml highlight={2} wrap
    [programs.localnet]
    my_program = "82sFkffP9wxwpyfZyeaKHH2chQoJPUGsJZSPi9mrUuXd"
    ```
  </div>

Aynı program adresi hem yapılandırmada hem de kodda yer alır. `Anchor.toml`,
Anchor'a bir küme için hangi adresi dağıtacağını veya çağıracağını bildirir.
`declare_id!` ise güvenlik denetimleri için program adresini program içinde
tanımlar.

### constants.rs

`constants.rs`, paylaşılan değerleri tek bir yerde tutar. Bu şablonda
`COUNTER_SEED` sayaç PDA'sını türetir, `HELLO_WORLD_LAMPORTS` başlatma
sırasında aktarılır ve `MAX_COUNT` artırmadan önce kontrol edilir.

```rust programs/my-program/src/constants.rs wrap
use anchor_lang::prelude::*;

#[constant]
pub const COUNTER_SEED: &[u8] = b"counter";

#[constant]
pub const HELLO_WORLD_LAMPORTS: u64 = 1;

#[constant]
pub const MAX_COUNT: u64 = 10;
```

<Note>
  **`#[constant]`**

  `#[constant]`, Anchor'a değeri program IDL'ine dahil etmesini söyler. Bu
  sayede önemli program sabitleri, oluşturulan istemciler ve araçlar tarafından
  görünür hâle gelir.

  **`COUNTER_SEED`**

  `COUNTER_SEED`, sayaç PDA'sını türetmek için kullanılan bayt dizisidir.
  Program ve test, ayrı bir keypair saklamaksızın hesap adresi üzerinde mutabık
  kalmak için bu seed'i birlikte kullanır. Bu şablon tek bir sabit seed
  kullandığından programın tek bir sayaç adresi vardır. Gerçek programlar,
  birbiriyle ilişkili pek çok hesap oluşturmak için seeds içine genellikle bir
  kullanıcı adresi ya da başka bir tanımlayıcı ekler.

  **`HELLO_WORLD_LAMPORTS`**

  `HELLO_WORLD_LAMPORTS`, `initialize` içinde ödeyiciden sayaç hesabına
  aktarılan lamport miktarıdır. Şablon, System Program'a yapılan bir CPI'ı
  gösterdiğinden bu değer kasıtlı olarak çok küçük tutulmuştur.

  **`MAX_COUNT`**

  `MAX_COUNT`, `increment` tarafından kontrol edilen üst sınırdır. Bu
  değerin burada tutulması; program, testler ve oluşturulan IDL'nin kural için tek
  bir ortak ad kullanmasını sağlar.
</Note>

    ```rust initialize.rs highlight={8,18} wrap
        // ...
        #[account(
    ```

    - `COUNTER_SEED` sayaç PDA adresini türetir.
    - `HELLO_WORLD_LAMPORTS` ödeyiciden sayaç

  </div>

### state.rs

`state.rs`, programın oluşturduğu ve sahip olduğu hesaplar için özel veri
türlerini tanımlar. Program bu veriyi oluşturmak, başlatmak ve güncellemek için
talimatlar tanımlar; ancak sayaç verisi programın kendisinde saklanmaz. Kendi
adresiyle ayrı bir hesapta saklanır.

```rust programs/my-program/src/state.rs wrap
use anchor_lang::prelude::*;

#[account]
#[derive(InitSpace)]
pub struct Counter {
    pub count: u64,
    pub authority: Pubkey,
}
```

<Note>
  **`#[account]`**

  `#[account]`, Anchor'a bu struct'ın bu program tarafından sahiplenilen
  zincir üstü bir hesapta saklanabilen veri olduğunu bildirir. Anchor bunu
  `Counter` hesaplarını serileştirmek, seri dışı bırakmak ve doğrulamak için
  kullanır.

  **`InitSpace`**

  `InitSpace`, Anchor'ın bu struct'ın alanları için gereken bayt sayısı olan
  `Counter::INIT_SPACE` değerini hesaplamasını sağlar. 8 baytlık Anchor hesap
  ayrıştırıcısı, hesap oluşturulurken ayrıca eklenir.

  **`count`**

  `count`, hesap verisinde saklanan sayaç değeridir.

  **`authority`**

  `authority`, sayacı artırma izni olan adresi saklar. `initialize` bu
  adresi yazar, `increment` ise aynı adresin imzalamasını zorunlu kılar.
</Note>

<Columns cols={2}>
  <div>

    ```rust initialize.rs highlight={4,12-13} wrap
        Ok(())
    }
    ```

    ```rust increment.rs highlight={4} wrap

        // ...

    }
    ```
  </div>

  <div>
    `state.rs`, `Counter` hesap verilerini tanımlar. Talimat dosyaları, hesabı
    oluştururken ve güncellerken bu türü kullanır:

    - `Counter::INIT_SPACE`, `state.rs` içinde
      tanımlanan alanlar için hesabı boyutlandırır.
    - `count` ve `authority`, hesap
      başlatıldığında yazılan alan değerleridir.
    - `count += 1`, doğrulama geçtikten sonra
      depolanan sayaç değerini günceller.
  </div>
</Columns>

### error.rs

`error.rs`, programın özel hatalarını tanımlar. Bu şablonda hatalar, bir çağıran
sayacı güncelleme yetkisine sahip olmadığında veya sayaç zaten `MAX_COUNT`
değerine ulaştığında talimat işleyicilerinin nasıl durduğunu göstermektedir.

```rust programs/my-program/src/error.rs wrap
use anchor_lang::prelude::*;

#[error_code]
pub enum ErrorCode {
    #[msg("Only the counter authority can update this counter")]
    Unauthorized,
    #[msg("Counter has reached the maximum value")]
    CounterOverflow,
}
```

<Note>
  **`#[error_code]`**

  `#[error_code]`, Anchor'a bu varyantları özel program hatalarına
  dönüştürmesini söyler. İstemciler ve testler, ham hata kodlarını tahmin etmek
  yerine bu hataları kullanabilir.

  **`Unauthorized`**

  `Unauthorized`, işlem imzalayıcısı sayaç hesabında depolanan yetkili
  olmadığında döndürülür.

  **`CounterOverflow`**

  `CounterOverflow`, artırma işlemi programın `MAX_COUNT` kuralını ihlal
  edeceğinde döndürülür.
</Note>

<Columns cols={2}>
  <div>
    ```rust increment.rs highlight={5,9} wrap
    pub fn handle_increment(ctx: Context<Increment>) -> Result<()> {
        require_keys_eq!(
            ctx.accounts.counter.authority,
            ctx.accounts.authority.key(),
            ErrorCode::Unauthorized,
        );
        require!(
            ctx.accounts.counter.count < MAX_COUNT,
            ErrorCode::CounterOverflow,
        );

        ctx.accounts.counter.count += 1;
        msg!("Hello, world! Counter is now {}", ctx.accounts.counter.count);
        Ok(())
    }
    ```
  </div>

  <div>
    `error.rs`, talimatın döndürebileceği hataları listeler:

    - `ErrorCode::Unauthorized`, imzalayıcı sayaç
      hesabında depolanan yetkili olmadığında döndürülür.
    - `ErrorCode::CounterOverflow`, sayaç zaten
      `MAX_COUNT` değerine ulaştığında döndürülür.
  </div>
</Columns>

### instructions.rs

`instructions.rs`, talimat dosyalarını program crate'ine bağlar; böylece
`lib.rs`, `initialize` ve `increment` talimat kodlarına erişebilir. Her
talimat dosyası, o talimat için gereken hesapları ve Anchor bu hesapları
doğruladıktan sonra çalışan işleyici mantığını tanımlar.

```rust programs/my-program/src/instructions.rs wrap
pub mod initialize;
pub mod increment;

pub use initialize::*;
pub use increment::*;
```

<Note>
  **`pub mod initialize`**

  `pub mod` satırları, `src/instructions/initialize.rs` ve
  `src/instructions/increment.rs` öğelerini program crate'inin bir parçası hâline
  getirir.

  **`pub use initialize`**

  `pub use` satırları, bu dosyalardan genel öğeleri yeniden dışa aktarır. Bu
  sayede talimat hesap yapıları ve işleyici fonksiyonlar `instructions` modülü
  aracılığıyla erişilebilir hâle gelir.
</Note>

### initialize.rs

`initialize.rs`, sayaç hesabını oluşturmak için gereken hesapları tanımlar ve
hesabın ilk değerlerini yazar. `#[derive(Accounts)]` yapısı, hangi
hesapların gerekli olduğunu ve yeni sayaç hesabının nasıl oluşturulduğunu
belirtmek için Anchor
[hesap kısıtlamalarını](https://www.anchor-lang.com/docs/references/account-constraints)
kullanır.

```rust programs/my-program/src/instructions/initialize.rs wrap
use anchor_lang::prelude::*;

use crate::{constants::*, state::Counter};

#[derive(Accounts)]
pub struct Initialize<'info> {
    #[account(mut)]
    pub payer: Signer<'info>,
    #[account(
        init,
        payer = payer,
        space = 8 + Counter::INIT_SPACE,
        seeds = [COUNTER_SEED],
        bump
    )]
    pub counter: Account<'info, Counter>,
    pub system_program: Program<'info, System>,
}

pub fn handle_initialize(ctx: Context<Initialize>) -> Result<()> {
    ctx.accounts.counter.count = 0;
    ctx.accounts.counter.authority = ctx.accounts.payer.key();

    let cpi_accounts = anchor_lang::system_program::Transfer {
        from: ctx.accounts.payer.to_account_info(),
        to: ctx.accounts.counter.to_account_info(),
    };
    let cpi_ctx = CpiContext::new(anchor_lang::system_program::ID, cpi_accounts);
    anchor_lang::system_program::transfer(cpi_ctx, HELLO_WORLD_LAMPORTS)?;

    msg!("Hello, world! Counter initialized");
    Ok(())
}
```

<Note>
  Bu dosya, paylaşılan sabitleri ve `Counter` hesap türünü içe aktarır.
  Talimat, PDA'yı türetmek, transfer miktarını belirlemek ve hesabı doğru veri
  boyutuyla tahsis etmek için bu tanımları kullanır.

  **`derive(Accounts)`**

  `Initialize`, `initialize` talimatı için hesap bağlamıdır. Struct'taki
  her alan, talimat çağrıldığında dahil edilmesi gereken ayrı bir hesabı temsil
  eder. Anchor, işleyici çalışmadan önce gelen hesapları doğrulamak için struct'ı
  kullanır.

  **`#[account(mut)]`**

  `#[account(mut)]`, Anchor'a ödeyici hesabın yazılabilir olması gerektiğini
  bildirir. Hesap oluşturma ve transfer CPI'sinin her ikisi de ödeyiciden lamport
  düştüğünden bu zorunludur.

  **`Signer<'info>`**

  `Signer<'info>`, Anchor'a ödeyicinin işlemi imzalaması gerektiğini bildirir.

  **`#[account(`**

  `#[account(...)]` bloğu, Anchor'a işleyici çalışmadan önce sayaç hesabının
  nasıl oluşturulacağını ve doğrulanacağını bildirir.

  **`init`**

  `init`, işleyici çalışmadan önce Anchor'ın `counter` hesabını
  oluşturmasını söyler. Yeni hesap bu programa ait olduğundan, bu program içinde
  `Counter` verilerini saklayabilir.

  **`payer = payer`**

  `payer = payer`, yeni sayaç hesabını oluşturmanın ödemecisi olarak
  `payer` hesabını belirtir.

  **`space = 8 + Counter::INIT_SPACE`**

  `space = 8 + Counter::INIT_SPACE`, Anchor'ın hesap ayrıştırıcısı ile
  `state.rs`'deki `Counter` alanları için bayt tahsis eder. Ayrıştırıcı,
  Anchor'ın hesabı okumadan önce beklenen türü sakladığını doğrulamasına yardımcı
  olur.

  **`seeds = [COUNTER_SEED]`**

  `seeds = [COUNTER_SEED]`, sayaç hesabı adresinin bu seed ve program
  kimliğinden türetilen PDA olması gerektiğini belirtir. Tek bir sabit seed ile bu
  program için tek bir sayaç PDA'sı bulunur. Gerçek bir programda ayrı sayaçlar
  oluşturmak için genellikle kullanıcının adresi gibi başka bir seed eklersiniz.

  **`bump`**

  `bump`, Anchor'a türetilen adresi geçerli bir PDA yapan ekstra bayt olan PDA
  bump'ını bulup doğrulamasını söyler.

  **`Account<'info, Counter>`**

  `Account<'info, Counter>`, Anchor'a hesap verilerini `state.rs`'deki
  `Counter` türü olarak ele almasını söyler. Anchor ayrıca hesabın bu programa
  ait olduğunu da doğrular.

  **`Program<'info, System>`**

  amacıyla eklenmiştir.

### increment.rs

`increment.rs`, mevcut bir sayaç hesabını güncellemek için gereken hesapları
tanımlar. İşleyici, imzalayanın kayıtlı yetkili olup olmadığını kontrol eder,
sayının belirtilen `MAX_COUNT` değerine ulaşıp ulaşmadığını kontrol eder ve
ardından sayımı artırır.

```rust programs/my-program/src/instructions/increment.rs wrap
use anchor_lang::prelude::*;

use crate::{constants::*, error::ErrorCode, state::Counter};

#[derive(Accounts)]
pub struct Increment<'info> {
    #[account(
        mut,
        seeds = [COUNTER_SEED],
        bump
    )]
    pub counter: Account<'info, Counter>,
    pub authority: Signer<'info>,
}

pub fn handle_increment(ctx: Context<Increment>) -> Result<()> {
    require_keys_eq!(
        ctx.accounts.counter.authority,
        ctx.accounts.authority.key(),
        ErrorCode::Unauthorized,
    );
    require!(
        ctx.accounts.counter.count < MAX_COUNT,
        ErrorCode::CounterOverflow,
    );

    ctx.accounts.counter.count += 1;
    msg!("Hello, world! Counter is now {}", ctx.accounts.counter.count);
    Ok(())
}
```

<Note>
  **`derive(Accounts)`**

  `Increment`, `increment` talimatı için hesap bağlamıdır. Anchor,
  değiştirilebilir sayaç hesabını ve gerekli imzalayanı doğrulamak için bunu
  kullanır.

  **`mut`**

  `mut`, Anchor'a sayaç hesabının yazılabilir olması gerektiğini söyler çünkü
  işleyici depolanan `count` değerini günceller.

  **`seeds = [COUNTER_SEED]`**

  `seeds = [COUNTER_SEED]`, sağlanan sayaç hesabının bu seed ve program
  kimliğinden türetilen PDA olduğunu doğrular.

  **`bump`**

  `bump`, Anchor'a sayaç hesabı için PDA bump'ını bulup doğrulamasını söyler.

  **`Account<'info, Counter>`**

  `Account<'info, Counter>`, Anchor'a hesap verilerini `state.rs`'den
  `Counter` türü olarak seri dışına çıkarmasını söyler. Anchor ayrıca hesabın
  bu program tarafından sahiplenildiğini kontrol eder.

  **`Signer`**

  `Signer`, yetkilinin imzasını zorunlu kılar. İşleyici daha sonra bu
  imzalayanın adresini sayaç hesabında depolanan yetkiliyle karşılaştırır.

  **`handle_increment`**

  İşleyici, Anchor hesap listesini doğruladıktan, sahipliği kontrol ettikten ve
  sayaç hesabını seri dışına çıkardıktan sonra çalışır.

  **`require_keys_eq!`**

  `require_keys_eq!`, iki açık anahtarı karşılaştırır ve imzalayanın adresi
  sayaç hesabında depolanan yetkiliyle eşleşmediği sürece talimatı durdurur. Bu,
  şablonun uygulama düzeyindeki yetkilendirme kuralıdır.

  **`require!`**

  `require!`, bir boolean kuralını kontrol eder ve sayaç zaten `MAX_COUNT`
  değerine ulaşmışsa talimatı `CounterOverflow` ile durdurur. Bu şablon
  kuralı, özel hataları ve mutasyondan önce başarısız olmayı gösterir.

  **`count += 1`**

  İşleyici, sayaç hesabı verilerini yalnızca her iki kontrol de geçtikten sonra
  günceller. Kontrollerden biri başarısız olursa işlem başarısız olur ve hesap
  değiştirilmez.

  **`msg!`**

  `msg!`, program çağrıldığında program günlüklerine bir ileti yazar.
</Note>

```rust programs/my-program/tests/test_initialize.rs wrap
use {
    anchor_lang::{
        prelude::Pubkey,
        solana_program::{instruction::Instruction, system_program},
        AccountDeserialize, InstructionData, ToAccountMetas,
    },
    litesvm::LiteSVM,
    solana_keypair::Keypair,
    solana_message::{Message, VersionedMessage},
    solana_signer::Signer,
    solana_transaction::versioned::VersionedTransaction,
};

#[test]
fn test_initialize() {
    let program_id = my_program::id();
    let payer = Keypair::new();
    let counter = Pubkey::find_program_address(
        &[my_program::constants::COUNTER_SEED],
        &program_id,
    )
    .0;
    let mut svm = LiteSVM::new();
    let bytes = include_bytes!(concat!(
        env!("CARGO_TARGET_TMPDIR"),
        "/../deploy/my_program.so"
    ));
    svm.add_program(program_id, bytes).unwrap();
    svm.airdrop(&payer.pubkey(), 1_000_000_000).unwrap();

    let instruction = Instruction::new_with_bytes(
        program_id,
        &my_program::instruction::Initialize {}.data(),
        my_program::accounts::Initialize {
            payer: payer.pubkey(),
            counter,
            system_program: system_program::ID,
        }
        .to_account_metas(None),
    );

    let blockhash = svm.latest_blockhash();
    let msg = Message::new_with_blockhash(&[instruction], Some(&payer.pubkey()), &blockhash);
    let tx = VersionedTransaction::try_new(VersionedMessage::Legacy(msg), &[&payer]).unwrap();

    let res = svm.send_transaction(tx);
    assert!(res.is_ok());

    let counter_account = svm.get_account(&counter).unwrap();
    let mut data: &[u8] = &counter_account.data;
    let counter_state = my_program::state::Counter::try_deserialize(&mut data).unwrap();
    assert_eq!(counter_state.count, 0);
    assert_eq!(counter_state.authority, payer.pubkey());

    let instruction = Instruction::new_with_bytes(
        program_id,
        &my_program::instruction::Increment {}.data(),
        my_program::accounts::Increment {
            counter,
            authority: payer.pubkey(),
        }
        .to_account_metas(None),
    );

    let blockhash = svm.latest_blockhash();
    let msg = Message::new_with_blockhash(&[instruction], Some(&payer.pubkey()), &blockhash);
    let tx = VersionedTransaction::try_new(VersionedMessage::Legacy(msg), &[&payer]).unwrap();

    let res = svm.send_transaction(tx);
    assert!(res.is_ok());

    let counter_account = svm.get_account(&counter).unwrap();
    let mut data: &[u8] = &counter_account.data;
    let counter_state = my_program::state::Counter::try_deserialize(&mut data).unwrap();
    assert_eq!(counter_state.count, 1);
    assert_eq!(counter_state.authority, payer.pubkey());
}
```

<Note>
  **`litesvm::LiteSVM`**

  `LiteSVM`, testler için süreç içi bir Solana VM'dir. Testin derlenmiş
  programı kaydetmesine, hesap oluşturmasına, işlem göndermesine ve bir validator
  süreci başlatmadan hesap durumunu incelemesine olanak tanır.

  **`let program_id`**

  Test, `my_program::id()` aracılığıyla `declare_id!` değerinden program
  adresini alır ve test işlemi için yeni bir payer keypair oluşturur.

  **`Pubkey::find_program_address`**

  Sayaç adresi, programın kullandığı aynı `COUNTER_SEED` ile türetilir. Bu,
  testin `initialize.rs`'in beklediği PDA'yı hedef almasını sağlar.

  **`include_bytes!`**

  `include_bytes!`, derleme tarafından üretilen derlenmiş `my_program.so`
  dosyasını okur. Bu baytlar, LiteSVM'nin testte çalıştıracağı yürütülebilir
  program kodudur.

  **`svm.add_program`**

  `svm.add_program`, derlenmiş program baytlarını LiteSVM'deki program
  adresine kaydeder. Airdrop, ödeyiciye işlem ve hesap oluşturma masraflarını
  karşılamak için yeterli yerel SOL sağlar.

  **`let instruction`**

  `Instruction::new_with_bytes`, programı çağırmak için bir talimat oluşturur.
  Program kimliğini, instruction data ve talimat hesaplarını içerir.

  **`svm.latest_blockhash`**

  Her Solana işlemi için güncel bir blok karması gereklidir. Bu testte LiteSVM,
  işlem için kullanılacak bir blok karması sağlar.

  **`Message::new_with_blockhash`**

  Mesaj, talimatı, işlem ücretini ödeyen tarafı ve blok karmasını içerir. Bu,
  imzalanacak işlem verisidir.

  **`VersionedTransaction::try_new`**

  `VersionedTransaction::try_new`, mesajı ödeyici keypair ile imzalar.
  Ödeyici, işlem ücretini ödediği ve yeni sayaç hesabını finanse ettiği için
  imzalar.

  **`svm.send_transaction`**

  `svm.send_transaction`, işlemi LiteSVM'de yürütür.

  **`svm.get_account`**

  İşlem çalıştıktan sonra test, hesap verisini inceleyebilmek için sayaç hesabını
  doğrudan LiteSVM'den okur.

  **`Counter::try_deserialize`**

  Sayaç hesabı serileştirilmiş veri depolar. `Counter::try_deserialize`,
  Anchor'ın hesap ayrıştırıcısını kontrol eder ve hesap verisini `state.rs`'den
  gelen `Counter` türüne geri dönüştürür.

  **`assert_eq!(counter_state.count, 0)`**

  `initialize` başarılı olduktan sonra test, sayaç hesabının serileştirmesini
  çözerek başlangıç durumunun `handle_initialize`'nin yazdığıyla eşleştiğini
  doğrular.

  **`assert_eq!(counter_state.count, 1)`**

  `increment` başarılı olduktan sonra, aynı sayaç hesabında `count` değeri
  `1` olarak ayarlanmış olmalı ve aynı yetki korunmalıdır.
</Note>

## Proje yapılandırması

Kök proje dosyaları, Anchor ve Cargo'ya programı nasıl derleyeceğini, test
edeceğini ve dağıtacağını söyler. Tam referans için
[Anchor.toml yapılandırması](https://www.anchor-lang.com/docs/references/anchor-toml)
ve [Anchor CLI](https://www.anchor-lang.com/docs/references/cli) için Anchor
belgelerine bakın.

```toml Anchor.toml
skip_local_validator = true

[toolchain]

[features]
resolution = true
skip-lint = false

[programs.localnet]
my_program = "82sFkffP9wxwpyfZyeaKHH2chQoJPUGsJZSPi9mrUuXd"

[provider]
cluster = "localnet"
wallet = "~/.config/solana/id.json"

[scripts]
test = "cargo test"

[hooks]
```

<Note>
  **`skip_local_validator`**

  `skip_local_validator = true`, Anchor'a `anchor test` için bir validator
  başlatmamasını söyler. Rust testi bunun yerine LiteSVM kullanır.

  **`programs.localnet`**

  `[programs.localnet]`, Rust crate adını yerel derlemeler ve testler için
  kullanılan program adresiyle eşleştirir.

  **`provider`**

  `[provider]`, `anchor deploy` gibi komutlar için varsayılan küme ve cüzdanı
  ayarlar.

  **`scripts`**

  `[scripts]`, `anchor test`'nin ne çalıştırdığını değiştirir. Bu şablonda
  `anchor test`, `cargo test`'yi çalıştırır.
</Note>
