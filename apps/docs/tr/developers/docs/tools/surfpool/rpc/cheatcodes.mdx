## Saat Semantiği

<Warning>
  **Zaman damgaları milisaniye cinsindendir; saat saniye raporlar**

  `surfnet_timeTravel`'ın `absoluteTimestamp` değeri, JavaScript'in `Date.now()` gibi **milisaniye** cinsindendir; ancak programların okuduğu `Clock` sysvar **saniye** cinsinden raporlar. Saatin döndürdüğü değeri doğrudan cheatcode'a geri geçirmek, tarihi 1970'lerin başına taşır — saat yalnızca ileri gittiğinden, çağrı yok sayılmak yerine reddedilir. Önce 1000 ile çarpın.
</Warning>

Saat cheatcode'larının SDK düzeyindeki karşılıkları için bkz. [Zaman Yolculuğu](/developers/docs/tools/surfpool/sdk/time-travel).
