前のセクションでは、アカウントをフェッチすることで
[Solanaネットワークからデータを読み取る](/developers/docs/intro/quick-start/reading-from-network)
方法を学びました。Solanaネットワークへのデータの書き込みには
[トランザクション](/developers/docs/core/transactions)が必要です。トランザクションには1つ以上の
[instructions](/developers/docs/core/instructions)が含まれており、各instructionはプログラムを呼び出します。

プログラムは各instructionのビジネスロジックを定義します。トランザクションを送信すると、SolanaランタイムはトランザクションのinstructionsをCONTENT順に実行します。トランザクションはアトミックです。トランザクション内のすべてのinstructionが成功するか、トランザクション全体が失敗するかのどちらかです。

このセクションの例では、以下の方法を示します：

1. アカウント間のSOL転送
2. 新しいトークンミントの作成

## SOLの転送

以下の例では、あるアカウントから別のアカウントへSOLを送金します。アカウントのデータを変更したり、残高からlamportを差し引いたりできるのは、そのアカウントのオーナーとして指定されたプログラムのみです。ウォレットアカウントは[System Program](/developers/docs/core/programs/builtin-programs#the-system-program)によって所有されているため、ウォレットアカウント間でSOLを送金するには、System Programの[transfer](https://github.com/anza-xyz/agave/blob/v2.1.11/programs/system/src/system_processor.rs#L183-L213) instructionsを呼び出すinstructionsが必要です。また、送金元アカウントはトランザクションに署名する必要があります。

```ts title="Transfer SOL"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getTransferSolInstruction } from "@solana-program/system";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const receiver = await generateKeyPairSigner();

const transferInstruction = getTransferSolInstruction({
  source: client.payer,
  destination: receiver.address,
  amount: lamports(10_000_000n)
});

const result = await client.sendTransaction([transferInstruction]);

console.log("Transaction Signature:", result.context.signature);

const { value: senderBalance } = await client.rpc
  .getBalance(client.payer.address)
  .send();
const { value: receiverBalance } = await client.rpc
  .getBalance(receiver.address)
  .send();

console.log("Sender Balance:", senderBalance);
console.log("Receiver Balance:", receiverBalance);
```

<Note>
  **`createClient`**

  ローカルvalidator用のKitクライアントを作成します。`generatedPayer()`は支払者の署名者を追加し、`solanaRpc()`はRPCとトランザクション送信機能を追加し、`rpcAirdrop()`は`client.airdrop`を追加し、`airdropPayer()`はテスト用SOLで支払者に資金を供給します。

  **`receiver`**

  SOLを受け取るアカウントの署名者を生成します。受信者はこの転送に署名する必要はありません。受信者のアドレスにまだアカウントが存在しない場合、SOLを受け取ることでそのアドレスにシステムアカウントが作成されます。

  **`transferInstruction`**

  クライアントのペイヤーからレシーバーへlamportsを転送するSystem Program
  instructionsを作成します。

  **`sendTransaction`**

  instructionsをトランザクションとして送信します。Kitクライアントは最新のブロックハッシュを取得し、手数料支払者を設定し、必要な署名者で署名し、トランザクションを送信して確認を待ちます。

  **`balances`**

  トランザクションが確認された後、送信者と受信者の残高を取得します。
</Note>

## トークンを作成する

以下の例では、[Token Extensions Program](/developers/docs/tokens/extensions)
を使用して新しいトークン mint account を作成します。mint
account とは、小数点以下の桁数、供給量、mint 権限、凍結権限などのトークンのグローバル設定を定義するアカウントです。

mint account を作成するには、2つのinstructionsが必要です：

1. System Program を呼び出して、Token Extensions
   Program が所有する新しいアカウントを作成します。
2. Token Extensions
   Program を呼び出して、そのアカウントを mint として初期化します。

```ts title="Create mint account"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getCreateAccountInstruction } from "@solana-program/system";
import {
  fetchMint,
  getInitializeMintInstruction,
  getMintSize,
  TOKEN_2022_PROGRAM_ADDRESS
} from "@solana-program/token-2022";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const mint = await generateKeyPairSigner();

const space = BigInt(getMintSize());

const rent = await client.rpc.getMinimumBalanceForRentExemption(space).send();

const createAccountInstruction = getCreateAccountInstruction({
  payer: client.payer,
  newAccount: mint,
  space,
  lamports: rent,
  programAddress: TOKEN_2022_PROGRAM_ADDRESS
});

const initializeMintInstruction = getInitializeMintInstruction({
  mint: mint.address,
  decimals: 2,
  mintAuthority: client.payer.address,
  freezeAuthority: client.payer.address,
  tokenProgram: TOKEN_2022_PROGRAM_ADDRESS
});

const result = await client.sendTransaction([
  createAccountInstruction,
  initializeMintInstruction
]);

console.log("Mint Address:", mint.address);
console.log("Transaction Signature:", result.context.signature);

const mintAccount = await fetchMint(client.rpc, mint.address);
console.log("Mint Account:", mintAccount);
```

<Note>
  **`createClient`**

  ローカル validator 用の Kit クライアントを作成してファンドします。ファンドされた支払者はアカウントの rent とトランザクション手数料を支払います。

  **`mint`**

  新しい mint
  account のアドレスとして使用する署名者を生成します。署名者はそのアカウントの作成を承認します。

  **`space`**

  拡張機能なしの mint account に必要なバイト数を計算します。

  **`rent`**

  mint account を rent 免除にするために必要な lamport 数を計算します。

  **`createAccountInstruction`**

  mint account を作成し、そのアカウントを Token Extensions
  Program に割り当てる System Program の instructions を構築します。

  **`initializeMintInstruction`**

  新しいアカウントに初期 mint データを書き込む Token Extensions
  Program の instructions を構築します。

  **`sendTransaction`**

  両方のinstructionsを1つのトランザクションとして送信します。instructionの順序が重要です。アカウントを初期化する前に、アカウントを作成する必要があります。

  **`mintAccount`**

  確認後にmint accountを取得します。ヘルパーはアカウントを読み取り、mint
  accountのデータフィールドをMint型にデシリアライズします。
</Note>

    ```ts title="Create mint account" focus={12-23}
    import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
    import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
    import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
    import { getCreateAccountInstruction } from "@solana-program/system";
    import {
      fetchMint,
      getInitializeMintInstruction,
      getMintSize,
      TOKEN_2022_PROGRAM_ADDRESS
    } from "@solana-program/token-2022";

    const client = await createClient()
      .use(generatedPayer())
      .use(
        solanaRpc({
          rpcUrl: "http://localhost:8899",
          rpcSubscriptionsUrl: "ws://localhost:8900"
        })
      )
      .use(rpcAirdrop())
      .use(airdropPayer(lamports(1_000_000_000n)));

    const mint = await generateKeyPairSigner();
    ```

    ```ts title="Mint account size and rent"
    const space = BigInt(getMintSize());

    const rent = await client.rpc.getMinimumBalanceForRentExemption(space).send();
    ```

    ```ts title="Create account instruction"
    const createAccountInstruction = getCreateAccountInstruction({
      payer: client.payer,
      newAccount: mint,
      space,
      lamports: rent,
      programAddress: TOKEN_2022_PROGRAM_ADDRESS
    });
    ```

    ```ts title="Initialize mint instruction"
    const initializeMintInstruction = getInitializeMintInstruction({
      mint: mint.address,
      decimals: 2,
      mintAuthority: client.payer.address,
      freezeAuthority: client.payer.address,
      tokenProgram: TOKEN_2022_PROGRAM_ADDRESS
    });
    ```

    ```ts title="Send transaction"
    const result = await client.sendTransaction([
      createAccountInstruction,
      initializeMintInstruction
    ]);
    ```

    ```ts title="Create mint account" focus={45-48} expandable
    console.log("Mint Address:", mint.address);
    console.log("Transaction Signature:", result.context.signature);
    ```

    ```ts title="Fetch mint account"
    const mintAccount = await fetchMint(client.rpc, mint.address);
    console.log("Mint Account:", mintAccount);
    ```
