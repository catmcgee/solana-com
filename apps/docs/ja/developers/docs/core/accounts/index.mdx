アカウントは、状態を保存するためのSolanaの基本的なデータ単位です。ネットワークは、すべての状態をキーバリューストアに保存します。各キーは32バイトのアドレスで、各値はアカウントです。

## 重要な事実

- **構造**: すべてのアカウントは同じ[5つのフィールド](/developers/docs/core/accounts/account-structure)を持ちます：lamports、data、owner、executable、rent_epoch。
- **アドレス**: 各アカウントは一意の32バイトアドレス（Ed25519公開鍵または[PDA](/developers/docs/core/pda)のいずれか）で識別されます。
- **所有権**: アカウントの所有者プログラムのみがデータを変更したり、lamportsを引き落としたりできます。任意のプログラムは、書き込み可能な任意のアカウントにlamportsを入金できます。
- **アカウントストレージ**: すべてのアカウントは、オンチェーンに存在し続けるために、データサイズに比例した返金可能な最低限のlamport残高を保持する必要があります。

| --------------------------------- | ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 最大アカウントデータサイズ             | 10 MiB (10,485,760バイト)                                   | [`MAX_ACCOUNT_DATA_LEN`](https://github.com/anza-xyz/agave/blob/v3.1.8/transaction-context/src/lib.rs#L34)                    |
| 命令ごとの最大データ増加量   | 10 KiB (10,240バイト)                                       | [`MAX_PERMITTED_DATA_INCREASE`](https://github.com/anza-xyz/solana-sdk/blob/clock%40v2.2.3/account-info/src/lib.rs#L17)       |
| トランザクションごとの最大データ増加量   | 20 MiB (20,971,520バイト)                                   | [`MAX_ACCOUNT_DATA_GROWTH_PER_TRANSACTION`](https://github.com/anza-xyz/agave/blob/v3.1.8/transaction-context/src/lib.rs#L38) |
| アカウント基本ストレージオーバーヘッド     | アカウントあたり64バイト                                        | [`TRANSACTION_ACCOUNT_BASE_SIZE`](https://github.com/anza-xyz/agave/blob/v3.1.8/svm/src/account_loader.rs#L45)                |
| アドレスサイズ                      | 32バイト (Ed25519公開鍵)                               | --                                                                                                                            |
| 最低ストレージ残高（計算式） | (account_size + 128) \* 3,480 lamport/バイト年 \* 2年 | [`minimum_balance()`](https://github.com/anza-xyz/solana-sdk/blob/clock%40v2.2.3/rent/src/lib.rs#L93)                         |
