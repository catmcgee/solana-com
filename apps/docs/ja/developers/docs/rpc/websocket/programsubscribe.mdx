title: programSubscribe RPCメソッド
sidebarTitle: programSubscribe
---

指定されたプログラムが所有するアカウントのlamportまたはデータが変更されたときに通知を受け取るためにプログラムをサブスクライブします

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "programSubscribe",
    "params": [
      "11111111111111111111111111111111",
      {
        "encoding": "base64",
        "filters": [{ "dataSize": 80 }]
      }
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 24040,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

<ParamField body="0" type="string" required>
  `program_id`のpubkeyをbase-58でエンコードした文字列
</ParamField>

<ParamField body="1" type="object">
  以下のフィールドを含む設定オブジェクト：

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      コミットメントは、その時点でブロックがどの程度確定しているかを示します。
      [ステートコミットメントの設定](/developers/docs/rpc#configuring-state-commitment)を参照してください。
    </ParamField>

    <ParamField body="filters" type="array">
      様々なフィルターオブジェクトを使用して結果をフィルタリングします。
      [フィルタリング](/developers/docs/rpc/http/getprogramaccounts#param-filters)を参照してください。

      <Info>
        結果に含まれるためには、アカウントは**すべての**フィルター条件を満たす必要があります
      </Info>
    </ParamField>

    <ParamField body="encoding" type="string">
      Values: `base58`, `base64`, `base64+zstd`, `jsonParsed`

      アカウントデータのエンコーディング形式

      - `base58`は処理が遅いです。
      - `jsonParsed`エンコーディングは、プログラム固有の状態パーサーを使用して、より人間が読みやすく明示的なアカウント状態データを返すことを試みます。
      - `jsonParsed`が要求されたがパーサーが見つからない場合、そのフィールドは`base64`エンコーディングにフォールバックします。これは`data`フィールドが`string`型である場合に検出できます。
    </ParamField>
  </Expandable>
</ParamField>

### Result

<ResponseField name="result" type="integer">
  サブスクリプションID（登録解除に必要）
</ResponseField>

#### 通知フォーマット

通知フォーマットは、[getProgramAccounts](/developers/docs/rpc/http/getprogramaccounts) RPC
HTTPメソッドで見られる<b>単一</b>のprogram accountオブジェクトです。

  "method": "programNotification",

        "slot": 5208469

      "value": {
        "pubkey": "H4vnBqifaSACnKa7acsxstsY1iV1bvJNxsCY7enrd1hq",
