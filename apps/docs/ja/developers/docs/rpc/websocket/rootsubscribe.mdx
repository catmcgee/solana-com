---
title: rootSubscribe RPCメソッド
sidebarTitle: rootSubscribe
---

validatorによって新しいルートが設定されるたびに通知を受け取るためにサブスクライブします。

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**なし**

### Result

<ResponseField name="result" type="integer">
  サブスクリプションID（サブスクリプション解除に必要）
</ResponseField>

#### 通知フォーマット：

結果は最新のルートslot番号です。

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
