title: getInflationGovernor RPCメソッド

---

現在のインフレーションガバナーを返します

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getInflationGovernor",
      "params": [
        {
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc, type Commitment } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let commitment: Commitment = "finalized";
  let inflationGovener = await rpc.getInflationGovernor({ commitment }).send();

  console.log(inflationGovener);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let commitment = "finalized";
  let inflationGovener = await connection.getInflationGovernor();

  console.log(inflationGovener);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let inflation_govener = client.get_inflation_governor().await?;

      println!("{:#?}", inflation_govener);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="0" type="object">
  設定オブジェクト。

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      コミットメントは、その時点でブロックがどの程度確定しているかを示します。
      [ステートコミットメントの設定](/developers/docs/rpc#configuring-state-commitment)を参照してください。
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="object">
  結果フィールドは以下のフィールドを持つJSONオブジェクトです：

  <Expandable title="properties" defaultOpen>
    <ResponseField name="foundation" type="f64">
      財団に割り当てられる総インフレーションの割合
    </ResponseField>

    <ResponseField name="foundationTerm" type="f64">
      財団プールのインフレーション期間（年単位）
    </ResponseField>

    <ResponseField name="initial" type="f64">
      時間0からの初期インフレーション率
    </ResponseField>

    <ResponseField name="taper" type="f64">
      インフレーションが年間で低下する割合。（割合の減少はジェネシス設定の目標slot時間を使用して算出されます）
    </ResponseField>

    <ResponseField name="terminal" type="f64">
      最終的なインフレーション率
    </ResponseField>
  </Expandable>
</ResponseField>
