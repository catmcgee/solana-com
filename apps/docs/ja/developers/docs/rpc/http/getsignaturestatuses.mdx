---
title: getSignatureStatuses RPCメソッド
sidebarTitle: getSignatureStatuses
---

トランザクション署名のリストのステータスを返します。各署名は
[txid](/developers/docs/references/terminology#transaction-id)、つまりトランザクションの最初の署名である必要があります。

<Info>
  `searchTransactionHistory` 設定パラメータが含まれていない限り、
  このメソッドは最近のステータスキャッシュのみを検索します。このキャッシュには
  すべてのアクティブなslotと`MAX_RECENT_BLOCKHASHES`のルート化されたslotのステータスが保持されています。
</Info>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getSignatureStatuses",
      "params": [
        [
          "4cdd1oX7cfVALfr26tP52BZ6cSzrgnNGtYD7BFhm6FFeZV5sPTnRvg6NRn8yC6DbEikXcrNChBM5vVJnTgKhGhVu"
        ],
        {
          "searchTransactionHistory": true
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc, type Signature } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let signatures = [
    "4cdd1oX7cfVALfr26tP52BZ6cSzrgnNGtYD7BFhm6FFeZV5sPTnRvg6NRn8yC6DbEikXcrNChBM5vVJnTgKhGhVu" as unknown as Signature
  ];

  let config = {
    searchTransactionHistory: true
  };

  let signatureStatus = await rpc.getSignatureStatuses(signatures, config).send();

  console.log(signatureStatus);
  ```

  ```ts web3.js
  import {
    Connection,
    clusterApiUrl,
    type SignatureStatusConfig
  } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let signatures = [
    "4cdd1oX7cfVALfr26tP52BZ6cSzrgnNGtYD7BFhm6FFeZV5sPTnRvg6NRn8yC6DbEikXcrNChBM5vVJnTgKhGhVu"
  ];

  let config: SignatureStatusConfig = {
    searchTransactionHistory: true
  };

  let signatureStatus = await connection.getSignatureStatuses(signatures, config);
  console.log(signatureStatus);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::{commitment_config::CommitmentConfig, signature::Signature};
  use std::str::FromStr;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let signatures_str = [
          "4cdd1oX7cfVALfr26tP52BZ6cSzrgnNGtYD7BFhm6FFeZV5sPTnRvg6NRn8yC6DbEikXcrNChBM5vVJnTgKhGhVu",
      ];
      let signatures = signatures_str.map(|sig| Signature::from_str(sig).unwrap());

      let signature_status = client
          .get_signature_statuses_with_history(&signatures)
          .await?;

      println!("{:#?}", signature_status);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="0" type="array" required>
  確認するトランザクション署名の配列（base-58エンコード文字列として、最大256個まで）
</ParamField>

<ParamField body="1" type="object">
  以下のフィールドを含む設定オブジェクト：

  <Expandable title="properties" defaultOpen>
    <ParamField body="searchTransactionHistory" type="bool">
      `true`の場合 -
      Solanaノードは最近のステータスキャッシュで見つからない署名をレジャーキャッシュから検索します
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="array">
  `RpcResponse<object>`の配列。各要素は`null`または以下のフィールドを含むオブジェクトのいずれかです：

  <Expandable title="properties" defaultOpen>
    <ResponseField name="slot" type="u64">
      トランザクションが処理されたスロット
    </ResponseField>

    <ResponseField name="confirmations" type="usize | null">
      署名確認以降のブロック数、ルート化されている場合は
      `null`、およびクラスターの絶対多数によって確定されている場合
    </ResponseField>

    <ResponseField name="err" type="object | null">
      トランザクションが失敗した場合のエラー、トランザクションが成功した場合は
      `null`。
      [TransactionErrorの定義](https://github.com/anza-xyz/solana-sdk/blob/50dfbd088c51b7229c67d432d8c8801dafaa7904/transaction-error/src/lib.rs#L15)を参照
    </ResponseField>

    <ResponseField name="status" type="object">
      **非推奨** トランザクションステータス

      - `"Ok": <null>` - トランザクションは成功しました
      - `"Err": <ERR>` - トランザクションはTransactionErrorで失敗しました
    </ResponseField>

    <ResponseField name="confirmationStatus" type="string | null">
      トランザクションのクラスター確認ステータス。`processed`、`confirmed`、または
      `finalized`
      のいずれか。楽観的確認の詳細については[コミットメント](/developers/docs/rpc/#configuring-state-commitment)を参照してください。
    </ResponseField>
  </Expandable>
</ResponseField>
