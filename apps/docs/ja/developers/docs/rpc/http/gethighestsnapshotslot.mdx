---
title: getHighestSnapshotSlot RPCメソッド
sidebarTitle: getHighestSnapshotSlot
---

ノードが持つスナップショットの最高スロット情報を返します。

これは最高の完全スナップショットスロットを見つけ、それに基づいた最高の増分スナップショットスロット（存在する場合）を見つけます。

<Warning>
  **バージョン制限**

  このメソッドは `solana-core` v1.9以降でのみ利用可能です。`solana-core`
  v1.8以下では
  [getSnapshotSlot](/developers/docs/rpc/deprecated/getsnapshotslot)を使用してください。
</Warning>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getHighestSnapshotSlot"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let hightestSnapshotSlot = await rpc.getHighestSnapshotSlot().send();

  console.log(hightestSnapshotSlot);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let highest_snapshot_slot = client.get_highest_snapshot_slot().await?;

      println!("{:#?}", highest_snapshot_slot);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json スナップショット
  {
    "jsonrpc": "2.0",
    "result": {
      "full": 100,
      "incremental": 110
    },
    "id": 1
  }
  ```

  ```json スナップショットなし
  {
    "jsonrpc": "2.0",
    "error": {
      "code": -32008,
      "message": "No snapshot"
    },
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

None

## Result

<ResponseField name="result" type="object" post={["スナップショット"]}>
  ノードがスナップショットを持っている場合、以下のフィールドを含むJSONオブジェクトを返します：

  <Expandable title="properties" defaultOpen>
    <ResponseField name="full" type="u64">
      最高の完全スナップショットスロット
    </ResponseField>

    <ResponseField name="incremental" type="u64 | null">
      `full`に基づいた最高の増分スナップショットスロット
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="result" type="object" post={["スナップショットなし"]}>
  ノードにスナップショットがない場合、JSON RPCエラーレスポンスが返されます。
</ResponseField>
