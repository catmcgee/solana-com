複数のPubkeyに対するアカウント情報を返します。

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getMultipleAccounts",
      "params": [
        [
          "vines1vzrYbzLMRdu58ou5XTby4qAqVRLmqo36NKPTg",
          "4fYNw3dojWmQ4dXtSGE9epjRGy9pFSx62YypT7avPYvA"
        ],
        {
          "encoding": "base58",
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { address, createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let addresses = [
    address("vines1vzrYbzLMRdu58ou5XTby4qAqVRLmqo36NKPTg"),
    address("4fYNw3dojWmQ4dXtSGE9epjRGy9pFSx62YypT7avPYvA")
  ];

  let config = {
    encoding: "base58",
    commitment: "finalized"
  };

  let accounts = await rpc.getMultipleAccounts(addresses, config).send();

  console.log(accounts);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_account_decoder::UiAccountEncoding;
  use solana_client::{nonblocking::rpc_client::RpcClient, rpc_config::RpcAccountInfoConfig};
  use solana_sdk::{commitment_config::CommitmentConfig, pubkey};

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let addresses = [
          pubkey!("vines1vzrYbzLMRdu58ou5XTby4qAqVRLmqo36NKPTg"),
          pubkey!("4fYNw3dojWmQ4dXtSGE9epjRGy9pFSx62YypT7avPYvA"),
      ];

      let config = RpcAccountInfoConfig {
          encoding: UiAccountEncoding::Base58.into(),
          data_slice: None,
          commitment: CommitmentConfig::finalized().into(),
          min_context_slot: None,
      };

      let accounts = client
          .get_multiple_accounts_with_config(&addresses, config)
          .await?;

      println!("{:#?}", accounts);

      Ok(())
  }
  ```

## Parameters

<ParamField body="0" type="array" required>
  クエリするPubkeyの配列（base-58エンコードされた文字列として）（最大100個まで）
</ParamField>

<ParamField body="1" type="object">
  以下のフィールドを含む設定オブジェクト：

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      コミットメントは、その時点でブロックがどの程度確定しているかを示します。[ステートコミットメントの設定](/developers/docs/rpc#configuring-state-commitment)を参照してください。
    </ParamField>

    <ParamField body="minContextSlot" type="number">
      リクエストが評価される最小のslot
    </ParamField>

    <ParamField body="dataSlice" type="object">
      アカウントデータのスライスをリクエストします。

      - `length: <usize>` - 返すバイト数
      - `offset: <usize>` - 読み取りを開始するバイトオフセット

      <Info>
        データスライシングは `base58`、`base64`、または `base64+zstd`
        エンコーディングでのみ利用可能です。
      </Info>
    </ParamField>

    <ParamField body="encoding" type="string" default="base64">
      Values: `jsonParsed`, `base58`, `base64`, `base64+zstd`

      返されるアカウントデータのエンコーディング形式

      - `base58` は処理が遅く、アカウントデータが129バイト未満に制限されています。
      - `base64`
        はどのサイズのアカウントデータでもbase64エンコードされたデータを返します。
      - `base64+zstd`
        は[Zstandard](https://facebook.github.io/zstd/)を使用してアカウントデータを圧縮し、その結果をbase64エンコードします。
      - `jsonParsed`
        エンコーディングはプログラム固有の状態パーサーを使用して、より読みやすく明示的なアカウント状態データを返そうとします。
      - `jsonParsed` が要求されたがパーサーが見つからない場合、フィールドは `base64`
        エンコーディングにフォールバックします。これは `data` フィールドが `<string>`
        型の場合に検出できます。
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="array">
  結果は以下のいずれかを含む配列になります：

  - `null` - そのpubkeyのアカウントが存在しない場合、または
  - 以下のフィールドを持つアカウントオブジェクト：

  <Expandable title="properties" defaultOpen>
    <ResponseField name="data" type="[string,encoding] | object">
      アカウントに関連付けられたデータ。エンコードされたバイナリデータまたはJSON形式
      `{<program>: <state>}` - エンコーディングパラメータによって異なります
    </ResponseField>

    <ResponseField name="executable" type="bool">
      アカウントがプログラムを含むかどうかを示すブール値（含む場合は厳密に読み取り専用）
    </ResponseField>

    <ResponseField name="lamports" type="u64">
      このアカウントに割り当てられたlamportの数
    </ResponseField>

    <ResponseField name="owner" type="string">
      このアカウントが割り当てられたプログラムのBase-58エンコードされたpubkey
    </ResponseField>

    <ResponseField name="rentEpoch" type="u64">
      このアカウントが次にrentを支払うepoch
    </ResponseField>

    <ResponseField name="space" type="u64">
      アカウントのデータサイズ
    </ResponseField>
  </Expandable>
</ResponseField>
