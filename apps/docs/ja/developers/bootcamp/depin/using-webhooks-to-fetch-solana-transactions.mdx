## レッスンの目標

クリーンなイベントパイプラインを設定し、継続的な手動ポーリングなしにデバイスやアプリがSolanaのアクティビティに反応できるようにします。

## チェックポイント

- フローに関連するWebhookイベントを把握する。
- 受信サービスがそれらをどのようにvalidateし処理すべきかを確認する。
- Webhookの配信が失敗または遅延した場合の対処方法を決定する。
