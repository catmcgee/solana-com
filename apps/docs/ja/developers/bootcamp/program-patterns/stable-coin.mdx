## プロジェクトの目標

トークンの作成、ミント権限、および転送ルールが製品の動作にどう影響するかを理解する。

## チェックポイント

- ミントを管理する者と、その権限を交代できる者を書き留める。
- 残高、供給量、メタデータの検証方法を確認する。
- 通常のミントフローと権限のエッジケースの両方をテストする。
