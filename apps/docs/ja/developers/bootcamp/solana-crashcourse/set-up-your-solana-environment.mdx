## レッスンの目標

動画を見るだけでなく、実際にSolanaでビルドを始められるよう、安定したローカル環境を構築します。

## チェックポイント

- コアCLIと開発サポートツールをインストールする。
- マシンが想定されるローカルワークフローを実行できることを確認する。
- 次のステップに進む前に修正が必要なセットアップの問題を洗い出す。
