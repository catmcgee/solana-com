Solanaの単一グローバル状態、約400msのブロックタイム、そして1セント未満の手数料により、オンチェーンファイナンスとDeFiの中心地となっています。DEX、レンディングマーケット、オラクル、パーペチュアルなど、あらゆるプログラムが単一のアトミックトランザクション内でコンポーザブルです。このセクションは金融アプリケーション構築のためのワークフロー層であり、基礎となるメカニズムについては[コアコンセプト](/docs/core/transactions)および[クックブック](/developers/cookbook)にリンクしています。
