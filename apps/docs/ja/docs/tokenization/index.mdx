Solanaは、トークン化された資産を大規模に発行・運用するために設計されています。サブ秒のファイナリティ、$0.001未満の手数料、そしてネイティブなコンプライアンス制御（転送制限、一時停止機能、機密転送、永続デリゲート）を備えたトークン標準を提供しており、他のチェーンではカスタムスマートコントラクトが必要なこれらの機能をすぐに利用できます。

## 全体像

Solana上のトークン化された資産は、[Token-2022 program](/docs/tokens)とその[拡張機能](/docs/tokens/extensions)をベースに構築されています。これらはコアドキュメントに記載されている共通のプリミティブです。このセクションはワークフロー指向で構成されており、各ページではタスクをエンドツーエンドで解説し、完全なAPIサーフェスが必要な場合は基盤となる拡張機能のリファレンスへのリンクも提供しています。
