1つのコマンドでローカルのSolana開発環境をセットアップできます。このコマンドにより、Rust、Solana CLI、Anchor フレームワーク、Surfpool、Node.js、およびYarnがWindows（WSL）、Linux、Macにインストールされます。

## 前提条件

<AccordionGroup>
<Accordion title="Windows">

WindowsでSolanaプログラムを開発するには、[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)（WSL）を**必ず**使用する必要があります。WSLをインストールした後、他のすべての依存関係はLinuxターミナルを通じてインストールされます。

WSLをインストールするには、Windows PowerShellで次のコマンドを実行します。

```bash Terminal
wsl --install
```

インストールプロセスでは、デフォルトのユーザーアカウントを作成するよう求められます。

<Frame caption="WSLインストール">
  ![WSLインストール](/docs-assets/assets/docs/intro/installation/wsl-install.png)
</Frame>

デフォルトでは、WSLはUbuntuをインストールします。検索バーで「Ubuntu」を検索することで、Linuxターミナルを開くことができます。

<Frame caption="WSL Ubuntu">
  ![WSL Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-search.png)
</Frame>

Ubuntuターミナルが下の画像のように表示される場合、`ctrl + v`（貼り付けのキーボードショートカット）がターミナルで機能しない問題が発生する可能性があります。

<Frame caption="Ubuntuターミナル">
  ![Ubuntuターミナル](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)
</Frame>

この問題が発生した場合は、検索バーで「Terminal」を検索してWindowsターミナルを開きます。

<Frame caption="Windowsターミナル">
  ![Windowsターミナル](/docs-assets/assets/docs/intro/installation/wsl-windows-terminal.png)
</Frame>

次に、Windowsターミナルを閉じて、再度Ubuntuを検索してLinuxターミナルを開き直します。ターミナルは下の画像のように表示され、`ctrl + v`（貼り付けのキーボードショートカット）が機能するようになります。

<Frame caption="Ubuntuターミナル">
  ![Ubuntuターミナル](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)
</Frame>

VS
Codeを使用している場合、[WSL拡張機能](https://code.visualstudio.com/docs/remote/wsl-tutorial)を使用すると、WSLとVS
Codeを一緒に使用できます。

<Frame caption="VS CodeでのWSLセットアップ">
  ![VS CodeでのWSLセットアップ](/docs-assets/assets/docs/intro/installation/wsl-vscode.png)
</Frame>

VS Codeのステータスバーに以下が表示されます:

<Frame caption="WSL: Ubuntu">
  ![WSL: Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-vscode-ubuntu.png)
</Frame>

WSLのセットアップが完了したら、次のいずれかを実行できます:

- Ubuntu（Linux）ターミナルを使用して[クイックインストール](#installation)を完了する
- 以下に説明するように、[Rust](/docs/intro/installation/dependencies#install-rust)、[Solana CLI](/docs/intro/installation/dependencies#install-solana-cli)、[Anchor CLI](/docs/intro/installation/dependencies#install-anchor-cli)を個別にインストールする

</Accordion>
<Accordion title="Linux">

<Tabs>
<Tab title=".deb">
DebianまたはUbuntuやMintなどのDebian派生の代替OSを使用している場合は、以下の手順に従ってください:

1. すべてのパッケージが最新であることを確認するために、パッケージリストを更新します:

```bash Terminal
sudo apt-get update
```

2. 以下の依存関係をインストールします:

```bash Terminal
sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Note>
`protobuf-compiler`のインストール時に以下のエラーが発生した場合は、まず`sudo apt-get update`を実行してください

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Note>

  </Tab>

    <Tab title=".rpm">
    FedoraやRed Hat LinuxなどのRHEL派生OSの場合は、以下の手順に従ってください。

以下のコマンドを実行して、パッケージの新しいバージョンを取得するためにパッケージリストを更新します。

    ```bash Terminal
    sudo dnf upgrade --refresh
    ```

    次に、以下の依存関係をインストールします:

    ```bash Terminal
    sudo dnf group install c-development development-tools \
    && sudo dnf install pkg-config openssl-devel
    ```

  </Tab>
</Tabs>

## インストール

1. ターミナルに以下のコマンドを入力して、必要なすべての依存関係をインストールします:

```bash Terminal
curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

インストールが成功すると、次のような出力が返されます:

```txt title="Example output"
Installed Versions:
Rust: rustc 1.91.1 (ed61e7d7e 2025-11-07)
Solana CLI: solana-cli 3.0.10 (src:96c3a851; feat:3604001754, client:Agave)
Anchor CLI: anchor-cli 0.32.1
Surfpool CLI: surfpool 0.12.0
Node.js: v24.10.0
Yarn: 1.22.1
```

2. インストールされた各依存関係のバージョンを確認して、インストールが成功したことを検証します。

```bash Terminal
rustc --version && solana --version && anchor --version && surfpool --version && node --version && yarn --version
```

<Note>
  インストールコマンドが失敗した場合は、[各依存関係を個別にインストール](/docs/intro/installation/dependencies)してください。
</Note>
