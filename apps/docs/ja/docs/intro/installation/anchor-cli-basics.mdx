このセクションでは、[Anchor CLI](https://www.anchor-lang.com/docs)の使用を開始するための一般的なコマンドと例を紹介します。

<Steps titleSize="h3">
<Step title="プロジェクトの初期化">

以下のコマンドを実行して、新しいAnchorプロジェクトを作成します。プロジェクト名で新しいディレクトリが作成され、新しいAnchorプロジェクトが初期化されます。

```bash Terminal
anchor init <project-name>
```

例えば、以下のコマンドは`my-project`というプロジェクトを作成します。`my-project`ディレクトリには、基本的なRustプログラムとTypeScriptテストテンプレートが含まれます。

```bash Terminal
anchor init my-project
```

次に、プロジェクトディレクトリに移動します：

```bash Terminal
cd <project-name>
```

Anchorの[プロジェクトファイル構造](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure)を参照してください。

</Step>
<Step title="プログラムのビルド">

プロジェクトをビルドするには、次のコマンドを実行します：

```bash Terminal
anchor build
```

コンパイルされたプログラムは`/target/deploy`ディレクトリにあります。

<Warning>

`anchor build`を実行する際に、次のエラーが発生した場合：

<AccordionGroup>
<Accordion title="error: not a directory">

```
error: not a directory: '.../solana-release/bin/sdk/sbf/dependencies/platform-tools/rust/lib'
```

次の解決策を試してください：

1. 次のコマンドを使用して強制インストールします：

```bash Terminal
cargo build-sbf --force-tools-install
```

2. 前述の解決策が機能しない場合は、Solanaキャッシュをクリアします：

```bash Terminal
rm -rf ~/.cache/solana/*
```

</Accordion>

<Accordion title="lock file version 4 requires `-Znext-lockfile-bump">
`Cargo.lock`ファイルのversionフィールドを4から3に変更することで修正できます：

```diff Cargo.lock
-version = 4
+version = 3
```

詳細については、[この問題](https://github.com/solana-foundation/anchor/issues/3392)を参照してください。

</Accordion>

</AccordionGroup>

前述の解決策を適用した後、再度`anchor build`を実行してください。

</Warning>

</Step>
<Step title="プログラムをデプロイする">

プロジェクトをデプロイするには、次のコマンドを実行します：

```bash Terminal
anchor deploy
```

このコマンドは、[`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml)ファイルで指定された`cluster`にプログラムをデプロイします。

</Step>
<Step title="プログラムをテストする">

プロジェクトをテストするには、次のコマンドを実行します：

```bash Terminal
anchor test
```

このコマンドは、プロジェクトのビルド、デプロイ、テストの実行を行います。

<Note>
  `localnet`クラスターを使用する場合、Anchorは自動的にローカルvalidatorを起動し、プログラムをデプロイし、テストを実行してから、validatorを停止します。
</Note>

<Warning>

次のいずれかのエラーは、Node.jsまたはYarnがインストールされていないことを示している可能性があります：

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Warning>

</Step>
</Steps>
