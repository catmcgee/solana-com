slot通知の購読を解除する

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="integer" required>
  キャンセルするサブスクリプションID
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  購読解除成功メッセージ
</ResponseField>
