sidebarTitle: slotSubscribe

validatorによって処理されるたびにslotの通知を受け取るためにサブスクライブします

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**なし**

### Result

<ResponseField name="result" type="integer">
  サブスクリプションID（サブスクリプション解除に必要）
</ResponseField>

#### 通知フォーマット：

通知は以下のフィールドを持つオブジェクトになります：

- `parent: <u64>` - 親slot
- `root: <u64>` - 現在のルートslot
- `slot: <u64>` - 新しく設定されたslot値

例：

```json
{
  "jsonrpc": "2.0",
  "method": "slotNotification",
  "params": {
    "result": {
      "parent": 75,
      "root": 44,
      "slot": 76
    },
    "subscription": 0
  }
}
```
