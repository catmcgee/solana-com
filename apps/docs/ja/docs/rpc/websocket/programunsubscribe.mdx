プログラム所有アカウントの変更通知からの登録解除

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "programUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  キャンセルするアカウントサブスクリプションのID
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  登録解除成功メッセージ
</ResponseField>
