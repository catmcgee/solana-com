노드의 원장에서 정보를 가지고 있는 가장 낮은 slot을 반환합니다.

<Info>
  노드가 오래된 원장 데이터를 제거하도록 구성된 경우 이 값은 시간이 지남에 따라
  증가할 수 있습니다
</Info>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "minimumLedgerSlot"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let minLedgerSlot = await rpc.minimumLedgerSlot().send();

  console.log(minLedgerSlot);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let minLedgerSlot = await connection.getMinimumLedgerSlot();

  console.log(minLedgerSlot);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let min_ledger_slot = client.minimum_ledger_slot().await?;

      println!("{}", min_ledger_slot);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 1234,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

None

## Result

<ResponseField name="result" type="u64">
  최소 원장 slot 번호
</ResponseField>
