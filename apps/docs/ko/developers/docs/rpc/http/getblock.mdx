원장에서 확인된 블록에 대한 식별 정보와 트랜잭션 정보를 반환합니다

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getBlock",
      "params": [
        378967388,
        {
          "commitment": "finalized",
          "encoding": "json",
          "transactionDetails": "full",
          "maxSupportedTransactionVersion": 0,
          "rewards": false
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  const slot_number = BigInt(377261141);

  let block = await rpc
    .getBlock(
      slot_number,
      {
        commitment: "finalized",
        encoding: "json",
        transactionDetails: "full",
        maxSupportedTransactionVersion: 0,
        rewards: false
      }
    )
    .send();

  console.log("block:", block);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  const slot_number = 377261141;

  const block = await connection.getBlock(
    slot_number,
    {
      commitment: "finalized",
      transactionDetails: "full",
      maxSupportedTransactionVersion: 0,
      rewards: false
    }
  );

  console.log("block:", block);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;
  use solana_transaction_status_client_types::{TransactionDetails, UiTransactionEncoding};

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let slot_number = 377261141;

      let config = solana_client::rpc_config::RpcBlockConfig {
          encoding: UiTransactionEncoding::Base58.into(),
          transaction_details: TransactionDetails::Full.into(),
          rewards: None,
          commitment: CommitmentConfig::finalized().into(),
          max_supported_transaction_version: Some(0),
      };
      let block = client.get_block_with_config(slot_number, config).await?;

      println!("Block: {:#?}", block);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="slot number" type="u64" required>
  Slot 번호.
</ParamField>

<ParamField body="1" type="object">
  설정 객체.

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string" default="finalized">
      Values: `confirmed`, `finalized`

      커밋먼트는 해당 시점에서 블록이 얼마나 확정되었는지를 설명합니다.
      [상태 커밋먼트 설정](/developers/docs/rpc#configuring-state-commitment)을 참조하세요.

      - `processed`는 지원되지 않습니다.
    </ParamField>

    <ParamField body="encoding" type="string" default="json">
      Values: `json`, `jsonParsed`, `base58`, `base64`

      반환된 각 트랜잭션의 인코딩 형식입니다.
      [파싱된 응답](/developers/docs/rpc#parsed-responses)을 참조하세요.

      - `jsonParsed`는 프로그램별 명령어 파서를 사용하여
        `transaction.message.instructions` 목록에서 더 읽기 쉽고 명시적인 데이터를
        반환하려고 시도합니다.
      - `jsonParsed`가 요청되었지만 파서를 찾을 수 없는 경우, 명령어는 일반 JSON
        인코딩(`accounts`, `data`, 및 `programIdIndex` 필드)으로 대체됩니다.
    </ParamField>

    <ParamField body="transactionDetails" type="string" default="full">
      Values: `full`, `accounts`, `signatures`, `none`

      반환할 트랜잭션 세부 정보의 수준입니다.

      - `accounts`가 요청된 경우, 트랜잭션 세부 정보는 서명과 각 트랜잭션의 주석이
        달린 계정 목록만 포함합니다.
      - 트랜잭션 메타데이터는 다음으로만 제한됩니다: fee, err, pre_balances,
        post_balances, pre_token_balances, post_token_balances.
    </ParamField>

    <ParamField body="maxSupportedTransactionVersion" type="number" default="0">
      Values: `0`

      현재, 이 매개변수에 유효한 값은 `0`뿐입니다. 이 값을 `0`으로 설정하면 버전이
      지정된 트랜잭션과 레거시 트랜잭션을 포함한 모든 트랜잭션을 가져올 수 있습니다.

      이 매개변수는 응답에서 반환될 최대 트랜잭션 버전을 결정합니다. 이 값보다 높은
      버전의 트랜잭션을 요청하면 오류가 반환됩니다. 이 매개변수를 생략하면 레거시
      트랜잭션만 반환되며, 버전이 지정된 트랜잭션은 오류를 발생시킵니다.
    </ParamField>

    <ParamField body="rewards" type="bool">
      보상 배열을 채울지 여부입니다. 매개변수가 제공되지 않으면 기본적으로 보상이
      포함됩니다.
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="object | null">
  지정된 블록이 확인되지 않은 경우 결과는 `null`입니다. 그렇지 않으면 다음을
  포함하는 객체입니다:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="blockHeight" type="u64 | null">
      이 블록 아래에 있는 블록의 수입니다.
    </ResponseField>

    <ResponseField name="blockTime" type="i64 | null">
      유닉스 타임스탬프(유닉스 에포크 이후 초)로 표시된 예상 생성 시간입니다. 사용할
      수 없는 경우 `null`입니다.
    </ResponseField>

    <ResponseField name="blockhash" type="string">
      base-58로 인코딩된 문자열로 표시된 이 블록의 블록해시입니다
    </ResponseField>

    <ResponseField name="parentSlot" type="u64">
      이 블록의 부모 slot 인덱스입니다
    </ResponseField>

    <ResponseField name="previousBlockhash" type="string">
      이 블록의 부모 블록해시로, base-58로 인코딩된 문자열입니다. 원장 정리로 인해
      부모 블록을 사용할 수 없는 경우, 이 필드는 "11111111111111111111111111111111"을
      반환합니다.
    </ResponseField>

    <ResponseField name="transactions" type="array">
      "전체" 트랜잭션 세부 정보가 요청된 경우 표시됩니다. 다음을 포함하는 JSON 객체
      배열입니다:

      - `transaction: <object|[string,encoding]>` - 인코딩 매개변수에 따라 JSON 형식
        또는 인코딩된 이진 데이터로 된
        [트랜잭션](/developers/docs/rpc/json-structures#transactions) 객체입니다.
      - `meta: <object>` - 트랜잭션 상태
        [메타데이터 객체](/developers/docs/rpc/json-structures#transaction-status-metadata) 또는
        `null`.
    </ResponseField>
  </Expandable>
</ResponseField>
