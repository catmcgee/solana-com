최근 성능 샘플 목록을 슬롯 역순으로 반환합니다. 성능 샘플은 60초마다 수집되며,
주어진 시간 창에서 발생한 트랜잭션 수와 슬롯 수를 포함합니다.

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getRecentPerformanceSamples",
      "params": [
        2
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let limit = 2;

  let performanceSamples = await rpc.getRecentPerformanceSamples(limit).send();

  console.log(performanceSamples);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let limit = 2;

  let performanceSamples = await connection.getRecentPerformanceSamples(limit);

  console.log(performanceSamples);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let limit = 2;
      let performance_samples = client.get_recent_performance_samples(limit.into()).await?;

      println!("{:#?}", performance_samples);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="샘플 수" type="usize">
  반환할 샘플 수(최대 720개)
</ParamField>

## Result

<ResponseField name="result" type="array">
  다음 내용을 포함하는 성능 샘플 객체의 배열:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="slot" type="u64">
      샘플이 수집된 슬롯
    </ResponseField>

    <ResponseField name="numTransactions" type="u64">
      샘플 기간 동안 처리된 트랜잭션 수
    </ResponseField>

    <ResponseField name="numSlots" type="u64">
      샘플 기간 동안 완료된 슬롯 수
    </ResponseField>

    <ResponseField name="samplePeriodSecs" type="u16">
      샘플 윈도우의 초 단위 시간
    </ResponseField>

    <ResponseField name="numNonVoteTransactions" type="u64">
      샘플 기간 동안 처리된 비투표 트랜잭션 수

      <Info>
        `numNonVoteTransactions`는 v1.15부터 제공됩니다. 투표 트랜잭션 수를 계산하려면
        다음을 사용하세요: `numTransactions - numNonVoteTransactions`
      </Info>
    </ResponseField>
  </Expandable>
</ResponseField>
