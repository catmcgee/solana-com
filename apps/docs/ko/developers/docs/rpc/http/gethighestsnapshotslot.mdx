---
title: getHighestSnapshotSlot RPC 메소드
sidebarTitle: getHighestSnapshotSlot
---

노드가 가지고 있는 스냅샷의 가장 높은 slot 정보를 반환합니다.

이는 가장 높은 전체 스냅샷 slot과, 만약 존재한다면 전체 스냅샷 slot을 _기반으로
한_ 가장 높은 증분 스냅샷 slot을 찾습니다.

<Warning>
  **버전 제한**

  이 메소드는 `solana-core` v1.9 이상에서만 사용 가능합니다. `solana-core` v1.8
  이하에서는 [getSnapshotSlot](/developers/docs/rpc/deprecated/getsnapshotslot)을 사용해
  주세요.
</Warning>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getHighestSnapshotSlot"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let hightestSnapshotSlot = await rpc.getHighestSnapshotSlot().send();

  console.log(hightestSnapshotSlot);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let highest_snapshot_slot = client.get_highest_snapshot_slot().await?;

      println!("{:#?}", highest_snapshot_slot);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json 스냅샷
  {
    "jsonrpc": "2.0",
    "result": {
      "full": 100,
      "incremental": 110
    },
    "id": 1
  }
  ```

  ```json title="스냅샷 없음"
  {
    "jsonrpc": "2.0",
    "error": {
      "code": -32008,
      "message": "No snapshot"
    },
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

None

## Result

<ResponseField name="result" type="object" post={["스냅샷"]}>
  노드에 스냅샷이 있을 때, 다음 필드를 포함하는 JSON 객체를 반환합니다:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="full" type="u64">
      가장 높은 전체 스냅샷 slot
    </ResponseField>

    <ResponseField name="incremental" type="u64 | null">
      `full`을 _기반으로 한_ 가장 높은 증분 스냅샷 slot
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="result" type="object" post={["스냅샷 없음"]}>
  노드에 스냅샷이 없는 경우, JSON RPC 오류 응답이 반환됩니다.
</ResponseField>
