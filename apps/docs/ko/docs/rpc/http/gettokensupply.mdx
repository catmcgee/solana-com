SPL 토큰 유형의 총 공급량을 반환합니다.

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getTokenSupply",
      "params": [
        "3wyAj7Rt1TWVPZVteFJPLa26JmLvdb1CAKEFZm3NY75E",
        {
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { address, createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let mint = address("Gh9ZwEmdLJ8DscKNTkTqPbNwLNNBjuSzaG9Vp2KGtKJr");

  let tokenSupply = await rpc.getTokenSupply(mint).send();

  console.log(tokenSupply);
  ```

  ```ts web3.js
  import { Connection, PublicKey, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let mint = new PublicKey!("Gh9ZwEmdLJ8DscKNTkTqPbNwLNNBjuSzaG9Vp2KGtKJr");

  let tokenSupply = await connection.getTokenSupply(mint);

  console.log(tokenSupply);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::{commitment_config::CommitmentConfig, pubkey};

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let mint = pubkey!("Gh9ZwEmdLJ8DscKNTkTqPbNwLNNBjuSzaG9Vp2KGtKJr");

      let token_supply = client.get_token_supply(&mint).await?;

      println!("{:#?}", token_supply);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="pubkey" type="string" required>
  조회할 토큰 Mint의 pubkey, base-58로 인코딩된 문자열
</ParamField>

<ParamField body="1" type="object">
  다음 필드를 포함하는 구성 객체:

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      commitment는 해당 시점에서 블록이 얼마나 확정되었는지를 설명합니다.
      [상태 커밋 구성](/docs/rpc#configuring-state-commitment)을 참조하세요.
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="object">
  다음을 포함하는 JSON 객체:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="amount" type="string">
      소수점 없는 원시 토큰 총 공급량, u64의 문자열 표현
    </ResponseField>

    <ResponseField name="decimals" type="u8">
      소수점 오른쪽의 10진수 자릿수
    </ResponseField>

    <ResponseField name="uiAmount" type="number | null !deprecated">
      민트에서 지정한 소수점을 사용한 총 토큰 공급량
    </ResponseField>

    <ResponseField name="uiAmountString" type="string">
      민트에서 지정한 소수점을 사용한 문자열 형태의 총 토큰 공급량
    </ResponseField>
  </Expandable>
</ResponseField>
