title: rootSubscribe RPC 메소드
sidebarTitle: rootSubscribe
---

Validator가 새로운 루트를 설정할 때마다 알림을 받기 위해 구독합니다.

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**없음**

### Result

<ResponseField name="result" type="integer">
  구독 ID (구독 취소 시 필요)
</ResponseField>

#### 알림 형식:

결과는 최신 루트 slot 번호입니다.

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
