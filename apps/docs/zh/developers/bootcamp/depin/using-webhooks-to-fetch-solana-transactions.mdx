## 课程目标

建立更简洁的事件管道，使设备或应用能够响应 Solana 活动，
无需持续手动轮询。

## 检查点

- 了解哪些 Webhook 事件对您的流程至关重要。
- 注意接收服务应如何验证和处理这些事件。
- 确定当 Webhook 推送失败或延迟时应采取的应对措施。
