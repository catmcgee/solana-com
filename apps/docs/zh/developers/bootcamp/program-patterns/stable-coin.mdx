## 项目目标

了解代币创建、铸造权限和转账规则如何影响产品行为。

## 检查点

- 记录谁控制铸造权限以及谁可以轮换该权限。
- 确认应如何验证余额、供应量和元数据。
- 测试正常铸造流程和权限边界情况。
