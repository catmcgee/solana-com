## 项目目标

通过明确的所有权和释放规则，模拟托管交互流程。

## 检查点

- 在编写代码之前，列出所有托管状态转换。
- 验证创建、接受、取消和结算操作的权限模型。
- 确认每个步骤的 PDA 派生方式和签名者要求。
