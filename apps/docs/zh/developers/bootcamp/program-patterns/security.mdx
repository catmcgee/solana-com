## 回顾目标

将你在训练营中已经使用过的模式转化为可重复执行的安全检查清单。

## 检查要点

- 审查账户约束条件和签名者假设。
- 查找缺失的权限检查和意外的状态转换。
- 至少记录一个你希望测试在后续持续验证的不变量。
