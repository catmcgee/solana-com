## 课程目标

搭建一个稳定可靠的本地环境，让你能够从观看视频转变为真正在 Solana 上进行开发。

## 检查要点

- 安装核心 CLI 及相关开发工具。
- 确认你的机器能够运行预期的本地工作流。
- 记录所有需要在继续之前解决的配置问题。
