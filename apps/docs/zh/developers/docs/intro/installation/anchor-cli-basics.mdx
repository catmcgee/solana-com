本节提供了一些常用命令和示例，帮助您开始使用
[Anchor CLI](https://www.anchor-lang.com/docs)。

<Steps titleSize="h3">
<Step title="初始化项目">

通过运行下方命令创建一个新的 Anchor 项目。该命令会以项目名称创建一个新目录，并在其中初始化一个新的 Anchor 项目。

```bash Terminal
anchor init <project-name>
```

例如，下方命令会创建一个名为 `my-project` 的项目。 `my-project`
目录中将包含一个基础 Rust 程序和 TypeScript 测试模板。

```bash Terminal
anchor init my-project
```

然后进入项目目录：

```bash Terminal
cd <project-name>
```

参见 Anchor 的[项目文件结构](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure)。

</Step>
<Step title="构建程序">

要构建您的项目，请运行以下命令：

```bash Terminal
anchor build
```

编译后的程序可以在 `/target/deploy` 目录中找到。

<Warning>

运行 `anchor build` 时，如果遇到以下错误：

<AccordionGroup>
<Accordion title="error: not a directory">

```
error: not a directory: '.../solana-release/bin/sdk/sbf/dependencies/platform-tools/rust/lib'
```

请尝试以下解决方法：

1. 使用下方命令强制安装：

```bash Terminal
cargo build-sbf --force-tools-install
```

2. 如果上述方法无效，请清除 Solana 缓存：

```bash Terminal
rm -rf ~/.cache/solana/*
```

</Accordion>

<Accordion title="lock file version 4 requires `-Znext-lockfile-bump">
您可以通过将 `Cargo.lock` 文件中的 version 字段从 4 改为 3 来解决此问题：

```diff Cargo.lock
-version = 4
+version = 3
```

有关更多信息，请参见
[此 issue](https://github.com/solana-foundation/anchor/issues/3392)。

</Accordion>

</AccordionGroup>

应用上述方法后，请再次尝试运行 `anchor build`。

</Warning>

</Step>
<Step title="部署程序">

要部署您的项目，请运行以下命令：

```bash Terminal
anchor deploy
```

此命令会将您的程序部署到
[`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml)
文件中指定的 `cluster`。

</Step>
<Step title="测试程序">

要测试您的项目，请运行以下命令：

```bash Terminal
anchor test
```

此命令会构建、部署并运行您的项目测试。

<Note>
  当使用 `localnet` 集群时，Anchor 会自动启动本地
  validator，部署程序，运行测试，然后停止 validator。
</Note>

<Warning>

出现以下任一错误可能表示您未安装 Node.js 或 Yarn：

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Warning>

</Step>
</Steps>
