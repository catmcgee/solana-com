title: rootSubscribe RPC 方法
sidebarTitle: rootSubscribe
---

订阅以在 validator 设置新 root 时接收通知。

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**无**

### Result

<ResponseField name="result" type="integer">
  订阅 ID（用于取消订阅）
</ResponseField>

#### 通知格式：

结果是最新的 root slot 编号。

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
