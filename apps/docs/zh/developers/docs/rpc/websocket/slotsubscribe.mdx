订阅以在验证器处理 slot 时接收通知

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**无**

### Result

<ResponseField name="result" type="integer">
  订阅 ID（用于取消订阅）
</ResponseField>

#### 通知格式：

通知将是一个包含以下字段的对象：

- `parent: <u64>` - 父 slot
- `root: <u64>` - 当前根 slot
- `slot: <u64>` - 新设置的 slot 值

示例：

```json
{
  "jsonrpc": "2.0",
  "method": "slotNotification",
  "params": {
    "result": {
      "parent": 75,
      "root": 44,
      "slot": 76
    },
    "subscription": 0
  }
}
```
