返回与查询的 blockhash 关联的费用计算器，或者如果 blockhash 已过期，则返回
`null`

<Warning>
  **已弃用的方法**

  此方法预计将在 `solana-core` v2.0 中移除。请改用
  [isBlockhashValid](/developers/docs/rpc/http/isblockhashvalid) 或
  [getFeeForMessage](/developers/docs/rpc/http/getfeeformessage)。
</Warning>
