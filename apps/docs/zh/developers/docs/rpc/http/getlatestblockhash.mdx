返回最新的区块哈希值

<Warning>
  **版本限制**

  此方法仅适用于 `solana-core` v1.9 或更新版本。对于 `solana-core` v1.8
  及以下版本，请使用
  [getRecentBlockhash](/developers/docs/rpc/deprecated/getrecentblockhash)。
</Warning>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getLatestBlockhash",
      "params": [
        {
          "commitment": "processed"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc, type Commitment } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let commitment: Commitment = "processed";
  let latestBlockhash = await rpc.getLatestBlockhash({ commitment }).send();

  console.log(latestBlockhash);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl, type Commitment } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let commitment: Commitment = "processed";
  let latestBlockhash = await connection.getLatestBlockhash(commitment);

  console.log(latestBlockhash);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let commitment = CommitmentConfig::processed();
      let latest_blockhash = client
          .get_latest_blockhash_with_commitment(commitment)
          .await?;

      println!("{:#?}", latest_blockhash);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="0" type="object">
  包含以下字段的配置对象：

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      承诺描述了区块在该时间点的最终确定程度。详见
      [配置状态承诺](/developers/docs/rpc#configuring-state-commitment)。
    </ParamField>

    <ParamField body="minContextSlot" type="number">
      请求可以评估的最小 slot
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="object">
  RpcResponse JSON 对象，其中 `value` 字段设置为包含以下内容的 JSON 对象：

  <Expandable title="properties" defaultOpen>
    <ResponseField name="blockhash" type="string">
      以 base-58 编码的哈希字符串
    </ResponseField>

    <ResponseField name="lastValidBlockHeight" type="u64">
      最后一个
      [区块高度](/developers/docs/references/terminology#block-height)，在该高度区块哈希仍然有效
    </ResponseField>
  </Expandable>
</ResponseField>
