---
title: getSignaturesForAddress RPC 方法
sidebarTitle: getSignaturesForAddress
---

返回包含指定地址的已确认交易的签名，这些交易的 `accountKeys`
列表中包含该地址。从提供的签名或最近确认的区块开始，按时间倒序返回签名。

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getSignaturesForAddress",
      "params": [
        "Vote111111111111111111111111111111111111111",
        {
          "commitment": "finalized",
          "limit": 1
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { address, createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let addr = address("Vote111111111111111111111111111111111111111");

  let signaturesForConfig = {
    limit: 1
  };

  let signatures = await rpc
    .getSignaturesForAddress(addr, signaturesForConfig)
    .send();

  console.log(signatures);
  ```

  ```ts web3.js
  import {
    Connection,
    PublicKey,
    clusterApiUrl,
    type SignaturesForAddressOptions
  } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let signaturesOptions: SignaturesForAddressOptions = {
    limit: 1
  };

  let address = new PublicKey("Vote111111111111111111111111111111111111111");
  let signatures = await connection.getSignaturesForAddress(
    address,
    signaturesOptions
  );

  console.log(signatures);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::{
      nonblocking::rpc_client::RpcClient, rpc_client::GetConfirmedSignaturesForAddress2Config,
  };
  use solana_sdk::{commitment_config::CommitmentConfig, pubkey};

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let address = pubkey!("Vote111111111111111111111111111111111111111");

      let signatures_for_config = GetConfirmedSignaturesForAddress2Config {
          before: None,
          until: None,
          limit: Some(1),
          commitment: CommitmentConfig::finalized().into(),
      };

      let signatures = client
          .get_signatures_for_address_with_config(&address, signatures_for_config)
          .await?;

      println!("{:#?}", signatures);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="address" type="string" required>
  账户地址，使用 base-58 编码的字符串
</ParamField>

<ParamField body="1" type="object">
  包含以下字段的配置对象：

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      承诺描述了区块在某一时间点的最终确定程度。详见
      [配置状态承诺](/developers/docs/rpc#configuring-state-commitment)。
    </ParamField>

    <ParamField body="minContextSlot" type="number">
      请求可以评估的最小 slot
    </ParamField>

    <ParamField body="limit" type="number">
      返回的最大交易签名数量（介于 1 到 1,000 之间）。

      默认值：`1000`
    </ParamField>

    <ParamField body="before" type="string">
      从此交易签名开始向后搜索。如果未提供，则从最高确认区块的顶部开始搜索。
    </ParamField>

    <ParamField body="until" type="string">
      搜索直到找到此交易签名，或在达到限制之前找到为止。
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="array">
  一个交易签名信息对象的数组，从**最新**到**最旧**的交易排序，包含：

  <Expandable title="properties" defaultOpen>
    <ResponseField name="signature" type="string">
      以 base-58 编码的交易签名字符串
    </ResponseField>

    <ResponseField name="slot" type="u64">
      包含该交易区块的 slot
    </ResponseField>

    <ResponseField name="err" type="object | null">
      如果交易失败则显示错误信息，如果交易成功则为 null。更多信息请参见[交易错误定义](https://github.com/solana-labs/solana/blob/c0c60386544ec9a9ec7119229f37386d9f070523/sdk/src/transaction/error.rs#L13)。
    </ResponseField>

    <ResponseField name="memo" type="string | null">
      与交易相关的备注，如果没有备注则为 null。
    </ResponseField>

    <ResponseField name="blockTime" type="i64 | null">
      交易处理时的估计生产时间，以 Unix 时间戳（自 Unix 纪元以来的秒数）表示。如果不可用则为 null。
    </ResponseField>

    <ResponseField name="confirmationStatus" type="string | null">
      交易的集群确认状态；可以是 `processed`、`confirmed` 或
      `finalized`。有关乐观确认的更多信息，请参阅
      [Commitment](/developers/docs/rpc/#configuring-state-commitment)。
    </ResponseField>
  </Expandable>
</ResponseField>
