返回一组 Pubkeys 的账户信息。

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getMultipleAccounts",
      "params": [
        [
          "vines1vzrYbzLMRdu58ou5XTby4qAqVRLmqo36NKPTg",
          "4fYNw3dojWmQ4dXtSGE9epjRGy9pFSx62YypT7avPYvA"
        ],
        {
          "encoding": "base58",
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { address, createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let addresses = [
    address("vines1vzrYbzLMRdu58ou5XTby4qAqVRLmqo36NKPTg"),
    address("4fYNw3dojWmQ4dXtSGE9epjRGy9pFSx62YypT7avPYvA")
  ];

  let config = {
    encoding: "base58",
    commitment: "finalized"
  };

  let accounts = await rpc.getMultipleAccounts(addresses, config).send();

  console.log(accounts);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_account_decoder::UiAccountEncoding;
  use solana_client::{nonblocking::rpc_client::RpcClient, rpc_config::RpcAccountInfoConfig};
  use solana_sdk::{commitment_config::CommitmentConfig, pubkey};

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let addresses = [
          pubkey!("vines1vzrYbzLMRdu58ou5XTby4qAqVRLmqo36NKPTg"),
          pubkey!("4fYNw3dojWmQ4dXtSGE9epjRGy9pFSx62YypT7avPYvA"),
      ];

      let config = RpcAccountInfoConfig {
          encoding: UiAccountEncoding::Base58.into(),
          data_slice: None,
          commitment: CommitmentConfig::finalized().into(),
          min_context_slot: None,
      };

      let accounts = client
          .get_multiple_accounts_with_config(&addresses, config)
          .await?;

      println!("{:#?}", accounts);

      Ok(())
  }
  ```

## Parameters

<ParamField body="0" type="array" required>
  一个要查询的 Pubkeys 数组，使用 base-58 编码的字符串（最多 100 个）。
</ParamField>

<ParamField body="1" type="object">
  包含以下字段的配置对象：

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      承诺描述了在某一时间点区块的最终确定程度。详见[配置状态承诺](/developers/docs/rpc#configuring-state-commitment)。
    </ParamField>

    <ParamField body="minContextSlot" type="number">
      请求可以被评估的最小 slot。
    </ParamField>

    <ParamField body="dataSlice" type="object">
      请求账户数据的一个切片。

      - `length: <usize>` - 要返回的字节数
      - `offset: <usize>` - 开始读取的字节偏移量

      <Info>
        数据切片仅适用于 `base58`、`base64` 或 `base64+zstd` 编码格式。
      </Info>
    </ParamField>

    <ParamField body="编码" type="string" default="base64">
      Values: `jsonParsed`, `base58`, `base64`, `base64+zstd`

      返回账户数据的编码格式

      - `base58` 速度较慢且仅限于小于 129 字节的账户数据。
      - `base64` 将返回任何大小账户数据的 base64 编码数据。
      - `base64+zstd` 使用 [Zstandard](https://facebook.github.io/zstd/)
        压缩账户数据并对结果进行 base64 编码。
      - `jsonParsed`
        编码尝试使用特定于程序的状态解析器返回更具可读性和更明确的账户状态数据。
      - 如果请求了 `jsonParsed` 但未找到解析器，则字段会回退到 `base64` 编码，可通过
        `data` 字段为类型 `<string>` 检测到。
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="array">
  结果将是一个包含以下内容的数组：

  - `null` - 如果该 Pubkey 的账户不存在，或者
  - 包含以下字段的账户对象：

  <Expandable title="properties" defaultOpen>
    <ResponseField name="数据" type="[string,encoding] | object">
      与账户关联的数据，可以是编码的二进制数据或 JSON 格式
      `{<program>: <state>}` - 取决于编码参数
    </ResponseField>

    <ResponseField name="可执行" type="bool">
      布尔值，指示账户是否包含程序（并且严格为只读）
    </ResponseField>

    <ResponseField name="lamports" type="u64">
      分配给此账户的 lamports 数量
    </ResponseField>

    <ResponseField name="所有者" type="string">
      分配给此账户的程序的 Base-58 编码 Pubkey
    </ResponseField>

    <ResponseField name="rentEpoch" type="u64">
      此账户下一次需要支付租金的 epoch
    </ResponseField>

    <ResponseField name="space" type="u64">
      账户的数据大小
    </ResponseField>
  </Expandable>
</ResponseField>
