---
title: getTokenAccountBalance RPC 方法
sidebarTitle: getTokenAccountBalance
---

返回 SPL Token 账户的代币余额。

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getTokenAccountBalance",
      "params": [
        "7fUAJdStEuGbc3sM84cKRL6yYaaSstyLSU4ve5oovLS7",
        {
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { address, createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let tokenAddress = address("48gpnn8nsmkvkgso7462Z1nFhUrprGQ71u1YLBPzizbY");

  let tokenBalance = await rpc.getTokenAccountBalance(tokenAddress).send();

  console.log(tokenBalance);
  ```

  ```ts web3.js
  import { Connection, PublicKey, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let tokenAddress = new PublicKey(
    "48gpnn8nsmkvkgso7462Z1nFhUrprGQ71u1YLBPzizbY"
  );

  let tokenBalance = await connection.getTokenAccountBalance(tokenAddress);

  console.log(tokenBalance);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::{commitment_config::CommitmentConfig, pubkey};

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let token_address = pubkey!("48gpnn8nsmkvkgso7462Z1nFhUrprGQ71u1YLBPzizbY");
      let token_acc_bal = client.get_token_account_balance(&token_address).await?;

      println!("{:#?}", token_acc_bal);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="pubkey" type="string" required>
  要查询的 Token 账户的 pubkey，使用 base-58 编码的字符串。
</ParamField>

<ParamField body="1" type="object">
  包含以下字段的配置对象：

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      commitment 描述了区块在某一时间点的最终确定程度。详见
      [配置状态承诺](/developers/docs/rpc#configuring-state-commitment)。
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="object">
  结果将是一个包含以下内容的 JSON 对象：

  <Expandable title="properties" defaultOpen>
    <ResponseField name="amount" type="string">
      不带小数点的原始余额，u64 的字符串表示形式。
    </ResponseField>

    <ResponseField name="decimals" type="u8">
      小数点右侧的基数为 10 的位数
    </ResponseField>

    <ResponseField name="uiAmount" type="number | null">
      余额，使用代币指定的小数位数 **已弃用**
    </ResponseField>

    <ResponseField name="uiAmountString" type="string">
      余额作为字符串，使用代币指定的小数位数
    </ResponseField>
  </Expandable>
</ResponseField>

<Info>
  有关返回数据的更多详细信息，请参阅 [Token Balances
  Structure](/developers/docs/rpc/json-structures#token-balances) 中的响应，该响应与
  [getBlock](/developers/docs/rpc/http/getblock) 的结构类似。
</Info>
