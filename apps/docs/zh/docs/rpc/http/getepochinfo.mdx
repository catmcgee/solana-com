---
title: getEpochInfo RPC 方法
sidebarTitle: getEpochInfo
---

返回当前 epoch 的信息

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getEpochInfo",
      "params": [
        {
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let epochInfo = await rpc.getEpochInfo().send();

  console.log(epochInfo);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let epochInfo = await connection.getEpochInfo();

  console.log(epochInfo);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let epoch_info = client.get_epoch_info().await?;

      println!("{:#?}", epoch_info);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="0" type="object">
  配置对象。

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      commitment 描述了在某一时刻区块的最终确定程度。详见
      [配置状态承诺](/docs/rpc#configuring-state-commitment)。
    </ParamField>

    <ParamField body="minContextSlot" type="number">
      请求可以被评估的最小 slot。
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="object">
  result 字段将是一个包含以下字段的对象：

  <Expandable title="properties" defaultOpen>
    <ResponseField name="absoluteSlot" type="u64">
      当前的 slot
    </ResponseField>

    <ResponseField name="blockHeight" type="u64">
      当前区块高度
    </ResponseField>

    <ResponseField name="epoch" type="u64">
      当前 epoch
    </ResponseField>

    <ResponseField name="slotIndex" type="u64">
      当前 slot 相对于当前 epoch 开始的索引
    </ResponseField>

    <ResponseField name="slotsInEpoch" type="u64">
      此 epoch 中的 slot 数量
    </ResponseField>

    <ResponseField name="transactionCount" type="u64 | null">
      自创世以来处理且无错误的交易总数
    </ResponseField>
  </Expandable>
</ResponseField>
