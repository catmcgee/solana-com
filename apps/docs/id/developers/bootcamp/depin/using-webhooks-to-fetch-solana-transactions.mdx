## Tujuan pelajaran

Siapkan pipeline event yang lebih bersih agar perangkat atau aplikasi dapat merespons aktivitas Solana
tanpa perlu melakukan polling manual secara terus-menerus.

## Pos pemeriksaan

- Pahami event webhook mana yang penting untuk alur Anda.
- Perhatikan bagaimana layanan penerima harus memvalidasi dan memprosesnya.
- Tentukan apa yang harus terjadi ketika pengiriman webhook gagal atau terlambat.
