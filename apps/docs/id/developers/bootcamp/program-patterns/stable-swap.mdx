## Tujuan proyek

Pelajari bagaimana aturan swap, likuiditas, dan asumsi harga memengaruhi perilaku protokol.

## Pos pemeriksaan

- Identifikasi invarian pool yang harus selalu terpenuhi.
- Lacak jalur swap dari input pengguna hingga saldo yang diperbarui.
- Verifikasi bagaimana biaya dan slippage ditampilkan dalam kode maupun antarmuka pengguna.
