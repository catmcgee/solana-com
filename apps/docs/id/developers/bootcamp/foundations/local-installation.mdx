## Apa yang akan Anda bangun

Pengaturan developer lokal dengan semua alat yang diperlukan untuk menjalankan contoh dan
men-deploy ke devnet.

## Daftar periksa pengaturan

- Instal Rust dan Solana CLI.
- Instal Node.js dan package manager pilihan Anda.
- Konfirmasi versi CLI dan konfigurasi wallet.
- Jalankan perintah dasar untuk memvalidasi lingkungan Anda.

## Kriteria selesai

Anda dapat menjalankan perintah tooling secara lokal tanpa error lingkungan.
