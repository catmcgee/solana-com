title: Metode RPC getRecentPrioritizationFees
sidebarTitle: getRecentPrioritizationFees

Mengembalikan daftar biaya prioritisasi dari blok-blok terbaru.

<Info>
  Saat ini, cache biaya prioritisasi node menyimpan data dari hingga 150 blok.
</Info>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getRecentPrioritizationFees",
      "params": [
        ["CxELquR1gPP8wHe33gZ4QxqGB3sZ9RSwsJ2KshVewkFY"]
      ]
    }
  '
  ```

  ```ts Kit
  import { address, createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let addresses = [address("CxELquR1gPP8wHe33gZ4QxqGB3sZ9RSwsJ2KshVewkFY")];
  let prioritizationFees = await rpc
    .getRecentPrioritizationFees(addresses)
    .send();

  console.log(prioritizationFees);
  ```

  ```ts web3.js
  import { Connection, PublicKey, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let addresses = [new PublicKey("CxELquR1gPP8wHe33gZ4QxqGB3sZ9RSwsJ2KshVewkFY")];

  let prioritizationFees = await connection.getRecentPrioritizationFees({
    lockedWritableAccounts: addresses
  });

  console.log(prioritizationFees);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::{commitment_config::CommitmentConfig, pubkey};

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let addresses = [pubkey!("CxELquR1gPP8wHe33gZ4QxqGB3sZ9RSwsJ2KshVewkFY")];
      let prioritization_fees = client.get_recent_prioritization_fees(&addresses).await?;

      println!("{:#?}", prioritization_fees);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="address" type="array">
  Array alamat Akun (hingga maksimum 128 alamat), sebagai string yang dienkode
  base-58

  <Info>
    Jika parameter ini disediakan, respons akan mencerminkan biaya untuk
    menjalankan transaksi yang mengunci semua akun yang disediakan sebagai
    writable.
  </Info>
</ParamField>

## Result

<ResponseField name="result" type="array">
  Array objek biaya prioritisasi yang berisi:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="slot" type="u64">
      Slot di mana biaya tersebut diamati
    </ResponseField>

    <ResponseField name="prioritizationFee" type="u64">
      Biaya per-unit-komputasi yang dibayarkan oleh setidaknya satu transaksi yang
      berhasil dijalankan, dinyatakan dalam satuan mikro-lamport (0,000001 lamport)
    </ResponseField>
  </Expandable>
</ResponseField>
