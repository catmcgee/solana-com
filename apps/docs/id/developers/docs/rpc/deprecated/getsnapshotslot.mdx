Mengembalikan slot tertinggi yang dimiliki node dalam bentuk snapshot

<Warning>
  **Metode yang Tidak Digunakan Lagi**

  Metode ini diperkirakan akan dihapus di `solana-core` v2.0. Silakan gunakan
  [getHighestSnapshotSlot](/developers/docs/rpc/http/gethighestsnapshotslot) sebagai
  gantinya.
</Warning>
