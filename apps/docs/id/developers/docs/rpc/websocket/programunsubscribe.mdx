---
title: Metode RPC programUnsubscribe
sidebarTitle: programUnsubscribe
---

Berhenti berlangganan notifikasi perubahan akun yang dimiliki program

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "programUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  id dari langganan akun yang akan dibatalkan
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  pesan keberhasilan berhenti berlangganan
</ResponseField>
