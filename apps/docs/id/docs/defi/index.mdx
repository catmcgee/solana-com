State global tunggal Solana, waktu blok ~400md, dan biaya di bawah satu sen menjadikannya
pusat keuangan onchain dan DeFi: setiap program - DEX, pasar pinjaman,
oracle, perps - dapat dikomposisikan dalam satu transaksi atomik. Bagian ini
adalah lapisan alur kerja untuk membangun aplikasi keuangan; bagian ini menautkan ke
[Konsep Inti](/docs/core/transactions) dan
[buku masak](/developers/cookbook) untuk mekanisme yang mendasarinya.
