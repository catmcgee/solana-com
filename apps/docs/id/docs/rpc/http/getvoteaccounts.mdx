title: Metode RPC getVoteAccounts
sidebarTitle: getVoteAccounts

Mengembalikan info akun dan stake terkait untuk semua akun voting di bank saat
ini.

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getVoteAccounts",
      "params": [
        {
          "commitment": "finalized",
          "votePubkey": "i7NyKBMJCA9bLM2nsGyAGCKHECuR2L5eh4GqFciuwNT"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { address, createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let votePubkey = address("5ZWgXcyqrrNpQHCme5SdC5hCeYb2o3fEJhF7Gok3bTVN");

  let voteAccounts = await rpc
    .getVoteAccounts({
      votePubkey
    })
    .send();

  console.log(voteAccounts);
  ```

  ```ts web3.js
  import { Connection, PublicKey, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let version = await connection.getVoteAccounts();

  console.log(version);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::{nonblocking::rpc_client::RpcClient, rpc_config::RpcGetVoteAccountsConfig};
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let vote_pubkey = String::from("5ZWgXcyqrrNpQHCme5SdC5hCeYb2o3fEJhF7Gok3bTVN");

      let config = RpcGetVoteAccountsConfig {
          vote_pubkey: Some(vote_pubkey),
          commitment: CommitmentConfig::finalized().into(),
          keep_unstaked_delinquents: None,
          delinquent_slot_distance: None,
      };

      let vote_accounts = client.get_vote_accounts_with_config(config).await?;

      println!("{:#?}", vote_accounts);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="0" type="object">
  Objek konfigurasi yang berisi bidang-bidang berikut:

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      Commitment menjelaskan seberapa final suatu blok pada titik waktu tersebut.
      Lihat [Mengonfigurasi State Commitment](/docs/rpc#configuring-state-commitment).
    </ParamField>

    <ParamField body="votePubkey" type="string">
      Hanya mengembalikan hasil untuk alamat vote validator ini (dikodekan base-58)
    </ParamField>

    <ParamField body="keepUnstakedDelinquents" type="bool">
      Tidak memfilter validator yang lalai tanpa stake
    </ParamField>

    <ParamField body="delinquentSlotDistance" type="u64">
      Tentukan jumlah slot di belakang tip yang harus dilewati validator untuk
      dianggap lalai. **CATATAN:** Demi konsistensi antara produk ekosistem,
      _**tidak** disarankan untuk menentukan argumen ini._
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="object">
  Bidang hasil akan berupa objek JSON dari akun `current` dan `delinquent`,
  masing-masing berisi array objek JSON dengan sub bidang berikut:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="activatedStake" type="u64">
      Stake, dalam lamport, yang didelegasikan ke akun vote ini dan aktif dalam epoch
      ini
    </ResponseField>

    <ResponseField name="commission" type="number">
      Persentase (0-100) dari pembayaran rewards yang diberikan ke akun vote
    </ResponseField>

    <ResponseField name="epochCredits" type="array">
      Riwayat terbaru dari kredit yang diperoleh hingga lima epoch, sebagai array dari
      array yang berisi: `[epoch, credits, previousCredits]`
    </ResponseField>

    <ResponseField name="epochVoteAccount" type="bool">
      Apakah akun vote di-stake untuk epoch ini
    </ResponseField>

    <ResponseField name="lastVote" type="u64">
      Slot terbaru yang divoting oleh akun vote ini
    </ResponseField>

    <ResponseField name="nodePubkey" type="string">
      Identitas validator, sebagai string yang dikodekan base-58
    </ResponseField>

    <ResponseField name="rootSlot" type="u64">
      Slot root saat ini untuk akun vote ini
    </ResponseField>

    <ResponseField name="votePubkey" type="string">
      Alamat akun vote, sebagai string yang dikodekan base-58
    </ResponseField>
  </Expandable>
</ResponseField>
