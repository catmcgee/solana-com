---
title: Metode RPC getHighestSnapshotSlot
sidebarTitle: getHighestSnapshotSlot
---

Mengembalikan informasi slot tertinggi yang memiliki snapshot pada node.

Ini akan menemukan slot snapshot penuh tertinggi, dan slot snapshot inkremental
tertinggi _berdasarkan_ slot snapshot penuh, jika ada.

<Warning>
  **Batasan Versi**

  Metode ini hanya tersedia di `solana-core` v1.9 atau yang lebih baru. Silakan
  gunakan [getSnapshotSlot](/docs/rpc/deprecated/getsnapshotslot) untuk
  `solana-core` v1.8 dan yang lebih lama.
</Warning>

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getHighestSnapshotSlot"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let hightestSnapshotSlot = await rpc.getHighestSnapshotSlot().send();

  console.log(hightestSnapshotSlot);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let highest_snapshot_slot = client.get_highest_snapshot_slot().await?;

      println!("{:#?}", highest_snapshot_slot);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Snapshot
  {
    "jsonrpc": "2.0",
    "result": {
      "full": 100,
      "incremental": 110
    },
    "id": 1
  }
  ```

  ```json title="Tidak Ada Snapshot"
  {
    "jsonrpc": "2.0",
    "error": {
      "code": -32008,
      "message": "No snapshot"
    },
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

None

## Result

<ResponseField name="result" type="object" post={["Snapshot"]}>
  Ketika node memiliki snapshot, ini mengembalikan objek JSON dengan bidang-bidang
  berikut:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="full" type="u64">
      Slot snapshot penuh tertinggi
    </ResponseField>

    <ResponseField name="incremental" type="u64 | null">
      Slot snapshot inkremental tertinggi _berdasarkan_ `full`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="result" type="object" post={["Tidak Ada Snapshot"]}>
  Jika node tidak memiliki snapshot, respons error JSON RPC akan dikembalikan.
</ResponseField>
