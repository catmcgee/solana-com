Mengembalikan saldo lamport dari akun dengan Pubkey yang diberikan

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getBalance",
      "params": [
        "83astBRguLMdt2h5U1Tpdq5tjFoJ6noeGwaY3mDLVcri",
        {
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { address, createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  const publicKey = address("83astBRguLMdt2h5U1Tpdq5tjFoJ6noeGwaY3mDLVcri");
  const balance = await rpc.getBalance(publicKey).send();

  console.log("Account Balance:", balance);
  ```

  ```ts web3.js
  import { Connection, PublicKey, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");
  const publicKey = new PublicKey("83astBRguLMdt2h5U1Tpdq5tjFoJ6noeGwaY3mDLVcri");
  const balance = await connection.getBalance(publicKey);

  console.log("Account Balance:", JSON.stringify(balance, null, 2));
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::{
      commitment_config::CommitmentConfig, native_token::LAMPORTS_PER_SOL, pubkey::Pubkey,
  };
  use std::str::FromStr;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let pubkey = Pubkey::from_str("83astBRguLMdt2h5U1Tpdq5tjFoJ6noeGwaY3mDLVcri")?;
      let balance = client.get_balance(&pubkey).await?;

      println!("{:#?} SOL", balance / LAMPORTS_PER_SOL);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="pubkey" type="string" required>
  Pubkey dari akun yang ingin diquery, sebagai string yang dienkode base-58.
</ParamField>

<ParamField body="1" type="object">
  Objek konfigurasi.

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      Commitment menjelaskan seberapa final suatu blok pada titik waktu tersebut.
      Lihat [Mengonfigurasi State Commitment](/docs/rpc#configuring-state-commitment).
    </ParamField>

    <ParamField body="minContextSlot" type="number">
      Slot minimum di mana permintaan dapat dievaluasi.
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="u64">
  Objek JSON RpcResponse dengan field value yang diatur ke saldo.
</ResponseField>
