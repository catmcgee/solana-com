title: Metode RPC slotSubscribe
sidebarTitle: slotSubscribe
---

Berlangganan untuk menerima notifikasi setiap kali slot diproses oleh validator

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Tidak ada**

### Result

<ResponseField name="result" type="integer">
  Id langganan (diperlukan untuk berhenti berlangganan)
</ResponseField>

#### Format Notifikasi:

Notifikasi akan berupa objek dengan bidang-bidang berikut:

- `parent: <u64>` - Slot induk
- `root: <u64>` - Slot root saat ini
- `slot: <u64>` - Nilai slot yang baru ditetapkan

Contoh:

```json
{
  "jsonrpc": "2.0",
  "method": "slotNotification",
  "params": {
    "result": {
      "parent": 75,
      "root": 44,
      "slot": 76
    },
    "subscription": 0
  }
}
```
