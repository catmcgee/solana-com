pembayaran dan pasar onchain sesuai kebutuhan produk Anda. Jika Anda baru dengan
model akun dan transaksi Solana, mulailah dengan [Konsep Inti](/docs/core).

## Menerbitkan dan mengelola aset

Jika Anda membuat aset alih-alih mengintegrasikan yang sudah ada,
lanjutkan ke [Penerbitan & Tokenisasi](/docs/tokenization). Ini mencakup pembuatan token,
kontrol akses, penyelesaian delivery-versus-payment, dan operasi dana.
