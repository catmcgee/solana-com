Siapkan lingkungan pengembangan Solana lokal Anda dengan satu perintah. Ini menginstal
Rust, Solana CLI, Anchor Framework, Surfpool, Node.js, dan Yarn di Windows
(WSL), Linux, dan Mac.

## Prasyarat

<AccordionGroup>
<Accordion title="Windows">

Untuk mengembangkan program Solana di Windows, Anda **harus** menggunakan
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). Setelah menginstal WSL, semua dependensi lainnya akan diinstal melalui
terminal Linux.

Untuk menginstal WSL, jalankan perintah berikut di Windows PowerShell:

```bash Terminal
wsl --install
```

Proses instalasi akan meminta Anda untuk membuat akun pengguna default.

<Frame caption="Instalasi WSL">
  ![Instalasi WSL](/docs-assets/assets/docs/intro/installation/wsl-install.png)
</Frame>

Secara default, WSL menginstal Ubuntu. Anda dapat membuka terminal Linux dengan
mencari "Ubuntu" di bilah pencarian.

<Frame caption="WSL Ubuntu">
  ![WSL Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-search.png)
</Frame>

Jika terminal Ubuntu Anda terlihat seperti gambar di bawah ini, Anda mungkin
mengalami masalah di mana `ctrl + v` (pintasan keyboard paste) tidak berfungsi
di terminal.

<Frame caption="Terminal Ubuntu">
  ![Terminal Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)
</Frame>

Jika Anda mengalami masalah ini, buka Windows Terminal dengan mencari "Terminal"
di bilah pencarian.

<Frame caption="Windows Terminal">
  ![Windows Terminal](/docs-assets/assets/docs/intro/installation/wsl-windows-terminal.png)
</Frame>

Selanjutnya, tutup Windows Terminal dan buka kembali terminal Linux dengan
mencari Ubuntu lagi. Terminal sekarang seharusnya terlihat seperti gambar di
bawah ini, di mana `ctrl + v` (pintasan keyboard paste) berfungsi.

<Frame caption="Terminal Ubuntu">
  ![Terminal Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)
</Frame>

Jika Anda menggunakan VS Code,
[ekstensi WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial)
memungkinkan Anda menggunakan WSL dan VS Code secara bersamaan.

<Frame caption="Pengaturan WSL di VS Code">
  ![Pengaturan WSL di VS Code](/docs-assets/assets/docs/intro/installation/wsl-vscode.png)
</Frame>

Anda akan melihat hal berikut di status bar VS Code:

<Frame caption="WSL: Ubuntu">
  ![WSL: Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-vscode-ubuntu.png)
</Frame>

Setelah Anda menyiapkan WSL, Anda siap untuk:

- Menyelesaikan [instalasi cepat](#installation) menggunakan terminal Ubuntu
  (Linux)
- Menginstal [Rust](/docs/intro/installation/dependencies#install-rust),
  [Solana CLI](/docs/intro/installation/dependencies#install-solana-cli), dan
  [Anchor CLI](/docs/intro/installation/dependencies#install-anchor-cli) secara
  terpisah, seperti yang dijelaskan di bawah ini

</Accordion>
<Accordion title="Linux">

<Tabs>
<Tab title=".deb">
Jika menggunakan Debian atau alternatif turunan Debian seperti Ubuntu atau Mint, ikuti langkah-langkah berikut:

1. Perbarui daftar paket untuk memastikan semua paket sudah terbaru:

```bash Terminal
sudo apt-get update
```

2. Instal dependensi berikut:

```bash Terminal
sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Note>
Jika Anda mengalami error berikut saat menginstal `protobuf-compiler`, pastikan
Anda menjalankan `sudo apt-get update` terlebih dahulu

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Note>

  </Tab>

    <Tab title=".rpm">
    Untuk turunan RHEL seperti Fedora atau Red Hat Linux, ikuti langkah-langkah berikut.

Perbarui daftar paket untuk mendapatkan versi paket yang lebih baru dengan
menjalankan perintah.

    ```bash Terminal
    sudo dnf upgrade --refresh
    ```

    Selanjutnya, instal dependensi berikut:

    ```bash Terminal
    sudo dnf group install c-development development-tools \
    && sudo dnf install pkg-config openssl-devel
    ```

  </Tab>

## Instalasi

1. Masukkan perintah berikut ke terminal Anda untuk menginstal semua dependensi
   yang diperlukan:

```bash Terminal
curl --proto '=https' --tlsv1.2 -sSfL https://solana-install.solana.workers.dev | bash
```

Instalasi yang berhasil akan menampilkan output seperti berikut:

```txt title="Example output"
Installed Versions:
Rust: rustc 1.91.1 (ed61e7d7e 2025-11-07)
Solana CLI: solana-cli 3.0.10 (src:96c3a851; feat:3604001754, client:Agave)
Anchor CLI: anchor-cli 0.32.1
Surfpool CLI: surfpool 0.12.0
Node.js: v24.10.0
Yarn: 1.22.1
```

2. Verifikasi instalasi yang berhasil dengan memeriksa versi dari setiap
   dependensi yang terinstal.

```bash Terminal
rustc --version && solana --version && anchor --version && surfpool --version && node --version && yarn --version
```

<Note>
  Jika perintah instalasi gagal, [instal setiap dependensi
  secara terpisah](/docs/intro/installation/dependencies).
</Note>
