  Learn how to write data to the Solana network by sending transactions and
  instructions. Follow step-by-step examples to transfer SOL and create a token
  mint using Solana Kit.

Di bagian sebelumnya, Anda telah mempelajari cara
[membaca data dari jaringan Solana](/docs/intro/quick-start/reading-from-network)
dengan mengambil akun. Menulis data ke jaringan Solana memerlukan sebuah
[transaksi](/docs/core/transactions). Sebuah transaksi berisi satu atau lebih
[instruksi](/docs/core/instructions), dan setiap instruksi memanggil sebuah
program.

Program mendefinisikan logika bisnis untuk setiap instruksi. Saat Anda mengirim
sebuah transaksi, runtime Solana mengeksekusi instruksi-instruksi dalam
transaksi tersebut secara berurutan. Transaksi bersifat atomik. Baik semua
instruksi dalam transaksi berhasil, atau seluruh transaksi gagal.

Contoh-contoh di bagian ini menunjukkan cara:

1. Mentransfer SOL antar akun
2. Membuat token mint baru

## Transfer SOL

Contoh di bawah ini mentransfer SOL dari satu akun ke akun lain. Hanya program
yang ditunjuk sebagai pemilik akun yang dapat mengubah data akun atau mengurangi
lamport dari saldonya. Akun dompet dimiliki oleh
[System Program](/docs/core/programs/builtin-programs#the-system-program), sehingga
menstransfer SOL antara akun dompet memerlukan instruksi yang memanggil
instruksi
[transfer](https://github.com/anza-xyz/agave/blob/v2.1.11/programs/system/src/system_processor.rs#L183-L213)
milik System Program. Akun sumber juga harus menandatangani transaksi.

```ts title="Transfer SOL"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getTransferSolInstruction } from "@solana-program/system";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const receiver = await generateKeyPairSigner();

const transferInstruction = getTransferSolInstruction({
  source: client.payer,
  destination: receiver.address,
  amount: lamports(10_000_000n)
});

const result = await client.sendTransaction([transferInstruction]);

console.log("Transaction Signature:", result.context.signature);

const { value: senderBalance } = await client.rpc
  .getBalance(client.payer.address)
  .send();
const { value: receiverBalance } = await client.rpc
  .getBalance(receiver.address)
  .send();

console.log("Sender Balance:", senderBalance);
console.log("Receiver Balance:", receiverBalance);
```

<Note>
  **`createClient`**

  Buat klien Kit untuk validator lokal. `generatedPayer()` menambahkan penanda
  tangan pembayar, `solanaRpc()` menambahkan kemampuan RPC dan pengiriman
  transaksi, `rpcAirdrop()` menambahkan `client.airdrop`, dan `airdropPayer()`
  mendanai pembayar dengan SOL uji coba.

  **`receiver`**

  Buat penanda tangan untuk akun yang menerima SOL. Penerima tidak perlu
  menandatangani transfer ini. Jika alamat penerima belum memiliki akun, menerima
  SOL akan membuat akun sistem di alamat tersebut.

  **`transferInstruction`**

  Buat instruksi System Program yang mentransfer lamport dari pembayar klien ke
  penerima.

  **`sendTransaction`**

  Kirim instruksi sebagai transaksi. Klien Kit mengambil blockhash terbaru,
  menetapkan pembayar biaya, menandatangani dengan penanda tangan yang diperlukan,
  mengirim transaksi, dan menunggu konfirmasi.

  **`balances`**

  Ambil saldo pengirim dan penerima setelah transaksi dikonfirmasi.
</Note>

## Buat token

Contoh di bawah ini membuat mint token baru menggunakan
[Token Extensions Program](/docs/tokens/extensions). Sebuah mint account adalah
akun yang mendefinisikan pengaturan global token, seperti desimal, pasokan,
otoritas mint, dan otoritas pembekuan.

Membuat mint account memerlukan dua instruksi:

1. Panggil System Program untuk membuat akun baru yang dimiliki oleh Token
   Extensions Program.
2. Panggil Token Extensions Program untuk menginisialisasi akun tersebut sebagai
   mint.

```ts title="Create mint account"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getCreateAccountInstruction } from "@solana-program/system";
import {
  fetchMint,
  getInitializeMintInstruction,
  getMintSize,
  TOKEN_2022_PROGRAM_ADDRESS
} from "@solana-program/token-2022";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const mint = await generateKeyPairSigner();

const space = BigInt(getMintSize());

const rent = await client.rpc.getMinimumBalanceForRentExemption(space).send();

const createAccountInstruction = getCreateAccountInstruction({
  payer: client.payer,
  newAccount: mint,
  space,
  lamports: rent,
  programAddress: TOKEN_2022_PROGRAM_ADDRESS
});

const initializeMintInstruction = getInitializeMintInstruction({
  mint: mint.address,
  decimals: 2,
  mintAuthority: client.payer.address,
  freezeAuthority: client.payer.address,
  tokenProgram: TOKEN_2022_PROGRAM_ADDRESS
});

const result = await client.sendTransaction([
  createAccountInstruction,
  initializeMintInstruction
]);

console.log("Mint Address:", mint.address);
console.log("Transaction Signature:", result.context.signature);

const mintAccount = await fetchMint(client.rpc, mint.address);
console.log("Mint Account:", mintAccount);
```

<Note>
  **`createClient`**

  Buat dan danai klien Kit untuk validator lokal. Pembayar yang didanai membayar
  rent akun dan biaya transaksi.

  **`mint`**

  Buat signer untuk digunakan sebagai alamat mint account baru. Signer tersebut
  mengotorisasi pembuatan akun itu.

  **`space`**

  Hitung jumlah byte yang diperlukan untuk mint account tanpa ekstensi.

  **`rent`**

  Hitung lamport yang diperlukan agar mint account bebas dari rent.

  **`createAccountInstruction`**

  Buat instruksi System Program yang membuat mint account dan menetapkan akun
  tersebut ke Token Extensions Program.

  **`initializeMintInstruction`**

  Buat instruksi Token Extensions Program yang menulis data mint awal ke dalam
  akun baru.

  **`sendTransaction`**

  Kirim kedua instruksi sebagai satu transaksi. Urutan instruksi penting: akun
  harus dibuat sebelum akun dapat diinisialisasi.

  **`mintAccount`**

  Ambil mint account setelah konfirmasi. Helper membaca akun dan mendeserialisasi
  field data mint account ke dalam tipe Mint.
</Note>
