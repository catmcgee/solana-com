Solanas einheitlicher globaler Zustand, ~400ms Blockzeiten und Sub-Cent-Fee machen es zum
Zuhause der Onchain-Finanzen und DeFi: Jedes Programm – DEXs, Kreditmärkte,
Oracles, Perps – ist innerhalb einer einzigen atomaren Transaktion kombinierbar. Dieser Abschnitt
ist die Workflow-Ebene für die Entwicklung von Finanzanwendungen; er verweist auf
[Core Concepts](/docs/core/transactions) und das
[Cookbook](/developers/cookbook) für die zugrundeliegenden Mechanismen.
