---
title: getSupportedTokens
description: Ruft die Liste der für Gebührenzahlungen unterstützten Token ab.
---

## JSON-RPC-Anfrage

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getSupportedTokens",
  "params": []
}
```

## JSON-RPC-Antwort

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "tokens": ["EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"]
  }
}
```

## cURL-Beispiel

```bash
curl -X POST http://localhost:8080 \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"getSupportedTokens","params":[]}'
```

## TypeScript SDK

```typescript
const { tokens } = await client.getSupportedTokens();
console.log("Supported tokens:", tokens);
// Output: ['EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v', ...]
```
