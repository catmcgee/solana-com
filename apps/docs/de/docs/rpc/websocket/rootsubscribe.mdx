---
title: rootSubscribe RPC-Methode
sidebarTitle: rootSubscribe
---

Abonnieren Sie Benachrichtigungen, wann immer ein neuer Root durch den Validator
festgelegt wird.

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Keine**

### Result

<ResponseField name="result" type="integer">
  Abonnement-ID (wird zum Abbestellen benötigt)
</ResponseField>

#### Benachrichtigungsformat:

Das Ergebnis ist die neueste Root-Slot-Nummer.

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
