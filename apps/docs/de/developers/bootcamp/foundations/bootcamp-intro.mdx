## Was diese Lektion behandelt

- Wie das vierspurige Bootcamp aufgebaut ist
- Wofür jede Begleitseite gedacht ist
- Wie man zwischen Videos, Notizen, Code und Checkpoints wechselt

## Bevor Sie fortfahren

- Setzen Sie das Bootcamp-Repository und die Lektions-Seitenleiste als Lesezeichen.
- Entscheiden Sie, wie Sie Notizen, Codeänderungen und Fragen festhalten möchten.
- Planen Sie, die Lektionen der Reihe nach abzuschließen, damit die späteren Tracks auf den früheren aufbauen.
