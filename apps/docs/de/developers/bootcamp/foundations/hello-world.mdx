## Projektziel

Ein minimales Solana-Projekt im Hello-World-Stil erstellen und erfolgreich ausführen.

## Meilensteine

1. Die Projektstruktur initialisieren.
2. Die kleinstmögliche sinnvolle Anweisung implementieren.
3. Die Anweisung ausführen und das Ergebnis überprüfen.
4. Erwartete Zustandsänderungen verifizieren.

## Wiederverwendung aus dem Schnellstart: Konten-Status lesen

Bevor Sie zu größeren Projekten übergehen, verwenden Sie den genauen Workflow zum Lesen von Konten aus
[`/docs/intro/quick-start/reading-from-network`](/docs/intro/quick-start/reading-from-network) erneut.

Verwenden Sie das Ergebnis dieser Anleitung, um folgende Grundlagen zu validieren:

- `executable` ist `false` für Wallet-Konten.
- `owner` ist das System Program für Wallet-Konten.
- `lamports` spiegelt das aufgeladene Guthaben wider.
- `space` ist `0` für System-Wallets ohne benutzerdefinierte Daten.

## Überprüfung

- Das Programm wird ohne Laufzeitfehler ausgeführt.
- Die Transaktionsbestätigung ist erfolgreich.
- Die erwartete Ausgabe bzw. der erwartete Zustand ist in den Logs oder Konten-Daten sichtbar.
