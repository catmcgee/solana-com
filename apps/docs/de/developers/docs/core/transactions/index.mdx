Eine Transaktion umfasst eine oder mehrere
[Anweisungen](/developers/docs/core/instructions), die Signaturen von Konten, die die
Änderungen autorisieren, und einen aktuellen Blockhash. Das Netzwerk verarbeitet
alle Anweisungen in einer Transaktion gemeinsam. Wenn eine Anweisung
fehlschlägt, schlägt die gesamte Transaktion fehl und alle Zustandsänderungen
werden rückgängig gemacht.

## Wichtige Fakten

- **Atomare Ausführung**: Alle Anweisungen sind erfolgreich oder alle werden
  rückgängig gemacht. Fees werden auch bei Fehlschlag berechnet.
- **Größenbeschränkung**: Maximal 1.232 Bytes, abgeleitet aus der IPv6-Mindest-MTU (1.280
  Bytes) abzüglich 48 Bytes für Netzwerk-Header. Das kommende
  [v1-Format](/developers/docs/core/transactions/versioned-transactions#v1-message-format)
  erhöht diesen Wert auf 4.096 Bytes.
- **Signaturen**: Jeder Signer liefert eine 64-Byte-Ed25519-Signatur.
- **Blockhash-Ablauf**: Der aktuelle Blockhash einer Transaktion ist für 150
  Slots gültig.
