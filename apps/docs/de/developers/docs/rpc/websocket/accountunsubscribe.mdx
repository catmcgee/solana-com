Abmeldung von Kontenänderungsbenachrichtigungen

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "accountUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  ID des Konten-Abonnements, das gekündigt werden soll
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  Erfolgsmeldung zur Abmeldung
</ResponseField>
