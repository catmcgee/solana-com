Abonnieren Sie ein Konto, um Benachrichtigungen zu erhalten, wenn sich die
Lamports oder Daten für einen bestimmten öffentlichen Kontoschlüssel ändern

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "accountSubscribe",
    "params": [
      "CM78CPUeXjn8o3yroDHxUtKsZZgoy4GPkPPXfouKNH12",
      {
        "encoding": "jsonParsed",
        "commitment": "finalized"
      }
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 23784,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

<ParamField body="0" type="string" required>
  Konto-Pubkey, als base-58 kodierte Zeichenfolge
</ParamField>

<ParamField body="1" type="object">
  Konfigurationsobjekt mit den folgenden Feldern:

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      Das Commitment beschreibt, wie endgültig ein Block zu diesem Zeitpunkt ist.
      Siehe
      [Konfiguration des State Commitment](/developers/docs/rpc#configuring-state-commitment).
    </ParamField>

    <ParamField body="encoding" type="string">
      Values: `base58`, `base64`, `base64+zstd`, `jsonParsed`

      Kodierungsformat für Kontodaten

      - `base58` ist langsam.
      - `jsonParsed` Kodierung versucht, programmspezifische Zustandsparser zu
        verwenden, um besser lesbare und explizitere Kontenzustandsdaten zurückzugeben
      - Wenn `jsonParsed` angefordert wird, aber kein Parser gefunden werden kann,
        fällt das Feld auf binäre Kodierung zurück, erkennbar wenn das `data` Feld vom
        Typ `string` ist.
    </ParamField>
  </Expandable>
</ParamField>

### Result

<ResponseField name="result" type="number">
  Abonnement-ID (wird zum Abbestellen benötigt)
</ResponseField>

#### Benachrichtigungsformat:

Das Benachrichtigungsformat ist dasselbe wie im
[getAccountInfo](/developers/docs/rpc/http/getaccountinfo) RPC HTTP-Methode.

Base58-Kodierung:

```json
{
  "jsonrpc": "2.0",
  "method": "accountNotification",
  "params": {
    "result": {
      "context": {
        "slot": 5199307
      },
      "value": {
        "data": [
          "11116bv5nS2h3y12kD1yUKeMZvGcKLSjQgX6BeV7u1FrjeJcKfsHPXHRDEHrBesJhZyqnnq9qJeUuF7WHxiuLuL5twc38w2TXNLxnDbjmuR",
          "base58"
        ],
        "executable": false,
        "lamports": 33594,
        "owner": "11111111111111111111111111111111",
        "rentEpoch": 635,
        "space": 80
      }
    },
    "subscription": 23784
  }
}
```
