Ruft den aktuellen Status einer Transaktionssignatur ab (verarbeitet, bestätigt,
finalisiert).

<Warning>
  **Veraltete Methode**

  Diese Methode wird voraussichtlich in `solana-core` v2.0 entfernt. Bitte
  verwenden Sie stattdessen
  [getSignatureStatuses](/developers/docs/rpc/http/getsignaturestatuses).
</Warning>
