---
title: Schnellstart
description:
  Einzahlen, übertragen und abheben im Solana Devnet in unter 30 Minuten
---

Dieser Schnellstart führt Sie durch den vollständigen Private Channels-Ablauf im Solana Devnet:
Richten Sie die Client-Umgebung ein, zahlen Sie SPL-Token in das Escrow ein, senden Sie eine
Off-Chain-Übertragung zwischen zwei Wallets und heben Sie Mittel zurück in Ihre Solana-Wallet ab.

Am Ende werden Sie den vollständigen Zyklus aus Einzahlung -> Off-Chain-Übertragung ->
Auszahlung verstehen und funktionierenden TypeScript-Code für jeden Schritt besitzen.

<Info>
  Dieser Schnellstart setzt voraus, dass eine Private Channels-Instanz bereits deployed ist und
  auf dem Devnet läuft, mit Ihrer Mint auf der Allowlist. Falls Sie zuerst eine deployen müssen,
  beschreibt der [Operators-Leitfaden](/developers/docs/tools/private-channels/operators) das
  vollständige Setup; rechnen Sie mit 30–60 Minuten für den ersten Docker-Build.
</Info>

## Schritte

1. **[Installation](/developers/docs/tools/private-channels/quickstart/installation)** –
   Repository klonen und die TypeScript-Clients generieren (5 Minuten)
2. **[Token einzahlen](/developers/docs/tools/private-channels/quickstart/deposit)** –
   SPL-Token in das Escrow einzahlen; warten Sie ca. 15 Sekunden, bis der Indexer
   Ihr Channel-Guthaben gutschreibt
3. **[Übertragung senden](/developers/docs/tools/private-channels/quickstart/transfer)** –
   eine Off-Chain-Übertragung über das Gateway senden; bestätigt in unter einer Sekunde,
   berührt niemals das Mainnet
4. **[Mittel abheben](/developers/docs/tools/private-channels/quickstart/withdraw)** – verbrennen Sie
   Ihr channel-seitiges Guthaben; der Operator überweist die Mittel innerhalb weniger Sekunden an Ihre Mainnet-Wallet
