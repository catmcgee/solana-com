Na seção anterior, você aprendeu como
[ler dados da rede Solana](/developers/docs/intro/quick-start/reading-from-network)
buscando contas. Para gravar dados na rede Solana, é necessária uma
[transação](/developers/docs/core/transactions). Uma transação contém uma ou mais
[instruções](/developers/docs/core/instructions), e cada instrução invoca um programa.

Os programas definem a lógica de negócio para cada instrução. Quando você envia
uma transação, o runtime da Solana executa as instruções da transação em ordem.
As transações são atômicas. Ou todas as instruções da transação são executadas
com sucesso, ou a transação inteira falha.

Os exemplos nesta seção mostram como:

1. Transferir SOL entre contas
2. Criar um novo token mint

## Transferir SOL

O exemplo abaixo transfere SOL de uma conta para outra. Apenas o programa
designado como proprietário de uma conta pode modificar os dados da conta ou deduzir
lamports do seu saldo. As contas de carteira são de propriedade do
[System Program](/developers/docs/core/programs/builtin-programs#the-system-program), portanto,
transferir SOL entre contas de carteira requer uma instrução que invoca
a instrução
[transfer](https://github.com/anza-xyz/agave/blob/v2.1.11/programs/system/src/system_processor.rs#L183-L213)
do System Program. A conta de origem também deve assinar a transação.

```ts title="Transfer SOL"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getTransferSolInstruction } from "@solana-program/system";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const receiver = await generateKeyPairSigner();

const transferInstruction = getTransferSolInstruction({
  source: client.payer,
  destination: receiver.address,
  amount: lamports(10_000_000n)
});

const result = await client.sendTransaction([transferInstruction]);

console.log("Transaction Signature:", result.context.signature);

const { value: senderBalance } = await client.rpc
  .getBalance(client.payer.address)
  .send();
const { value: receiverBalance } = await client.rpc
  .getBalance(receiver.address)
  .send();

console.log("Sender Balance:", senderBalance);
console.log("Receiver Balance:", receiverBalance);
```

<Note>
  **`createClient`**

  Crie um cliente Kit para o validator local. `generatedPayer()` adiciona um
  signatário pagador, `solanaRpc()` adiciona capacidades de RPC e envio de
  transações, `rpcAirdrop()` adiciona `client.airdrop`, e `airdropPayer()`
  financia o pagador com SOL de teste.

  **`receiver`**

  Gere um signatário para a conta que receberá SOL. O receptor não precisa assinar
  esta transferência. Se o endereço do receptor ainda não tiver uma conta, receber
  SOL cria uma conta de sistema nesse endereço.

  **`transferInstruction`**

  Construa a instrução do System Program que transfere lamports do pagador do
  cliente para o destinatário.

  **`sendTransaction`**

  Envie a instrução como uma transação. O cliente Kit obtém um blockhash recente,
  define o pagador de taxa, assina com os signatários necessários, envia a
  transação e aguarda a confirmação.

  **`balances`**

  Obtenha os saldos do remetente e do destinatário após a confirmação da
  transação.
</Note>

## Criar um token

O exemplo abaixo cria um novo mint de token usando o
[Token Extensions Program](/developers/docs/tokens/extensions). Um mint account é a conta
que define as configurações globais de um token, como decimais, fornecimento,
autoridade de mint e autoridade de congelamento.

Criar um mint account requer duas instruções:

1. Invocar o System Program para criar uma nova conta de propriedade do Token
   Extensions Program.
2. Invocar o Token Extensions Program para inicializar essa conta como um mint.

```ts title="Create mint account"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getCreateAccountInstruction } from "@solana-program/system";
import {
  fetchMint,
  getInitializeMintInstruction,
  getMintSize,
  TOKEN_2022_PROGRAM_ADDRESS
} from "@solana-program/token-2022";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const mint = await generateKeyPairSigner();

const space = BigInt(getMintSize());

const rent = await client.rpc.getMinimumBalanceForRentExemption(space).send();

const createAccountInstruction = getCreateAccountInstruction({
  payer: client.payer,
  newAccount: mint,
  space,
  lamports: rent,
  programAddress: TOKEN_2022_PROGRAM_ADDRESS
});

const initializeMintInstruction = getInitializeMintInstruction({
  mint: mint.address,
  decimals: 2,
  mintAuthority: client.payer.address,
  freezeAuthority: client.payer.address,
  tokenProgram: TOKEN_2022_PROGRAM_ADDRESS
});

const result = await client.sendTransaction([
  createAccountInstruction,
  initializeMintInstruction
]);

console.log("Mint Address:", mint.address);
console.log("Transaction Signature:", result.context.signature);

const mintAccount = await fetchMint(client.rpc, mint.address);
console.log("Mint Account:", mintAccount);
```

<Note>
  **`createClient`**

  Crie e financie um cliente Kit para o validator local. O pagador financiado
  cobre o rent da conta e as taxas de transação.

  **`mint`**

  Gere um assinante para usar como endereço do novo mint account. O assinante
  autoriza a criação dessa conta.

  **`space`**

  Calcule o número de bytes necessários para um mint account sem extensões.

  **`rent`**

  Calcule os lamports necessários para tornar o mint account isento de rent.

  **`createAccountInstruction`**

  Construa a instrução do System Program que cria o mint account e atribui a conta
  ao Token Extensions Program.

  **`initializeMintInstruction`**

  Construa a instrução do Token Extensions Program que grava os dados iniciais do
  mint na nova conta.

  **`sendTransaction`**

  Envie ambas as instruções como uma única transação. A ordem das instruções
  importa: a conta deve ser criada antes de poder ser inicializada.

  **`mintAccount`**

  Busque a mint account após a confirmação. O auxiliar lê a conta e desserializa o
  campo de dados da mint account no tipo Mint.
</Note>

  Estes exemplos usam `generatedPayer()` para criar um keypair descartável para
  testes locais. Aplicações em produção nunca devem armazenar chaves privadas
  brutas no código — delegue a assinatura a um backend de gerenciamento de
  chaves. Consulte [Assinatura em
  Produção](/developers/docs/core/transactions/signing-in-production).
</Info>
