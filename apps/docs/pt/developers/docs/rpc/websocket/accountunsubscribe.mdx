---
title: Método RPC accountUnsubscribe
sidebarTitle: accountUnsubscribe
---

Cancelar inscrição de notificações de alteração de conta

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "accountUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  id da inscrição da conta a ser cancelada
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  mensagem de sucesso do cancelamento da inscrição
</ResponseField>
