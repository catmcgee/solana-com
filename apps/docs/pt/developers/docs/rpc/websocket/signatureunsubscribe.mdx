---
title: Método RPC signatureUnsubscribe
sidebarTitle: signatureUnsubscribe
---

Cancelar inscrição de notificação de confirmação de assinatura

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "signatureUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  id de inscrição a ser cancelada
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  mensagem de sucesso do cancelamento da inscrição
</ResponseField>
