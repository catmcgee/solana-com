title: Método RPC confirmTransaction
sidebarTitle: confirmTransaction

---

Busque o status atual de uma assinatura de transação (processada, confirmada,
finalizada).

<Warning>
  **Método Obsoleto**

  Este método deve ser removido na `solana-core` v2.0. Por favor, use
  [getSignatureStatuses](/developers/docs/rpc/http/getsignaturestatuses) em vez disso.
</Warning>
