sidebarTitle: getSignatureConfirmation

Consulte o status atual de uma assinatura de transação (processada, confirmada,
finalizada).

<Warning>
  **Método Obsoleto**

  Este método deverá ser removido na `solana-core` v2.0. Por favor, use
  [getSignatureStatuses](/developers/docs/rpc/http/getsignaturestatuses) em vez disso.
</Warning>
