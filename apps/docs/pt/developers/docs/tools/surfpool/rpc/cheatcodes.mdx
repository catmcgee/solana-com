## Semântica do Relógio

<Warning>
  **Os timestamps estão em milissegundos; o relógio reporta segundos**

  `surfnet_timeTravel`'s `absoluteTimestamp` está em **milissegundos**, como
  o `Date.now()` do JavaScript, mas o sysvar `Clock` que os programas leem reporta
  **segundos**. Passar um valor diretamente do relógio de volta para o cheatcode
  resulta no início de 1970 — e como o relógio só avança, a chamada é
  rejeitada em vez de ignorada. Multiplique por 1000 primeiro.
</Warning>

Para os equivalentes em nível de SDK dos cheatcodes de relógio, consulte
[Viagem no Tempo](/developers/docs/tools/surfpool/sdk/time-travel).
