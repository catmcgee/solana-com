## and_bool

`and_bool` retorna o AND binário dos argumentos do lado esquerdo e do lado
direito.

### Entradas

| Nome  | Tipo | Descrição         |
| ----- | ---- | ----------------- |
| `lhs` | bool | Um valor booleano |
| `rhs` | bool | Um valor booleano |

### Saída

| Nome    | Tipo | Descrição                                              |
| ------- | ---- | ------------------------------------------------------ |
| `value` | bool | O resultado de um AND binário entre os dois argumentos |

```hcl
output "my_bool" {
  value = false && true
}
// > my_bool: false
```

## div

`div` retorna a divisão inteira do argumento do lado esquerdo pelo argumento do
lado direito, arredondando qualquer resto para o inteiro mais próximo abaixo.

### Entradas

| Nome  | Tipo    | Descrição   |
| ----- | ------- | ----------- |
| `lhs` | inteiro | O dividendo |
| `rhs` | inteiro | O divisor   |

### Saída

| Nome    | Tipo    | Descrição                                        |
| ------- | ------- | ------------------------------------------------ |
| `value` | inteiro | O resultado da divisão do dividendo pelo divisor |

```hcl
output "my_int" {
  value = 11 / -3
}
// > my_int: -3
```

## eq

`eq` retorna `true` se os argumentos do lado esquerdo e do lado direito forem
iguais e `false` se não forem.

### Entradas

| Nome  | Tipo | Descrição      |
| ----- | ---- | -------------- |
| `lhs` | any  | Qualquer valor |
| `rhs` | any  | Qualquer valor |

### Saída

| Nome    | Tipo | Descrição                                                          |
| ------- | ---- | ------------------------------------------------------------------ |
| `value` | bool | O resultado de uma verificação de igualdade entre as duas entradas |

```hcl
output "is_eq" {
  value = "arg" == "arg"
}
// > is_eq: true
```
