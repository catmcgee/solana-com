## Kora v2.2.0-beta.6

_23/03/2026_ |
[Versão no GitHub](https://github.com/solana-foundation/kora/releases/tag/v2.2.0-beta.6)
| `cargo install kora-cli@2.2.0-beta.6`

Pré-lançamento com suporte a pacotes Jito, novos métodos RPC e recursos de
segurança aprimorados.

- Adicionado suporte a pacotes Jito com os métodos `signBundle`,
  `signAndSendBundle` e `estimateBundleFee`
- Adicionado método RPC `getVersion`
- Adicionada proteção de pagador de taxas Lighthouse
- Adicionada proteção contra bots reCAPTCHA v3 para endpoints de assinatura
- Adicionados limites de uso por carteira com suporte Redis
- Adicionadas imagens Docker oficiais no GHCR
- Adicionadas regras granulares de limite de uso
- SDK: `KoraClient` agora aceita objeto de opções; novo `koraPlugin` para
  `@solana/kit`

Consulte a [Documentação Beta](/developers/docs/tools/kora/beta) para mais detalhes.

## SDK TypeScript do Kora v0.2.0

_09/03/2026_ |
[Versão no GitHub](https://github.com/solana-foundation/kora/releases/tag/ts-sdk-v0.2.0)
| `pnpm add @solana/kora@0.2.0`

Arquitetura de plugin do cliente Kit para transações sem taxas componíveis.

- Adicionado `createKitKoraClient()` com composição de plugins Kit (plugins de
  planejamento, execução e pagamento)
- Permite composição com plugins de programa Kit como `tokenProgram()`
- Adicionado suporte Token-2022 via opção de configuração `tokenProgramId`
- Adicionado suporte a instruções de orçamento de computação com estimativa de
  CU baseada em simulação
- Adicionado campo `signature` ausente à resposta `signAndSendTransaction`
- Retorna `NoopSigner` de `getPaymentInstruction` para desduplicação de
  signatário Kit v6
- Atualizada dependência peer `@solana/kit` para `^6.1.0`

Consulte o [Guia do Cliente Kit](/developers/docs/tools/kora/guides/kit-client).

## Kora v2.0.0

_19/11/2025_ |
[Versão no GitHub](https://github.com/solana-foundation/kora/releases/tag/v2.0.0)
| `cargo install kora-cli@2.0.0`

Lançamento principal com nova arquitetura.

- Introduzida uma nova arquitetura para o nó Kora
- Publicado TypeScript SDK `@solana/kora` v0.1.0
- Migrado para Solana SDK v3.0.x e atualizadas todas as dependências
- Substituído o Kora Signer personalizado pela crate solana-signers
- Removidos os métodos `sign_transaction_if_paid` e `get_all_signers`
- Alterados os tipos de resposta: removidas as assinaturas de
  `signAndSendTransaction` e `signTransaction`
- Melhorada a experiência do desenvolvedor, segurança e desempenho
