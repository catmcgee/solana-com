Métodos para manipular o tempo e acessar variáveis do sistema. Cada getter de sysvar possui um setter correspondente; as structs são espelhos Go simples da fonte Solana.

## Manipulação de Clock

### WarpToSlot

```go
func (s *LiteSVM) WarpToSlot(slot uint64) error
```

Avança o clock interno para um slot específico.

```go
before, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("current slot: %d", before.Slot)

if err := svm.WarpToSlot(10_000_000); err != nil {
    t.Fatal(err)
}

after, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("new slot:     %d", after.Slot)
```

### Clock

```go
// sysvar is github.com/gagliardetto/solana-go/sysvar
type Clock struct {
    Slot                uint64
    EpochStartTimestamp int64
    Epoch               uint64
    LeaderScheduleEpoch uint64
    UnixTimestamp       int64
}

func (s *LiteSVM) Clock() (*sysvar.Clock, error)
```

Lê a sysvar Clock.

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
t.Logf("slot=%d epoch=%d unix=%d", c.Slot, c.Epoch, c.UnixTimestamp)
```

### SetClock

```go
func (s *LiteSVM) SetClock(c *sysvar.Clock) error
```

Sobrescreve a sysvar Clock. Leia-a, altere os campos e grave de volta quando precisar de controle sobre `Epoch` ou `UnixTimestamp` (que `WarpToSlot` não atualiza).

```go
c, err := svm.Clock()
if err != nil {
    t.Fatal(err)
}
c.Slot = 1_000
c.Epoch = 10
c.UnixTimestamp = 1_735_689_600
if err := svm.SetClock(c); err != nil {
    t.Fatal(err)
}
```

<Info>
  `WarpToSlot` atualiza apenas o `Slot`. Use `SetClock` quando seu programa ler
  `Epoch` ou `UnixTimestamp` da sysvar Clock.
</Info>

## Epoch Rewards

```go
type EpochRewards struct {
    DistributionStartingBlockHeight uint64
    NumPartitions                   uint64
    ParentBlockhash                 solana.Hash
    TotalPoints                     bin.Uint128 // u128 total_points
    TotalRewards                    uint64
    DistributedRewards              uint64
    Active                          bool
}

func (s *LiteSVM) EpochRewards() (*sysvar.EpochRewards, error)
func (s *LiteSVM) SetEpochRewards(e *sysvar.EpochRewards) error
```

`total_points` é um `u128` no lado Solana; `litesvm-go` expõe ambas as metades
explicitamente para que os chamadores Go não precisem de uma biblioteca u128. Para valores que cabem em 64
bits, `TotalPointsHi` é `0` e `TotalPointsLo` é o valor.

### SlotHistory

`SlotHistory` é um bitvec de ~128 KB; `litesvm-go` o expõe como um handle em vez
de um slice.

```go
sh := sysvar.NewSlotHistory()

sh.Add(42)

switch sh.Check(42) {
case sysvar.SlotHistoryFound:
    // ...
case sysvar.SlotHistoryNotFound:
    // ...
case sysvar.SlotHistoryTooOld:
    // ...
case sysvar.SlotHistoryFuture:
    // ...
}

if err := svm.SetSlotHistory(sh); err != nil {
    t.Fatal(err)
}
```

| Método                                           | Descrição                                |
| ------------------------------------------------ | ------------------------------------------ |
| `litesvm.NewSlotHistory() (*SlotHistory, error)` | Handle vazio                               |
| `sh.Add(slot uint64)`                            | Registrar um slot                              |
| `sh.Check(slot uint64) SlotHistoryCheck`         | `Future` / `TooOld` / `Found` / `NotFound` |
| `sh.Oldest() uint64`                             | Slot mais antigo rastreado                        |
| `sh.Newest() uint64`                             | Slot mais recente rastreado                        |
| `sh.NextSlot() uint64`                           | Próximo slot a registrar                        |
| `sh.SetNextSlot(slot uint64) error`              | Substituir o marcador do próximo slot              |
| `sh.Close()`                                     | Liberar o handle                         |
| `svm.SlotHistory() (*SlotHistory, error)`        | Ler em um novo handle                   |
| `svm.SetSlotHistory(*SlotHistory) error`         | Instalar na SVM                         |

## Testando Lógica Dependente de Tempo

Use `WarpToSlot` para avanço simples baseado em slot, `SetClock` para controle total:

```go
func TestTimeLockedVault(t *testing.T) {
    svm, err := litesvm.New()
    if err != nil {
        t.Fatal(err)
    }
    defer svm.Close()

    const unlockSlot = uint64(10_000)

    // Setup: create the time-locked account ...

    // Test 1: Try to withdraw before unlock (should fail)
    before, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("current slot: %d", before.Slot)
    // ... attempt withdrawal, expect failure ...

    // Warp time forward past unlock slot
    if err := svm.WarpToSlot(unlockSlot + 1); err != nil {
        t.Fatal(err)
    }

    // Test 2: Try to withdraw after unlock (should succeed)
    after, err := svm.Clock()
    if err != nil {
        t.Fatal(err)
    }
    t.Logf("new slot: %d", after.Slot)
    // ... attempt withdrawal, expect success ...
}
```
