Sete conceitos formam a base do desenvolvimento na Solana. Comece por Contas
e Programas, e depois acompanhe como as Instruções se tornam Transações. PDAs, CPIs e
Taxas complementam esse modelo de execução.

<Columns cols={2}>
  <Card title="Contas" href="/developers/docs/core/accounts">
    A Solana armazena todo o estado em contas, um repositório chave-valor indexado por
    endereços de 32 bytes. Cada conta possui cinco campos: lamports, data, owner, executable
    e rent_epoch.
  </Card>
  <Card title="Programas" href="/developers/docs/core/programs">
    Os contratos inteligentes da Solana, compilados para sBPF. Os programas são stateless e todo
    o estado mutável reside em contas de dados separadas, passadas via instruções.
  </Card>
  <Card title="Instruções" href="/developers/docs/core/instructions">
    Uma solicitação para executar um programa, contendo um ID de programa, uma lista de contas
    e bytes de dados opacos. Múltiplas instruções são compostas em uma única
    transação.
  </Card>
  <Card title="Transações" href="/developers/docs/core/transactions">
    A unidade atômica de execução na Solana. Contém assinaturas e uma mensagem
    (endereços de contas, blockhash recente e instruções compiladas). Máximo de 1232
    bytes, ou 4096 com o formato v1.
  </Card>
  <Card title="Taxas" href="/developers/docs/core/fees">
    Taxa base de 5.000 lamports por assinatura, mais uma taxa de prioridade opcional
    baseada nas unidades de computação solicitadas. Máximo de 1,4 milhão de unidades de computação por transação.
  </Card>
  <Card title="Program Derived Addresses (PDAs)" href="/developers/docs/core/pda">
    Endereços determinísticos derivados de um ID de programa e seeds. Apenas o programa
    proprietário pode assinar em nome de um PDA via invoke_signed.
  </Card>
  <Card title="Cross-Program Invocations (CPIs)" href="/developers/docs/core/cpi">
    Um programa chamando outro via invoke ou invoke_signed. Os privilégios de assinante e
    de escrita são estendidos ao destinatário. Profundidade máxima da pilha de instruções de 5 (nível superior
    mais CPIs).
  </Card>
</Columns>
