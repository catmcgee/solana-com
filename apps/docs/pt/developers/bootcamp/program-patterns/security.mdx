## Objetivo da revisão

Transforme os padrões do bootcamp que você já utilizou em uma lista de verificação de segurança repetível.

## Pontos de verificação

- Revise as restrições de conta e as suposições do signatário.
- Procure verificações de autoridade ausentes e transições de estado inesperadas.
- Capture pelo menos um invariante que você deseja que os testes imponham daqui para frente.
