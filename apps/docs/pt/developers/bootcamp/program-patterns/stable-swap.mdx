## Objetivo do projeto

Aprenda como as regras de swap, liquidez e premissas de precificação afetam o
comportamento do protocolo.

## Checkpoints

- Identificar os invariantes do pool que devem ser sempre mantidos.
- Rastrear o caminho do swap desde a entrada do usuário até os saldos atualizados.
- Verificar como as taxas e o deslizamento são apresentados tanto no código quanto na interface.
