## Objetivo do projeto

Criar um projeto Solana mínimo no estilo hello-world e executá-lo com sucesso.

## Marcos

1. Inicializar a estrutura do projeto.
2. Implementar a menor instrução útil.
3. Executar a instrução e inspecionar o resultado.
4. Verificar as mudanças de estado esperadas.

## Reutilização do início rápido: ler estado da conta

Antes de passar para projetos maiores, reutilize o fluxo exato de leitura de conta de
[`/developers/docs/intro/quick-start/reading-from-network`](/developers/docs/intro/quick-start/reading-from-network).

Use o resultado desse guia para validar estes fundamentos:

- `executable` é `false` para contas de carteira.
- `owner` é o System Program para contas de carteira.
- `lamports` reflete o saldo financiado.
- `space` é `0` para carteiras do sistema sem dados personalizados.

## Verificação

- O programa é executado sem erros de tempo de execução.
- A confirmação da transação é bem-sucedida.
- A saída/estado esperado está visível nos logs ou nos dados da conta.
