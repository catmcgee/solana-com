## Objetivo da lição

Construa uma ponte de notificações que torne a atividade de smart contracts útil fora
do próprio aplicativo.

## Checkpoints

- Identifique quais eventos devem gerar mensagens no Telegram.
- Decida qual contexto cada mensagem precisa ter para ser acionável.
- Analise os limites de taxa, falhas de entrega e ruído do operador.
