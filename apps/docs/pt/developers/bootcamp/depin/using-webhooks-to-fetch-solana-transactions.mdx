## Objetivo da lição

Configure um pipeline de eventos mais limpo para que o dispositivo ou aplicativo reaja à atividade da Solana
sem necessidade de polling manual constante.

## Pontos de verificação

- Entenda quais eventos de webhook são relevantes para o seu fluxo.
- Observe como o serviço receptor deve validar e processá-los.
- Decida o que deve acontecer quando a entrega do webhook falhar ou atrasar.
