---
title: Método RPC getBlocksWithLimit
sidebarTitle: getBlocksWithLimit
---

Retorna uma lista de blocos confirmados começando no slot especificado

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getBlocksWithLimit",
      "params": [
        5,
        3
      ],
      {
        "commitment": "finalized"
      }
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let startSlot = BigInt(377268280);
  let limit = 5;
  let blocks = await rpc.getBlocksWithLimit(startSlot, limit).send();

  console.log("blocks produced:", blocks);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let start_slot = 377268280;
      let limit = 5;

      let blocks = client.get_blocks_with_limit(start_slot, limit).await?;

      println!("Blocks produced: {:?}", blocks);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": [5, 6, 7],
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="start slot" type="u64" required>
  Slot inicial
</ParamField>

<ParamField body="limit" type="u64">
  Limite (não deve ser mais de 500.000 blocos acima do `start_slot`)
</ParamField>

<ParamField body="2" type="object">
  Objeto de configuração

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      O commitment descreve quão finalizado está um bloco naquele momento. Veja
      [Configurando State Commitment](/docs/rpc#configuring-state-commitment).

      - "processed" não é suportado
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="array">
  Um array de inteiros u64 listando blocos confirmados começando em `start_slot`
  para até `limit` blocos, inclusive.
</ResponseField>
