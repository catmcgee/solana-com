---
title: Método RPC rootSubscribe
sidebarTitle: rootSubscribe
---

Inscreva-se para receber notificações sempre que uma nova raiz for definida pelo
validator.

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Nenhum**

### Result

<ResponseField name="result" type="integer">
  id de inscrição (necessário para cancelar a inscrição)
</ResponseField>

#### Formato de notificação:

O resultado é o número do slot raiz mais recente.

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
