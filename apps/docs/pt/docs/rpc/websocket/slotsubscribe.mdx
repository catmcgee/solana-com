---
title: Método RPC slotSubscribe
sidebarTitle: slotSubscribe
---

Inscreva-se para receber notificações sempre que um slot for processado pelo
validator

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Nenhum**

### Result

<ResponseField name="result" type="integer">
  Id de inscrição (necessário para cancelar a inscrição)
</ResponseField>

#### Formato de notificação:

A notificação será um objeto com os seguintes campos:

- `parent: <u64>` - O slot pai
- `root: <u64>` - O slot raiz atual
- `slot: <u64>` - O valor do slot recém-definido

Exemplo:

```json
{
  "jsonrpc": "2.0",
  "method": "slotNotification",
  "params": {
    "result": {
      "parent": 75,
      "root": 44,
      "slot": 76
    },
    "subscription": 0
  }
}
```
