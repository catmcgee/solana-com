Cancelar inscrição de notificações de voto

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "voteUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="integer" required>
  id de inscrição a ser cancelado
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  mensagem de sucesso do cancelamento de inscrição
</ResponseField>
