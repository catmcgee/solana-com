## Wat zijn overdrachtskosten?

De `TransferFeeConfig` mint-extensie van het Token Extensions Program past
bij elke overdracht voor die mint een vergoeding toe.

Op het moment van overdracht:

- Het overgedragen bedrag wordt verminderd met de geconfigureerde vergoeding
- De ingehouden vergoeding wordt bijgehouden op de bestemmings-token account
- Ingehouden vergoedingen kunnen rechtstreeks worden opgenomen van token
  accounts of verzameld worden bij de mint
- De `withdraw_withheld_authority` kan verzamelde vergoedingen verplaatsen naar
  een ontvangende token account voor kosten

<Info>
  **Token Account-extensies**

  Wanneer een token account wordt geïnitialiseerd voor een mint met
`TransferFeeConfig`, wordt het token account geïnitialiseerd met
`TransferFeeAmount`. Wanneer het token account wordt aangemaakt via het
  [Associated Token
  Program](/docs/tokens/basics/create-token-account#how-to-create-an-associated-token-account),
  wordt de vereiste accountgrootte berekend en wordt het token account
  aangemaakt met de vereiste grootte en huurvrije lamports.
</Info>

## Hoe maak je een mint met overdrachtskosten

Om een mint met overdrachtskosten te maken:

1. Bereken de grootte van het mint-account en de benodigde huur voor de mint en
   de `TransferFeeConfig`-extensie.
2. Creëer het mint-account met `CreateAccount`, initialiseer
   `TransferFeeConfig` en initialiseer de mint met `InitializeMint`.
3. Creëer token accounts voor de mint. `TransferFeeAmount` wordt automatisch
   ingeschakeld voor token accounts.
4. Gebruik `TransferCheckedWithFee` om tokens over te dragen en verifieer de
   verwachte vergoeding. `TransferChecked` werkt ook en houdt automatisch de
   geconfigureerde vergoeding in op het bestemmings-token account.
5. Gebruik `WithdrawWithheldTokensFromAccounts` om ingehouden vergoedingen
   rechtstreeks van token accounts naar een ontvangende token account voor
   kosten te verplaatsen, ondertekend door de `withdraw_withheld_authority` van
   de mint.
6. Gebruik toestemmingsvrije `HarvestWithheldTokensToMint` om ingehouden
   vergoedingen van token accounts naar het mint-account te verplaatsen, en
   gebruik vervolgens `WithdrawWithheldTokensFromMint` om de ingehouden
   vergoedingen van het mint-account op te nemen naar een ontvangende token
   account voor kosten, ondertekend door de `withdraw_withheld_authority` van de
   mint.
7. Gebruik `SetTransferFee` om de volgende configuratie van
   overdrachtskosten bij te werken, die twee epochs later van kracht wordt.

  <Step title="Bereken accountgrootte">
    Bereken de mint account-grootte voor de basis-mint plus de
    `TransferFeeConfig`-extensie. Dit is de grootte die wordt gebruikt in
    `CreateAccount`.

    ```ts Voorbeeld focus={14-27,30}
    const client = await createClient()
      .use(generatedPayer())
      .use(
        solanaRpc({
          rpcUrl: "http://localhost:8899",
          rpcSubscriptionsUrl: "ws://localhost:8900"
        })
      )
      .use(rpcAirdrop())
      .use(airdropPayer(lamports(1_000_000_000n)));

    const mint = await generateKeyPairSigner();

    const transferFeeConfigExtension = extension("TransferFeeConfig", {
      transferFeeConfigAuthority: client.payer.address,
      withdrawWithheldAuthority: client.payer.address,
      withheldAmount: 0n,
      olderTransferFee: {
        epoch: 0n,
        maximumFee: 10n,
        transferFeeBasisPoints: 150
      },
      newerTransferFee: {
        epoch: 0n,
        maximumFee: 10n,
        transferFeeBasisPoints: 150
      }
    });

    const mintSpace = BigInt(getMintSize([transferFeeConfigExtension]));
    ```
