---
title: rootSubscribe RPC-methode
sidebarTitle: rootSubscribe
---

Abonneer je om een melding te ontvangen wanneer een nieuwe root wordt ingesteld
door de validator.

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Geen**

### Result

<ResponseField name="result" type="integer">
  abonnement-id (nodig om het abonnement op te zeggen)
</ResponseField>

#### Meldingsformaat:

Het resultaat is het laatste root slot-nummer.

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
