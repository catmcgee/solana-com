title: accountSubscribe RPC-methode
sidebarTitle: accountSubscribe
---

Abonneer je op een account om meldingen te ontvangen wanneer de lamports of
gegevens voor een bepaalde account public key veranderen

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "accountSubscribe",
    "params": [
      "CM78CPUeXjn8o3yroDHxUtKsZZgoy4GPkPPXfouKNH12",
      {
        "encoding": "jsonParsed",
        "commitment": "finalized"
      }
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 23784,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

<ParamField body="0" type="string" required>
  Account pubkey, als base-58 gecodeerde string
</ParamField>

<ParamField body="1" type="object">
  Configuratieobject met de volgende velden:

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      De commitment beschrijft hoe definitief een blok is op dat moment. Zie
      [Configureren van state commitment](/developers/docs/rpc#configuring-state-commitment).
    </ParamField>

    <ParamField body="encoding" type="string">
      Values: `base58`, `base64`, `base64+zstd`, `jsonParsed`

      Coderingsformaat voor accountgegevens

      - `base58` is traag.
      - `jsonParsed` codering probeert programmaspecifieke state parsers te gebruiken
        om meer leesbare en expliciete accountstatusgegevens te retourneren
      - Als `jsonParsed` wordt aangevraagd maar er geen parser kan worden gevonden,
        valt het veld terug naar binaire codering, te herkennen wanneer het `data`
        veld van het type `string` is.
    </ParamField>
  </Expandable>
</ParamField>

### Result

<ResponseField name="result" type="number">
  Abonnement-id (nodig om het abonnement op te zeggen)
</ResponseField>

#### Meldingsformaat:

Het notificatieformaat is hetzelfde als te zien in de
[getAccountInfo](/developers/docs/rpc/http/getaccountinfo) RPC HTTP-methode.

Base58-codering:

```json
{
  "jsonrpc": "2.0",
  "method": "accountNotification",
  "params": {
    "result": {
      "context": {
        "slot": 5199307
      },
      "value": {
        "data": [
          "11116bv5nS2h3y12kD1yUKeMZvGcKLSjQgX6BeV7u1FrjeJcKfsHPXHRDEHrBesJhZyqnnq9qJeUuF7WHxiuLuL5twc38w2TXNLxnDbjmuR",
          "base58"
        ],
        "executable": false,
        "lamports": 33594,
        "owner": "11111111111111111111111111111111",
```
