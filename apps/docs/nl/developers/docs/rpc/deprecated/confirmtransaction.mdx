Haal de huidige status op van een transactiehandtekening (verwerkt, bevestigd,
definitief).

<Warning>
  **Verouderde methode**

  Deze methode zal naar verwachting worden verwijderd in `solana-core` v2.0.
  Gebruik in plaats daarvan
  [getSignatureStatuses](/developers/docs/rpc/http/getsignaturestatuses).
</Warning>
