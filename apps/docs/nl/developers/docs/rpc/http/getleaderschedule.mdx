Geeft het leiderschema voor een epoch terug

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getLeaderSchedule",
      "params": [
        null,
        {
          "commitment": "processed",
          "identity": "dv2eQHeP4RFrJZ6UeiZWoc3XTtmtZCUKxxCApCDcRNV"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { address, createSolanaRpc, type Commitment } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let slotNumber = null;

  let identity = address("dv1ZAGvdsz5hHLwWXsVnM94hWf1pjbKVau1QVkaMJ92");
  let commitment: Commitment = "finalized";

  let leaderSchedule = await rpc
    .getLeaderSchedule(slotNumber, { identity, commitment })
    .send();

  console.log(leaderSchedule);
  ```

  ```ts web3.js
  import { Connection, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let leaderSchedule = await connection.getLeaderSchedule();

  console.log(leaderSchedule);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::{nonblocking::rpc_client::RpcClient, rpc_config::RpcLeaderScheduleConfig};
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let slot_number = None;
      let config = RpcLeaderScheduleConfig {
          identity: String::from("dv1ZAGvdsz5hHLwWXsVnM94hWf1pjbKVau1QVkaMJ92").into(),
          commitment: CommitmentConfig::finalized().into(),
      };
      let leader_schedule = client
          .get_leader_schedule_with_config(slot_number, config)
          .await?;

      println!("{:#?}", leader_schedule);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="slot number" type="u64">
  Haalt het leiderschema op voor de epoch die overeenkomt met de opgegeven slot.
  Indien niet gespecificeerd, wordt het leiderschema voor de huidige epoch
  opgehaald.
</ParamField>

<ParamField body="1" type="object">
  Configuratieobject met de volgende velden:

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      De commitment beschrijft hoe definitief een blok is op dat moment. Zie
      [Configureren van state commitment](/developers/docs/rpc#configuring-state-commitment).
    </ParamField>

    <ParamField body="identity" type="string">
      Geef alleen resultaten terug voor deze validator-identiteit (base-58 gecodeerd)
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="object | null">
  Geeft `null` terug als de gevraagde epoch niet wordt gevonden, anders wordt een
  object teruggegeven waarin:

  - Keys zijn validator-identiteiten (als base-58 gecodeerde strings)
  - Values zijn arrays van leader slot-indices relatief aan de eerste slot in de
    gevraagde epoch
</ResponseField>
