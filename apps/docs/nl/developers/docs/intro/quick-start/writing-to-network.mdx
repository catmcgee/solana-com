  Learn how to write data to the Solana network by sending transactions and
  instructions. Follow step-by-step examples to transfer SOL and create a token
  mint using Solana Kit.

In het vorige gedeelte hebt u geleerd hoe u
[gegevens van het Solana-netwerk kunt lezen](/developers/docs/intro/quick-start/reading-from-network)
door accounts op te halen. Het schrijven van gegevens naar het Solana-netwerk
vereist een [transactie](/developers/docs/core/transactions). Een transactie bevat een of
meer [instructies](/developers/docs/core/instructions), en elke instructie roept een
programma aan.

Programma's definiëren de bedrijfslogica voor elke instructie. Wanneer u een
transactie verzendt, voert de Solana-runtime de instructies van de transactie op
volgorde uit. Transacties zijn atomair. Ofwel slaagt elke instructie in de
transactie, ofwel mislukt de gehele transactie.

De voorbeelden in dit gedeelte laten zien hoe u:

1. SOL overdraagt tussen accounts
2. Een nieuwe token mint aanmaakt

## SOL overdragen

Het onderstaande voorbeeld verplaatst SOL van het ene account naar het andere. Alleen het programma dat is aangewezen als eigenaar van een account kan de gegevens van het account wijzigen of lamports van het saldo aftrekken. Wallet-accounts zijn eigendom van het
[System Program](/developers/docs/core/programs/builtin-programs#the-system-program), dus om SOL tussen wallet-accounts over te maken is een instructie vereist die de
[transfer](https://github.com/anza-xyz/agave/blob/v2.1.11/programs/system/src/system_processor.rs#L183-L213)-instructie
van het System Program aanroept. Het bronaccount moet de transactie ook ondertekenen.

```ts title="Transfer SOL"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getTransferSolInstruction } from "@solana-program/system";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const receiver = await generateKeyPairSigner();

const transferInstruction = getTransferSolInstruction({
  source: client.payer,
  destination: receiver.address,
  amount: lamports(10_000_000n)
});

const result = await client.sendTransaction([transferInstruction]);

console.log("Transaction Signature:", result.context.signature);

const { value: senderBalance } = await client.rpc
  .getBalance(client.payer.address)
  .send();
const { value: receiverBalance } = await client.rpc
  .getBalance(receiver.address)
  .send();

console.log("Sender Balance:", senderBalance);
console.log("Receiver Balance:", receiverBalance);
```

<Note>
  **`createClient`**

  Maak een Kit-client aan voor de lokale validator. `generatedPayer()` voegt een
  betalende ondertekenaar toe, `solanaRpc()` voegt RPC- en
  transactieverzendfuncties toe, `rpcAirdrop()` voegt `client.airdrop` toe, en
  `airdropPayer()` vult de betaler met test-SOL.

  **`receiver`**

  Genereer een ondertekenaar voor het account dat SOL ontvangt. De ontvanger hoeft
  deze overdracht niet te ondertekenen. Als het ontvangersadres nog geen account
  heeft, wordt er door het ontvangen van SOL een systeemaccount aangemaakt op dat
  adres.

  **`transferInstruction`**

  Bouw de System Program instructie die lamports overdraagt van de betalende
  client naar de ontvanger.

  **`sendTransaction`**

  Verstuur de instructie als een transactie. De Kit-client haalt een recente
  blockhash op, stelt de betaler in, ondertekent met de vereiste ondertekenaars,
  verstuurt de transactie en wacht op bevestiging.

  **`balances`**

  Haal de saldi van de verzender en ontvanger op nadat de transactie is bevestigd.
</Note>

## Een token aanmaken

Het onderstaande voorbeeld maakt een nieuwe token mint aan met behulp van het
[Token Extensions Program](/developers/docs/tokens/extensions). Een mint account is het
account dat de algemene instellingen van een token definieert, zoals decimalen,
aanbod, mint authoriteit en bevriezingsauthoriteit.

Het aanmaken van een mint account vereist twee instructies:

1. Roep het System Program aan om een nieuw account te maken dat eigendom is van
   het Token Extensions Program.
2. Roep het Token Extensions Program aan om dat account te initialiseren als een
   mint.

```ts title="Create mint account"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getCreateAccountInstruction } from "@solana-program/system";
import {
  fetchMint,
  getInitializeMintInstruction,
  getMintSize,
  TOKEN_2022_PROGRAM_ADDRESS
} from "@solana-program/token-2022";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const mint = await generateKeyPairSigner();

const space = BigInt(getMintSize());

const rent = await client.rpc.getMinimumBalanceForRentExemption(space).send();

const createAccountInstruction = getCreateAccountInstruction({
  payer: client.payer,
  newAccount: mint,
  space,
  lamports: rent,
  programAddress: TOKEN_2022_PROGRAM_ADDRESS
});

const initializeMintInstruction = getInitializeMintInstruction({
  mint: mint.address,
  decimals: 2,
  mintAuthority: client.payer.address,
  freezeAuthority: client.payer.address,
  tokenProgram: TOKEN_2022_PROGRAM_ADDRESS
});

const result = await client.sendTransaction([
  createAccountInstruction,
  initializeMintInstruction
]);

console.log("Mint Address:", mint.address);
console.log("Transaction Signature:", result.context.signature);

const mintAccount = await fetchMint(client.rpc, mint.address);
console.log("Mint Account:", mintAccount);
```

<Note>
  **`createClient`**

  Maak een Kit-client aan voor de lokale validator en financier deze. De
  gefinancierde betaler betaalt account rent en transactiekosten.

  **`mint`**

  Genereer een ondertekenaar om te gebruiken als adres van het nieuwe mint
  account. De ondertekenaar autorisert de aanmaak van dat account.

  **`space`**

  Bereken het aantal bytes dat vereist is voor een mint account zonder extensies.

  **`rent`**

  Bereken de lamports die nodig zijn om het mint account rent-exempt te maken.

  **`createAccountInstruction`**

  Bouw de System Program-instructie die het mint account aanmaakt en het account
  toewijst aan het Token Extensions Program.

  **`initializeMintInstruction`**

  Bouw de Token Extensions Program-instructie die de initiële mint-gegevens in het
  nieuwe account schrijft.

  **`sendTransaction`**

  Stuur beide instructies als één transactie. De volgorde van instructies is
  belangrijk: het account moet worden aangemaakt voordat het account kan worden
  geïnitialiseerd.

  **`mintAccount`**

  Haal het mint account op na bevestiging. De helperfunctie leest het account en
  deserialiseert het gegevensveld van het mint account naar het Mint-type.
</Note>
