Dit gedeelte biedt enkele veelgebruikte commando's en voorbeelden om je op weg
te helpen met het gebruik van de Solana CLI.

## Solana configuratie

Je Solana configuratie specificeert de volgende variabelen:

- **Configuratiebestand**: Het pad naar je configuratiebestand
- **RPC URL & Websocket URL**: Het Solana-cluster waarnaar de CLI verzoeken
  stuurt
- **Keypair-pad**: Het pad naar de standaard Solana-wallet (keypair) die wordt
  gebruikt om transactiekosten te betalen en programma's te deployen. Standaard
  wordt dit bestand opgeslagen in `~/.config/solana/id.json`.

Om je huidige configuratie-instellingen te bekijken, voer je het volgende
commando in je terminal in.

```bash Terminal
solana config get
```

Een succesvol commando zal output teruggeven die lijkt op het volgende:

```txt title="Example output"
Config File: /Users/test/.config/solana/cli/config.yml
RPC URL: https://api.mainnet.solana.com
WebSocket URL: wss://api.mainnet.solana.com/ (computed)
Keypair Path: /Users/test/.config/solana/id.json
Commitment: confirmed
```

Je kunt de Solana CLI cluster wijzigen met de volgende commando's:

<Tabs>

<Tab title="Full commands">

```bash Terminal
solana config set --url mainnet-beta
solana config set --url devnet
solana config set --url localhost
solana config set --url testnet
```

</Tab>
<Tab title="Short commands">

```bash Terminal
solana config set -um    # For mainnet
solana config set -ud    # For devnet
solana config set -ul    # For localhost
solana config set -ut    # For testnet
```

</Tab>
</Tabs>

## Een wallet aanmaken

Voordat je transacties kunt verzenden met de Solana CLI, heb je een Solana
wallet nodig die gevuld is met SOL.

Om een keypair aan te maken op het standaard keypair pad, voer je het volgende
commando uit:

```bash Terminal
solana-keygen new
```

Een succesvol commando zal output teruggeven die lijkt op het volgende:

```txt title="Example output"
Generating a new keypair

For added security, enter a BIP39 passphrase

NOTE! This passphrase improves security of the recovery seed phrase NOT the
keypair file itself, which is stored as insecure plain text

BIP39 Passphrase (empty for none):

Wrote new keypair to /Users/test/.config/solana/id.json
===========================================================================
pubkey: 8dBTPrjnkXyuQK3KDt9wrZBfizEZijmmUQXVHpFbVwGT
===========================================================================
Save this seed phrase and your BIP39 passphrase to recover your new keypair:
cream bleak tortoise ocean nasty game gift forget fancy salon mimic amazing
===========================================================================
```

<Info>
  Deze opdracht overschrijft geen bestaand account op de standaardlocatie,
  tenzij je de `--force` vlag gebruikt.
</Info>

Om het adres van je wallet (publieke sleutel) te bekijken, voer je uit:

```bash Terminal
solana address
```

## SOL airdrop

Vraag een airdrop van SOL aan voor je wallet om te betalen voor transacties en
programma implementaties.

1. Stel je cluster in op Devnet:

```bash Terminal
solana config set -ud
```

2. Vraag een airdrop van Devnet SOL aan:

```bash Terminal
solana airdrop 2
```

<Note>

Devnet airdrops beperken verzoeken tot 5 SOL per aanvraag. Als je tegen
snelheidsbeperkingen aanloopt of fouten tegenkomt, probeer dan in plaats daarvan
de [Web Faucet](https://faucet.solana.com) te gebruiken.

</Note>

Om het SOL-saldo van je wallet te controleren, voer je het volgende commando
uit:

```bash Terminal
solana balance
```
