## Что такое расширения Group и Group Member?

Группа — это минт, представляющий коллекцию. Участник группы — это минт, который
принадлежит этой коллекции.

Используйте эти расширения, когда один минт должен представлять коллекцию, а
другие минты — элементы, принадлежащие ей.

Token Extensions Program может хранить данные группы токенов непосредственно на
минте с помощью четырех связанных расширений:

- `GroupPointer` указывает минт на аккаунт, в котором хранятся данные
  группы.
- `TokenGroup` хранит сами данные группы, включая орган обновления, текущий
  размер и максимальный размер.
- `GroupMemberPointer` указывает минт на аккаунт, в котором хранятся данные
  участника.
- `TokenGroupMember` хранит адрес группы участника и номер участника.

`GroupPointer` и `GroupMemberPointer` могут ссылаться на любой аккаунт,
принадлежащий программе, реализующей
[интерфейс Token group](https://github.com/solana-program/token-group/tree/main/interface).

Token Extensions Program также реализует этот интерфейс напрямую через
расширения минта `TokenGroup` и `TokenGroupMember`.

## Как создать группы и участников, хранящихся на аккаунте минта

Чтобы создать группы и участников, хранящихся на аккаунте минта:

1. Создайте аккаунт группового минта и инициализируйте `GroupPointer`.
2. Инициализируйте групповой минт с помощью `InitializeMint`.
3. Инициализируйте `TokenGroup` на том же минте.
4. Создайте аккаунт минта участника и инициализируйте `GroupMemberPointer`.
5. Инициализируйте минт участника с помощью `InitializeMint`.
6. Инициализируйте `TokenGroupMember` на том же минте так, чтобы он ссылался
   на групповой минт.

<Info>
**Указатели и порядок инструкций**

`GroupPointer` и `GroupMemberPointer` хранят адрес аккаунта,
где находятся данные группы или участника. `TokenGroup` и
`TokenGroupMember` хранят фактические данные группы или участника.

`GroupPointerInstruction::Initialize` и
`GroupMemberPointerInstruction::Initialize` должны быть выполнены перед
`InitializeMint`. `TokenGroupInstruction::InitializeGroup` и
`TokenGroupInstruction::InitializeMember` должны быть выполнены после
`InitializeMint`. Для каждого минта `CreateAccount`, инструкция
инициализации указателя и `InitializeMint` должны быть включены в одну и ту
же транзакцию.

</Info>

### Справочная информация по исходному коду

`GroupPointer` и `GroupMemberPointer` — это инструкции-указатели в Token
Extensions Program. `TokenGroup` и `TokenGroupMember` следуют интерфейсу
Token group, который реализует Token Extensions Program.

#[tokio::main]

        .request_airdrop(&authority.pubkey(), 5_000_000_000)

        if confirmed {

        }

        Some(group_mint.pubkey()), // Account address that stores the group data.
    )?;

    let initialize_group_mint_instruction = initialize_mint(
        &TOKEN_2022_PROGRAM_ID,    // Program that owns the mint account.

        &member_mint.pubkey(),    // New member mint account to create.
        member_mint_rent,         // Lamports funding the mint account rent.
        member_mint_space as u64, // Account size in bytes for the mint plus GroupMemberPointer.
