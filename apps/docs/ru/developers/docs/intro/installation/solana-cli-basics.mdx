В этом разделе представлены некоторые распространенные команды и примеры,
которые помогут вам начать использовать Solana CLI.

## Конфигурация Solana

Ваша конфигурация Solana определяет следующие переменные:

- **Файл конфигурации**: путь к вашему config-файлу
- **RPC URL и Websocket URL**: Solana-кластер, к которому CLI отправляет запросы
- **Путь к keypair**: путь к кошельку Solana по умолчанию (keypair), который
  используется для оплаты комиссий за транзакции и деплоя программ. По умолчанию
  этот файл хранится по адресу `~/.config/solana/id.json`.

Чтобы увидеть текущие настройки конфигурации, введите следующую команду в вашем
терминале.

```bash Terminal
solana config get
```

Успешное выполнение команды вернет результат, похожий на следующий:

```txt title="Example output"
Config File: /Users/test/.config/solana/cli/config.yml
RPC URL: https://api.mainnet.solana.com
WebSocket URL: wss://api.mainnet.solana.com/ (computed)
Keypair Path: /Users/test/.config/solana/id.json
Commitment: confirmed
```

Вы можете изменить кластер Solana CLI с помощью следующих команд:

<Tabs>

<Tab title="Full commands">

```bash Terminal
solana config set --url mainnet-beta
solana config set --url devnet
solana config set --url localhost
solana config set --url testnet
```

</Tab>
<Tab title="Short commands">

```bash Terminal
solana config set -um    # For mainnet
solana config set -ud    # For devnet
solana config set -ul    # For localhost
solana config set -ut    # For testnet
```

</Tab>
</Tabs>

## Создание кошелька

Прежде чем вы сможете отправлять транзакции с помощью Solana CLI, вам
понадобится кошелек Solana, пополненный SOL.

Чтобы сгенерировать keypair по пути keypair по умолчанию, выполните следующую
команду:

```bash Terminal
solana-keygen new
```

Успешное выполнение команды вернет результат, похожий на следующий:

```txt title="Example output"
Generating a new keypair

For added security, enter a BIP39 passphrase

NOTE! This passphrase improves security of the recovery seed phrase NOT the
keypair file itself, which is stored as insecure plain text

BIP39 Passphrase (empty for none):

Wrote new keypair to /Users/test/.config/solana/id.json
===========================================================================
pubkey: 8dBTPrjnkXyuQK3KDt9wrZBfizEZijmmUQXVHpFbVwGT
===========================================================================
Save this seed phrase and your BIP39 passphrase to recover your new keypair:
cream bleak tortoise ocean nasty game gift forget fancy salon mimic amazing
===========================================================================
```

<Info>
  Эта команда не перезапишет существующий аккаунт по умолчанию, если только вы
  не используете флаг `--force`.
</Info>

Чтобы просмотреть адрес вашего кошелька (публичный ключ), выполните команду:

```bash Terminal
solana address
```

## Airdrop SOL

Запросите airdrop SOL на ваш кошелек для оплаты транзакций и развертывания
программ.

1. Установите ваш кластер на Devnet:

```bash Terminal
solana config set -ud
```

2. Запросите airdrop Devnet SOL:

```bash Terminal
solana airdrop 2
```

<Note>

Airdrop в Devnet ограничивает запросы до 5 SOL за один запрос. Если вы достигли
лимита запросов или столкнулись с ошибками, попробуйте использовать
[веб-краник](https://faucet.solana.com).

</Note>

Чтобы проверить баланс SOL вашего кошелька, выполните следующую команду:

```bash Terminal
solana balance
```
