В этом разделе приведены основные команды и примеры, которые помогут вам начать
работу с [Anchor CLI](https://www.anchor-lang.com/docs).

<Steps titleSize="h3">
<Step title="Инициализация проекта">

Создайте новый проект Anchor, выполнив команду ниже. Она создаст новую
директорию с именем проекта и инициализирует в ней новый проект Anchor.

```bash Terminal
anchor init <project-name>
```

Например, команда ниже создаст проект с именем `my-project`. Директория
`my-project` будет содержать базовую программу на Rust и шаблон теста на
TypeScript.

```bash Terminal
anchor init my-project
```

Затем перейдите в директорию проекта:

```bash Terminal
cd <project-name>
```

См.
[структуру файлов проекта](https://www.anchor-lang.com/docs/quickstart/local#project-file-structure)
Anchor.

</Step>
<Step title="Сборка программы">

Чтобы собрать ваш проект, выполните следующую команду:

```bash Terminal
anchor build
```

Скомпилированная программа будет находиться в директории `/target/deploy`.

<Warning>

При запуске `anchor build`, если вы столкнулись со следующими ошибками:

<AccordionGroup>
<Accordion title="error: not a directory">

```
error: not a directory: '.../solana-release/bin/sdk/sbf/dependencies/platform-tools/rust/lib'
```

Попробуйте следующие решения:

1. Принудительно установите с помощью следующей команды:

```bash Terminal
cargo build-sbf --force-tools-install
```

2. Если предыдущее решение не помогло, очистите кэш Solana:

```bash Terminal
rm -rf ~/.cache/solana/*
```

</Accordion>

<Accordion title="lock file version 4 requires `-Znext-lockfile-bump">
Вы можете исправить это, изменив поле version в файле `Cargo.lock` с 4 на 3:

```diff Cargo.lock
-version = 4
+version = 3
```

Подробнее смотрите в
[этой задаче](https://github.com/solana-foundation/anchor/issues/3392).

</Accordion>

</AccordionGroup>

После применения предыдущего решения попробуйте снова запустить
`anchor build`.

</Warning>

</Step>
<Step title="Деплой программы">

Чтобы задеплоить проект, выполните следующую команду:

```bash Terminal
anchor deploy
```

Эта команда деплоит вашу программу в `cluster`, указанный в файле
[`Anchor.toml`](https://www.anchor-lang.com/docs/references/anchor-toml).

</Step>
<Step title="Тестирование программы">

Чтобы протестировать проект, выполните следующую команду:

```bash Terminal
anchor test
```

Эта команда собирает, деплоит и запускает тесты для вашего проекта.

<Note>
  При использовании кластера `localnet` Anchor автоматически запускает локальный
  validator, деплоит программу, выполняет тесты и затем останавливает validator.
</Note>

<Warning>

Любая из следующих ошибок может означать, что у вас не установлен Node.js или
Yarn:

```
Permission denied (os error 13)
```

```
No such file or directory (os error 2)
```

</Warning>

</Step>
</Steps>
