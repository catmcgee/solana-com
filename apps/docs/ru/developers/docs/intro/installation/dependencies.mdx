Руководство по настройке локального окружения для разработки на Solana. Узнайте,
как установить Rust, Solana CLI и Anchor Framework на Windows (WSL), Linux и
Mac. Используйте это руководство, если вы предпочитаете устанавливать каждую
зависимость отдельно или если [быстрая установка](/developers/docs/intro/installation/) не
сработала по какой-либо причине.

### Предварительные требования

<AccordionGroup>
<Accordion title="Windows">

Для разработки программ на Solana в Windows вы **должны** использовать
[Windows Subsystem for Linux](https://learn.microsoft.com/en-us/windows/wsl/install)
(WSL). После установки WSL все остальные зависимости будут устанавливаться через
терминал Linux.

Чтобы установить WSL, выполните следующую команду в Windows PowerShell:

```bash Terminal
wsl --install
```

В процессе установки вам будет предложено создать пользователя по умолчанию.

<Frame caption="Установка WSL">
  ![Установка WSL](/docs-assets/assets/docs/intro/installation/wsl-install.png)
</Frame>

По умолчанию WSL устанавливает Ubuntu. Открыть терминал Linux можно, найдя
"Ubuntu" в строке поиска.

<Frame caption="WSL Ubuntu">
  ![WSL Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-search.png)
</Frame>

Если ваш терминал Ubuntu выглядит как на изображении ниже, вы можете столкнуться
с проблемой, когда `ctrl + v` (горячая клавиша вставки) не работает в терминале.

<Frame caption="Терминал Ubuntu">
  ![Терминал Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-1.png)
</Frame>

Если вы столкнулись с этой проблемой, откройте Windows Terminal, найдя
"Terminal" в строке поиска.

<Frame caption="Windows Terminal">
  ![Windows Terminal](/docs-assets/assets/docs/intro/installation/wsl-windows-terminal.png)
</Frame>

Затем закройте Windows Terminal и снова откройте терминал Linux, найдя Ubuntu.
Теперь терминал должен выглядеть как на изображении ниже, где `ctrl + v`
(горячая клавиша вставки) работает.

<Frame caption="Терминал Ubuntu">
  ![Терминал Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-ubuntu-terminal-2.png)
</Frame>

Если вы используете VS Code, то
[расширение WSL](https://code.visualstudio.com/docs/remote/wsl-tutorial)
позволяет использовать WSL и VS Code вместе.

<Frame caption="Настройка WSL в VS Code">
  ![Настройка WSL в VS Code](/docs-assets/assets/docs/intro/installation/wsl-vscode.png)
</Frame>

В строке состояния VS Code вы увидите следующее:

<Frame caption="WSL: Ubuntu">
  ![WSL: Ubuntu](/docs-assets/assets/docs/intro/installation/wsl-vscode-ubuntu.png)
</Frame>

После настройки WSL вы готовы либо:

- Завершить [быструю установку](/developers/docs/intro/installation) с помощью терминала
  Ubuntu (Linux)
- Установить [Rust](#install-rust), [Solana CLI](#install-solana-cli) и
  [Anchor CLI](#install-anchor-cli) по отдельности, как описано ниже

<Accordion title="Linux">

<Tabs>
<Tab title=".deb">
Если вы используете Debian или производные, такие как Ubuntu или Mint, выполните следующие шаги:

1. Обновите списки пакетов, чтобы убедиться, что все пакеты актуальны:

```bash Terminal
sudo apt-get update
```

2. Установите следующие зависимости:

```bash Terminal
sudo apt-get install -y \
    build-essential \
    pkg-config \
    libudev-dev llvm libclang-dev \
    protobuf-compiler libssl-dev
```

<Note>
Если при установке `protobuf-compiler` возникает ошибка,
убедитесь, что вы сначала выполнили `sudo apt-get update`

```
Package protobuf-compiler is not available, but is referred to by another package.
This may mean that the package is missing, has been obsoleted, or
is only available from another source
```

</Note>

  </Tab>

    <Tab title=".rpm">
    Для дистрибутивов на базе RHEL, таких как Fedora или Red Hat Linux, выполните следующие шаги.

Обновите списки пакетов, чтобы получить более новые версии, выполнив команду.

    ```bash Terminal
    sudo dnf upgrade --refresh
    ```

    Далее установите следующие зависимости:

    ```bash Terminal
    sudo dnf group install c-development development-tools \
    && sudo dnf install pkg-config openssl-devel
    ```

  </Tab>
</Tabs>

<Steps titleSize="h3">
<Step title="Установка Rust">

Разработчики создают программы для Solana с помощью языка программирования
[Rust](https://www.rust-lang.org/).

1. Установите Rust с помощью [rustup](https://www.rust-lang.org/tools/install),
   введя следующую команду в терминале:

```bash Terminal
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
```

После успешной установки вы увидите следующее сообщение:

<AccordionGroup>
<Accordion title="Сообщение об успешной установке Rust">

```
Rust is installed now. Great!

To get started you may need to restart your current shell.
This would reload your PATH environment variable to include
Cargo's bin directory ($HOME/.cargo/bin).

To configure your current shell, you need to source
the corresponding env file under $HOME/.cargo.

This is usually done by running one of the following (note the leading DOT):
. "$HOME/.cargo/env"            # For sh/bash/zsh/ash/dash/pdksh
source "$HOME/.cargo/env.fish"  # For fish
```

</Accordion>
</AccordionGroup>

2. Перезагрузите переменную окружения PATH, чтобы добавить директорию bin из
   [Cargo](https://github.com/rust-lang/cargo):

```bash Terminal
. "$HOME/.cargo/env"
```

3. Проверьте, что установка прошла успешно.

```bash Terminal
rustc --version
```

Вы увидите вывод, похожий на следующий:

```
rustc 1.86.0 (05f9846f8 2025-03-31)
```

</Step>
<Step title="Установка Solana CLI">

Solana CLI предоставляет все необходимые инструменты для создания и деплоя
программ Solana.

1. Установите набор инструментов Solana CLI с помощью официальной команды
   установки:

```bash Terminal
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

<Note>
  Вы можете заменить `stable` на тег релиза, соответствующий версии нужного вам
  ПО (например, `v2.0.3`), или использовать одно из трёх символических названий
  каналов: `stable`, `beta` или `edge`.
</Note>

2. Добавьте переменную окружения PATH

При первой установке Solana CLI вам может быть предложено добавить переменную
окружения `PATH`. Для этого закройте и откройте терминал заново или выполните
следующую команду в вашей оболочке:

```
export PATH="/Users/test/.local/share/solana/install/active_release/bin:$PATH"
```

3. Обновите переменную окружения PATH

<Tabs>
<Tab title="Windows & Linux">

Если вы используете **Linux** или **WSL**, необходимо добавить бинарный файл
Solana CLI в PATH, чтобы команда была доступна в терминале. Для этого выполните
следующие шаги:

**a.** Проверьте, какую оболочку вы используете:

```bash Terminal
echo $SHELL
```

- Если вывод содержит `/bash`, используйте `.bashrc`.
- Если вывод содержит `/zsh`, используйте `.zshrc`.

**б.** Выполните соответствующую команду в зависимости от вашей оболочки.

Для Bash (`bashrc`):

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

Для Zsh (`zshrc`):

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

</Tab>
<Tab title="Mac">

Если вы используете Mac с `zsh`, выполнение стандартной команды `export PATH`,
полученной при установке, не сохранится после закрытия терминала. Вместо этого
добавьте PATH в конфигурационный файл вашей оболочки, выполнив следующую
команду:

```bash Terminal
echo 'export PATH="$HOME/.local/share/solana/install/active_release/bin:$PATH"' >> ~/.zshrc
```

<Note>
  Описанные выше шаги не применяются к пользователям `bash`, так как изменения
  переменной PATH сохраняются по умолчанию.
</Note>

</Tab>
</Tabs>

4. Перезапустите терминал или выполните следующую команду, чтобы обновить сессию
   терминала:

```bash Terminal
source ~/.bashrc # If using Bash
source ~/.zshrc # If using Zsh
```

5. Проверьте, что установка прошла успешно, проверив версию Solana CLI:

```bash Terminal
solana --version
```

Вы увидите вывод, похожий на следующий:

```
solana-cli 2.2.12 (src:0315eb6a; feat:1522022101, client:Agave)
```

<Note>

Вы можете просмотреть все доступные версии в
[репозитории Agave на Github](https://github.com/anza-xyz/agave/releases). Agave
— это клиент validator от [Anza](https://www.anza.xyz/), ранее известный как
клиент validator Solana Labs.

</Note>

5. При необходимости обновите Solana CLI до последней версии _(необязательно)_

```bash Terminal
agave-install update
```

</Step>
<Step title="Установите Anchor CLI">

[Anchor](https://www.anchor-lang.com/) — это фреймворк для разработки программ
на Solana. Anchor использует макросы Rust, чтобы упростить процесс написания
программ для Solana.

#### Предварительные требования

Тестовый файл проекта Anchor по умолчанию (TypeScript), созданный с помощью
команды `anchor init`, требует наличия Node.js и Yarn. (Шаблон теста на
Rust доступен с помощью `anchor init --test-template rust`)

<AccordionGroup>
<Accordion title="Установка Node">

1. Установите Node с помощью
   [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm), выполнив
   следующую команду:

```bash Terminal
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/master/install.sh | bash
```

2. Перезапустите терминал и убедитесь, что команда `nvm` выполняется успешно:

```bash Terminal
command -v nvm
```

3. Используйте `nvm` для установки Node:

```bash Terminal
nvm install node
```

4. Проверьте, что установка прошла успешно, проверив версию Node:

```bash Terminal
node --version
```

Вы увидите вывод, похожий на следующий:

```
v23.7.0
```

</Accordion>
<Accordion title="Установка Yarn">

1. Установите Yarn:

```bash Terminal
npm install --global yarn
```

2. Проверьте, что установка прошла успешно, проверив версию Yarn:

```bash Terminal
yarn --version
```

Вы увидите следующий вывод:

```
1.22.1
```

</Accordion>
</AccordionGroup>

#### Установка

Вы можете установить Anchor CLI и инструменты двумя способами:

- Anchor Version Manager (AVM) — рекомендуемый способ установки
- Без AVM — установка напрямую из GitHub

<Tabs>
<Tab title="AVM">

Anchor Version Manager (AVM) позволяет устанавливать и управлять разными
версиями Anchor на вашей системе, а также легко обновлять версии Anchor в
будущем. Чтобы установить Anchor с помощью AVM, выполните следующие шаги:

1. Установите AVM с помощью следующей команды:

```bash Terminal
curl -sSfL https://raw.githubusercontent.com/otter-sec/anchor/master/avm/install | sh
```

2.  Убедитесь, что AVM установлен успешно:

```bash Terminal
avm --version
```

3. Установите Anchor CLI с помощью AVM:

Чтобы установить последнюю версию:

```bash Terminal
avm install latest
avm use latest
```

Чтобы установить определённую версию, укажите номер версии:

```bash Terminal
avm install 0.30.1
avm use 0.30.1
```

<Warning>

При установке Anchor CLI на Linux или WSL вы можете столкнуться с этой ошибкой:

```
error: could not exec the linker cc = note: Permission denied (os error 13)
```

Если вы видите это сообщение об ошибке, выполните следующие шаги:

1. Установите зависимости, перечисленные в разделе
   [Linux](/developers/docs/intro/installation/dependencies) в верхней части этой
   страницы.
2. Повторите установку Anchor CLI.

</Warning>

4. Убедитесь, что установка прошла успешно, проверив версию Anchor CLI:

```bash Terminal
anchor --version
```

Вы увидите вывод, похожий на следующий:

```
anchor-cli 0.31.1
```

<Info>

Не забудьте выполнить команду `avm use`, чтобы указать версию Anchor CLI,
которая будет использоваться в вашей системе.

- Если вы установили версию `latest`, выполните `avm use latest`.
- Если вы установили версию `0.30.1`, выполните `avm use 0.30.1`.

</Info>

</Tab>

<Tab title="Without AVM">

1. Установите определённую версию Anchor CLI с помощью следующей команды:

```bash Terminal
cargo install --git https://github.com/solana-foundation/anchor --tag v0.30.1 anchor-cli
```

2. Убедитесь, что установка прошла успешно, проверив версию Anchor CLI:

```bash Terminal
anchor --version
```

Вы увидите вывод, похожий на следующий:

```
anchor-cli 0.31.1
```

</Tab>

<Step title="Установите Surfpool CLI">

[Surfpool](https://surfpool.run/) — это инструмент для локальной разработки и
улучшенная замена `solana-test-validator`. Подробнее о возможностях Surfpool
читайте в [документации Surfpool](https://docs.surfpool.run/).

1. Установите Surfpool с помощью следующей команды:

```bash Terminal
curl -sL https://run.surfpool.run/ | bash
```

2. Убедитесь, что установка прошла успешно, проверив версию Surfpool CLI:

```bash Terminal
surfpool --version
```

Вы увидите вывод, похожий на следующий:

```
surfpool 0.12.0
```

</Step>
