---
title: Метод RPC getTokenLargestAccounts
sidebarTitle: getTokenLargestAccounts
---

Возвращает 20 крупнейших аккаунтов определённого типа токенов SPL.

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getTokenLargestAccounts",
      "params": [
        "3wyAj7Rt1TWVPZVteFJPLa26JmLvdb1CAKEFZm3NY75E",
        {
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { address, createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let mint = address("Gh9ZwEmdLJ8DscKNTkTqPbNwLNNBjuSzaG9Vp2KGtKJr");

  let largestHolders = await rpc.getTokenLargestAccounts(mint).send();

  console.log(largestHolders);
  ```

  ```ts web3.js
  import { Connection, PublicKey, clusterApiUrl } from "@solana/web3.js";

  const connection = new Connection(clusterApiUrl("devnet"), "confirmed");

  let mint = new PublicKey!("Gh9ZwEmdLJ8DscKNTkTqPbNwLNNBjuSzaG9Vp2KGtKJr");

  let largestHolders = await connection.getTokenLargestAccounts(mint);

  console.log(largestHolders);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::{commitment_config::CommitmentConfig, pubkey};

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let mint = pubkey!("Gh9ZwEmdLJ8DscKNTkTqPbNwLNNBjuSzaG9Vp2KGtKJr");

      let largest_holders = client.get_token_largest_accounts(&mint).await?;

      println!("{:#?}", largest_holders);

      Ok(())
  }
  ```
</RequestExample>

## Parameters

<ParamField body="pubkey" type="string" required>
  Pubkey токена Mint для запроса, закодированный в формате base-58
</ParamField>

<ParamField body="1" type="object">
  Объект конфигурации, содержащий следующие поля:

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      Commitment описывает, насколько завершён блок на данный момент времени. См.
      [Настройка состояния Commitment](/developers/docs/rpc#configuring-state-commitment).
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="array">
  Массив JSON-объектов, содержащих:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="address" type="string">
      Адрес аккаунта токена
    </ResponseField>

    <ResponseField name="amount" type="string">
      Сырой баланс токен-аккаунта без десятичных знаков, строковое представление u64
    </ResponseField>

    <ResponseField name="decimals" type="u8">
      Количество цифр в десятичной системе справа от десятичной точки
    </ResponseField>

    <ResponseField name="uiAmount" type="number | null">
      Баланс токен-аккаунта с использованием десятичных знаков, предписанных mint
      **УСТАРЕЛО**
    </ResponseField>

    <ResponseField name="uiAmountString" type="string">
      Баланс токен-аккаунта в виде строки с использованием десятичных знаков,
      предписанных mint
    </ResponseField>
  </Expandable>
</ResponseField>
