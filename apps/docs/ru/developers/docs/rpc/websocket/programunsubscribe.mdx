---
title: Метод RPC programUnsubscribe
sidebarTitle: programUnsubscribe
---

Отписаться от уведомлений об изменениях аккаунтов, принадлежащих программе

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "programUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  id подписки на аккаунт, которую нужно отменить
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  сообщение об успешной отписке
</ResponseField>
