---
title: Метод RPC getConfirmedBlock
sidebarTitle: getConfirmedBlock
mode: wide
---

Возвращает информацию о подтвержденном блоке в реестре, включая его
идентификатор и данные о транзакциях.

<Warning>
  **Устаревший метод**

  Ожидается, что этот метод будет удален в версии `solana-core` v2.0.
  Пожалуйста, используйте [getBlock](/developers/docs/rpc/http/getblock) вместо него.
</Warning>
