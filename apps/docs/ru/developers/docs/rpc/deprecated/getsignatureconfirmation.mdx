---
title: Метод RPC getSignatureConfirmation
sidebarTitle: getSignatureConfirmation
mode: wide
---

Получите текущий статус подписи транзакции (обработано, подтверждено,
завершено).

<Warning>
  **Устаревший метод**

  Ожидается, что этот метод будет удалён в версии `solana-core` v2.0.
  Пожалуйста, используйте
  [getSignatureStatuses](/developers/docs/rpc/http/getsignaturestatuses) вместо него.
</Warning>
