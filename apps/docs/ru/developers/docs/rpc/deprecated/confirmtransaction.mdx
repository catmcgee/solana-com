title: Метод RPC confirmTransaction
sidebarTitle: confirmTransaction
mode: wide
---

Получите текущий статус подписи транзакции (обработано, подтверждено,
завершено).

<Warning>
  **Устаревший метод**

  Этот метод планируется удалить в версии `solana-core` v2.0. Пожалуйста,
  используйте [getSignatureStatuses](/developers/docs/rpc/http/getsignaturestatuses) вместо
  него.
</Warning>
