## Цель проверки

Превратите паттерны буткемпа, которые вы уже использовали, в повторяемый чеклист безопасности.

## Контрольные точки

- Проверьте ограничения аккаунта и предположения о подписантах.
- Найдите отсутствующие проверки прав доступа и неожиданные переходы состояний.
- Зафиксируйте хотя бы один инвариант, который должны обеспечивать тесты в дальнейшем.
