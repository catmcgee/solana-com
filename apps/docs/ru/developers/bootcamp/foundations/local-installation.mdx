## Что вы создадите

Локальная среда разработки со всеми необходимыми инструментами для запуска примеров и
развёртывания в devnet.

## Контрольный список настройки

- Установите Rust и Solana CLI.
- Установите Node.js и менеджер пакетов.
- Проверьте версии CLI и конфигурацию кошелька.
- Выполните базовую команду для проверки вашей среды.

## Критерии завершения

Вы можете запускать команды инструментов локально без ошибок среды.
