## Ключевые практики

- Относитесь к выводу ИИ как к черновику, а не к источнику истины.
- Вручную проверяйте все ограничения аккаунта и проверки прав доступа.
- Покрывайте тестами сгенерированные пути выполнения кода перед выпуском.
- Храните промпты и результаты в системе контроля версий для проверки командой.

## Практический рабочий процесс

1. Запрашивайте у ИИ узкое, тестируемое изменение кода.
2. Запускайте статические проверки и тесты.
3. Сравнивайте сгенерированную логику с документацией по протоколу.
4. Итерируйтесь с явными сценариями сбоев.
