Отписка от уведомлений об изменении аккаунта

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "accountUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="number" required>
  id подписки аккаунта, которую нужно отменить
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  сообщение об успешной отписке
</ResponseField>
