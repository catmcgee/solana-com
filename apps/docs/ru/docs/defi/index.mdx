Единое глобальное состояние Solana, время блока ~400 мс и комиссии менее цента делают её домом для онchain-финансов и DeFi: каждая программа — DEX, рынки кредитования, оракулы, перпы — компонуема в рамках одной атомарной транзакции. Этот раздел — рабочий слой для создания финансовых приложений; он ссылается на [Основные концепции](/docs/core/transactions) и [кулинарную книгу](/developers/cookbook) для изучения базовой механики.
