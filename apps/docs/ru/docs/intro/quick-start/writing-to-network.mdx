В предыдущем разделе вы узнали, как
[читать данные из сети Solana](/docs/intro/quick-start/reading-from-network)
путём получения аккаунтов. Запись данных в сеть Solana требует
[транзакции](/docs/core/transactions). Транзакция содержит одну или несколько
[инструкций](/docs/core/instructions), и каждая инструкция вызывает программу.

Программы определяют бизнес-логику для каждой инструкции. Когда вы отправляете
транзакцию, среда выполнения Solana выполняет инструкции транзакции по порядку.
Транзакции являются атомарными: либо все инструкции в транзакции выполняются
успешно, либо вся транзакция завершается с ошибкой.

Примеры в этом разделе показывают, как:

1. Перевести SOL между аккаунтами
2. Создать новый токен-минт

## Перевод SOL

Пример ниже переводит SOL с одного аккаунта на другой. Только программа, назначенная владельцем аккаунта, может изменять данные аккаунта или списывать lamports с его баланса. Кошельковые аккаунты принадлежат [System Program](/docs/core/programs/builtin-programs#the-system-program), поэтому перевод SOL между кошельковыми аккаунтами требует инструкции, которая вызывает инструкцию [transfer](https://github.com/anza-xyz/agave/blob/v2.1.11/programs/system/src/system_processor.rs#L183-L213) System Program. Исходный аккаунт также должен подписать транзакцию.

```ts title="Transfer SOL"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getTransferSolInstruction } from "@solana-program/system";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const receiver = await generateKeyPairSigner();

const transferInstruction = getTransferSolInstruction({
  source: client.payer,
  destination: receiver.address,
  amount: lamports(10_000_000n)
});

const result = await client.sendTransaction([transferInstruction]);

console.log("Transaction Signature:", result.context.signature);

const { value: senderBalance } = await client.rpc
  .getBalance(client.payer.address)
  .send();
const { value: receiverBalance } = await client.rpc
  .getBalance(receiver.address)
  .send();

console.log("Sender Balance:", senderBalance);
console.log("Receiver Balance:", receiverBalance);
```

<Note>
  **`createClient`**

  Создайте клиент Kit для локального validator. `generatedPayer()` добавляет
  подписанта-плательщика, `solanaRpc()` добавляет возможности RPC и отправки
  транзакций, `rpcAirdrop()` добавляет `client.airdrop`, а `airdropPayer()`
  пополняет баланс плательщика тестовыми SOL.

  **`receiver`**

  Сгенерируйте подписанта для аккаунта, получающего SOL. Получателю не нужно
  подписывать этот перевод. Если по адресу получателя ещё нет аккаунта, получение
  SOL создаст системный аккаунт по этому адресу.

  **`transferInstruction`**

  Создайте инструкцию System Program, которая переводит lamports от плательщика
  клиента получателю.

  **`sendTransaction`**

  Отправьте инструкцию в виде транзакции. Клиент Kit получает последний блокхэш,
  устанавливает плательщика комиссии, подписывает с необходимыми подписантами,
  отправляет транзакцию и ожидает подтверждения.

  **`balances`**

  Получите балансы отправителя и получателя после подтверждения транзакции.
</Note>

## Создание токена

В примере ниже создаётся новый mint account с использованием
[Token Extensions Program](/docs/tokens/extensions). mint account — это аккаунт,
определяющий глобальные настройки токена: количество знаков после запятой,
эмиссию, полномочия на выпуск и полномочия на заморозку.

Создание mint account требует двух инструкций:

1. Вызов System Program для создания нового аккаунта, принадлежащего Token
   Extensions Program.
2. Вызов Token Extensions Program для инициализации этого аккаунта как mint.

```ts title="Create mint account"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getCreateAccountInstruction } from "@solana-program/system";
import {
  fetchMint,
  getInitializeMintInstruction,
  getMintSize,
  TOKEN_2022_PROGRAM_ADDRESS
} from "@solana-program/token-2022";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const mint = await generateKeyPairSigner();

const space = BigInt(getMintSize());

const rent = await client.rpc.getMinimumBalanceForRentExemption(space).send();

const createAccountInstruction = getCreateAccountInstruction({
  payer: client.payer,
  newAccount: mint,
  space,
  lamports: rent,
  programAddress: TOKEN_2022_PROGRAM_ADDRESS
});

const initializeMintInstruction = getInitializeMintInstruction({
  mint: mint.address,
  decimals: 2,
  mintAuthority: client.payer.address,
  freezeAuthority: client.payer.address,
  tokenProgram: TOKEN_2022_PROGRAM_ADDRESS
});

const result = await client.sendTransaction([
  createAccountInstruction,
  initializeMintInstruction
]);

console.log("Mint Address:", mint.address);
console.log("Transaction Signature:", result.context.signature);

const mintAccount = await fetchMint(client.rpc, mint.address);
console.log("Mint Account:", mintAccount);
```

<Note>
  **`createClient`**

  Создайте и пополните Kit-клиент для локального validator. Пополненный плательщик
  покрывает rent аккаунта и комиссии за транзакции.

  **`mint`**

  Сгенерируйте подписанта для использования в качестве адреса нового mint account.
  Подписант авторизует создание этого аккаунта.

  **`space`**

  Вычислите количество байт, необходимых для mint account без расширений.

  **`rent`**

  Вычислите количество lamport, необходимых для освобождения mint account от rent.

  **`createAccountInstruction`**

  Создайте инструкцию System Program, которая создаёт mint account и назначает
  аккаунт в Token Extensions Program.

  **`initializeMintInstruction`**

  Создайте инструкцию Token Extensions Program, которая записывает начальные
  данные mint в новый аккаунт.

  **`sendTransaction`**

  Отправьте обе инструкции как одну транзакцию. Порядок инструкций важен: аккаунт
  должен быть создан до того, как его можно будет инициализировать.

  **`mintAccount`**

  Получите mint account после подтверждения. Вспомогательная функция считывает
  аккаунт и десериализует поле данных mint account в тип Mint.
</Note>

    После подтверждения транзакции получите mint account.

    ```ts title="Fetch mint account"

    console.log("Mint Account:", mintAccount);
    ```

    ```ts title="Create mint account" focus={53-54} expandable
    import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
    import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
    import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
    import { getCreateAccountInstruction } from "@solana-program/system";
    import {
      fetchMint,
      getInitializeMintInstruction,
      getMintSize,
      TOKEN_2022_PROGRAM_ADDRESS
    } from "@solana-program/token-2022";

    const client = await createClient()
      .use(generatedPayer())
      .use(
        solanaRpc({
          rpcUrl: "http://localhost:8899",
          rpcSubscriptionsUrl: "ws://localhost:8900"
        })
      )
      .use(rpcAirdrop())
      .use(airdropPayer(lamports(1_000_000_000n)));

    const mint = await generateKeyPairSigner();

    const space = BigInt(getMintSize());

    const rent = await client.rpc.getMinimumBalanceForRentExemption(space).send();

    const createAccountInstruction = getCreateAccountInstruction({
      payer: client.payer,
      newAccount: mint,
      space,
      lamports: rent,
      programAddress: TOKEN_2022_PROGRAM_ADDRESS
    });

    const initializeMintInstruction = getInitializeMintInstruction({
      mint: mint.address,
      decimals: 2,
      mintAuthority: client.payer.address,
      freezeAuthority: client.payer.address,
      tokenProgram: TOKEN_2022_PROGRAM_ADDRESS
    });

    const result = await client.sendTransaction([
      createAccountInstruction,
      initializeMintInstruction
    ]);

    console.log("Mint Address:", mint.address);
    console.log("Transaction Signature:", result.context.signature);

    const mintAccount = await fetchMint(client.rpc, mint.address);
    console.log("Mint Account:", mintAccount);
    ```
  </Step>
</Steps>

<Info>
  В этих примерах используется `generatedPayer()` для создания временного
  keypair при локальном тестировании. В производственных приложениях никогда не
  следует хранить приватные ключи в открытом виде в коде — делегируйте
  подписание бэкенду управления ключами. См. [Подписание в производственной
  среде](/docs/core/transactions/signing-in-production).
