## Cel projektu

Modeluj interakcję escrow z jasno określonymi zasadami własności i wydania środków.

## Punkty kontrolne

- Wypisz wszystkie przejścia stanów escrow przed napisaniem kodu.
- Zweryfikuj model uprawnień dla akcji tworzenia, akceptowania, anulowania i rozliczania.
- Potwierdź derywacje PDA i oczekiwania dotyczące sygnatariuszy dla każdego kroku.
