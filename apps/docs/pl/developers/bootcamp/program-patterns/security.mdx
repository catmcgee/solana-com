## Cel przeglądu

Przekształć wzorce bootcampu, których już używałeś, w powtarzalną listę kontrolną bezpieczeństwa.

## Punkty kontrolne

- Przejrzyj ograniczenia kont i założenia dotyczące sygnatariuszy.
- Szukaj brakujących sprawdzeń uprawnień i nieoczekiwanych przejść stanów.
- Zidentyfikuj co najmniej jeden niezmiennik, który testy mają egzekwować w przyszłości.
