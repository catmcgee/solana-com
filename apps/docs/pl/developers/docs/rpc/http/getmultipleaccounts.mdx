Zwraca informacje o koncie dla listy Pubkeys.

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getMultipleAccounts",
      "params": [
        [
          "vines1vzrYbzLMRdu58ou5XTby4qAqVRLmqo36NKPTg",
          "4fYNw3dojWmQ4dXtSGE9epjRGy9pFSx62YypT7avPYvA"
        ],
        {
          "encoding": "base58",
          "commitment": "finalized"
        }
      ]
    }
  '
  ```

  ```ts Kit
  import { address, createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_account_decoder::UiAccountEncoding;
  use solana_client::{nonblocking::rpc_client::RpcClient, rpc_config::RpcAccountInfoConfig};
  use solana_sdk::{commitment_config::CommitmentConfig, pubkey};

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let addresses = [
          pubkey!("vines1vzrYbzLMRdu58ou5XTby4qAqVRLmqo36NKPTg"),
          pubkey!("4fYNw3dojWmQ4dXtSGE9epjRGy9pFSx62YypT7avPYvA"),
      ];

      let config = RpcAccountInfoConfig {
          encoding: UiAccountEncoding::Base58.into(),
          data_slice: None,
          commitment: CommitmentConfig::finalized().into(),
          min_context_slot: None,
      };

      let accounts = client
          .get_multiple_accounts_with_config(&addresses, config)
          .await?;

      println!("{:#?}", accounts);

      Ok(())
  }
  ```

## Parameters

<ParamField body="0" type="array" required>
  Tablica Pubkeys do zapytania, jako ciągi zakodowane w base-58 (do maksymalnie
  100).
</ParamField>

<ParamField body="1" type="object">
  Obiekt konfiguracyjny zawierający następujące pola:

  <Expandable title="properties" defaultOpen>
    <ParamField body="commitment" type="string">
      Commitment opisuje, jak bardzo zfinalizowany jest blok w danym momencie. Zobacz
      [Konfigurowanie zaangażowania stanu](/developers/docs/rpc#configuring-state-commitment).
    </ParamField>

    <ParamField body="minContextSlot" type="number">
      Minimalny slot, w którym można ocenić żądanie.
    </ParamField>

    <ParamField body="dataSlice" type="object">
      Żądanie fragmentu danych konta.

      - `length: <usize>` - liczba bajtów do zwrócenia
      - `offset: <usize>` - offset bajtowy, od którego rozpocząć odczyt

      <Info>
        Dzielenie danych jest dostępne tylko dla `base58`, `base64` lub `base64+zstd`
        kodowań.
      </Info>
    </ParamField>

    <ParamField body="kodowanie" type="string" default="base64">
      Values: `jsonParsed`, `base58`, `base64`, `base64+zstd`

      Format kodowania dla zwróconych danych konta

      - `base58` jest wolne i ograniczone do mniej niż 129 bajtów danych konta.
      - `base64` zwróci dane zakodowane w base64 dla danych konta dowolnego rozmiaru.
      - `base64+zstd` kompresuje dane konta za pomocą
        [Zstandard](https://facebook.github.io/zstd/) i koduje wynik w base64.
      - `jsonParsed` kodowanie próbuje użyć parserów stanu specyficznych dla programu,
        aby zwrócić bardziej czytelne dla człowieka i bardziej szczegółowe dane stanu
        konta.
      - Jeśli `jsonParsed` jest żądane, ale parser nie może zostać znaleziony, pole
        wraca do kodowania `base64`, co można wykryć, gdy pole `data` ma typ
        `<string>`.
    </ParamField>
  </Expandable>
</ParamField>

## Result

<ResponseField name="result" type="array">
  Wynik będzie tablicą zawierającą albo:

  - `null` - jeśli konto pod tym Pubkey nie istnieje, lub
  - Obiekty konta z następującymi polami:

  <Expandable title="properties" defaultOpen>
    <ResponseField name="dane" type="[string,encoding] | object">
      Dane powiązane z kontem, albo jako zakodowane dane binarne, albo w formacie JSON
      `{<program>: <state>}` - w zależności od parametru kodowania
    </ResponseField>

    <ResponseField name="wykonywalne" type="bool">
      Wartość logiczna wskazująca, czy konto zawiera program (i jest ściśle tylko do
      odczytu)
    </ResponseField>

    <ResponseField name="lamporty" type="u64">
      Liczba lamportów przypisana do tego konta
    </ResponseField>

    <ResponseField name="właściciel" type="string">
      Zakodowany w Base-58 Pubkey programu, do którego przypisano to konto
    </ResponseField>

    <ResponseField name="rentEpoch" type="u64">
      Epoka, w której to konto będzie musiało ponownie zapłacić za przechowywanie
      danych
    </ResponseField>

    <ResponseField name="space" type="u64">
      Rozmiar danych konta
    </ResponseField>
  </Expandable>
</ResponseField>
