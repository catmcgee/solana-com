---
title: Metoda RPC getHealth
sidebarTitle: getHealth
---

Zwraca aktualny stan zdrowia węzła. Zdrowy węzeł to taki, który znajduje się w
`HEALTH_CHECK_SLOT_DISTANCE` slotach od najnowszego potwierdzonego slotu
klastra.

<RequestExample>
  ```bash cURL
  curl https://api.devnet.solana.com -s -X POST \
    -H "Content-Type: application/json" \
    -d '
    {
      "jsonrpc": "2.0",
      "id": 1,
      "method": "getHealth"
    }
  '
  ```

  ```ts Kit
  import { createSolanaRpc } from "@solana/kit";

  const rpc_url = "https://api.devnet.solana.com";
  const rpc = createSolanaRpc(rpc_url);

  let health = await rpc.getHealth().send();

  console.log(health);
  ```

  ```rs Rust
  use anyhow::Result;
  use solana_client::nonblocking::rpc_client::RpcClient;
  use solana_sdk::commitment_config::CommitmentConfig;

  #[tokio::main]
  async fn main() -> Result<()> {
      let client = RpcClient::new_with_commitment(
          String::from("https://api.devnet.solana.com"),
          CommitmentConfig::confirmed(),
      );

      let health = client.get_health().await?;

      println!("{:#?}", health);

      Ok(())
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Zdrowy
  {
    "jsonrpc": "2.0",
    "result": "ok",
    "id": 1
  }
  ```

  ```json Niezdrowy
  {
    "jsonrpc": "2.0",
    "error": {
      "code": -32005,
      "message": "Node is unhealthy",
      "data": { "numSlotsBehind": 42 }
    },
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

None

## Result

<ResponseField name="result" type="string" post={["Zdrowy"]}>
  Jeśli węzeł jest zdrowy: "ok"
</ResponseField>

<ResponseField name="result" type="object" post={["Niezdrowy"]}>
  Jeśli węzeł jest niezdrowy, zwracana jest odpowiedź błędu JSON RPC. Szczegóły
  odpowiedzi błędu są **NIESTABILNE** i mogą ulec zmianie w przyszłości.
</ResponseField>
