Anuluj subskrypcję powiadomień o slotach

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "slotUnsubscribe",
    "params": [
      0
    ]
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": true,
    "id": 1
  }
  ```
</ResponseExample>

## Parameters

<ParamField body="0" type="integer" required>
  id subskrypcji do anulowania
</ParamField>

## Result

<ResponseField name="result" type="boolean">
  wiadomość o pomyślnym anulowaniu subskrypcji
</ResponseField>
