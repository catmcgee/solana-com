Zwraca listę potwierdzonych bloków pomiędzy dwoma slotami

<Warning>
  **Metoda przestarzała**

  Ta metoda zostanie usunięta w wersji `solana-core` v2.0. Proszę używać
  [getBlocks](/developers/docs/rpc/http/getblocks) zamiast niej.
</Warning>
