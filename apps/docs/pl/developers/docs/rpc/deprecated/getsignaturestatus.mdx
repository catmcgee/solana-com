title: Metoda RPC getSignatureStatus
sidebarTitle: getSignatureStatus

---

Pobierz aktualny status podpisu transakcji (przetworzony, potwierdzony,
sfinalizowany).

<Warning>
  **Metoda przestarzała**

  Ta metoda zostanie usunięta w wersji `solana-core` v2.0. Proszę używać
  [getSignatureStatuses](/developers/docs/rpc/http/getsignaturestatuses) zamiast niej.
</Warning>
