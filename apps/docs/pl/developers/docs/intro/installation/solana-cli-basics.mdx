Ta sekcja zawiera kilka podstawowych poleceń i przykładów, które pomogą Ci
rozpocząć korzystanie z Solana CLI.

## Konfiguracja Solana

Twoja konfiguracja Solana określa następujące zmienne:

- **Plik konfiguracyjny**: Ścieżka do twojego pliku konfiguracyjnego
- **RPC URL i Websocket URL**: Adresy klastra Solana, do którego CLI wysyła
  żądania
- **Ścieżka do keypair**: Ścieżka do domyślnego portfela Solana (keypair),
  używanego do opłacania prowizji transakcyjnych i wdrażania programów.
  Domyślnie ten plik jest przechowywany w `~/.config/solana/id.json`.

Aby zobaczyć bieżące ustawienia konfiguracji, wpisz następujące polecenie w
swoim terminalu.

```bash Terminal
solana config get
```

Pomyślne wykonanie polecenia zwróci wynik podobny do poniższego:

```txt title="Example output"
Config File: /Users/test/.config/solana/cli/config.yml
RPC URL: https://api.mainnet.solana.com
WebSocket URL: wss://api.mainnet.solana.com/ (computed)
Keypair Path: /Users/test/.config/solana/id.json
Commitment: confirmed
```

Możesz zmienić klaster Solana CLI za pomocą następujących poleceń:

<Tabs>

<Tab title="Full commands">

```bash Terminal
solana config set --url mainnet-beta
solana config set --url devnet
solana config set --url localhost
solana config set --url testnet
```

</Tab>
<Tab title="Short commands">

```bash Terminal
solana config set -um    # For mainnet
solana config set -ud    # For devnet
solana config set -ul    # For localhost
solana config set -ut    # For testnet
```

</Tab>
</Tabs>

## Utwórz portfel

Zanim będziesz mógł wysyłać transakcje za pomocą Solana CLI, potrzebujesz
portfela Solana zasilonego SOL.

Aby wygenerować keypair w domyślnej ścieżce keypair, uruchom następujące
polecenie:

```bash Terminal
solana-keygen new
```

Pomyślne wykonanie polecenia zwróci wynik podobny do poniższego:

```txt title="Example output"
Generating a new keypair

For added security, enter a BIP39 passphrase

NOTE! This passphrase improves security of the recovery seed phrase NOT the
keypair file itself, which is stored as insecure plain text

BIP39 Passphrase (empty for none):

Wrote new keypair to /Users/test/.config/solana/id.json
===========================================================================
pubkey: 8dBTPrjnkXyuQK3KDt9wrZBfizEZijmmUQXVHpFbVwGT
===========================================================================
Save this seed phrase and your BIP39 passphrase to recover your new keypair:
cream bleak tortoise ocean nasty game gift forget fancy salon mimic amazing
===========================================================================
```

<Info>
  To polecenie nie nadpisze istniejącego konta w domyślnej lokalizacji, chyba że
  użyjesz flagi `--force`.
</Info>

Aby wyświetlić adres (klucz publiczny) swojego portfela, uruchom:

```bash Terminal
solana address
```

## Airdrop SOL

Poproś o airdrop SOL do swojego portfela, aby opłacić transakcje i wdrożenia
programów.

1. Ustaw swój klaster na Devnet:

```bash Terminal
solana config set -ud
```

2. Poproś o airdrop Devnet SOL:

```bash Terminal
solana airdrop 2
```

<Note>

Airdropy na Devnecie ograniczają żądania do 5 SOL na jedno żądanie. Jeśli
osiągniesz limity lub napotkasz błędy, spróbuj skorzystać z
[Web Faucet](https://faucet.solana.com).

</Note>

Aby sprawdzić saldo SOL w swoim portfelu, uruchom następujące polecenie:

```bash Terminal
solana balance
```
