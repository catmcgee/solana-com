  mint using Solana Kit.

W poprzedniej sekcji nauczyłeś się, jak
[odczytywać dane z sieci Solana](/developers/docs/intro/quick-start/reading-from-network)
pobierając konta. Zapisywanie danych w sieci Solana wymaga
[transakcji](/developers/docs/core/transactions). Transakcja zawiera jedną lub więcej
[instrukcji](/developers/docs/core/instructions), a każda instrukcja wywołuje program.

Programy definiują logikę biznesową dla każdej instrukcji. Gdy wysyłasz
transakcję, środowisko uruchomieniowe Solana wykonuje instrukcje transakcji w
kolejności. Transakcje są atomowe. Albo każda instrukcja w transakcji zakończy
się sukcesem, albo cała transakcja zakończy się niepowodzeniem.

Przykłady w tej sekcji pokazują, jak:

1. Przelewać SOL między kontami
2. Utworzyć nowy mint tokenów

## Przelew SOL

Poniższy przykład transferuje SOL z jednego konta na drugie. Tylko program
wyznaczony jako właściciel konta może modyfikować dane konta lub pobierać
lamports z jego salda. Konta portfela są własnością
[System Program](/developers/docs/core/programs/builtin-programs#the-system-program), więc
przesyłanie SOL między kontami portfela wymaga instrukcji, która wywołuje
instrukcję
[transfer](https://github.com/anza-xyz/agave/blob/v2.1.11/programs/system/src/system_processor.rs#L183-L213)
System Program. Konto źródłowe musi również podpisać transakcję.

```ts title="Transfer SOL"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getTransferSolInstruction } from "@solana-program/system";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const receiver = await generateKeyPairSigner();

const transferInstruction = getTransferSolInstruction({
  source: client.payer,
  destination: receiver.address,
  amount: lamports(10_000_000n)
});

const result = await client.sendTransaction([transferInstruction]);

console.log("Transaction Signature:", result.context.signature);

const { value: senderBalance } = await client.rpc
  .getBalance(client.payer.address)
  .send();
const { value: receiverBalance } = await client.rpc
  .getBalance(receiver.address)
  .send();

console.log("Sender Balance:", senderBalance);
console.log("Receiver Balance:", receiverBalance);
```

<Note>
  **`createClient`**

  Utwórz klienta Kit dla lokalnego validator. `generatedPayer()` dodaje
  podpisującego płatnika, `solanaRpc()` dodaje możliwości RPC i wysyłania
  transakcji, `rpcAirdrop()` dodaje `client.airdrop`, a `airdropPayer()` zasila
  płatnika testowym SOL.

  **`receiver`**

  Wygeneruj podpisującego dla konta odbierającego SOL. Odbiorca nie musi
  podpisywać tego przelewu. Jeśli adres odbiorcy nie ma jeszcze konta, otrzymanie
  SOL tworzy konto systemowe pod tym adresem.

  **`transferInstruction`**

  Zbuduj instrukcję System Program, która transferuje lamports od płatnika klienta
  do odbiorcy.

  **`sendTransaction`**

  Wyślij instrukcję jako transakcję. Klient Kit pobiera najnowszy blockhash,
  ustawia płatnika opłat, podpisuje wymaganymi sygnatariuszami, wysyła transakcję
  i czeka na potwierdzenie.

  **`balances`**

  Pobierz salda nadawcy i odbiorcy po potwierdzeniu transakcji.
</Note>

## Utwórz token

Poniższy przykład tworzy nowy mint tokena przy użyciu
[Token Extensions Program](/developers/docs/tokens/extensions). mint account to konto
definiujące globalne ustawienia tokena, takie jak liczba miejsc po przecinku,
podaż, uprawnienia do mintowania oraz uprawnienia do zamrażania.

Utworzenie mint account wymaga dwóch instrukcji:

1. Wywołaj System Program, aby utworzyć nowe konto należące do Token Extensions
   Program.
2. Wywołaj Token Extensions Program, aby zainicjować to konto jako mint.

```ts title="Create mint account"
import { createClient, generateKeyPairSigner, lamports } from "@solana/kit";
import { solanaRpc, rpcAirdrop } from "@solana/kit-plugin-rpc";
import { generatedPayer, airdropPayer } from "@solana/kit-plugin-signer";
import { getCreateAccountInstruction } from "@solana-program/system";
import {
  fetchMint,
  getInitializeMintInstruction,
  getMintSize,
  TOKEN_2022_PROGRAM_ADDRESS
} from "@solana-program/token-2022";

const client = await createClient()
  .use(generatedPayer())
  .use(
    solanaRpc({
      rpcUrl: "http://localhost:8899",
      rpcSubscriptionsUrl: "ws://localhost:8900"
    })
  )
  .use(rpcAirdrop())
  .use(airdropPayer(lamports(1_000_000_000n)));

const mint = await generateKeyPairSigner();

const space = BigInt(getMintSize());

const rent = await client.rpc.getMinimumBalanceForRentExemption(space).send();

const createAccountInstruction = getCreateAccountInstruction({
  payer: client.payer,
  newAccount: mint,
  space,
  lamports: rent,
  programAddress: TOKEN_2022_PROGRAM_ADDRESS
});

const initializeMintInstruction = getInitializeMintInstruction({
  mint: mint.address,
  decimals: 2,
  mintAuthority: client.payer.address,
  freezeAuthority: client.payer.address,
  tokenProgram: TOKEN_2022_PROGRAM_ADDRESS
});

const result = await client.sendTransaction([
  createAccountInstruction,
  initializeMintInstruction
]);

console.log("Mint Address:", mint.address);
console.log("Transaction Signature:", result.context.signature);

const mintAccount = await fetchMint(client.rpc, mint.address);
console.log("Mint Account:", mintAccount);
```

<Note>
  **`createClient`**

  Utwórz i zasilij klienta Kit dla lokalnego validator. Finansujący płatnik
  pokrywa rent konta oraz opłaty transakcyjne.

  **`mint`**

  Wygeneruj sygnatariusza, który będzie używany jako adres nowego mint account.
  Sygnatariusz upoważnia do utworzenia tego konta.

  **`space`**

  Oblicz liczbę bajtów wymaganych dla mint account bez rozszerzeń.

  **`rent`**

  Oblicz lamport wymagane do zwolnienia mint account z rent.

  **`createAccountInstruction`**

  Zbuduj instrukcję System Program, która tworzy mint account i przypisuje konto
  do Token Extensions Program.

  **`initializeMintInstruction`**

  Zbuduj instrukcję Token Extensions Program, która zapisuje początkowe dane mint
  do nowego konta.

  **`sendTransaction`**

  Wyślij obie instrukcje jako jedną transakcję. Kolejność instrukcji ma znaczenie:
  konto musi zostać utworzone przed jego inicjalizacją.

  **`mintAccount`**

  Pobierz mint account po potwierdzeniu. Pomocnik odczytuje konto i deserializuje
  pole danych mint account do typu Mint.
</Note>
