## Czym są rozszerzenia Group i Group Member?

Grupa to mint reprezentujący kolekcję. Członek grupy to mint należący do tej
kolekcji.

Używaj tych rozszerzeń, gdy jeden mint powinien reprezentować kolekcję, a inne
minty elementy do niej należące.

Token Extensions Program może przechowywać dane grupy tokenów bezpośrednio na
mincie za pomocą czterech powiązanych rozszerzeń:

- `GroupPointer` wskazuje mint na konto przechowujące dane grupy.
- `TokenGroup` przechowuje same dane grupy, w tym uprawnienia do
  aktualizacji, aktualny rozmiar i maksymalny rozmiar.
- `GroupMemberPointer` wskazuje mint na konto przechowujące dane członka.
- `TokenGroupMember` przechowuje adres grupy członka oraz numer członka.

`GroupPointer` i `GroupMemberPointer` mogą odwoływać się do dowolnego
konta będącego własnością programu implementującego
[interfejs Token group](https://github.com/solana-program/token-group/tree/main/interface).

Token Extensions Program również implementuje ten interfejs bezpośrednio poprzez
rozszerzenia mintów `TokenGroup` i `TokenGroupMember`.

## Jak tworzyć grupy i członków przechowywanych na koncie mintu

Aby utworzyć grupy i członków przechowywanych na koncie mintu:

1. Utwórz konto mintu grupy i zainicjalizuj `GroupPointer`.
2. Zainicjalizuj mint grupy za pomocą `InitializeMint`.
3. Zainicjalizuj `TokenGroup` na tym samym mincie.
4. Utwórz konto mintu członka i zainicjalizuj `GroupMemberPointer`.
5. Zainicjalizuj mint członka za pomocą `InitializeMint`.
6. Zainicjalizuj `TokenGroupMember` na tym samym mincie, tak aby odwoływał
   się do mintu grupy.

<Info>
**Wskaźniki i kolejność instrukcji**

`GroupPointer` i `GroupMemberPointer` przechowują adres konta,
w którym znajdują się dane grupy lub członka. `TokenGroup` i
`TokenGroupMember` przechowują rzeczywiste dane grupy lub członka.

`GroupPointerInstruction::Initialize` i
`GroupMemberPointerInstruction::Initialize` muszą być wykonane przed
`InitializeMint`. `TokenGroupInstruction::InitializeGroup` i
`TokenGroupInstruction::InitializeMember` muszą być wykonane po
`InitializeMint`. Dla każdego mint, `CreateAccount`, instrukcja
inicjalizacji wskaźnika i `InitializeMint` muszą być zawarte w tej samej
transakcji.

</Info>

use anyhow::Result;
use solana_client::nonblocking::rpc_client::RpcClient;
use solana_commitment_config::CommitmentConfig;
use solana_sdk::{

#[tokio::main]
async fn main() -> Result<()> {

        String::from("http://localhost:8899"),
        CommitmentConfig::confirmed(),
    );
    let authority = Keypair::new();

    let airdrop_signature = client
        .request_airdrop(&authority.pubkey(), 5_000_000_000)
        .await?;

    loop {
        let confirmed = client.confirm_transaction(&airdrop_signature).await?;
        if confirmed {
            break;
        }
    }

        ExtensionType::try_calculate_account_len::<Mint>(&[ExtensionType::GroupPointer])?;

        ExtensionType::GroupPointer,
        ExtensionType::TokenGroup,

    );

        &TOKEN_2022_PROGRAM_ID,
        &group_mint.pubkey(),      // Mint account that stores the GroupPointer extension.
        Some(authority.pubkey()),  // Authority allowed to update the group pointer later.
        Some(group_mint.pubkey()), // Account address that stores the group data.
    )?;

    let initialize_group_mint_instruction = initialize_mint(
        &TOKEN_2022_PROGRAM_ID,    // Program that owns the mint account.
        &group_mint.pubkey(),      // Mint account to initialize.
        &authority.pubkey(),       // Authority allowed to mint new tokens.
        Some(&authority.pubkey()), // Authority allowed to freeze token accounts.
        0,                         // Number of decimals for the token.

        &member_mint.pubkey(),    // New member mint account to create.
        member_mint_rent,         // Lamports funding the mint account rent.
        member_mint_space as u64, // Account size in bytes for the mint plus GroupMemberPointer.
