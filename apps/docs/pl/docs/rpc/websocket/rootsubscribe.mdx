---
title: Metoda RPC rootSubscribe
sidebarTitle: rootSubscribe
---

Subskrybuj, aby otrzymywać powiadomienia za każdym razem, gdy nowy root zostanie
ustawiony przez validator.

<RequestExample>
  ```json WebSocket
  {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "rootSubscribe"
  }
  ```
</RequestExample>

<ResponseExample>
  ```json Response
  {
    "jsonrpc": "2.0",
    "result": 0,
    "id": 1
  }
  ```
</ResponseExample>

### Parameters

**Brak**

### Result

<ResponseField name="result" type="integer">
  id subskrypcji (potrzebny do anulowania subskrypcji)
</ResponseField>

#### Format powiadomienia:

Wynik to numer najnowszego slotu root.

```json
{
  "jsonrpc": "2.0",
  "method": "rootNotification",
  "params": {
    "result": 42,
    "subscription": 0
  }
}
```
