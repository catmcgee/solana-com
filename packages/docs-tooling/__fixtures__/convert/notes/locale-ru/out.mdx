```rust title="state.rs"
#[account]
#[derive(InitSpace)]
pub struct Counter {
    pub count: u64,
}
```

<Note>
  **`#[account]`**

  _rs`#[account]`_ помечает структуру как данные аккаунта.

  **`InitSpace`**

  _rs`InitSpace`_ вычисляет размер аккаунта.
</Note>
