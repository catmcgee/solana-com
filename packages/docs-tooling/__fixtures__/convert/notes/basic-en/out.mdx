### lib.rs

```rust title="programs/my-program/src/lib.rs" -w
pub mod constants;

#[program]
pub mod my_program {
    pub fn initialize(ctx: Context<Initialize>) -> Result<()> {
        // !mark
        Ok(())
    }

    pub fn increment(ctx: Context<Increment>) -> Result<()> {
        Ok(())
    }
}
```

<Note>
  **`pub mod constants`**

  _rs`pub mod constants`_ makes `constants.rs` part of the program crate.

  The _rs`pub use`_ lines re-export the child modules.

  **`#[program]`**

  _rs`#[program]`_ generates the entrypoint.

  - It dispatches instructions.
  - It is required.

  **`pub fn initialize`, `pub fn increment`**

  _rs`initialize`_ and _rs`increment`_ are the two instructions.
</Note>
