O estado global único da Solana, tempos de bloco de ~400ms e taxas abaixo de um centavo fazem dela o lar das finanças onchain e DeFi: cada programa — DEXs, mercados de empréstimo, oráculos, perps — é componível dentro de uma única transação atômica. Esta seção é a camada de fluxo de trabalho para a construção de aplicações financeiras; ela se conecta a
[Conceitos Fundamentais](/docs/core/transactions) e ao
[cookbook](/developers/cookbook) para os mecanismos subjacentes.
