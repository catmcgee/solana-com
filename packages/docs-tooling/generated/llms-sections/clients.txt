# Solana Documentation: Solana SDKs

> Every page is available as raw Markdown by appending `.md` to its URL
> (the links here already include it). The site-wide index is at
> https://solana.com/llms.txt.

- [Solana SDKs](https://solana.com/developers/docs/clients.md): SDKs for building on Solana - TypeScript, Rust, Python, Java, Go, and game engines.
- [Solana Gaming SDKs](https://solana.com/developers/docs/clients/community/game-sdks.md): A list of Solana Gaming SDKs to get you started creating your first Solana Game
- [Go SDK for Solana](https://solana.com/developers/docs/clients/community/go.md): Learn how to interact with Solana using the Go SDK (gagliardetto/solana-go).
- [Java SDK for Solana](https://solana.com/developers/docs/clients/community/java.md): Learn how to interact with Solana using the Java SDK (sava-software/sava).
- [Python SDK for Solana](https://solana.com/developers/docs/clients/community/python.md): Learn how to interact with Solana using the Python SDK (michaelhly/solana-py).
- [JavaScript/TypeScript SDK for Solana](https://solana.com/developers/docs/clients/official/javascript.md): Learn how to interact with Solana using the JavaScript/TypeScript client libraries.
- [Rust SDK for Solana](https://solana.com/developers/docs/clients/official/rust.md): Official Rust crates for building on Solana.
