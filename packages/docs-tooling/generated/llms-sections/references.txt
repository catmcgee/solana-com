# Solana Documentation: references

> Every page is available as raw Markdown by appending `.md` to its URL
> (the links here already include it). The site-wide index is at
> https://solana.com/llms.txt.

- [Clusters and Public RPC Endpoints](https://solana.com/developers/docs/references/clusters.md): Solana's clusters (mainnet, devnet, and testnet): what each is for, its public RPC endpoint, and its rate limits.
- [Solana CLI Reference](https://solana.com/developers/docs/references/solana-cli.md): Complete command index and practical examples for the Agave Solana command-line interface.
- [SPL Token CLI Reference](https://solana.com/developers/docs/references/spl-token-cli.md): Complete command index and practical examples for creating and managing SPL Token and Token-2022 mints and accounts.
- [Staking on Solana](https://solana.com/developers/docs/references/staking.md): How delegating SOL to validators works and how staked SOL earns rewards.
- [Stake Accounts](https://solana.com/developers/docs/references/staking/stake-accounts.md): How Solana stake accounts work: addresses, authorities, delegation, merging, warmup and cooldown, and lockups.
- [Stake Programming](https://solana.com/developers/docs/references/staking/stake-program.md): Manage stake programmatically with the Solana Foundation Delegation Program and stake pools.
- [Terminology](https://solana.com/developers/docs/references/terminology.md): Learn the essential terminology used throughout the Solana blockchain and development models.
