# Solana Documentation: Payments

> Sending, accepting, and processing payments on Solana - subscriptions, batching, and agentic flows.

> Every page is available as raw Markdown by appending `.md` to its URL
> (the links here already include it). The site-wide index is at
> https://solana.com/llms.txt.

- [Payments](https://solana.com/developers/docs/payments.md): Build payment systems on Solana. Payments confirm in under a second, and the network fee is a fraction of a cent.
- [Accept Payments](https://solana.com/developers/docs/payments/accept-payments.md): Accept stablecoin and token payments on Solana
- [Indexing](https://solana.com/developers/docs/payments/accept-payments/indexing.md): Production-grade transaction monitoring for high-volume payment systems
- [Verification Tools](https://solana.com/developers/docs/payments/accept-payments/verification-tools.md): Verify incoming stablecoin payments and reconcile them with your orders.
- [Deferred Execution](https://solana.com/developers/docs/payments/advanced-payments/deferred-execution.md): Sign transactions now, execute later—enabling approval workflows, treasury operations, and secure signing
- [Spend Permissions](https://solana.com/developers/docs/payments/advanced-payments/spend-permissions.md): Delegate token spending to third parties for automated and escrowed payments
- [Pay-per-call & agents](https://solana.com/developers/docs/payments/agentic-payments.md): Charge per request with x402 or MPP, settled on Solana, and let AI agents pay for APIs and tools on their own.
- [Machine Payments Protocol on Solana](https://solana.com/developers/docs/payments/agentic-payments/mpp.md): Use Machine Payments Protocol challenges, credentials, and receipts for one-time charges or metered payment sessions on Solana.
- [x402 on Solana](https://solana.com/developers/docs/payments/agentic-payments/x402.md): Build a current x402 V2 client and resource server for payment-gated HTTP APIs settled with SPL tokens on Solana.
- [Accept dollar payments that settle in seconds](https://solana.com/developers/docs/payments/checkout.md): Take USDC from anyone with a wallet. Payments confirm in under a second, the network fee is a fraction of a cent, and there are no chargebacks.
- [Confirm payments from your backend](https://solana.com/developers/docs/payments/checkout/backend.md): Ship an order only after your server has looked the payment up on the network and checked the amount, the recipient, and the order reference.
- [Try the payment button](https://solana.com/developers/docs/payments/checkout/browser.md): Read the payment code your checkout sends, then optionally configure a Commerce Kit payment button in the browser playground and pay with test money.
- [Go live with your checkout](https://solana.com/developers/docs/payments/checkout/go-live.md): Switch the checkout to mainnet, decide who pays network fees, and handle the edge cases real customers hit.
- [Pay as a customer](https://solana.com/developers/docs/payments/checkout/try-it.md): Before writing any code, see a USDC payment from the customer's side and read the transaction it produces.
- [Payment Developer Tools](https://solana.com/developers/docs/payments/developer-tools.md): SDKs, Solana payment tools, and services for building payment flows
- [How Payments Work on Solana](https://solana.com/developers/docs/payments/how-payments-work.md): Core concepts for sending and receiving payments on Solana
- [Interacting with Solana](https://solana.com/developers/docs/payments/interacting-with-solana.md): Connect to the network and explore blockchain data
- [Pay.sh](https://solana.com/developers/docs/payments/pay-sh.md): Accept pay-per-use and subscription payments for APIs with the Pay.sh command-line gateway.
- [Charge a few cents per API call](https://solana.com/developers/docs/payments/paywall-api.md): Price each API request at a cent or less. Clients, whether people's apps or AI agents, pay inline over HTTP with x402, with no signup, API key or invoice.
- [Read the paywall server](https://solana.com/developers/docs/payments/paywall-api/browser.md): Read the server that answers 402 with a price, checks the signed payment and settles it, then step through its output to see what an unpaid request gets.
- [Go live with your paywall](https://solana.com/developers/docs/payments/paywall-api/go-live.md): Switch the paywall to mainnet, move to the x402 SDK and a facilitator, and protect unpaid routes. Then pick where to go next.
- [Add it to your server](https://solana.com/developers/docs/payments/paywall-api/server.md): Pay for your endpoint from a client with a spending cap, run the server and client on a local test network, and move the handler into your own app.
- [Call a paid API](https://solana.com/developers/docs/payments/paywall-api/try-it.md): Call a paywalled endpoint and follow the HTTP 402 flow: request, price, payment, and data, with the output of the real example code at each step.
- [Send Payments](https://solana.com/developers/docs/payments/send-payments.md): Send stablecoin payments that confirm in under a second, for a network fee of a fraction of a cent.
- [Basic Payment](https://solana.com/developers/docs/payments/send-payments/basic-payment.md): Learn how to send a single token transfer between wallets.
- [Payment Processing](https://solana.com/developers/docs/payments/send-payments/payment-processing.md): Process payments at scale with gasless transactions and fee abstraction
- [Batch Payments](https://solana.com/developers/docs/payments/send-payments/payment-processing/batch-payments.md): Learn how to pay multiple recipients in a single transaction.
- [Fee Abstraction](https://solana.com/developers/docs/payments/send-payments/payment-processing/fee-abstraction.md): Learn how fee sponsorship works and implement fee abstraction with Kora.
- [Payment with Memo](https://solana.com/developers/docs/payments/send-payments/payment-with-memo.md): Learn how to attach invoice IDs or notes to a payment.
- [Verify Address](https://solana.com/developers/docs/payments/send-payments/verify-address.md): Learn how to verify addresses before sending payments on Solana to prevent fund loss.
- [Close Subscription Authority](https://solana.com/developers/docs/payments/subscriptions/close-subscription-authority.md): Guide for closing a user's Subscription Authority account.
- [Create Subscription Authority](https://solana.com/developers/docs/payments/subscriptions/create-subscription-authority.md): Guide for initializing a user's Subscription Authority account.
- [Fixed Delegation](https://solana.com/developers/docs/payments/subscriptions/fixed-delegation.md): Guide for setting up fixed delegation transactions.
- [Overview](https://solana.com/developers/docs/payments/subscriptions/overview.md): Overview of the Solana subscriptions program.
- [Recurring Delegation](https://solana.com/developers/docs/payments/subscriptions/recurring-delegation.md): Guide for setting up recurring delegation transactions.
- [Revoke Abandoned Delegations And Subscriptions](https://solana.com/developers/docs/payments/subscriptions/revoke-abandoned.md): Guide for reclaiming rent from a delegation or subscription whose Subscription Authority is gone.
- [Subscription Plan](https://solana.com/developers/docs/payments/subscriptions/subscription-plan.md): Guide for setting up subscription plan transactions.
