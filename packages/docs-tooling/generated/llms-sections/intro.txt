# Solana Documentation: intro

> Every page is available as raw Markdown by appending `.md` to its URL
> (the links here already include it). The site-wide index is at
> https://solana.com/llms.txt.

- [Coding with agents](https://solana.com/developers/docs/intro/coding-with-agents.md): Use Solana MCP and Agent Skills to give coding agents current Solana knowledge and reusable workflows.
- [Local Installation](https://solana.com/developers/docs/intro/installation.md): A quick installation guide that allows you to set up your local Solana development environment with a single command. Install Rust, the Solana CLI, and Anchor Framework on Windows (WSL), Linux, and Mac.
- [Anchor CLI Basics](https://solana.com/developers/docs/intro/installation/anchor-cli-basics.md): This section walks through some common Anchor CLI commands to get you started.
- [Install Dependencies](https://solana.com/developers/docs/intro/installation/dependencies.md): A guide to setting up your local Solana development environment. Learn how to install Rust, the Solana CLI, and Anchor Framework on Windows (WSL), Linux, and Mac.
- [Solana CLI Basics](https://solana.com/developers/docs/intro/installation/solana-cli-basics.md): This section walks through some common Solana CLI commands to get you started.
- [Surfpool CLI Basics](https://solana.com/developers/docs/intro/installation/surfpool-cli-basics.md): Learn essential Surfpool CLI commands for local Solana development, including starting a validator and using Surfpool Studio.
- [Quick Start](https://solana.com/developers/docs/intro/quick-start.md): Learn Solana development basics. Create your first program, understand accounts, send transactions, and explore PDAs and CPIs using Solana Playground - no installation required.
- [Reading from Network](https://solana.com/developers/docs/intro/quick-start/reading-from-network.md): Learn how to read data from the Solana blockchain network. This guide covers fetching wallet accounts, program accounts, and token mint accounts with JavaScript/TypeScript examples using Solana Kit.
- [Writing to the Network](https://solana.com/developers/docs/intro/quick-start/writing-to-network.md): Learn how to write data to the Solana network by sending transactions and instructions. Follow step-by-step examples to transfer SOL and create a token mint using Solana Kit.
