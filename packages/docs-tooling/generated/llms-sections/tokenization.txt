# Solana Documentation: tokenization

> Issuing stablecoins, tokenizing real-world assets, and operating compliant tokens on Solana.

> Every page is available as raw Markdown by appending `.md` to its URL
> (the links here already include it). The site-wide index is at
> https://solana.com/llms.txt.

- [Delivery vs Payment (DvP) using delegation](https://solana.com/developers/docs/tokenization/dvp.md): Settle commercial paper and other securities against USDC atomically (delivery vs payment) with Token-2022 extensions, without writing a program.
- [NAV Strikes for Money Market Funds on Solana](https://solana.com/developers/docs/tokenization/nav-strikes.md): Run multiple daily NAV strikes for a money market fund with Token-2022 extensions, with atomic subscription and redemption.
- [Permissioned tokens with Token ACL (sRFC37)](https://solana.com/developers/docs/tokenization/token-acl.md): Issue permissioned tokens on Solana with Token ACL and the ABL Gate program: allow and block lists that the network enforces.
