# Solana Documentation: Write onchain programs

> Every page is available as raw Markdown by appending `.md` to its URL
> (the links here already include it). The site-wide index is at
> https://solana.com/llms.txt.

- [Write onchain programs](https://solana.com/developers/docs/programs.md): When existing programs aren't enough, write your own: Rust, Anchor, testing and deploying.
- [Anchor framework](https://solana.com/developers/docs/programs/anchor.md): Anchor is a Rust framework for writing, testing, deploying and calling Solana programs. What it does for you, and where to learn it.
- [Anchor Events](https://solana.com/developers/docs/programs/anchor-events.md): Define, emit, decode, subscribe to, version, and test Anchor events, with guidance for log truncation and CPI events.
- [Build Your First Solana Program](https://solana.com/developers/docs/programs/build-first-program.md): Create a local Anchor program, build and test it, and walk through every file in the default counter program.
- [Generating Clients](https://solana.com/developers/docs/programs/codama/clients.md): Complete guide to generating clients for Solana programs using the Codama CLI.
- [Deploying Programs](https://solana.com/developers/docs/programs/deploying.md): Complete guide to building, deploying, and managing Solana programs using the Solana CLI.
- [Program Examples](https://solana.com/developers/docs/programs/examples.md): A list of Solana program examples in different languages and frameworks, which can help you learn and use as reference for your own projects.
- [IDL - an easy to use Program Interface](https://solana.com/developers/docs/programs/idls.md): An IDL is a JSON description of a program's interface. Use it to decode instructions and accounts and to generate clients in different languages.
- [Limitations](https://solana.com/developers/docs/programs/limitations.md): What Solana programs cannot do: Rust library, compute, call depth, float, static data, and signed division limits.
- [Developing Programs in Rust](https://solana.com/developers/docs/programs/rust.md): Create, build, test, and deploy Solana programs in native Rust.
- [Rust Program Structure](https://solana.com/developers/docs/programs/rust/program-structure.md): Learn how to structure Solana programs in Rust, including entrypoints, state management, instruction handling, and testing.
- [Mollusk](https://solana.com/developers/docs/programs/testing/mollusk.md): Comprehensive guide to testing Solana programs using Mollusk
- [Verifying Programs](https://solana.com/developers/docs/programs/verified-builds.md): Verified builds is a way to link your program to its source code and let everyone independently verify that the program was indeed built from that provided source code.
